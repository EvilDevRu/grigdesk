## Обновление

В GrigDesk откройте «Настройки → Сервер», нажмите «Проверить обновления» и
установите предложенный стабильный релиз. Установка доступна только на чистой
ветке `main` с fast-forward-историей.

## Проверка

- server tests;
- web tests;
- production web build;
- обновление с предыдущего стабильного тега на отдельном clone.
