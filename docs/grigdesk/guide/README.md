# Руководство GrigDesk

Здесь описана работа с выпущенным GrigDesk: от установки до задач и восстановления. Версия указана под оглавлением; при удалённом подключении руководство принадлежит выбранному серверу.

## Перед началом

Для чтения встроенных статей не нужны интернет и оплата модели. Руководство пока написано по-русски; язык кнопок следует настройкам интерфейса.

## Что делать

1. Выберите статью в оглавлении либо найдите слова темы, например «рабочая папка». Текущая статья выделена; поиск можно очистить крестиком в поле.
2. Нажмите кнопку со знаком вопроса в круге рядом с настройками или F1 на рабочем экране для помощи по разделу. В настройках справка открывается поверх формы и сохраняет черновик.
3. Переходите по ссылкам связанных статей. Отдельный адрес статьи можно сохранить; история браузера возвращает к предыдущей странице.
4. «Объяснить с агентом» создаёт новый разговор с черновиком вопроса и версией статьи. Прочитайте его и отправьте самостоятельно.
5. На широком экране список «На этой странице» справа переводит к нужному заголовку. На узком экране откройте «Оглавление» над статьёй для выбора темы; после выбора оно свернётся, сохранив поиск.

## Результат

Одна и та же редакция руководства доступна приложению, инструменту агента и сайту соответствующего выпуска.

## Ограничения и восстановление

Внешние плагины хранят собственные инструкции в пакетах. Неизвестная статья, пустой поиск и недоступный сервер имеют отдельные состояния. При ошибке загрузки используйте повтор либо обновление выбранного сервера.
