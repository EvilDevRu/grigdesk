# Руководство GrigDesk

Пользовательские статьи и поисковые каталоги разделены по языкам:

- [Русское руководство](ru/README.md) — статьи в `ru/`, каталог `ru/catalog.json`.
- [English guide](en/README.md) — статьи в `en/`, каталог `en/catalog.json`.

Встроенная справка выбирает язык устройства. Идентификаторы, имена файлов и порядок
статей совпадают у обоих языков; при изменении поведения обновляйте обе редакции.
Этот README служит картой исходников и не входит в корпус статей.

Сборка включает обе редакции в серверный пакет и сайт справки.
[Контракт поставки и проверки](../overview/packaged-help.md).

Немедленное переключение языка экранов и сохранение пользовательских данных описаны
в обеих редакциях статьи «Настройки»: [RU](ru/settings.md), [EN](en/settings.md).
