# Входящие, Telegram и GitHub

Входящие собирают материалы из настроенных источников и помогают превратить их в задачи.
На узком экране длинные подписи ссылок на задачи и настройки каналов переносятся;
действия выбранной переписки остаются в нижней полосе.

## Перед началом

Подключите нужный источник и настройте правила для проекта. У Telegram и GitHub собственные авторизация, доступность сети и настройки.

## Что делать

1. Откройте соответствующий источник или общую очередь «Входящие».
2. Выберите карточку и прочитайте исходный материал и обсуждение. Используйте поиск и фильтры для нужного состояния.
3. Проверьте предложенную постановку и проект. Ответьте на уточнения; при нескольких независимых темах разделите их на задачи.
4. Подтвердите предложенное действие. Следите отдельно за обработкой сообщения и состоянием созданной задачи.
5. При отказе источника восстановите доступ в его настройках, затем повторите именно неудавшееся действие.

Во «Входящих» компактные вкладки «К разбору / История» переключают очередь без потери
фильтров. Строка «Каналы» раскрывает подключения и приём новых обращений.
Во время первого чтения каркас сохраняет место вкладок и поиска, чтобы готовая очередь
не сдвигала эти области.

## Результат

Материал получает явное решение, а созданная задача доступна для дальнейшей оценки и запуска.

## Ограничения и восстановление

Состояние источника, разбор карточки и доставка операции независимы. Обрыв после отправки не доказывает отсутствие результата: проверьте назначение перед повтором. Отключённое правило не удаляет уже полученные материалы.
