# Рабочая папка разговора

Кнопка папки в шапке показывает каталог запуска агента. Полный путь и дополнительные репозитории доступны в подсказке и меню.

## Перед началом

Каталог должен существовать на выбранном сервере. Git не обязателен. Проект и рабочие копии задачи могут задавать свои корни.

## Что делать

1. В свободном разговоре выберите «Проект» в шапке. По умолчанию откроется основной
   репозиторий этого проекта. Чтобы выбрать другой его репозиторий, откройте меню рабочей папки.
2. Если нужен произвольный каталог, выберите «Без проекта». В меню папки можно выбрать
   GrigDesk, недавнюю папку или нажать «По пути» и ввести абсолютный путь.
   Корень файловой системы, весь домашний каталог, относительный путь и запись с `~/` не подходят.
3. Проверьте текущую папку под каталогом. Дополнительные репозитории отмечены в списке проекта.
   Дополнительные пути вне списка показаны под текущей папкой. Контекст открытого экрана сам по себе папку не меняет.
4. Если исполнитель требует переноса памяти, выберите «Сжать разговор и перейти», переход без выжимки либо отмену.
   Пока готовится выжимка, окно показывает «Сжимаю контекст…». Во время переноса можно набирать
   черновик в другом окне. Новый ход ждёт завершения переноса.
5. После ответа проверьте папку в шапке и уведомление перехода. При потерянном ответе используйте предложенный повтор той же операции.

## Результат

Следующий обычный ход запускается в подтверждённой папке. Рабочие копии выбранной задачи имеют приоритет; снятие задачи возвращает сохранённый выбор.

Явный выбор проекта в свободном чате также определяет проект надзорного доступа к
базам. Обычный путь, даже совпадающий с папкой репозитория, такого доступа не даёт.
SSH доступен независимо от выбранной папки и проекта: агент видит все открытые сессии
с включёнными «Командами агента». Каждая команда требует отдельного подтверждения.

## Ограничения и восстановление

Claude и Codex продолжают разговор при смене папки; DeepSeek/GLM, Kimi и Qwen могут
потребовать новую память. Qwen поддерживает дополнительные репозитории проекта и
рабочие копии задачи с записью; смена их набора требует перехода памяти.
Дополнительные корни и запись зависят от исполнителя и режима изоляции.
Если исходная сессия больше не подходит к настройкам исполнителя, окно покажет причину отказа.
Папка и память сохранятся. Можно отменить переход или явно выбрать «Перейти без выжимки».
Ошибка явного пути не переключает разговор молча. Старый чат удалённой регистрации
сохраняет прежние корни, но новый выбор этой регистрации запрещён.
