# Прогноз лимитов

Прогноз во всплывашке исполнителя оценивает, хватит ли текущего окна лимита до сброса при наблюдаемом темпе.

## Перед началом

Должен быть включён системный плагин «Прогноз лимитов» и накоплены числовые замеры полос аккаунта.
Общее «Автообновление квот» в настройках исполнителей по умолчанию выключено: тогда
новые точки появляются только от ручной ↻ выбранного исполнителя. Последние снимки
и их прежнее время остаются видны. Для фонового сбора включите тумблер и нажмите «Применить».

## Что делать

1. Откройте всплывашку исполнителя в верхней панели.
2. Сопоставьте срок сброса, текущий темп и ожидаемый расход. Для длинного окна вердикт опирается на средний темп; короткое оценивается по текущему.
3. Если прогноза нет, накапливайте замеры кнопкой ↻ либо включите автообновление квот. «Расход стоит» означает отсутствие заметного изменения в наблюдаемом интервале.
4. В настройках плагина выберите исполнителей и фоновый замер без окон. Пустой список означает всех;
   общий запрет автообновления сильнее этой настройки.
5. Чтобы скрыть только блок, отключите размещение; чтобы прекратить сбор — выключите плагин.

## Результат

Прогноз помогает планировать работу, сохраняя отдельными факты квоты и оценку будущего расхода.

## Ограничения и восстановление

При сетевом сбое последние успешные данные сохраняются с отметкой об устаревании.
Проверка GLM, DeepSeek и Tripo выполняется отдельно от основного сервера: зависший
запрос завершается по таймауту. Следующий замер запускается при разрешённой автоматике
либо по ручной кнопке.
Codex Reset использует такую же защиту при поддержке её установленным ядром и плагином.
Его внешняя статистика управляется отдельно от общих квот.
Работающий чат и проверка статистики обращаются к сервису независимо.

Наблюдения ограничены доступными снимками аккаунта. Недостаток данных и неизвестный срок сброса не дают обещания «хватит». У DeepSeek вместо окон показан отдельный прогноз предоплаченного счёта. Использование аккаунта вне этой машины тоже влияет на остаток.
