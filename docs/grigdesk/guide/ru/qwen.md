# Подключить Qwen Code

GrigDesk запускает Qwen Code 1.0 Preview.2 на Linux x64 в песочнице bwrap. Поставку
можно установить прямо из карточки исполнителя. GrigDesk загружает официальный
архив и проверяет его перед установкой в свой каталог данных.

## Подготовить доступ и модели

1. Откройте «Настройки → ИИ-исполнители → Qwen Code → Обзор» и нажмите «Установить».
   Если карточка уже показывает готовую поставку Preview.2, перейдите к шагу 2.
   После завершения версия появится в карточке. При сетевом отказе нажмите «Установить» повторно.
2. Во вкладке «Доступ» выберите «Сервис API и регион», соответствующие выданному ключу.
   Без выбора используется Alibaba Model Studio в Сингапуре. QwenCloud, Coding Plan,
   Token Plan и OpenRouter имеют отдельные варианты: ключи разных сервисов не взаимозаменяемы.
   Для **Individual Plan или Team Plan на qwencloud.com** выберите
   **«QwenCloud Token Plan — Сингапур»**. Alibaba Coding Plan — отдельный сервис;
   его каталог может отличаться от моделей вашей подписки QwenCloud.
3. Введите «Ключ API» и нажмите «Применить». Пустой ввод сохраняет прежний ключ;
   удаление задаётся отдельным действием окна. Если ключ уже сохранён, повторять ввод не нужно.
4. Каталог загружается из API выбранного сервиса автоматически. Ручной JSON не требуется:
   GrigDesk подготавливает настройки для CLI в его приватной среде. Новые модели появляются после обновления каталога.
5. Выберите Qwen и модель в чате. При отказе каталога карточка показывает причину, например
   HTTP 401. Проверьте выбранный сервис, регион и ключ. GrigDesk не пробует отправлять ключ
   другим сервисам. Успешное получение каталога ещё не подтверждает оплаченный запрос к модели.

Если Qwen отсутствует в списке моделей, внизу этого списка нажмите
«Qwen Code · Нет моделей», если это действие предложено, либо откройте карточку через
«Настройки → ИИ-исполнители». Карточка объясняет причину
и предлагает перепроверить подключение или перейти к его настройке. Вкладка «Обзор» показывает
версию проверенной поставки. Результаты обслуживания прежней npm-копии скрыты в карточке.

Подтверждённое сохранение сервиса не отменяется, пока обновляется список моделей.
Если после сохранения пропала связь, сообщение «Доступ сохранён» предлагает
«Перепроверить»: вводить уже сохранённый ключ повторно не требуется.

Пока доступ не применён, карточка показывает «Сохраните подключение» и кнопку
«Применить». Перепроверка до сохранения использует прежнее подключение.
Каталог Qwen не сворачивает разные модели в одну: подтверждённые новые модели
и модели других разработчиков остаются в кратком списке. В чате видны только модели,
пригодные для текстового разговора, свежие — выше прежних. Видео, речь и другие
нечат-модели сервиса в выборе не показываются и для чата не выбираются; старые
версии чатовых моделей можно показать в «Настройки → ИИ-исполнители → Модели».

Если вы уже настроили `modelProviders` в Qwen CLI, GrigDesk использует эту конфигурацию
вместо автоматического подключения и не меняет её. Выбор сервиса тогда не показывается;
доступ задаётся для имён `envKey` из конфигурации. Повреждённый JSON требует исправления
источника и не заменяется автоматическими настройками.

## Работа чата

В проекте с несколькими репозиториями основной задаёт папку запуска, а остальные доступны
как дополнительные рабочие корни. Файлы `.env` и настройки `.qwen` проекта закрыты в песочнице.
После перехода на Preview.2 история GrigDesk сохраняется, а память CLI начинает новую сессию.
Следующие ходы продолжают сохранённую сессию Preview.2. «Стоп» прерывает текущий ход.

GrigDesk проверяет запрос инструмента перед эффектом. «Спрашивать» показывает карточку
разрешения. «Авто» использует общий классификатор GrigDesk и спрашивает разрешение для
действий, которые он не может одобрить. «Без подтверждений» допускает разрешённые политикой
действия сразу. В режиме «План» GrigDesk закрывает запись и запуск команд. Для исполнения
плана выберите рабочий режим прав.

Можно приложить PNG, JPEG, GIF и WebP. Для этого нужна модель с заявленной поддержкой
изображений. Доступно до 10 картинок, до 10 МБ каждая и до 32 МиБ суммарно.

## Доступные возможности Preview.2

В песочнице доступны чтение, поиск по файлам, редактирование, Bash, чтение страниц,
субагенты в текущем ходе и разрешённые сервером рабочие MCP. Сообщение, отправленное во время
ответа, встаёт в очередь этой сессии. Qwen ответит на него отдельным блоком после текущего запроса.

Режим «Хост» включается с отдельным подтверждением. Он даёт доступ к файлам и
службам пользователя сервера. Подтверждения инструментов и запрет прямого SSH действуют
по выбранным настройкам. Требуется включить «Держать агента чата живым между ходами»
и запустить GrigDesk через пользовательскую службу systemd. Закрывайте процесс вручную
в списке живых сессий. Фоновые задачи и автоуборка простоя в Preview.2 недоступны.

Откройте значок Qwen в верхней панели. Полоса «Квота подписки» отключена, пока
интеграции недоступны остаток и дата сброса. Под ней появятся входные и выходные
токены последнего хода с измерением. Замер хранится до перезапуска GrigDesk.
