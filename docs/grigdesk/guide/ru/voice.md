# Озвучка текста командой voice

`voice` создаёт WAV из текста: через облачный Qwen с обычным API или подпиской
QwenCloud Token Plan, либо локально через Piper и Silero. Команду можно поручить агенту;
в терминале исходников используйте `bin/utilities/voice`
либо `grigdesk-ctl voice`. Готовый бинарник входит в серверный комплект.

## Перед началом

В исходниках соберите команду: `bash tools/build-go-utilities.sh "$PWD/bin/utilities"`. Её также собирает
цель «Всё» `grigdesk-ctl build`; полная сборка устанавливает и другие компоненты приложения.
Для локального движка нужны Python3 с venv, сеть и место под модель и зависимости.

Для облака задайте `GRIGDESK_VOICE_QWEN_API_KEY` или `DASHSCOPE_API_KEY` в окружении.
Приоритет: `--api-key` → `GRIGDESK_VOICE_QWEN_API_KEY` → `DASHSCOPE_API_KEY`.
Для Token Plan перед `DASHSCOPE_API_KEY` также проверяется `TOKEN_PLAN_API_KEY`.
Флаг `--api-key` виден в списке процессов, поэтому предпочтительнее окружение.
Команда не читает файловые хранилища доступов сервера. Агент может унаследовать
`DASHSCOPE_API_KEY` от процесса исполнителя Qwen — это тоже рабочий источник ключа.

Выберите облачный сервис: `--service model-studio` для обычного платного API или
`--service qwencloud-token` для QwenCloud Token Plan. Можно задать
`GRIGDESK_VOICE_QWEN_SERVICE`; по умолчанию используется `model-studio`.
По префиксу `sk-sp-…` нельзя отличить Token Plan от Coding Plan. Команда не выбирает
сервис по ключу и не наследует его из настроек исполнителя чата. Model Studio
отвергает подписочный ключ до сети; у Token Plan наличие ключа не заменяет живую проверку.
[Подписочный API QwenCloud](https://docs.qwencloud.com/token-plan/best-practices/speech-synthesis).

Без `--engine` выбирается первый готовый движок: Qwen → Piper → Silero.
**При готовом облачном профиле текст уйдёт поставщику с оплатой по API или из подписки.**
Для локальной речи явно укажите
`--engine piper` или `--engine silero`. После отказа другой движок не вызывается.

## Что делать

1. Выполните `voice engines`, чтобы увидеть готовность и причины отказа.
2. Установите локальный движок: `voice install piper` или `voice install silero`.
   Загрузка проверяется по SHA256 и возобновляется после обрыва. Успех установки
   означает, что контрольная фраза дала непустой WAV с проверенным пиком речи.
3. Посмотрите модели: `voice models`; голоса: `voice voices --engine silero`.
4. Создайте файл, например:

```sh
voice generate --engine piper --text "Проверка связи" --out speech.wav
voice generate --engine silero --voice xenia --text "з+амок и зам+ок" --pace slow
voice generate --engine qwen --file narration.txt --out narration.wav
voice generate --service qwencloud-token --engine qwen \
  --text "Я плач+у за билет в старинный з+амок" \
  --instruction "В слове плачу ударение на У" --out speech.wav
```

`--file` принимает UTF-8; используйте либо его, либо `--text`. Ударение — `+` перед
гласной. Темп: `slowest`, `slow`, `normal`, `fast`, `fastest`. Голоса по умолчанию:
Cherry у Model Studio, `longanhuan_v3.6` у Token Plan, irina у Piper, xenia у Silero.
`voice voices --engine qwen --service qwencloud-token` показывает системные и базовые
голоса Token Plan с их языками. Используйте `--voice` с ID из списка. Token Plan учитывает
текст и языки голоса (`ru`, `en`, `zh`), а `--language` явно задаёт один из поддерживаемых
этим голосом языков. Русский у Long An Huan проверен экспериментально. Model Studio
по умолчанию использует Auto. Неизвестный голос считается ошибкой.

## Результат

Успешный `generate` сохраняет WAV и выводит одну JSON-строку с движком, моделью,
сервисом, голосом, путём, размером и форматом. `ignoredDirections` перечисляет
неприменённые указания, `warnings` — предупреждения об экспериментальных ударениях.
Без `--out` имя содержит дату UTC и случайный UUID. Ошибка сохраняет прежний файл.
У списков и установки `--json` включает машиночитаемый вывод; ошибки идут в stderr.
Коды выхода: 0 — успех, 2 — аргументы, 1 — выполнение.

## Ограничения и восстановление

Лимит канонического текста: Model Studio — 600 символов, Token Plan/Piper/Silero — 2000.
Формат только WAV, MP3 и автоматической конвертации нет. 48 голосов с русским относятся
к Model Studio. Этот профиль игнорирует темп, `+` и `--instruction` и сообщает об этом.
Piper применяет темп, Silero — темп и ударения. Silero требует записать латиницу и цифры словами.

Token Plan передаёт темп и `--instruction`. Ударения `плач+у` или `плачу́` преобразуются
в метки после гласной и усиливаются подсказкой. Общий предел инструкции с подсказкой —
1600 символов. Это экспериментальный способ: ручная проверка была частично успешной,
но слово «стоит» осталось проблемным. Прослушивайте каждую важную реплику;
отсутствие `ignoredDirections` не гарантирует правильного ударения.

Piper скачивает около 58 МБ модели, Silero — около 145 МБ плюс runtime и зависимости.
Голос Piper указан как GPLv2; Silero — CC BY-NC-SA 4.0 для некоммерческого использования.
После обрыва повторите install. При занятой установке дождитесь её завершения;
неизвестный владелец блокировки автоматически не удаляется. Обычный каталог вместо
управляемого venv требует ручного разбора причины, команда не удаляет его.

Данные: `--dir` → `GRIGDESK_VOICE_DIR` → `~/.grigdesk/voice`.
Автоматические проверки работают на поддельных сервисе и Python. Живой синтез не заменяет
проверку произношения на слух; настоящие установки локальных моделей требуют отдельной проверки.
В презентациях голос выбирается в редакторе ролика; локальный Qwen, Edge, Yandex, RHVoice,
распознавание и постоянный сеанс `voice serve` в эту версию не входят.
