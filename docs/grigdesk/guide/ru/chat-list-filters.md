# Фильтры списка чатов

Список чатов показывает активные разговоры; архив переключается компактным
сегментом «Активные / Архив» рядом с поиском. В общем списке у подписи «Архив»
показано число архивных разговоров. Для пустого архива и при выборе проекта
счётчик скрыт. Переключатель оформлен как лёгкие вкладки, а иконка фильтров
стоит сразу за ними одним левым кластером.

## Проект

Выберите проект на полосе слева. На узком экране используйте поле «Проект чатов»
над поиском. На телефоне поле заменяет боковую полосу проектов. Открытый разговор
и его рабочая папка сохраняются. Верхняя кнопка со значком списка («Все чаты»)
возвращает общий список. «Без проекта» показывает разговоры без проектной привязки.

«Плюс» внизу полосы или рядом с полем «Проект чатов» открывает диалог «Новый проект».
Введите название. Идентификатор сформируется автоматически. На телефоне диалог
разворачивается на весь экран. «Отмена» и «Создать проект» находятся в нижней полосе.
«Отмена» и крестик закрывают диалог
с подтверждением, если в черновике есть правки. После создания проект сразу появляется
в выборе проектов.

Полоса и поле «Проект чатов» показывают активные проекты. Поиск, архив разговоров
и остальные фильтры действуют внутри выбранного проекта. Если выбранный проект
отправить в архив или удалить, список вернётся к «Все чаты». Открытый разговор
останется на месте. При ошибке каталога выбор сохраняется, а загрузку можно
повторить. Выбор запоминается для текущего подключения.

Кнопка нового чата подставляет проект из фильтра в шапку разговора и выбирает его
основной репозиторий. В «Без проекта» используется встроенная папка GrigDesk.
В «Все чаты» действуют обычные настройки нового разговора.

## Фильтры

Кнопка с воронкой раскрывает панель под шапкой списка. Видимой надписи у неё нет;
при наведении появляется подсказка «Фильтры чатов», а число рядом с воронкой
показывает количество активных фильтров:

- **Состояние** — кнопки «Непрочитанные», «Ждут ответа», «Работают».
  Нажатая кнопка подсвечивается; повторное нажатие выключает её фильтр.
- **Задача** — номер задачи Б24 либо режимы «С задачей» / «Без задачи».
  Введённый номер важнее режима.
- **Исполнитель** — один из исполнителей живого каталога; «Любой» снимает ограничение.
- **Свежесть** — за сутки, за неделю, за месяц (30 дней).

Поля расположены парами; в узкой панели они переходят в одну колонку.
Кнопка со стрелкой «Сбросить фильтры» находится сверху рядом с подписью состояния
и становится доступной после выбора фильтра. Она снимает фильтры панели, сохраняя выбранный проект.
Когда панель закрыта, включённые фильтры показаны чипами под кнопкой «Фильтры»:
крестик убирает один фильтр. Открытая панель не дублирует выбор чипами.
На всех экранах кнопка показывает только воронку и счётчик активных фильтров.
Пустая выдача тоже предлагает сброс. Выбор фильтров
и область «Активные / Архив» запоминаются между заходами. Поиск по чатам работает
вместе с фильтрами. Если сервер ещё не поддерживает фильтры, кнопка скрыта,
а сохранённые фильтры не применяются — список работает как прежде. Если сервер
откатили при открытом окне, после отказа запроса приложение проверит поддержку и
вернёт обычный список. При недоступной сети остаётся ошибка с кнопкой повтора.
После восстановления связи устаревшие строки могут оставаться до следующей загрузки
списка. Перезагрузка окна получает актуальную выдачу; возврат к уже загруженному
фильтру может использовать его сохранённую страницу.

Фильтры считает сервер, поэтому «Показать ещё» догружает именно отфильтрованные
чаты. Создание нового чата возвращает активный список и сбрасывает фильтры панели.
Выбранный проект и текст поиска сохраняются. Поиск может скрывать новую строку.
В подключённом окне новые вопросы и начало/конец работы обновляют фильтры состояния.
При ошибке обновления список сохраняется: кнопка повторяет загрузку с теми же фильтрами.
