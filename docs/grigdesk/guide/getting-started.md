# Первый запуск

GrigDesk объединяет разговоры с агентами, проекты и выполнение задач. Сначала выберите машину: её сервер хранит данные и выполняет действия.

## Перед началом

Установите приложение. Отдельного мастера первого запуска нет; подготовьте хотя бы одного исполнителя в настройках. Для начала достаточно свободного разговора; подключать трекер и конвейер сразу не требуется.

## Что делать

1. Откройте физический файл `GrigDesk` из распакованного комплекта. При первом запуске дождитесь подготовки местного сервера.
2. Если уже сохранён выбор машины, проверьте её имя. Удалённая машина остаётся выбранной до вашего решения; соседний новый сервер не заменяет её автоматически.
3. Откройте настройки, выберите режим задач и настройте исполнителя и доступ. Если чего-то не хватает для отправки, исправьте названную причину в соответствующей странице настроек.
4. В «Проектах» зарегистрируйте рабочую копию, если собираетесь работать с кодом. В «Чатах» создайте разговор, проверьте модель, права и рабочую папку.
5. Напишите небольшой запрос и отправьте его. Если агент спрашивает разрешение, прочитайте точное действие в карточке перед ответом.

## Результат

Машина подключена, исполнитель выбран, ответ и выполненные действия видны в разговоре. Встроенная справка читается без обращения к модели.

На широком экране разделы открываются значками слева. Иконки невыбранных разделов
имеют одинаковый приглушённый серо-синий цвет; числа под ними показывают состояние
соответствующего раздела.

## Ограничения и восстановление

Отсутствующий исполнитель или ключ не означает потерю данных. Исправьте причину в настройках и перепроверьте готовность. Не запускайте второй сервер на той же папке данных.
