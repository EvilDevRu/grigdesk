# Плагины

Плагины добавляют инструменты и панели. Системные возможности и внешние устанавливаемые пакеты управляются отдельно.

## Перед началом

Для внешнего пакета нужен доверенный источник и совместимая версия. Метки «Официальный» и «Сообщество» обозначают происхождение, а не результат проверки безопасности.

## Что делать

1. Откройте раздел плагинов: «Каталог» помогает выбрать пакет, «Установленные» показывает пользовательские пакеты. Настройки системных плагинов находятся в соответствующих страницах настроек.
2. Выберите пакет и версию либо используйте «Установить из Git…», задав репозиторий и точный тег.
3. После подготовки прочитайте источник, версию, изменения и предупреждения. Применение требует отдельного подтверждения.
4. Новый пакет появляется выключенным. Включите его и откройте объявленную панель; при несовместимости прочитайте причину в карточке.
5. Настройте параметры и размещения, затем примените. Размещение скрывает конкретный блок, сохраняя включённость плагина.
6. Для обновления или отката проверьте предлагаемый пакет. При неизвестном исходе сначала завершите восстановление текущей операции.
7. Чтобы удалить пользовательский пакет, выберите его в «Установленных», нажмите корзину
   и подтвердите удаление. Это доступно и для старого несовместимого пакета с установленными
   зависимостями. Отдельные данные и настройки плагина сохраняются.

## Другие рабочие инструменты

- **Терминал** открывает оболочку на выбранной машине. Перед вводом команды проверьте папку и назначение: это реальное исполнение от пользователя сервера.
- **SSH** требует настроенного подключения и открытой живой сессии. Для выдачи агенту выбираются разрешённые сессии; агент видит их метки и роли. Его команда проходит отдельное подтверждение человека, независимо от автоматического режима чата.
- **Базы** требуют установленного подходящего драйвера и настроенного подключения. Сначала выберите подключение и изучите схему, затем проверьте запрос и его результат. Надзорные запросы агента используют собственное подтверждение; отсутствие доступа не означает пустую базу.
- **Документы** открываются по поддерживаемым ссылкам из разговора или раздела файлов. Просмотрщик использует разрешённую область источника. Если документ недоступен, проверьте выбранную машину, исходный файл и рабочую папку; ссылка сама не даёт доступа к чужим файлам.

В узкой панели SSH общие вкладки переключают «Серверы / Терминал», а в «Базах» —
профили, консоль и запросы. Поиск в каталогах выглядит как поиск чатов.
Обновление стоит перед остальными действиями. Круглый плюс добавляет сервер либо
профиль; повторное нажатие на минус скрывает форму, сохраняя черновик.
В «Базах» кнопка «Драйвер» открывает установку драйвера из Git.

## Результат

Включённый совместимый пакет подключает свои возможности. Закрытие окна установки не отменяет активное задание.

Значки плагинов в боковых панелях совпадают по размеру с основными разделами.
В меню и плитках инструментов используется размер соответствующего списка.

## Ограничения и восстановление

Внешние пакеты могут отсутствовать в базовом релизе. Их документация остаётся внутри пакета: агент получает подсказку к оглавлению включённых плагинов. Руководство ядра её не копирует. Плагин без панели не получает отдельный пункт. Неисправный компонент показывает причину, не объявляясь рабочим.
