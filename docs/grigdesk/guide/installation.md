# Установка приложения

Переносимый комплект позволяет запустить GrigDesk без исходного репозитория и системного Node.

## Перед началом

Для настольного комплекта нужны Linux x64, glibc 2.28 или новее и библиотека FUSE 2 для AppImage. Для консольных команд нужны Bash и Python 3. CLI и авторизация внешних исполнителей настраиваются отдельно.

## Что делать

1. Скачайте опубликованный Linux-комплект с [сайта GrigDesk](https://grigdesk.com).
2. Распакуйте архив с сохранением прав файлов. Держите `GrigDesk`, `README.md` и `bin/` вместе; не запускайте файл прямо из менеджера архивов.
3. Закройте прежнее окно и запустите `GrigDesk` из выбранной папки. Уже открытая копия лишь получит фокус.
4. Дождитесь подготовки сервера. По желанию согласитесь добавить приложение в пользовательское меню.
5. Настройте исполнителей. Для телефона используйте полное Android-приложение и привязку к работающему серверу.

## Результат

Окно открывает интерфейс встроенной версии, а данные создаются отдельно от программы.

## Ограничения и восстановление

Приложение не устанавливает системные пакеты и не запрашивает sudo. При ошибке FUSE установите соответствующий пакет вашей системы. Переносите комплект после завершения ходов и закрытия своего сервера; ярлык хранит прежний путь, его нужно исправить вручную. Удаление папки программы оставляет данные и настройки окна.
