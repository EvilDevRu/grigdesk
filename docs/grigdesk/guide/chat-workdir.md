# Рабочая папка разговора

Кнопка папки в шапке показывает каталог запуска агента. Полный путь и дополнительные репозитории доступны в подсказке и меню.

## Перед началом

Каталог должен существовать на выбранном сервере. Git не обязателен. Проект и рабочие копии задачи могут задавать свои корни.

## Что делать

1. В свободном разговоре откройте папку и выберите GrigDesk, проект, недавний каталог либо «Другая папка…».
2. Для другой папки введите абсолютный путь. Корень файловой системы, весь домашний каталог, относительный путь и запись с `~/` не подходят.
3. Проверьте основной репозиторий и дополнительные корни. Контекст открытого экрана сам по себе папку не меняет.
4. Если исполнитель требует переноса памяти, выберите сжатие и переход, переход без выжимки либо отмену. Пока идёт перенос, можно набирать черновик; новый ход ждёт его завершения.
5. После ответа проверьте папку в шапке и уведомление перехода. При потерянном ответе используйте предложенный повтор той же операции.

## Результат

Следующий обычный ход запускается в подтверждённой папке. Рабочие копии выбранной задачи имеют приоритет; снятие задачи возвращает сохранённый выбор.

## Ограничения и восстановление

Claude и Codex продолжают разговор при смене папки; DeepSeek/GLM и Kimi могут потребовать новую память. Дополнительные корни и запись зависят от исполнителя и режима изоляции. Ошибка явного пути не переключает разговор молча. Старый чат удалённой регистрации сохраняет прежние корни, но новый выбор этой регистрации запрещён.
