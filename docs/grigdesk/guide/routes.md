# Редактор маршрутов

Редактор подготавливает маршрут для будущих запусков. Черновик и опубликованная версия — разные состояния.

## Перед началом

Выберите проект и маршрут. Для изменения нужны права на настройки профиля и понимание входов и результатов этапов.

## Что делать

1. Откройте «Маршруты», выберите проект и создайте либо откройте черновик.
2. Просмотрите схему и свойства этапов: исполнителя/команду, входы, проверки, переходы и возвраты. Укажите, где требуется решение человека.
3. Сохраните черновик. При конфликте редакций перечитайте новую версию и сопоставьте свои правки, затем сохраните согласованный вариант.
4. Запустите проверку маршрута и исправьте указанные ошибки связности, входов и доступности исполнителей.
5. Опубликуйте проверенную редакцию. В форме нового запуска убедитесь, что предлагается нужный маршрут.

В узкой панели области «Каталог / Маршрут / Свойства» переключаются компактными
вкладками, как на доске. Выбор и неприменённые поля сохраняются при переключении.
Круглый плюс в шапке каталога создаёт отдельный черновик. Такой же плюс рядом
с выбором проекта открывает создание проекта; назначение указано в подсказке.

Модель и усилие задаются политикой запуска вне каталога маршрута; инспектор показывает эффективную политику для чтения. При добавлении этапа мастер предлагает роль, требования к стенду/правам и место вставки, показывая пакет переходов до применения. Ctrl+S сохраняет применённые правки; локальный неприменённый ввод поля сначала нужно применить его кнопкой.

## Результат

Новые попытки используют опубликованный каталог. Само сохранение черновика запуск не меняет.

## Ограничения и восстановление

Публикация не переписывает уже закреплённый маршрут текущей попытки. Удалённый проект оставляет несохранённый черновик для чтения; сохранить его через сервер нельзя. Не обходите конфликт версии повторной записью вслепую.
