# Glossary

These terms distinguish task data, an agent's workspace and execution state.

## Before you begin

Names refer to the selected server and current section.

## Terms

- Project: registration of a name, working repositories and factory-profile connections.
- Working folder: where an agent starts. A project/task helps select it but does not replace permission mode.
- Executor: an adapter for an installed service or CLI. Model: the chosen model of that service.
- Turn: work from a sent message until a result, stop or error.
- Context: model working memory, separate from visible messages and account quota.
- Task: a specification and expected outcome. Triage: its assessment before launch.
- Route: stages and checks. Attempt: one execution of a route.
- Gate: a planned human decision point. Arbiter: assistance analysing a stop.
- Profile: project/automation configuration. Environment: a running workspace for testing.
- Plugin: an additional capability. Installed and enabled are different states.

## Result

Read statuses in their operation's context. One component being ready does not mean the whole task succeeded.

## Limits and recovery

Usage without units, unknown measurements and missing data cannot be treated as zero.
