# GrigDesk Guide

This guide covers the released GrigDesk application, from installation to tasks and recovery.
The version appears below the contents. When connected remotely, the guide belongs to the selected server.

## Before you begin

Built-in articles need neither internet access nor a paid model request. The contents, search and articles
follow the interface language. Select English or Russian in the device's interface settings;
an open help window changes language while keeping the selected article.

## What to do

1. Choose an article or search for a topic, such as “working folder”. The current article is highlighted;
   clear the search using the cross in the field.
2. Click the circled question mark beside settings or press F1 for help with the current section.
   In settings, help opens above the form and preserves your draft.
3. Follow related articles. Save an article's address for later; browser history returns to the previous page.
4. “Ask an agent” creates a conversation with a draft question and the article's version.
   Review the draft and send it yourself.
5. On wide screens, “On this page” links jump to headings. On narrow screens, open “Contents” above
   the article. Selecting a topic collapses the contents and keeps the search.

## Result

The application, agent tool and website for a release use the same edition of the guide.
“Open on website” keeps the selected interface language.

## Limits and recovery

External plugins keep their own instructions in their packages. Missing articles, empty search results
and an unavailable server have separate states. Retry a failed load or update the selected server.
An older server that only provides Russian articles displays a language notice in the English interface.
