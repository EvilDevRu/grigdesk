# GrigDesk User Guide

The compact connection list, shared account switcher below the limits and sign-in recovery are described in [Executor access profiles](access-profiles.md).

This guide covers the released GrigDesk, from installation to tasks and recovery. The version appears below the contents; when connected remotely, the guide belongs to the selected server.

## Before you start

Help is available as soon as you sign in successfully, including on first launch.

Reading the built-in articles requires neither Internet access nor a paid model call. Articles, contents and search follow the device's active interface language. System default uses Russian on a Russian system and English otherwise. Both languages are included in the release.

## What to do

1. Choose an article in the contents or search for a topic, such as “working directory”. The current article is highlighted; clear search with the cross in the field.
2. Press the circled question mark beside Settings, or F1 on a workspace, for help with that section. In Settings, help opens over the form and preserves your draft.
3. Follow links to related articles. You can save an article's address; browser history returns to the previous page.
4. “Explain with an agent” creates a new conversation with a draft question, article version and actual language. Review it and send it yourself.
5. On a wide screen, “On this page” on the right jumps to a heading. On a narrow screen, open “Contents” above the article to choose a topic; it collapses after selection and keeps the search.

Changing Russian/English updates the open article immediately and preserves its ID and history. An old heading fragment may return to the start of the same article. The standalone release reader has its own System default/Russian/English choice; its URL takes precedence over its saved preference.

## Result

The application, agent tool and website for the corresponding release use the same edition of the guide.

## Limitations and recovery

External plugins keep their own instructions in their packages. Unknown articles, empty searches and an unavailable server have separate states. Retry a failed load or update the selected server. If an older server only provides Russian, or English is explicitly unavailable, the Russian guide appears with an explanation. Search then uses the Russian text. Network failures and damaged resources show an error instead of substituting another server's guide.
