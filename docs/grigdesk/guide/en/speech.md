# Dictation and meetings

Dictation helps enter text; Meetings turns audio and video into transcripts and tasks.

## Before you start

Grant microphone permission on the device. For server recognition, prepare its environment and model in Speech settings; browser recognition availability depends on the device.

## What to do

1. In Speech settings, check recognition readiness, install offered components and wait for the model download.
2. For dictation, enable the microphone beside the input, speak, stop recording and check the text before sending.
3. For a meeting, open Video/Meetings and add a recording; several files can form one meeting.
4. Wait for transcription and analysis, then review topics and frames. Correct task descriptions and select a project and assignee.
5. Before creation, check task splitting and attachments, then confirm.

## Result

Text is available for editing, and tasks are created after human review. Meeting analysis survives leaving the page.

## Limitations and recovery

Model downloads need network and disk space. For Python or dependency failures, use the cause shown in settings. Browser and server speech use different capabilities; unavailable recognition is not counted as success. Presentation narration is configured separately.
