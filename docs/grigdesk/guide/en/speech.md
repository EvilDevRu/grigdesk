# Dictation and meetings

Dictation enters text. Meetings processes audio/video into transcripts and tasks.

## Before you begin

Grant microphone access on your device. Prepare the server environment and model in Speech settings
for server recognition; browser recognition availability depends on the device.

## What to do

1. Check recognition readiness in Speech, install offered components and wait for the model download.
2. Start the composer's microphone, speak, stop recording and review text before sending.
3. Open video/meetings and add a recording; several files can form one meeting.
4. Wait for transcription and analysis, review topics/frames, edit tasks and choose project/assignee.
5. Check task splitting and attached materials before confirming creation.

## Result

Text is editable and tasks are created after human review. Meeting analysis survives leaving the page.

## Limits and recovery

Model downloads need network and disk space. Use the stated settings reason for Python/dependency failures.
Browser and server recognition have different capabilities; unavailable recognition is not success.
Presentation narration is configured separately.
