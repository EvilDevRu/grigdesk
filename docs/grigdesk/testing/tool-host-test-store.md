# Двойник dock store включает ограничение ширины

ToolHost при mount измеряет доступную область и вызывает `dock.fitWidth(maxWidth)`.
Двойники store в component-тестах должны предоставлять этот метод вместе с `setWidth`:
иначе даже проверка значка закрытой полки падает до своего assert.

В тесте значка метод может быть пустым: геометрия не является предметом сценария,
а happy-dom не вычисляет раскладку. Сохранение желаемой ширины и временное ограничение
проверяются настоящим store; край ресайза и размеры поверхности — настоящим renderer.
