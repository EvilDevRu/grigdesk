# Расширения Fastify в изолированных HTTP-фикстурах

Веб-проверки «Спросить агента» импортируют настоящий серверный модуль чата через
`tests/server/helpers/chat-turns.js`, без `server/src/app.ts`. Поэтому импорты
`@fastify/multipart` и `@fastify/websocket` из сборки приложения не попадают в программу
`web/tsconfig.tests.json`.

`server/src/lib/fastifyDecorations.ts` подключает объявления этих пакетов через
`import type {}`. Эта общая точка уже включена в программу типов HTTP-фикстур.
Без multipart запрос теряет `file()`, а без websocket перегрузка маршрута не различает
обработчик сокета и обычный HTTP-обработчик: появляются ошибки `readyState`, `send`,
`close`, `on` и параметров сообщения.

Импорты типов не регистрируют плагины и не исполняются в runtime. Регистрация остаётся
в сборке приложения; для поведенческой проверки конкретного транспорта фикстуре
по-прежнему нужен соответствующий плагин. Дублировать объявления Fastify или ослаблять
строгую проверку типов не требуется.

Команды проверки: `npm --prefix web run typecheck:tests` и
`npm --prefix server run typecheck`.
