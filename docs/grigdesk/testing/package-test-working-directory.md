# Тест запускается из папки своего пакета

`npm --prefix server test` и `npm --prefix web test` устанавливают рабочую папку
процесса в `server/` и `web/`. Отдельная проверка через сторож памяти из корня
репозитория может пройти, хотя тот же файл падает в полном прогоне.

Пути исходников в тесте вычисляются относительно `import.meta.url`, например через
`fileURLToPath(new URL('../../', import.meta.url))`. Если дочерний процесс использует
импорт относительно корня, ему явно передаётся этот вычисленный `cwd`. Тест не должен
принимать текущую папку вызывающего процесса за корень проекта.

Регрессия проверяется через `tests/run-node-tests-safe.sh` из папки соответствующего
пакета. Проверка пути не должна подменять проверку исходного контракта: обход дерева
импортов и конфликт владельцев библиотеки остаются настоящими.
