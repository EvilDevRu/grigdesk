# Ожидание результата запуска в браузерной проверке арбитра

Кнопка «Повторить только запуск» в `ArbiterConversation.vue` доступна уже при исходе
`accepted`: запись решения подтверждена, а попытка resume ещё может выполняться.
Счётчик вызовов resume в фикстуре также меняется до сохранения окончательного исхода.

В `arbiter-conversation.browser.test.js` проверка отказа первого запуска ожидает
сообщение «Указание принято, но этап пока не запущен». Одного появления кнопки
недостаточно: немедленная проверка всей переписки иногда видела только промежуточное
сообщение о принятом указании. Следующее нажатие resume выполняется после этого
ожидания; проверки единственности goto и числа запусков сохраняются.
