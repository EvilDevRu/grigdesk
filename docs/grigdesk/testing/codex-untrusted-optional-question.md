# Необязательный вопрос в изолированном Codex

На установленном CLI 0.164.0 loopback-проверка `codex-untrusted.test.js` получает
точный обязательный набор `exec`/`wait`; `request_user_input_async` может отсутствовать.
Сторож допускает только этот необязательный вопрос, максимум один экземпляр, и
сохраняет точную проверку остальных tools. Ни новый namespace, ни вложенные host tools
такой совместимостью не разрешаются. Native policy изолированного runner остаётся never.
