# Happy DOM: начальное состояние слушателя matchMedia

В MediaQueryList.addEventListener Happy DOM 18.0.1 создаёт matchesState=false,
независимо от текущего совпадения запроса. Если listener установлен при уже совпадающем
media, первый переход к несовпадающему состоянию сравнивается с false и не вызывает change.
В настоящем браузере этот переход вызывает событие.

Для проверки изменения ширины в phone-topbar.component.test.js после монтажа
отправляется начальный resize при прежней ширине. Он запоминает текущее совпадение,
после чего setWindowSize вызывает настоящую смену media. Продуктовые обработчики
и значения matchMedia не подменяются. Проверяются узкий режим, переход на desktop
с возвращением конвейера и обратный переход.
