# Проверка типов UI и прежние импорты JavaScript

До переноса сторов `web/tsconfig.ui.json` включал composables, которые транзитивно
импортировали JS-модули. При унаследованном `allowJs: false` это давало TS7016:
для импортированного модуля не было декларации типов. Переходный `allowJs: true`
включал реализацию в программу, но при `checkJs: false` не проверял её собственные ошибки.

Сейчас собственный `web/src` полностью перенесён в TS, включая стор чата и его
потребителей. Основной `web/tsconfig.json` наследует `allowJs: false`, содержит
все продуктовые Vue и исключает только `shared/node`. Отдельные проекты областей,
тестов и scripts сохраняют свои настройки; общий перенос их не отключает.

Проверка реальной конфигурации: `npm --prefix web run typecheck`, включая отдельную
среду AudioWorklet. Текущий остаток других областей перечислен в
[состоянии миграции](../overview/typescript-migration-state.md).
