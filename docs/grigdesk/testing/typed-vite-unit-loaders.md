# Типизированные модули и загрузчики unit-тестов

Нативный import Node снимает поддерживаемые типы TypeScript, но не исполняет плагины
сборщика. Импорт `speechPcmWorklet.ts?worker&url` в Node разрешается как исходный модуль
процессора, у которого нет default URL. Прямой import контроллера, транзитивно читающего
такой транспорт, завершается до поведенческих assertions.

`tests/web/helpers/compile-vue.js:loadProductModule` использует существующий компилятор
и точную подмену этого Vite URL. Подменяется URL, а не реализация процессора.
Исполнение выпущенного Vite JavaScript проверяется отдельно от unit-потребителей.
Переходный `migrationUrl` выбирает путь, но сам по себе не превращает import в компиляцию.

Проверка экспортов router через compileModule затрагивает и его динамические импорты:
esbuild обходит Vue-экраны, включая Monaco, CSS и шрифты. Для проверки маршрутов или
имён экспортов нужны явные doubles lazy-компонентов. Барьер RUNTIME-router берёт их
из сохранённого списка маршрутов; импорты реальных экранов проверяются сборкой web
и соответствующими компонентными тестами.
