# Фильтр engine-набора сравнивается с полным путём

`tests/engine/run-offline.sh` применяет аргумент-фильтр как grep-выражение к абсолютному
пути теста. Если имя checkout само содержит слово фильтра, короткий аргумент выбирает
весь набор. Это свойство выбора файлов, а не ошибка конкретного теста.

Для точного набора DeepSeek подходит выражение `/deepseek[^/]*[.]sh$`: оно выбирает
пять DeepSeek contract/unit/integration файлов независимо от имени checkout.
Регрессию запускают через Node-обёртку под `tests/run-node-tests-safe.sh`, а отчёт
сохраняют отдельно от полного набора. Изменять тесты или их таймауты для фильтра не нужно.
