# Однострочные пояснения функций прошли незамеченными = сторож читаемости видел только TS в web/

Правила читаемости из `CLAUDE.md` действуют во всём коде, но `npm --prefix web run
check:readability` (`web/scripts/check-code-readability.mjs`) сверяет с базовой линией
только TypeScript в `web/src` и `web/dev` и блоки `<script lang="ts">`. JS-сторы
(`web/src/stores/*.js`), SFC без `lang="ts"`, сервер, `shared`, `tools` и тесты он не
открывал. В доставке ходов чата (27.09.2026) однострочные `/** … */` у нетривиальных
функций, `if` без скобок и слипшиеся группы операторов прошли все тесты и сторож.

## Что проверяет сторож

Одни и те же правила в обоих режимах:

- `function-explanation` — перед нетривиальной именованной функцией нужен комментарий
  минимум из двух непустых строк (блок или подряд идущие `//`). Нетривиальна функция
  экспортируемая, от четырёх операторов в теле или от двух ветвлений (`if`, `?:`,
  `switch`, циклы, `try`/`catch`). Однострочный `/** … */` правилу не удовлетворяет.
- `logical-spacing` — соседние операторы разного рода (объявление, ветвление, цикл,
  эффект, выход, `try`) и любые функции разделены пустой строкой.
- `unbraced-control` — у `if`/`for`/`while` тело в фигурных скобках.
- `packed-members` — от трёх полей объекта, типа или интерфейса каждое на своей строке.
- `one-line-function`, `line-length` (110 символов).

## Два режима

- **Базовая линия** (`check:readability`, тест `code-readability.contract.test.js`): отчёт
  по TypeScript в web/ обязан совпасть с `tests/web/fixtures/ui/code-readability-baseline.json`.
  Новый долг — ошибка; погашенный — перегенерировать линию `--print-baseline`.
- **Проверка файлов** (`--files <пути>` или `--changed`): любые слои, JS и TS, оба блока
  SFC; показывает только нарушения, внесённые относительно HEAD, с `файл:строка`. Прежний
  долг изменённого файла не мешает, но переписанная функция (другой отпечаток — первые
  180 символов её текста) обязана соблюдать правила. `--all` — все нарушения файлов.
  `--changed` берёт и чужие правки общего дерева, свой набор надёжнее дать через `--files`.

## Долг вне базовой линии

Замер 27.09.2026 по всем отслеживаемым файлам кода (`--files --all`, только
`function-explanation`): около 3 400 нетривиальных функций без многострочного пояснения,
из них ~2 000 в `server/src`, ~700 в тестах, ~370 в JS-коде и SFC `web/src`, ~150 в
`shared`, ~100 в `web/scripts`. Сторож по базовой линии их не видит; проверка файлов
ловит только новые и переписанные.
