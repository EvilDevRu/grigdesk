# Суффиксы Vite в проверке зависимостей

`tests/docs/shared-layout.test.mts` проверяет наличие исходников обоих каталогов shared
и запрещает прямые и транзитивные зависимости web от `shared/node/`.

Импорт `speechPcmWorklet.ts?worker&url` содержит режим обработки Vite. Буквальный поиск
такого имени на диске давал ложный отказ при существующем `speechPcmWorklet.ts`.

Общий для двух web-проверок `webDependencyPath` отбрасывает query и fragment перед
разрешением пути относительно импортирующего файла. Это сохраняет обход исходных
зависимостей worker, проверку наличия файлов и границу Node. Слеши и `..` в параметрах
не меняют путь исходника. Разбор импортов сохраняет исходную строку для сообщения
об ошибке; строгие проверки собственного слоя `shared/` не меняются.

Регрессии в том же файле проверяют обычный импорт, `?worker&url`, `?url`, fragment,
параметры со слешами, отсутствующий файл и сохранение запрета `shared/node/`.
Запуск: `bash tests/run-node-tests-safe.sh --test tests/docs/shared-layout.test.mts`.
