# Пропуск проверок неподготовленного драйвера

`tests/server/helpers/trackerPackage.js` получает контекст теста `t` при импорте
или копировании пакета. Если соседнего каталога `grigdesk-desk-drivers/grigdesk-b24`
либо `grigdesk-b24-discript` нет и соответствующая переменная `GRIGDESK_STOCK_DRIVER_DIR`
либо `GRIGDESK_CUSTOM_DRIVER_DIR` пуста или не задана, helper вызывает
`t.skip('пакет не подготовлен: …')`.

Импорт возвращает `null`, копирование — `false`; вызывающий тест или цепочка setup
сразу завершает зависимую проверку. Остальные тесты файла продолжают работать.
Импорт клиента на уровне файла запрещён: skip должен относиться к конкретному тесту.

Непустой явный путь делает пакет обязательным: отсутствие каталога остаётся ошибкой.
Ошибки доступа, некаталог вместо пакета и ошибки содержимого существующего каталога
также не превращаются в skip. С подготовленными обоими пакетами набор проходит без
пропусков; успешный прогон со skip не считается приёмкой драйверов.
