# Клавиши Playwright не доходят до меню Electron

Playwright `page.keyboard` вводит клавиши через протокол DevTools. Нажатие получает
страница, но главный процесс его не видит: accelerator пункта меню и `before-input-event`
от такого ввода не срабатывают. Сквозная проверка горячей клавиши меню поэтому остаётся
красной при любой реализации.

`webContents.sendInputEvent` из главного процесса (в тесте — через `app.evaluate`) идёт
путём обычного ввода. Сначала приходит `before-input-event`, затем keydown страницы,
затем accelerator меню.

Accelerator меню срабатывает только для нажатия, которое страница не забрала:
`preventDefault()` в keydown глушит пункт меню. `before-input-event` приходит раньше
страницы и от этого не зависит. Сочетание, которое должно работать и при фокусе в
терминале (xterm забирает клавиши себе), ловится в `before-input-event`. Пункт меню тогда
может показывать подсказку с `registerAccelerator: false`, чтобы действие не сработало
дважды.

Проверено пробой на Electron 44.7.0 под Linux в одноразовой сессии Xvfb (14.10.2026).
