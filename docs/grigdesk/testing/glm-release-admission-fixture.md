# Smoke GLM и меняющийся допуск выпуска

Обычный адаптер проверяет admission выбранного ELF, а не постоянный запрет на запуск
тестового candidate. `deepseek/compatibility/glm.json` уже содержит api admission;
совпадение с рассчитанной compatibility разрешает запуск Harness. `glm_auth_failed`
после этого относится к авторизации, а не доказывает пропущенную проверку допуска.

`glm-live-binary.test.js` проверяет SHA ELF до и после smoke, затем запускает обычный
адаптер без DI admission с синтетическим ключом, loopback endpoint и egress guard.
Допущенный выпуск выполняет настоящий протокол локально. Несовместимая identity проверяется
отдельно: `glm_runtime_not_admitted` должен возникнуть до spawn и до нового запроса модели.
Серверная политика Coding Plan остаётся закрытой. Внешняя сеть и реальные ключи не нужны.

Такой тест сохраняет отрицательную границу допуска и не принимает ошибку авторизации
за ожидаемый результат. Временный DI-допуск smoke не изменяет metadata или байты выпуска.
