# Изолированная сессия Electron изредка возвращает 1 при успешной проверке

`tests/desktop/e2e/isolated-session.sh` в конце удаляет свой временный `XDG_RUNTIME_DIR`. Если в
сессии по запросу D-Bus поднимался портал документов, он монтирует FUSE-точку
`$XDG_RUNTIME_DIR/doc`. Погибший портал иногда не снимает её, и `rm` не может удалить каталог:
сессия возвращает 1, хотя команда внутри завершилась с кодом 0.

Признак — успешный внутренний прогон и ошибка удаления `…/doc` в выводе. Это помеха среды, а не
отказ проверки: повторить один раз и записать. Наблюдалось дважды примерно на 60 запусках
(14.10.2026). Обёртка, которая сама делает `fusermount -u -z` своей точки перед удалением,
помехи не видит.
