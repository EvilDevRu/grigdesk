# Navigator.locks в Node-фикстуре окна

Node может предоставлять глобальный navigator.locks даже без DOM-окна. Транспорт
открытия native-поверхности использует этот lock для последовательных запросов.
Поэтому тест, который удерживает ответ первого запроса и ожидает второй до освобождения
первого, блокируется на собственной очереди и не доходит до проверки позднего fallback.

В fixture проверки независимых ответов явно подменяется navigator без locks с восстановлением
дескриптора в cleanup. Очередь браузера этим тестом не проверяется. Отдельные проверки окна
используют настоящий контракт поверхности и подтверждённые ответы. Отсутствие вывода после
успешных предыдущих тестов не доказывает зависание продуктового сервера.
