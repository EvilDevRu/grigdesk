# Окружение JVM-проверки смены маршрута

`tests/mobile/relay-route-native.test.js` запускает только `RelayRouteUpdateTest`:
обновление маршрута существующего профиля прежними key1/key2 и сохранение профиля при ошибке.
Это проверка шага 10а мастера удалённого доступа, а не сборка или установка APK.

Лаунчер принимает `GRIGDESK_ANDROID_JDK`, `GRIGDESK_ANDROID_HOME` и
`GRIGDESK_ANDROID_GRADLE_HOME`. Для каждой отсутствующей или пустой переменной он использует
стандартный путь инструментария машины. Конкретные пути и подготовка офлайн-кэша относятся
к машинному опыту в `docs/local/`, а не к контракту продукта.

До проверки окружения всегда сверяется закреплённый SHA-256 Java-фикстуры. Если стандартные
Java, SDK или кэш отсутствуют, тест получает skip с пометкой «не проверено» и перечнем
переменных для подготовки. Неверный непустой явный путь, отказ доступа, повреждённый кэш
и ошибки Gradle/JVM остаются ошибками теста.

При доступном окружении JVM-прогон обязателен: прежние assertions Java, офлайн-режим,
изоляция выходных каталогов и проверка успешного завершения Gradle сохраняются.
Skip не подтверждает критерии сохранения ключа и атомарного обновления профиля;
для их приёмки нужен фактический JVM-прогон без пропуска.

Запускать файл следует через профильную обёртку задачи со сторожем памяти, как и остальные
Node-тесты. Изменение этого лаунчера по прямому решению человека не разрешает менять
Java-фикстуры, другие закреплённые тесты, их доверенный снимок или обёртку проверки.
