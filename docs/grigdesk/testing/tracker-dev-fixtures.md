# Фикстуры после объединения трекеров и оболочки

Доска проверяет владельца снимка по ревизии `/api/trackers`. Mock ответов
должен возвращать `externalId` и `revision`; реквизиты удалённой формы Б24
не участвуют в проверке. HTTP-барьер отдельно проверяет AbortSignal у GET,
сохраняя точное сравнение прежних аргументов мутаций и тел ответов.

Фикстуры App подменяют отдельные окна инструментов и DesktopExitHost:
это самостоятельные владельцы жизненного цикла, которые через реестр панелей
или чат могут затянуть редактор Monaco. Тест настроек проверяет собственный
memory router, а не singleton маршрутизатора остальных страниц.
Mock доски объявляет `clearSource`, потому что потеря авторизации снимает снимок.

Desktop-фикстуры App предоставляют личным stores массив `external` и ветку `own`,
даже если подключённых внешних досок нет. Подписка межоконной синхронизации читает
массив сразу при mount; его отсутствие даёт `favorites.external is not iterable`
и обрывает регистрацию общего disposer уже созданных каналов. В Node такой канал
может удержать процесс теста до общего таймаута CI. Проверка таймера оболочки
учитывает третий аргумент мутации — подтверждённый источник задачи либо `undefined`.

Проверка drain при смене реквизитов должна передать действительно изменившееся
значение: сохранение прежнего `{}` является no-op и не закрывает допуск драйвера.
После удаления пакета selection и событие `trackers-changed` сохраняют полный
контракт `drivers`, `default`, `externalId`, `revision`.

В телефонной проверке оболочка до готовности доступа может держать sidebar
и phone-nav в DOM скрытыми. Ожидание attached проверяет появление машины;
доступность настроек по-прежнему проверяется после подтверждения входа.
Текст разных slot-элементов заголовка проверяется отдельно: CSS gap не является
пробельным символом в textContent. Сортировка внешнего источника имеет значение
`tracker`. Фикстуры каталога и языка содержат страницу `tools.browser`.

Конвейер, карточка и notify watcher читают `/api/tasks?sources=1`: фикстура прежнего
`/api/tasks` не подтверждает загрузку смешанных источников. Для собственной карточки
UI-store передаёт `taskSource`, а личные эффекты требуют методов `load` всех трёх stores.
Подмены компилятора используют актуальные `taskFavorites.ts` и `taskSeen.ts`, иначе
вместо двойников в граф попадают настоящие Pinia stores.

Отказ установщика проверяется через HTTP `ApiError`; кнопку повтора ищут заново в текущей
карточке пакета, поскольку error-рендер заменяет старый DOM. Выбор драйвера ищет option
нужного id, а не любой select соседнего мастера; поля схемы проверяются внутри редактора
подключения. Фикстура собственной карточки предоставляет также `.own` личных stores.
Карточка перечитывает конвейер до и после подтверждения деталей; раскрытие подробностей
не должно добавлять запросы к уже прочитанному снимку.
