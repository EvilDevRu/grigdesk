# Фикстуры после объединения трекеров и оболочки

Доска проверяет владельца снимка по ревизии `/api/trackers`. Mock ответов
должен возвращать `externalId` и `revision`; реквизиты удалённой формы Б24
не участвуют в проверке. HTTP-барьер отдельно проверяет AbortSignal у GET,
сохраняя точное сравнение прежних аргументов мутаций и тел ответов.

Фикстуры App подменяют отдельные окна инструментов и DesktopExitHost:
это самостоятельные владельцы жизненного цикла, которые через реестр панелей
или чат могут затянуть редактор Monaco. Тест настроек проверяет собственный
memory router, а не singleton маршрутизатора остальных страниц.
Mock доски объявляет `clearSource`, потому что потеря авторизации снимает снимок.

В телефонной проверке оболочка до готовности доступа может держать sidebar
и phone-nav в DOM скрытыми. Ожидание attached проверяет появление машины;
доступность настроек по-прежнему проверяется после подтверждения входа.
Текст разных slot-элементов заголовка проверяется отдельно: CSS gap не является
пробельным символом в textContent. Сортировка внешнего источника имеет значение
`tracker`. Фикстуры каталога и языка содержат страницу `tools.browser`.
