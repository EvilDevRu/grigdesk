# Незакрытый BroadcastChannel вешает файл теста

В Node `BroadcastChannel` — глобальный объект, и открытый канал держит процесс живым даже
без слушателя. Файл `node:test`, который оставил канал открытым, не падает: он висит до
таймаута раннера. Проверено на Node 22.22: процесс с одним `new BroadcastChannel('x')` сам
не завершается.

Веб-тесты переносят в `globalThis` только перечисленные объекты окна happy-dom. Если тест
не подменил `BroadcastChannel`, код веба под тестом получает канал Node.

Модуль, которому нужен канал, создаёт его лениво и только там, где канал действительно
используется, а не при импорте. Тест закрывает каждый канал в `t.after` либо передаёт
модулю подменную фабрику канала.
