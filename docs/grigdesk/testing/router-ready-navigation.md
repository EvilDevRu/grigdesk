# Готовность маршрутизатора перед повторной навигацией

В браузерной фикстуре настоящего App готовность авторизации и два кадра отрисовки
не гарантируют завершения начальной навигации Vue Router. Пока загружается lazy-модуль
первой страницы, `currentRoute` ещё может быть `/` с пустым `matched`.

Если в этот момент выполнить `page.goto` с другим hash того же документа, завершение
начальной навигации может вернуть прежний адрес. Следующий локатор тогда ищет элемент
в другом разделе. Увеличение таймаута локатора не завершает пропущенный переход.

Перед повторной навигацией фикстура должна дождаться `router.isReady()` либо видимого
содержимого начального маршрута. Для настоящего App маршрутизатор доступен через
`document.querySelector('#app').__vue_app__.config.globalProperties.$router`.
Это отдельный барьер от готовности shell и auth; проверкам offline и экрана выбора
компьютера не требуется ждать рабочую страницу.

Воспроизводить гонку можно удержанием ответа начального lazy-модуля: дождаться auth,
сменить hash, затем отпустить модуль. При ожидании `router.isReady()` перед сменой hash
переход сохраняется. Данные и API мастера для этого воспроизведения не нужны.
