# Явная связка ключей в чистом окружении Electron

`desktopLaunchOptions({ isolateEnv: true })` передаёт только разрешённые переменные сессии.
Признаки окружения рабочего стола в этот список не входят. Даже при работающем тестовом
GNOME Keyring Electron может выбрать `basic_text`; приложение отклонит такой backend
до создания первого `BrowserWindow`, а helper ожидания главного окна закончится таймаутом.

Запуск через `tests/desktop/e2e/isolated-session.sh` с этим режимом должен явно добавлять
`--password-store=gnome-libsecret` в `args`. Проверено на Electron 44.7.0: одноразовая связка
обслуживает вход, окно штатно показывается. Ослабление `requireProtectedStorage` не нужно.

Поэтому при таймауте без окон и без запросов к HTTP-фикстуре сначала проверяют выбор
backend, затем загрузку страницы. Пакетные проверки уже передают этот аргумент явно.
