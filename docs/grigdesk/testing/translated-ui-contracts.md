# Проверки интерфейса после переноса текстов в каталоги

При разборе падения строкового сравнения сначала проверяй владельца текста и его
контракт. Потеря значимого пробела в составной подписи — ошибка продукта;
сравнение объекта перевода с готовой строкой — ошибка проверки.

- `ConnectionsView.vue` импортирует `t`, `uiLocale`, `messageRef`, `resolveUiText`
  через `ui.ts`. Полная тестовая подмена этого модуля должна отдавать эти экспорты
  вместе с контролами. Отсутствующий экспорт ломает сборку тестового графа до mount.
- Стор 3D передаёт `MessageRef` в `alertUser`, чтобы открытый тост менял язык.
  Проверять видимый русский текст нужно через `resolveLocaleText(value, 'ru')`;
  превращение descriptor в строку внутри стора нарушит смену языка.
- Заголовок и метаданные `UiTopbarPanel` — отдельные flex-элементы с `gap`.
  `textContent` всего header не содержит CSS-расстояния между ними. Проверяй текст
  `.ui-topbar-panel__title` и `.ui-topbar-panel__meta` отдельно, а геометрию — в браузере.

Падения инвентаризации тоже требуют чтения причины: `collectMigrationInventory`
запускает `vue-tsc`, который наследует `NODE_OPTIONS` сторожа памяти. Для текущей
программы типов heap 1024 МиБ недостаточен; проверенный запуск:

```sh
NODE_TEST_HEAP_MB=2048 NODE_TEST_MAX_RSS_MB=4096 \
  bash tests/run-node-tests-safe.sh --test --test-concurrency=2 \
  tests/docs/migration-inventory.test.mts
```

V8 heap OOM дочернего компилятора не означает несовпадение снимка миграции.
Повышение heap не снимает общий RSS-предел и не разрешает прямые сравнения DOM-узлов.
