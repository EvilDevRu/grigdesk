# Временная папка вложенного сторожа тестов

`tests/run-node-tests-safe.sh` создаёт временную папку данных под `TMPDIR`, иначе
под `/tmp`. Если тест запускает ещё один сторож с явным урезанным env и сравнивает
его результат с `os.tmpdir()`, он передаёт тому же child `TMPDIR: os.tmpdir()`.
Иначе parent с нестандартным TMPDIR сравнивает свой путь с умолчанием child.

DH-11 проверяет и выделение папки, и удаление после выхода дочернего сторожа.
Проверка не зависит от того, выбран ли `/tmp` или отдельная папка артефактов.
