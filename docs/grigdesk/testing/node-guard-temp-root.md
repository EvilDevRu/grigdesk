# Временная папка вложенного сторожа тестов

`tests/run-node-tests-safe.sh` создаёт временную папку данных под `TMPDIR`, иначе
под `/tmp`. Если тест запускает ещё один сторож с явным урезанным env и сравнивает
его результат с `os.tmpdir()`, он передаёт тому же child `TMPDIR: os.tmpdir()`.
Иначе parent с нестандартным TMPDIR сравнивает свой путь с умолчанием child.

Изолированные тесты `dist build` получают короткий приватный TMPDIR. Фикстура Claude
проверяет, что одноразовый каталог создан внутри `os.tmpdir()` и удалён после хода.
Проверка настоящего Unix bind включает вложенность сокета Kimi и предел 107 байт.
Фикстуры миграции CLI используют `os.tmpdir()`: hex-имя резервной копии удваивает
длину абсолютного пути к `.bashrc` и учитывает предел длины имени файла.
DNS-фикстура оставляет диагностику в `shutdown-checks`, а Unix-сокет размещает
в короткой временной папке, которую удаляет после проверки.
Фикстура Qwen в конвейере дополнительно сокращает своё имя каталога. Вложенный
путь до Unix-сокета Work MCP составляет 106 байт под TMPDIR полного прогона.

DH-11 проверяет и выделение папки, и удаление после выхода дочернего сторожа.
Проверка не зависит от того, выбран ли `/tmp` или отдельная папка артефактов.

На Darwin до запуска Node сторож требует абсолютный путь к подготовленному
нативному `setsid` в `GRIGDESK_TEST_SETSID_BIN`. RSS по-прежнему суммируется
по группе процессов. Нативная проверка отказа при отсутствии инструмента
находится в `macos-sea-build.e2e.mts`.
