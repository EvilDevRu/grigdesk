# Граница общих Node-модулей в проверке web

`web/tsconfig.json` включает общий TypeScript через `../shared/**/*.ts`. После появления
`shared/node/` этот шаблон захватывает Node-модули даже без браузерного импорта. Браузерная
база намеренно не содержит Node-глобалей, поэтому возникает TS2307 на `node:fs`/`node:crypto`.

Исключение `../shared/node/**` ограничивает корневые файлы программы. Оно не запрещает
транзитивный импорт: такую зависимость проверяет `tests/docs/shared-layout.test.mts`.
Тот же сторож разбирает web tsconfig и проверяет, что шаблон не включает Node-модули.
Node-код проверяется серверными типами и типами его пакетов-потребителей.
