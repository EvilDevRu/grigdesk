# Каталог инструментов и Vue-панели имеют разные импорты

`web/src/shared/tools/catalog.ts` содержит только адреса, подписи, значки и владельцев.
Обработчик открытия `launcher.ts` использует `TOOL_META_BY_ID` из этого каталога;
ему не нужны компоненты панелей.

`registry.ts` добавляет Vue-компоненты через `asyncView.ts`. Обработчик ошибки загрузки
входит в основной пакет и импортирует `LoadFailure.vue` синхронно. Поэтому прямой импорт
реестра в обычном Node-тесте даёт `ERR_UNKNOWN_FILE_EXTENSION: .vue`.

Проверка значков читает каталог. Проверка состава Vue-реестра использует `compileModule`
и подмены панелей: её предмет — сопоставление инструментов, а не Monaco, WebGL и xterm.
Подмена только asyncView недостаточна: bundler всё равно обходит динамические импорты.
Загрузку настоящих панелей и видимый отказ проверяет UI-E01 в Electron.
