# Vue scoped CSS: :global заменяет весь селектор

Vue SFC-компилятор для `:global(html[data-ui-touch]) .hint` выдаёт только
`html[data-ui-touch]`: оставшаяся часть селектора теряется. Правило видимости подписи
в таком виде меняет display корневого документа.

Если глобальным нужен лишь предок, достаточно обычного
`html[data-ui-touch] .hint`: scoped-компилятор добавляет атрибут к `.hint`, сохраняя
корневой селектор. Полный `:global(...)` нужен только для полностью глобального правила.

CSS-проверка `chat-in-turn.component.test.js` использует настоящий `compileStyle`,
а после компиляции снимает только тестовый scope-маркер. Ручная замена :global
регулярным выражением скрывала бы такое изменение селектора. Проверяются видимость
обеих подсказок и отсутствие display: inline у корня.
