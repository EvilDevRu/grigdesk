# Happy DOM: корневой атрибут и старый computed style

После снятия data-ui-touch у html `element.matches()` уже возвращает false для touch-правила,
но getComputedStyle может сохранять прежнее значение. В проверке счётчика top оставался
2 px вместо desktop -3 px даже после очистки и повторного присвоения текста подключённого
style. Корневой атрибут при этом действительно отсутствовал.

Сценарии разных указателей проверяются на свежих DOM-компоненте и style для каждого режима.
Это сохраняет настоящий CSS и getComputedStyle, без подмены результата или media.
Такой способ используется в alert-history-popover.component.test.js. Он не подменяет
нативную проверку расположения и не доказывает аналогичный дефект Chromium/WebView.
