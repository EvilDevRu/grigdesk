# Лишнее поле тела прошло схему Fastify

`additionalProperties: false` само по себе не гарантирует отказ 400 в конфигурации Fastify
проекта. Валидатор может удалить лишнее поле, после чего обработчик получает допустимый
объект и возвращает успех.

Для мутации с закрытым набором полей нужна также `propertyNames` с перечислением разрешённых
имён. В `/api/system/update-restart` разрешено только `jobId`: его формат проверяет `pattern`,
а добавление другого поля должно давать 400. Такой же приём используется соседними
маршрутами применения и обновления.

Проверять следует поведение через `app.inject`, включая лишнее поле. Чтение текста схемы
не обнаружило бы удаления данных валидатором. Сценарий UP-07 в
`tests/server/system-desktop-restart.test.js` закрепляет этот отказ.
