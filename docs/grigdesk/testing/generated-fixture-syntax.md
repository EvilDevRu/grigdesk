# Синтаксис генерируемого child проверяется отдельно

Если тест генерирует JavaScript строкой и ждёт сигнал дочернего процесса, timeout
может скрывать SyntaxError ещё до входа в исследуемый код. В fixture проверки
наследования browser environment лишняя закрывающая скобка оставляла 24 из 25 тестов
зелёными, а stdio-сценарий ждал marker до deadline.

Сначала сохраните synthetic child в артефакты и выполните node --check над ним.
Отдельно наблюдайте exit/stderr и факт получения marker. После исправления синтаксиса
повторите исходную команду целиком, затем удалите временные диагностические логи.
Увеличение timeout не исправляет ошибку генерации и не доказывает работу транспорта.
