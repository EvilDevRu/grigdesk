# Повторная сборка SFC удерживает прежние фикстуры в ESM-кеше

`compileVue` из `tests/web/helpers/compile-vue.js` собирает граф компонента и импортирует
каждый результат под новым временным `file:` URL. Удаление файла после импорта не удаляет
сам модуль из кеша Node. Внешними singleton остаются Vue и Pinia, но продуктовые модули,
каталоги переводов и точные подмены портов входят в каждую новую сборку.

Если подмена захватывает `globalThis` на уровне модуля, например
`const monaco = globalThis.__codeViewMonaco`, импорт удерживает и старый тестовый порт.
Размонтирование компонента, `dispose()` редакторов и удаление глобальной переменной
не разрывают эту ссылку. Двойник Monaco дополнительно хранит созданные модели и редакторы
для assertions; его `dispose()` отмечает завершение, сохраняя записанные вызовы.

В прежнем загрузчике `code-view.component.test.js` каждое монтирование вызывало
`compileCodeView` заново. В полном прогоне память накапливалась даже между успешно
завершёнными сценариями. Диагностика через `WeakRef` старых портов и явную сборку мусора
подтвердила удержание; оно не доказывает утечку при обычной работе приложения
с одним загруженным модулем.

Текущий загрузчик переиспользует графы через `codeViewSlots`. Занятый слот содержит
собственные API, Monaco, router и chat; подмены читают их при обращении через слот.
После размонтирования after-хук очищает `slot.ports` и освобождает слот. Число графов
зависит от числа одновременно занятых слотов, а не от общего числа сценариев.
Перед новым mount загрузчик восстанавливает русскую локаль переиспользуемого графа.

Проверять нужно полный названный spec через сторож памяти. Успех отдельных фильтров
не доказывает, что весь файл помещается в бюджет одного процесса. V8 OOM после серии
зелёных assertions следует отличать от упавшего поведенческого ожидания и от превышения
общего RSS, которое отдельно сообщает сторож.

Переиспользование обвязки должно сохранять изоляцию портов и все assertions.
Простое кеширование компонента при прежних top-level подменах
возвращает фикстуры первого сценария: см. [изоляцию SFC](sfc-store-isolation.md).
