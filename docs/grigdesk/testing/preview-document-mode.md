# Режим HTML предпросмотра

Временный HTML стенда должен начинаться с `<!doctype html>`, как production `web/index.html`.
Перед проверкой геометрии нужно подтвердить `document.compatMode === 'CSS1Compat'`.

Предпросмотр браузера без doctype открылся в quirks mode. Chromium добавил форме
адресной строки нижний отступ 13 px при шрифте раздела 13 px. Из-за этого на снимке
между адресом и панелью доступа агентов появилась пустая полоса. После добавления doctype
отступ формы стал нулевым, а границы соседних панелей совпали без изменения их размеров.

Такой дефект следует исправлять в HTML фикстуры: дополнительный сброс margin в продукте
скрыл бы отличие режима документа, но оставил бы недостоверными остальные замеры стенда.
В браузерной проверке соседство панелей измеряется отдельно от общей ширины и переполнения.
