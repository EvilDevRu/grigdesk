# Проверка lazy-маршрутов после типизации

Таблица `web/src/router.ts` содержит многострочные объекты `RouteRecordRaw`.
Маршрут `/inbox` загружает `InboxView.vue`, а `/github` — `GitHubView.vue` через
отложенный `import()`. Перенос строки между `path` и `component` не меняет загрузку.

Регулярное выражение `path: '/inbox'.*InboxView` без флага `s` не находит такой объект:
точка не захватывает перевод строки. Уплотнение объекта ради этой проверки противоречит
правилам читаемости. Шаблон с произвольным whitespace также должен различать соседние
объекты, чтобы чужой `component` не подтвердил проверяемый маршрут.

Связь пути с компонентом проверяется по AST одного объекта либо исполнением таблицы
с подменами lazy-компонентов. `RUNTIME-router` в
`tests/web/webRuntimePreservation.test.mts` сравнивает всю таблицу с исходным снимком:
пути, имена, meta, redirects и результаты отложенных импортов.

Общие ограничения текстовых проверок описаны в
[проверках исходника после переноса на TypeScript](typed-source-contracts.md).
