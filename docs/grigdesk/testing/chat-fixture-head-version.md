# Версия шапки фиксируется до передачи изменяемого объекта в store

`protocolHead(chat)` вычисляет синтетическую непрозрачную версию по исходному JSON.
Store может дополнить переданный объект runtime-полями или нормализовать его при
применении шапки. Повторный `protocolHead(chat)` после этого уже даст другую версию.

В тестах сверки сохраняй полученную шапку до `_applyChatHead` и проверяй её `version`,
как версию уже прочитанного ответа сервера. Так `WEB-08` в `chat-store-sync.test.js`
проверяет известную серверную версию, а не хеш изменённого локального объекта.
