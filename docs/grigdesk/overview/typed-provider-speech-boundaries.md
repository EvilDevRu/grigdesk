# Типизированные границы исполнителей и речи

`stores/providers.ts` проверяет контейнер реестра и модели до замены карточек.
Произвольные provider/model/effort id остаются допустимыми. Неверный реестр сохраняет
прежние карточки, а `whenRegistryReady` сообщает отказ текущего запроса. Эпохи credentials,
порядок refresh и фильтрация моделей не меняются. Канонические модели и карточки
переиспользуют `shared/chat/providersContracts.ts`; клиентское представление настройки
оставляет её произвольное значение как unknown, чтобы рекурсивный JSON не раздувал
вычисление реактивных типов Pinia.

HTTP и общий SSE передают usage через одну проверку `features/providers/contracts.ts`.
Неверные контейнеры bars/resources не заменяют последний снимок. Проверка сохраняет
исходные объекты и расширения адаптеров. `ProviderUsageResources.vue` типизирует props
и локальное состояние подтверждения, сохраняя прежний requestId до явного повтора.

`stores/plugins.ts` проверяет переданные поля карточки и подтверждение записи.
Старые манифесты без category/group сохраняют прежние запасные карты размещения;
неизвестные поля плагина не проецируются. Неверный ACK тумблера возвращает прежнее
значение, не отправляя второй POST. Публичная форма state и id Pinia сохраняются.

`stores/notifyWatch.ts` проверяет список задач до обхода и граф до расчёта ворот.
Неверный граф остаётся неизвестным наблюдением; неверный список сохраняет прошлый
снимок и loadedAt. Наборы дедупликации и редкий страховочный интервал остаются прежними.
Клиентский envelope объявлен в `web/src/shared/pipelineContracts.ts`, отдельно от renderer DTO.

`features/speech/contracts.ts` описывает browser ports, lease, run и захват MediaRecorder.
Контроллер проверяет consent/settings до применения, не преобразуя строку в boolean.
Проверка upload принимает только строковый text, warmup использует только строковый id.
Сохраняются один provider, независимый язык речи, revision/generation, bounded cleanup,
полная запись для batch fallback и отсутствие автоматического reconnect.

`web/src/shared/speechStream.ts` проверяет читаемые поля JSON WebSocket до передачи машине
состояний. AudioWorklet получает URL выпущенного Vite JS. Очередь PCM, подтверждения,
flush хвоста, отмена и право владельца остановить MediaStream сохраняются.
