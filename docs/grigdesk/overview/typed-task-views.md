# Типы доски и карточки задачи

`BoardView` и `TaskModal` используют TS-script с прежними props, событиями,
таймерами и формой состояния. Клиентские DTO и проверки B24 принадлежат
`web/src/shared/boardContracts.ts`; общий формат вложения повторно использует
`InTurnAttachment` из `shared/chat/chatInTurnContracts.ts`.

Списки задач фабрики проверяются через `decodePipelineTasks` до публикации точек
конвейера. Повреждённый ответ не заменяет последний известный снимок. Дашборд
проверяет переданные массивы задач, числовые показатели и массивы графиков;
неизвестные расширения исходного объекта сохраняются.

Форма редактирования карточки принимает справочники только как пары строкового
или числового идентификатора и строкового имени. Неверный контейнер или элемент
даёт прежний пустой список. Комментарии проверяются перед назначением состояния;
отказ сохраняет прежний пустой fallback. Ответ загрузки вложения проверяется
по `file`, `name`, `mime` и `url` до добавления в уточнение. Неверный ответ
не создаёт миниатюру и показывает ошибку существующим способом.

Каталог запуска проверяется перед построением формы. Штатный недоступный каталог
с `defaultRoute: null`, пустыми routes и отсутствующей рекомендацией остаётся
допустимым ответом. Поля профиля, критерии, исполнители и hash сохраняются;
неизвестные расширения не проецируются. Подтверждение запуска проверяется перед
построением сообщения человеку; неверный ACK не запускает повторную команду.

Входной `UiContextDescriptor.routingScope` имеет тип `unknown`: компонент передаёт
сырой дескриптор, а store проверяет его при захвате контекста. Это уточнение типов
сохраняет прежнюю нормализацию строкового scope; переданный объект не получает
новой трактовки и не меняет выбор контекста.

Все продуктовые Vue включены в строгую проверку web без переходных исключений.
Остаток других областей и настройки отдельных сред перечислены
в [состоянии миграции](typescript-migration-state.md).
