# Типы чата и живого конвейера

Стор `chat.ts`, adapter `chatApprovals.ts`, `ChatSession` и `PipelineView` проверяются
общим строгим web-проектом. Очередь подтверждений остаётся прямым alias стора;
отдельная декларация больше не скрывает реализацию. Id сторов, storage keys,
порядок загрузки истории, pending, waiting, active и доставок сохранены.

`chatContracts.ts` проверяет оболочки HTTP, SSE и браузерных снимков до публикации.
Отсутствующее own-поле отличается от явного null: старый ответ другого окна
не стирает локальную рабочую папку или привязку к задаче. Исторические массивы
steps проверяются как контейнеры; их тела не обходятся и не клонируются ради типов.
Сообщения сохраняют вложения и неизвестные расширения, включая старые неполные
метаданные вложений. Новая загрузка файла требует строк file, name и url;
необязательный mime проверяется, если сервер его прислал.

Неверный receipt уточнения не подтверждает отправку и сохраняет прежний messageId
для сверки GET. Новый POST по другому id не создаётся. Ошибка HTTP сохраняет
статус и тело для существующих ветвей CAS и восстановления сессии.

`pipelineContracts.ts` описывает полный читаемый экраном live graph и активность,
а не только схему renderer. Проверка неверного графа оставляет прежний снимок
и показывает обычную ошибку загрузки. HTTP-отказ отдельного графа сохраняет прежний
skip. Старый граф без edges получает пустой массив рёбер; прочие поля и расширения
сохраняются. Список runner-ов проверяется перед заполнением выбора override.

Собственных JS и Vue с JS-script в `web/src` больше нет. Root allowJs выключен,
product exclude снят; tests и scripts остаются отдельными средами.
