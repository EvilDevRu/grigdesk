# Строгая проверка новых связей проекта

Создание и изменение соединений SSH и профилей БД проверяют tombstone через строгий
читатель настроек внутри `withReferences`. Проверка выполняется до изменения списка
соединений. При нечитаемых prefs запись отклоняется, существующие подключения сохраняются.

Допускающий ошибки каталог остаётся источником обзора. Сам по себе обнаруженный
физический профиль не доказывает, что регистрация доступна для новой связи.

Порты `isProjectDeleted` и `withReferences` передаются владельцам подключений из сборки
приложения. Они используют тот же реестр и ту же очередь, что удаление регистрации.
