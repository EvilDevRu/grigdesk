# Никаких проектных хардкодов в коде

Профиль — из реестра задачи (`registry.PROFILE`), список профилей — сканом
`profiles/*/graph.json` через `config.profilesDir` (`discoverProfiles`),
портал/креды B24 — из «Настроек» (`state/` папки данных),
пути (venv, снос стенда, factory bin) — через env (`GRIGDESK_*`). Пустой GrigDesk НЕ знает ни про
конкретный проект, ни про адрес портала. Не возвращать `|| '<имя проекта>'` и подобное.
