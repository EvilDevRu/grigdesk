# Типы чистых модулей web и локальных сторов

16 модулей `web/src/shared`, helper документов `features/documents/links.ts`, три helper-а
лимитов `features/providers` и локальные сторы `device`, `diff`, `dock`, `hotkeys`,
`uiContext` используют TypeScript и имена `lowerCamelCase.ts`.

Перенос сохраняет runtime-экспорты, id Pinia, форму state, ключи localStorage и порядок
lifecycle относительно согласованной входной редакции. [Форма после добавления языка](typed-web-i18n-integration.md)
включает причины ошибок устройства и дополнительные проекции лимитов. DOM, таймерный порт и формы UI-контекста принадлежат web. Геометрия графа
использует общие кортежи `shared/pipeline/factoryGraphContracts.ts`; новый серверный DTO
для представления лимитов или состояния дока не создаётся.

Ссылки на модули включают не только импорты продукта: точные ключи подмен тестов,
регулярные выражения, `new URL`, чтение исходников и performance stubs используют те же
актуальные имена. JS-script Vue остаются вне строгой проверки типов собственного script,
поэтому разрешение их импортов дополнительно проверяется сборкой и component-тестами.

Два барьера `pureModulesBehavior.test.mts` и `pureModulesMigration.test.mts` закрепляют
формы локальных сторов, раскладку маршрута, новые пути и точный набор runtime-экспортов.
Оба перечислены в `web/package.json` в `test:components`, поскольку glob `*.test.js`
не подхватывает MTS. Проверки запускаются через сторож памяти с явным списком файлов.
