# Лицензия проекта

GrigDesk распространяется под MIT. Полный текст и строка правообладателя находятся
в корневом [LICENSE](../../../LICENSE); README ссылается на этот файл.
В `desktop/package.json` лицензия указана как `MIT`.

Лицензии сторонних компонентов хранятся отдельно в соответствующих пакетах.
Например, `deepseek/build/licenses/` содержит тексты для зависимостей поставки DeepSeek.
