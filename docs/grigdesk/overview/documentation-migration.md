# История переноса знаний в документацию

**История.** Документ фиксирует перенос прежней базы знаний в Git, а не текущий размер
корпуса. Действующие правила — [поддержка документации](documentation-maintenance.md).

`docs/` доступен в обычном клоне без работающего сервера, прежней SQLite-базы и
инструмента `knowledge_search`. Причина снятия базы описана в
[истории решения](knowledge-base-history.md).

При исходной сверке учтены 268 записей: 265 общих записей собраны в 231 документ,
ещё три сохранены локально. Восемь записей уточнены при снятии плагина: его API,
инструменты, страница и регистрация перестали быть действующим контрактом.
Позднейшие документы в эти числа не входят.

Общие примеры обезличены. Локальные соответствия и опыт машины находятся в `docs/local/`,
не входят в Git и требуют отдельной резервной копии. Историю текстов и прежних адресов
сохраняет Git; для чтения используются ссылки на существующие документы.
