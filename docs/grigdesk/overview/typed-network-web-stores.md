# Типы малых сетевых сторов web

`auth.ts`, `system.ts`, `grigdeskUpdate.ts`, `taskFavorites.ts` и `taskSeen.ts`
сохраняют прежние id Pinia, ключи state и порядок lifecycle. Сетевой JSON проверяется
до присвоения реактивному состоянию; проверки не создают дополнительных запросов.

Авторизация принимает только boolean-поля configured/authenticated и строковый scope
либо прежний login. Неверный ответ проходит обычную ветку отказа: вход снимается,
ready устанавливается, подтверждение журнала не увеличивается. Ответ старой эпохи
не восстанавливает сессию после 401.

Метрики проверяют используемые числовые поля CPU и памяти. Старый ответ без блока
памяти допустим. При неверных метриках сохраняются последний снимок и updatedAt,
а stale/error отмечают отказ. WeakMap по-прежнему хранит таймер и общий летящий запрос
вне state. Опрос повторяется после завершения предыдущего запроса.

Стор обновления использует общие DTO из `shared/runtime/grigDeskUpdateContracts.ts`,
допуская частичные ответы прежнего сервера. Он проверяет переданные поля версии,
задания, причин блокировки и ошибки без проекции неизвестных расширений.
Неверный снимок не заменяет последний удачный статус. Таймеры версии и задания
остаются на уровне модуля; повторный start не создаёт второй таймер.

Избранное и отметки просмотра сохраняют нормализацию идентификаторов, scope/revision,
эпохи и порядок подтверждённых мутаций. Только отметки переиспользуют летящий Promise
в state; избранное сохраняет прежний результат повторного load во время загрузки.

`board.ts` проверяет дашборд через клиентский `shared/boardContracts.ts` до публикации
и до установки базовой линии просмотра. Тот же guard применяется к снимку relay.
Поздний GET сохраняет прежнюю проверку readAt. `tasks.ts` проверяет детали до замены
кеша; подтверждённые complete/renew обнуляют свежесть прежней записи и обновляют доску.
Непрочитанные тела команд остаются unknown.

`main.ts`, `router.ts` и `stores/ui.ts` сохраняют загрузку языка до mount, порядок
Pinia/router/device и раздельные main/surface роли. Публичная граница UI не меняется.
`App.vue`, `ToolDock.vue`, `ToolsGrid.vue` и `ToolsView.vue` получили TS-script.
Значение inert передаётся boolean; прежний незаявленный тон info уже нормализовался
UI-компонентом в neutral, теперь этот итог передаётся явно.
