# Удаление регистрации проекта

Удаление регистрации GrigDesk сохраняет папки проекта, исходные файлы, рабочие копии,
историю и ветки Git, физические профили, поднятые стенды, контейнеры и базы данных.
Оно не вызывает скрипты сноса и не очищает общие подключения или историю разговоров.

Контракт API и жизненного цикла описан в [проектах и репозиториях](../guide/projects.md).
