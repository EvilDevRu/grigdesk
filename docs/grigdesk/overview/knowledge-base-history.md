# История базы знаний

**История.** Плагин базы знаний удалён. Текущий источник знаний — файлы `docs/` и
README областей; [правила чтения и поддержки](documentation-maintenance.md).

База хранила записи и карты в SQLite вне репозитория. Новый клон не получал знаний,
хотя исходники уже рассчитывали на них. Перенос в Git сделал документы доступными
вместе с кодом и позволил проверять ссылки и оглавления автоматически.

Выборочная загрузка сохранилась: агент читает оглавление и нужный тематический файл,
а не весь корпус. Поиск выполняется через `rg` по `docs/`, без импорта областей через `@`.

Прежние `knowledge_search`, `/api/knowledge`, схемы SQLite и настройки плагина не являются
действующими интерфейсами. Их реализация и измерения старого корпуса доступны в истории
Git; команды восстановления старого плагина не нужны для чтения текущей документации.
Сверка полноты исходного переноса описана [отдельно](documentation-migration.md).
