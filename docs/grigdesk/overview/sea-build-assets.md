# Ресурсы общей конфигурации SEA

`shared/node/seaBuild.ts` предоставляет `seaConfig(assets?)`. Необязательный объект
сопоставляет имена встроенных ресурсов с файлами относительно рабочей папки сборки.
Каждый вызов создаёт новую конфигурацию и не меняет переданный объект.

Ресурс `NODE-LICENSE` всегда указывает на `LICENSE`. Вызов без аргументов сохраняет
конфигурацию сборщика Б24; дополнительные ресурсы принадлежат вызывающему пакету.
Установка зависимостей и запуск compiler/postject остаются в сборщике пакета.

Поведение проверяет `tests/deepseek/projectContract.test.mts`; совместимость существующего
сборщика проверяется быстрым набором Б24. Наличие SEA config само по себе не доказывает
работоспособность собранного ELF: для этого нужен отдельный запуск готового файла.
