# Фазы отказа при удалении регистрации

При частичном сбое `deletion_incomplete` называет первую неудавшуюся фазу:
«снимок корней», «настройки чатов» или «запись регистрации». Внешняя обработка
не заменяет это название своей фазой, а исходная ошибка остаётся в `cause`.
Финальная запись регистрации выполняется внутри очистки меты, но её отказ
по-прежнему относится к фазе «запись регистрации».

`PrefsCorruptedError` проходит через все фазы без обёртки и даёт прежний код
`prefs_corrupted`. Это относится и к ошибке, возникшей после начала очистки.
До успешного финала регистрация остаётся архивной, событие `deleted` не публикуется.
После устранения причины действие можно повторить.

Коды API и владение данными описаны в [проектах и репозиториях](../guide/ru/projects.md).
