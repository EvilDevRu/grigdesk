# Расшифровка видео сплошным потоком = у неё не было стилевой подсказки

Симптом: раздел «Видео» возвращает текст без единого знака препинания и с перемешанными
репликами — «что именно неудобно вот эти три точечки может чуть-чуть побольше». Выглядит
как слабая модель или испорченный звук, хотя `large-v3-turbo` на том же файле выдаёт
нормальную речь.

Механика: у видео `conditionOnPreviousText` зашит в `true` (`speech/options.js`, для этого
сценария настройка недоступна). Модель на первом сегменте срывается в текст без пунктуации,
а перенос контекста закрепляет стиль до конца записи — семнадцать минут встречи приезжают
одним потоком. Лечится `initial_prompt`, поэтому у видео появилась своя настройка
`videoInitialPrompt` («Настройки → Речь → Разбор видео»).

**Но подсказка — заряженное ружьё, и обе половины связки обязательны.**

- **`initial_prompt` — это не инструкция, а «уже сказанный текст», который модель
  ПРОДОЛЖАЕТ.** Заголовок с точкой продолжается речью; указание вроде «реплики записаны
  с пунктуацией, заглавными буквами и разбивкой на предложения» продолжается таким же
  указанием. Замер на записи 79 с: четыре сегмента «Реплика участников записаны с
  пунктами» вместо разговора — расшифровки не осталось вовсе. Тот же файл с подсказкой
  «Стенограмма рабочей встречи.» — 53 знака препинания и 16 нормальных сегментов.
  Поэтому дефолт короткий, а тест стережёт его длину.
- **`word_timestamps=True` включается вместе с промптом** (`word_timestamps=bool(initial_prompt)`
  в `transcribe.py`): выравнивание по словам подавляет повторы. Разорвать пару нечем —
  сторож в `speech-passthrough.test.js` запускает настоящий скрипт и проверяет оба
  параметра. Само по себе оно бесполезно: без промпта пунктуации не появляется (замер: 0 знаков).
- Параметры VAD к этому отношения не имеют: `min_silence_duration_ms` 500 против 700
  плюс `speech_pad_ms` дали ровно тот же результат. Не крутить их «заодно».

Проверять только сквозняком — реальным `transcribe.py` на реальном файле. Матрица
вариантов, собранная отдельным скриптом, показала связку рабочей, а первый прогон самого
скрипта с чуть иначе сформулированным дефолтом ушёл в петлю: разница была в двух словах
внутри промпта. Меняешь формулировку — прогоняй запись заново.
