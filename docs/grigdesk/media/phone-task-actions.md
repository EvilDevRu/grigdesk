# Добавление задачи на телефоне

На шаге «Задачи» кнопка «+ ещё задача» сохраняет полную подпись. До 520 px шапка
черновиков переносит действие на следующую строку, когда название и кнопка не помещаются
рядом. Заголовок получает гибкую ширину, кнопка сохраняет собственную ширину; размер и
оформление действия по-прежнему задаёт общий UI.

`tests/web/video-responsive.test.js` открывает настоящий раздел, передаёт синтетический
файл, дожидается расшифровки и создаёт черновик. Проверяются ширины 320/390/768/844/1024/1440,
крупный текст на телефоне, полная подпись, сенсорная площадка 44 px и добавление второго
черновика с сохранением заголовка первого. Проверка использует синтетический медиа-ответ;
распознавание, реальные файлы и Битрикс24 не запускаются.
