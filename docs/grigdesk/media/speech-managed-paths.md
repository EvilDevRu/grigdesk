# Штатный Python и ссылки в путях

Лексическое равенство `pythonPath` и `media-venv/bin/python` ошибочно скрывало
управление установкой, если штатное окружение использовало имя `python3` или путь
через alias родительского каталога. Регрессионная фикстура воспроизводит managed=false
для `media-venv/bin/python3`, хотя файл находится в том же venv.

Установщик сравнивает канонические родительские каталоги Python и штатного `bin`.
Для ещё не созданного окружения канонизируется ближайший существующий родитель,
а отсутствующий хвост сохраняется. Имена ограничены python, python3, python3.N.
Сам исполняемый файл не раскрывается через realpath: нормальный Python в venv
обычно ссылается на системный бинарник, общий для разных окружений.

Корень `media-venv` отдельно проверяется через lstat: ссылка вместо каталога
не обслуживается. Внешний `/usr/bin/python3` не становится управляемым только из-за
совпадения физического исполняемого файла. Команды установщика используют штатный
`bin/python`, а явный внешний Python сохраняет приоритет в runtime.

Проверки находятся в `tests/server/speech-install.test.js`.
