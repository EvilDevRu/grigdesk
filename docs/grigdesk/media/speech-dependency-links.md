# Установка системных зависимостей из настроек речи

При отсутствии ffmpeg/ffprobe рядом со статусом распознавания появляется ссылка
«Установить ffmpeg». Ошибка создания venv из-за отсутствующего ensurepip/venv
добавляет «Установить python3-venv». Один пакет ffmpeg содержит обе медиаутилиты.

Ссылка открывает терминал GrigDesk с командой `sudo apt install -y ffmpeg` либо
`sudo apt install -y python3-venv`. Команда вставляется без Enter: запуск и пароль
sudo остаются у человека. После установки нужно вернуться к настройкам речи,
перепроверить окружение и повторить «Обновить». Перезапуск сервера для этого не нужен.
Команды соответствуют системным зависимостям Ubuntu/Debian и производных.

Действие использует общий переход настроек. Неприменённый черновик вызывает обычный
выбор «Применить / Отменить / Продолжить редактирование» до открытия терминала.
Отказ от перехода сохраняет ввод и не отправляет команду.

Установщик возвращает необязательный dependency из закрытого списка ffmpeg/python_venv.
Старые ответы без поля допустимы. Отрицательные проверки ffmpeg/ffprobe дополняют
действие даже для прежнего сохранённого задания; успешная перепроверка скрывает ссылку.
Команды берутся из фиксированного перечня. Текст fix, ошибки и stdout/stderr остаются
данными и не исполняются. Неизвестные проверки не получают произвольной команды.

Проверки: speech-dependencies.test.js, settings-speech.component.test.js,
speech-install.test.js и общие settings-actions.test.js.
