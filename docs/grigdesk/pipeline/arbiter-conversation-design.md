# Компактное обсуждение с арбитром

`ArbiterConversation.vue` показывает подключение арбитра в шапке обсуждения: значок весов,
имя, состояние и доступную модель идущего разбора. Для этого блока окно этапа передаёт
`stageArbitrating` и убирает повторную плашку над открытым обсуждением; в журнале и настройках
плашка сохраняется. Исторический документ имеет
приоритет над признаком текущего разбора и не выдаётся за живое обсуждение.
Нижняя строка окна во время разбора показывает работу арбитра вместо ожидания человека.

Сообщения `node` вынесены в раскрываемую «Причину остановки» с подписью исполнителя или
проверки. По умолчанию видны две строки; полный исходный текст доступен после раскрытия.
Обновление документа через SSE не сбрасывает раскрытие, смена остановки его закрывает.

В переписке у каждой реплики есть автор и время, если оно сохранено. Арбитр обозначен
весами и акцентной подписью, сообщения человека стоят справа на отдельной поверхности,
служебные события имеют приглушённое оформление. Итог без отдельной реплики также
подписан арбитром; совпадающий с его сообщением текст не выводится повторно. Частичная
реплика получает подпись «пишет…», ожидание первой реплики — индикатор подготовки ответа.

Во время разбора обсуждение занимает всю ширину без пустой колонки будущих решений.
После ответа, при сбое и при неподтверждённом запросе панель действий остаётся доступной.
На узком экране она стоит перед историей, чтобы повтор и выбор не терялись под перепиской.
Поле сообщения использует общий компактный режим `workspace-note`, без отдельного скина.

Авторазбор объяснён одной строкой: «Авторазбор включён; исправление выбираете вы».
Изменение оформления не меняет допустимость обсуждения, применения и продолжения:
эти действия по-прежнему проверяются по состоянию документа и возможностям попытки.
