# Лёгкий маршрут сужал задачу молча: пустые критерии + «уже есть в коде»

Разбор прогона <TASK> (маршрут small): триаж описал объём верно, но критерии приёмки ушли в тикет пустыми (у small нет переводчика, который их формулирует). Разведка прочитала код, объявила пункт постановки «уже реализованным», сборка отбросила его «карточкой решения» в отчёте, ревью увидело дыру и отложило как «решение владельца», браузер проверил только diff — на приёмку уехала треть задачи без единого вопроса человеку. Ответы человека на два вопроса триажа были прочитаны как белый список объёма.

Что изменено: (1) триаж отдаёт scope.do/skip — по пункту на каждый пункт постановки; scope.do предзаполняет «Критерии приёмки» в форме запуска, skip показан рядом — человек подтверждает объём на запуске; (2) блок «Замкнутая область задачи» движка (engine/lib/core.sh) запрещает узлам сужать область: пустые критерии = пункты постановки как есть, «уже есть в коде» пункт не закрывает, отказ от пункта = неуспех с владельцем human, для ревью невыполненный пункт — блокирующее, не отложенное; (3) промпты профиля <PROFILE>: у scout обязательный раздел «Пункты постановки», build/review small/trivial/feature/debug — то же правило; (4) /pr-fixes: замечание про UI, принятый владельцем, — «спорно», не «чинить» (так иконка #8513 уехала во вторую строку по замечанию ревью).
