# Выбор исполнителя не закрывает окно

На вкладке «Исполнители» каждый установленный раннер занимает строку `UiSelectableRow`.
Кнопка строки меняет только черновик выбранного исполнителя; поля в actions-слоте
показывают его собственные доступные модели и effort. Переключение строки не делает POST.

«Применить» сохраняет всю связку, не закрывая окно. Сброс исполнителя также сначала
меняет черновик и после применения возвращает действующую task/profile policy. Модель
и effort сбрасываются независимо через «Из профиля».

У работающего этапа доступны сохранение для следующего запуска и отдельный явный
перезапуск с предупреждением. Для недоступного редактора прежние аварийные кнопки переключения резерва сохраняют
свою границу базовой цепочки; доступный редактор применяет только exact API. Точная семантика — [модель и effort](node-model-and-effort.md).

Запросы используют task/profile/attempt/node и объект конкретного открытия окна.
Ожидание одного узла блокирует только его действия; ответы старого каталога или
подтверждения не влияют на другой конвейер. SSE обновляет факт, сохраняя dirty draft.
Барьер — `pipeline-runner-override.component.test.js` и `pipeline-stage-isolation.component.test.js`.
