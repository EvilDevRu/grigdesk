# Выбор исполнителя не закрывает окно

На вкладке «Исполнители» каждый установленный раннер занимает строку `UiSelectableRow`.
Кнопка строки выбирает исполнителя; поля в actions-слоте показывают его собственные
доступные модели и effort. После чтения каталога клик сразу сохраняет выбор через exact API.

Изменение поля сохраняет всю связку, не закрывая окно. Сброс исполнителя сразу
возвращает действующую task/profile policy. Модель
и effort сбрасываются независимо через «Из профиля».

У работающего этапа доступны сохранение для следующего запуска и отдельный явный
перезапуск с предупреждением. Для недоступного редактора прежние аварийные кнопки переключения резерва сохраняют
свою границу базовой цепочки; доступный редактор применяет только exact API. Точная семантика — [модель и effort](node-model-and-effort.md).

Запросы сохранения захватывают task/profile/attempt/node и selection до чтения каталога.
Закрытие окна оставляет сохранение в работе; повторное открытие подхватывает выбранные
параметры и ожидание. Ожидание одного узла блокирует только его действия, во время каталога
можно заменить ещё не отправленный выбор. Завершение не меняет поля другого конвейера,
а ошибка закрытого окна показывается с исходной задачей и этапом.
SSE обновляет факт, сохраняя dirty draft.
Барьер — `pipeline-runner-override.component.test.js` и `pipeline-stage-isolation.component.test.js`.
