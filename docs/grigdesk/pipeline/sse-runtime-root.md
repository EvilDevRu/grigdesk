# Задача в UI «замирает»: SSE смотрит не в runtime root

Симптом: этап Скептик закончился, конвейер штатно встал у ворот
плана, чип «ждут тебя» в навигации зажёгся — а на схеме Скептик горел работой дальше, до
ручного F5.

Причина исторического инцидента: SSE watcher и движок смотрели в разные state roots,
поэтому запись `GATE_PLAN=waiting` не порождала `state-change`, а страница конвейера
обновлялась только по этому событию. Чип опрашивал состояние отдельно — отсюда
расхождение «чип горит, граф врёт».

После cutover runtime root один: `config.stateDir`; SSE принимает ровно его и не сканирует
исторические каталоги. Любой новый writer обязан использовать тот же root. Проверка —
`tests/server/sse-state.test.js`.
