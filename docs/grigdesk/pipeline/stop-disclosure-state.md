# Раскрытие подробностей при обновлении карточки

В [общей панели остановки](stall-panel.md) раскрытые подробности остаются открытыми
при обновлении счётчиков времени и повторном получении того же содержания остановки.
Это относится к карточке конвейера и окну задачи в представлениях dialog/document.

`PipelineStopPanel` наблюдает отдельные значения: идентификатор задачи, полный заголовок,
этап и сериализованные полки подробностей. Смена любого из них закрывает раскрытие,
чтобы другая задача или остановка начиналась с краткого вида.

Родитель может заново создать объект `view` при каждом рендере. Новая ссылка на объект
сама по себе не означает новую остановку. Наблюдение за геттером, который возвращает
новый массив ключей, ошибочно закрывает подробности при каждом таком рендере;
массив отдельных источников `watch` сравнивает их значения и сохраняет раскрытие.
