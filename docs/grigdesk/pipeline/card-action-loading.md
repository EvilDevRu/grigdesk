# Загрузка действия карточки

`PipelineView` хранит выполняемое действие отдельно для каждой задачи в
`pendingCardActions`. Пока команда выполняется и перечитывается список, все действия
этой карточки заблокированы. `PipelineCardActions` получает отдельные `disabled` и
`loading`: спиннер и `aria-busy` есть только у выполняемого действия, соседние кнопки
сохраняют видимые подписи. Карточки других задач остаются доступными.

Это правило действует для продолжения, остановки, перезапуска и сноса стенда,
закрытия задачи и запуска разбора арбитра. Отмена подтверждения не включает загрузку;
успех и отказ команды снимают её в `finally`. У массовой команды выбранные карточки
показывают загрузку соответствующего действия `resume` или `stop`.

Проверки поведения находятся в `tests/web/pipeline-stall-panel.component.test.js`:
один спиннер, блокировка соседних действий, защита от повторного запроса,
независимость другой задачи и восстановление после ответа или отказа.
