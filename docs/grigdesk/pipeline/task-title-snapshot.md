# Названия сохранённых тикетов конвейера

`GET /api/tasks` получает название каждой задачи из сохранённого тикета. Встроенный JSON
задач больше не читается и не перекрывает внешний текст при совпадении номеров.

Подтверждённые источники для `sources=1` читаются одним снимком индекса на запрос.
Сеть трекера не нужна; внешний source публикуется только после проверки trusted proof.
Пустой индекс и исторические записи не подменяются текущей доской машины.
