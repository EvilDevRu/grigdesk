# Один снимок собственных названий на запрос

`GET /api/tasks` читает хранилище собственных задач один раз для непустого
списка конвейера и строит карту по номеру. Каждая строка получает название и источник
из этого снимка; отсутствие собственной записи сохраняет чтение названия из тикета.
Полный документ не читается и не декодируется заново для каждой строки конвейера.

Снимок принадлежит одному запросу: следующий запрос перечитывает хранилище и видит
добавленные записи. Общего кеша и нового состояния нет. Пустой список не читает файл.
Ошибка хранилища сохраняет прежний отказ, а не подменяет источник задач.
