# Подтверждённый источник запуска

Сервер хранит небольшой индекс `factory-task-sources.json` в каталоге данных состояния,
путь задаёт `factoryTaskSourcesPath`. Он не меняет тикет, ключи задач и протокол движка.
Запись содержит taskId, source, отпечаток тикета, dispatchId и подтверждённую attempt.
Pending сохраняется перед spawn под блокировкой запуска. Directory lock и atomic rename
защищают индекс между процессами; файл имеет режим 0600.

Сервер получает источник из own-записи либо identity выбранного фасада до эффектов запуска.
Явный source карточки выбирает адресный фасад включённого драйвера и сверяется с его владельцем.
Без source сохраняется приоритет own, затем default. Перед dispatch внешний контекст
повторно проверяется тем же адресным фасадом; смена default его не инвалидирует.
URL и комментарии тикета, оценка и уточнения читаются у той же пары source/id.
GET launch-options и проверка expectedLaunch используют тот же source. Новый dispatch закрепляется существующим параметром движка.
Подтверждение и восстановление pending требуют совпадения dispatch, trusted attempt и
отпечатка существующего immutable ticket из control root. Mutable staging не является доказательством.
Resume сохраняет источник текущей попытки. CLI-запуски без такой связи остаются неизвестными.

`GET /api/tasks?sources=1` добавляет sourcesVersion:1 и подтверждённые внешние source.
Без opt-in внешний source отсутствует, как в прежнем строгом DTO. Own-запись остаётся
допустимым доказательством grigdesk для старого запуска. Индекс и own-названия читаются
одним снимком на запрос, сеть трекера на GET не нужна. Повреждение индекса диагностируется,
не скрывает список конвейера и запрещает перезаписать индекс пустым.

Доска, карточка и полка сопоставляют конвейер по паре source/id. Неизвестность не подменяется
текущим порталом. Триаж, его очередь, арбитр и пакет уточнений разделены по source/id;
внешние новые пакеты живут в by-source без переноса старых числовых файлов.
Физическое дерево фабрики и блокировка запуска по-прежнему адресуются номером:
одновременные прогоны разных порталов с одним id не изолированы. Запуск с explicit source
перед ранним already_running сверяет verified источник попытки: чужой даёт
409 task_source_mismatch, неизвестный — run_exists. Тикет и протокол движка не меняются.
