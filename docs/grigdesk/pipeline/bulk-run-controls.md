# Массовый запуск и остановка

В начале панели конвейера, перед вкладками проектов, стоят Плей, Стоп и разделитель.
Обе кнопки используют общие `UiIconButton` и `UiPopover` с плотностью панели.
Нажатие кнопки открывает меню; команда выполняется после выбора области:

- Плей: «Запустить все» или «Запустить все во вкладке».
- Стоп: «Остановить все» или «Остановить все во вкладке».

«Все» охватывает список конвейеров всех проектов. «Во вкладке» ограничивает его
выбранным проектом; во вкладке «Все» обе команды охватывают все проекты. Фильтр
состояния не ограничивает массовую команду. Число рядом с пунктом показывает
количество подходящих прогонов, пустой пункт недоступен.

Плей использует тот же гейт, что «Продолжить прогон»: запись доступна для управления,
есть попытка, оркестратор остановлен, результат не `completed` и не `abandoned`.
Команда вызывает `/api/tasks/:id/resume`, сохраняя текущую попытку. Работающие
конвейеры и завершённые задачи заново не запускаются. Стоп использует гейт карточки:
доступная для управления запись с работающим оркестратором, `/api/tasks/:id/stop`.

Список фиксируется при выборе команды. Занятые индивидуальным действием задачи
пропускаются; выбранные задачи блокируются и в карточках до завершения пакета.
Обе массовые кнопки также блокируются. Перед каждым запросом повторно проверяется
текущий снимок: исчезнувшая, сменившая попытку или уже сменившая состояние задача
пропускается. Для продолжения на сервер передаются попытка и профиль.

Запросы выполняются последовательно. Отказ одной задачи не прерывает остальные;
ошибки показываются одним общим сообщением с номерами задач. После пакета список
перечитывается один раз. При ошибке загрузки исходного снимка массовые кнопки
недоступны. Проверки поведения — `tests/web/pipeline-filters.component.test.js`.
