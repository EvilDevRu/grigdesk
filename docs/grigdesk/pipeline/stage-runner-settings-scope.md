# Область настройки исполнителя этапа

Настройка исполнителя, модели и effort локальна узлу
текущего прогона. Профиль и его runners.env остаются источником наследования;
переопределение не распространяется на другие узлы, задачи и новые прогоны.

Для работающего этапа включены оба режима: сохранить параметры следующего запуска
без остановки текущего и явно перезапустить с выбранной связкой после предупреждения.
Тот же исполнитель с другой моделью или только другим effort также получает новый запуск.

Настройка сначала является черновиком и сохраняется целиком только явным действием.
История и параметры текущего запуска отражают собственный факт независимо от будущего.
Технический контракт и проверки описаны в [настройках модели и effort](node-model-and-effort.md).
