# Выбор внешнего CLI для этапа

Сервер подготавливает частный дескриптор в каталоге управления. Для каждого провайдера
он содержит физический путь выбранного CLI, его identity, ключ ресурса lease и окружение
выбранного профиля. Проектный аргумент запуска не может подменить путь дескриптора.
Ключи доступа приходят в окружении участников маршрута.

Go использует этот путь для metadata-пробы и запуска этапа. Для прямых CLI
lease-helper проверяет identity и удерживает reader до выхода процесса.
Хост-обёртка Qwen выбирает тот же исполняемый файл через свой адаптер и использует
тот же API lease. При отсутствии записи провайдера используется локальный поиск CLI.

Аргументы модели содержат только флаги и подкоманды. Путь выбранного бинарника
добавляется ровно один раз. Регресс проверяют `TestExternalCLIPin` и тесты
адаптеров в `utilities/factory/internal/runner`.
