# Компоновка подвала карточки

Подвал `PipelineView` разделяет сведения о стенде и действия прогона. Слева стоят
статус стенда и группа адресов фронта/API; справа — `PipelineCardActions`. Состояние
строящегося стенда, возвраты и предупреждение об остановке остаются в группе сведений.
При нехватке ширины группы переносятся на следующие строки; отдельные адреса и действия
тоже допускают перенос без фиксированной ширины карточки.

Адреса используют `StandLink size="compact"`: основная ссылка и стрелка выбора браузера
расположены рядом с промежутком 2 px. Выбор открывается прежним `UiPopover`, стрелка
сохраняет доступное имя «Где открыть» и подсказку. Обычный `StandLink` сохраняет текстовый
переключатель. Стрелка есть только при доступном native bridge.

`UiActionLink` принимает общий `size`, как `UiButton`, и выводит `data-size` для того же
правила `actions.css`. Ссылки, стрелки и действия прогона имеют одну высоту:
28 px на desktop, 44 px на touch. Геометрия и палитра controls принадлежат UI-kit;
старое локальное правило `.strip a` удалено.

Условия показа действий, открытие стендов, выбор внутреннего/внешнего браузера,
подтверждение сноса и защита от повторного действия сохраняют прежние обработчики.
