# Границы короткого маршрута и сдачи образца

Сдача через `profile/deliver.py` принимает отдельный `--path repo:relative/path` для каждого
файла задачи. Каталог, включая `.`, отвергается до изменения index любого репозитория.
Проверка существования tracked-файла, status и add используют буквальные Git pathspec:
`*`, `?` и скобки не выбирают соседние файлы. Настоящее имя файла со скобками допустимо;
удалённый tracked-файл тоже можно сдать по точному имени. Неверный путь прерывает сдачу
с кодом 64 до stage и commit, даже если перед ним перечислены допустимые файлы.

Сочетание `workspace.mode=shared` и `delivery.strategy=pull-request` отвергается самой
сдачей до stage, commit, push и PR-команды. В shared используется рабочая ветка владельца,
отдельной ветки задачи нет. Для способа «ветка и PR» нужен isolated; автоматического
создания или переключения ветки в shared образец не выполняет.

В small приёмка за 15 минут сохраняет всю постановку, критерии и решения человека.
Часть 1 общей инструкции приёмки и структурированные доказательства выполняются целиком.
Дополнительный обзор интерфейса ограничен одной мобильной шириной, консолью, относящимся
журналом и ближайшим соседом затронутого сценария. Засев данных, обход всех экранов,
второй язык и несколько ширин обязательны только при прямом требовании постановки.
Без интерфейса используются тесты и команды. Непроверенный обязательный пункт или
недоступный стенд останавливают у человека; частичный результат не становится done.

Ревью исправляет мелкое только после сбора всех замечаний: до 30 строк на замечание,
не больше 3 файлов всего, однозначная правка без смены подхода сборки. Миграции,
зависимости, контракты, env, конфигурация окружения и закреплённые тесты не меняются.
Если хоть одно замечание выходит за границы, ревью ничего не правит и возвращает
блокеры раннему владельцу. Команды `git checkout`, `git restore`, `git stash`, `git reset`,
`git clean` и `git commit` запрещены. Раздел отчёта «Правки ревью» содержит
`id → изменение → команда и результат проверки`; после правок обязателен RECHECK.
