# Одинаковая высота действий карточки

`PipelineCardActions` явно задаёт всем кнопкам `size="compact"`.
Роли `pipeline-compact-action` и `pipeline-stall-answer-open` используют общий
`--toolbar-control-h`: 28 px на компьютере и 44 px в сенсорном режиме.
Главное действие с заливкой и вторичные действия с обводкой имеют одну высоту;
тип действия и состояние загрузки её не меняют.
До 600 CSS px площадка остаётся не меньше 44 px; длинная подпись может увеличить
кнопку по высоте, чтобы текст не обрезался в телефонной сетке действий. Все строки
сетки имеют высоту самой высокой кнопки; соседние действия растягиваются вместе с ней.

Ссылки стенда в подвале используют такой же `size="compact"` через `StandLink` и
`UiActionLink`; раскрытие выбора браузера — общую toolbar-иконку.
Расположение групп описано в [компоновке подвала карточки](card-footer-layout.md).
