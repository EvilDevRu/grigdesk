# Внешний источник оценки и конвейера

Встроенный JSON задач больше не читается ни для заголовков, ни для постановки, профиля
оценки или Telegram allowlist. Оценка читает описание и best-effort комментарии внешней
доски по умолчанию. Явный чужой source, включая исторический `grigdesk`, отвергается до
постановки в очередь. Профиль машины и ручной выбор профиля сохраняются.

Запуск использует внешний тикет, уточнения и разрешённые обсуждения. Источник захватывается
в контексте драйвера и подтверждается индексом `FactoryTaskSources` по immutable тикету
и dispatch identity. Исторические own-записи индекса читаются и сохраняются при внешней
записи, но не публикуются как активный source. Повреждённый индекс не заменяется пустым.

Заголовок списка берётся из сохранённого тикета. Внешняя карточка гидратируется через
трекер. [Общая доска](../b24/unified-board.md) и [ссылки](../web/task-source-links.md)
описывают внешнюю адресацию и безопасное отсутствие старой own-задачи.
