# Источник собственной задачи в оценке и конвейере

Источник задаёт существующая запись GrigDesk, а не номер задачи,
поле запроса запуска или сохранённый ручной тикет. Общий read-only читатель получает путь
из config и не создаёт каталогов. Старая конфигурация без пути сохраняет ветку Б24.
Ошибка чтения собственного хранилища не означает разрешение подставить текст портала.

Оценка читает исходные название и plain text описание GrigDesk с пустым списком
комментариев. Профиль определяется `projectId` до первого прогона и загружается отдельно
для каждой собственной задачи; глобальный профиль и кеш соседнего проекта не подменяют его.
Арбитр factual-вопросов получает тот же профиль номера задачи. Очередь, выбор модели,
права, вопросы и пакет уточнений остаются общими; сохранение задачи оценку не запускает.
Карточка передаёт источник операции оценки: собственная задача добавляется в своё
пространство полки grigdesk, если включена автоматическая постановка после оценки.
Проект для существующего Telegram allowlist также берётся из записи, без расширения доступа.

При ручном запуске собственные название, описание и sourceUrl сильнее тела запроса.
Критерии человека, внутренние уточнения, открытые вопросы и разрешённый разворот обсуждений
сохраняются. Блок комментариев Б24 пропускается. Ссылка ведёт в GrigDesk; построенный
preflight тикет передаётся существующему запуску без новой очереди или смены lifecycle.
Форма первоначально читает launch-options своего проекта; после явного выбора профиля
сохраняет его при обновлении каталога.

Сводка конвейера возвращает собственные `title` и `source:'grigdesk'`. Название открывает
общую карточку, имеет приоритет перед прежним кешем и не вызывает гидратацию из Б24 при
первом или повторном чтении. Старый ручной тикет без собственной записи остаётся статическим
названием с прежним поведением. Доска, запуск и действия задач Б24 сохраняют прежние контракты.

Подробности хранилища и ссылок: [собственные задачи](../b24/grigdesk-tasks.md).
