# Изоляция действий и ответов окна узла

`PipelineView.vue` хранит выполняемые действия узлов по сочетанию задачи, профиля,
попытки и идентификатора узла. Возврат курсора, решение ворот и смена исполнителя
занимают только свой узел: его действия заблокированы до завершения запроса,
а другие конвейеры остаются доступны. Закрытие окна не отменяет запрос; повторное
открытие этого узла показывает прежнее выполняемое действие. Новая попытка той же
задачи имеет отдельное состояние.

Каждое действие захватывает исходный узел до первого ожидания. После подтверждения
возврат и живое переключение исполнителя проверяют, что человек всё ещё находится
в исходном окне. Запоздалое подтверждение не отправляет команду в другое окно.
Завершение команды снимает только свою запись выполнения и закрывает только то
открытие окна, из которого команда была отправлена.

Загрузка документа и опрос активности также захватывают конкретное открытие окна.
Ответ прежнего открытия не меняет документ, загрузку или активность нового, даже
если человек повторно открыл тот же узел. Активность применяется только пока
исходный узел выполняется и его оркестратор жив.

Регрессионные сценарии с задержанными ответами находятся в
`tests/web/pipeline-stage-isolation.component.test.js`: параллельные возвраты,
успех и отказ первого запроса, ворота, подтверждение после смены окна, документы,
активность, выбор исполнителя и смена попытки.
