# Закрепление доступа конвейера

Перед spawn маршрута сервер сохраняет приватное закрепление выбранного доступа исполнителя.
Оно принадлежит задаче/попытке и не зависит от PID сервера или живого процесса движка.
Systemd и detached получают одно выбранное окружение; в systemd секреты передаются
файлом EnvironmentFile с правами 0600 и не попадают в argv.

Пауза на воротах и рестарт сервера не освобождают закрепление. Возобновление читает
прежнюю secret revision. Переключение этого исполнителя запрещено до доказанного
завершения по trusted ledger Factory. Ошибка чтения журнала блокирует переключение;
возраст файла и отсутствие PID не доказывают завершение. Другой исполнитель сохраняет
независимый допуск.

Новые профильные запуски используют отдельный каталог секретов запуска. Старый путь
`route-secrets.env` остаётся только для вызовов без профильного сервиса.
Установочный CLI lease и lifecycle-протокол Factory сохраняются отдельно от access pin.

Проверки: `access-factory.test.js` проходит HTTP start, systemd/detached, паузу,
рестарт, resume и освобождение после terminal. Реальная авторизация этапов требует
отдельного прогона с владельцем доступа.

Набор участников вычисляется из эффективных цепочек агентных этапов графа, включая
резервных исполнителей и task/stage overrides. Pins создаются в стабильном порядке.
До spawn они связаны с dispatch ID; подтверждённый start связывает их с точной
trusted attempt identity. Отказ до spawn снимает только новые pins своего dispatch.
Неизвестный исход после границы запуска сохраняет блокировку до сверки с ledger.

Добавление исполнителя этапа на паузе получает новый pin перед управляющим эффектом;
следующий resume объединяет прежние pins и новые effective chains. Живой движок может
переключаться между уже закреплёнными участниками. Для нового участника сначала нужна
пауза и resume: окружение уже запущенного процесса не подменяется незаметно.

HOME и XDG нового CLI-профиля передаются также в приватном descriptor конкретного
исполнителя. Каждый этап получает собственные пути, даже когда в цепочке несколько CLI.
Descriptor и файл окружения лежат в отдельном каталоге dispatch: соседний запуск
не заменяет снимок. Все credential env keys capabilities передаются файлом, включая
импортированный API-ключ Claude; значений этих переменных нет в argv systemd-run.
