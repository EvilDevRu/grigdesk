# Триаж GLM, Kimi и DeepSeek

Все пять исполнителей могут участвовать в триаже: Claude, Codex, GLM, Kimi и DeepSeek.
Настройка находится в «Плагины → Установленные → Триаж»; список строится по capability
`scopedWorkspace` общего реестра. Модель и effort сохраняются вместе с provider и передаются
именно его адаптеру, без подмены на Claude. У GLM дополнительно нужен допуск generation и
настроенный режим доступа; у DeepSeek и GLM runtime должен поддерживать native tool guard.

GLM, Kimi и DeepSeek используют отдельный одноразовый home и серверный файловый брокер
`executors/scopedWorkspace.ts`. Разрешённые корни кода и входов доступны для чтения, только
output анализа — для записи. Брокер предоставляет `read_file`, `list_files`, `search_files`,
`write_file`, `read_image` и, если владелец запуска передал его, bounded `repo_history`.
Явный список операций владельца дополнительно сужает этот набор: читающий арбитр не получает
запись даже при наличии output-каталога.
Поиск буквальный и ограничен по объёму; изображения возвращаются MCP-блоками image.
Shell, сеть как инструмент, внешние MCP и произвольные рабочие инструменты модели не выдаются.
Сетевая связь самого CLI с API модели и обновление авторизации сохраняются.

Пути проверяются по фактически открытому файловому дескриптору. Символические ссылки не
расширяют корни, запись через hardlink отклоняется до изменения файла. Файловые операции
ограничены по размеру, поиск — по числу файлов, глубине, объёму чтения и числу совпадений.
Режим требует Linux: проверка открытого inode использует `/proc/self/fd`.

GLM и DeepSeek запускаются через общий DSH web runtime с пустым собственным agent preset.
Собственный native guard разрешает только точные имена инструментов private MCP. До создания
сессии сервер проверяет случайное подтверждение регистрации guard; без него prompt не уходит.
GLM сохраняет свой API/coding-plan маршрут, ключ, модель, effort и проверку допуска generation.

Kimi получает минимальный config с явным `tools.enabled` и только собственным MCP.
Из исходного home подключается только каталог авторизации: чужие чаты, config и MCP не
копируются. Перед prompt сервер читает фактический каталог инструментов сессии: все штатные
инструменты должны быть выключены, все собственные MCP-инструменты — готовы. Неизвестный
активный инструмент закрывает запуск. Одноразовые процессы, IPC и каталоги удаляются после хода.

`triage-scoped-tools.test.mts` проверяет реальные файловые эффекты и обходы через ссылки;
`triage-scoped-runners.test.mts` запускает настоящие DSH/Kimi с локальными API-ответчиками:
выбранная модель читает код и записывает JSON, а каталог содержит только private MCP.
Ответчики также намеренно вызывают штатный shell-инструмент: вызов отклоняется, marker не создаётся.
`settings-plugin-model.component.test.js` проверяет выбор и сохранение всех трёх исполнителей
в настоящей системной карточке «Триаж».
