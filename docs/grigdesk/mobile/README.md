# Приложение на телефоне

Android-приложение использует общий интерфейс в WebView и локальную трубу.
Привязанные машины доступны через отдельный клиентский TLS-вход напрямую или через
посредника. Основной HTTP слушает loopback.

Читай перед правкой: `mobile/`, `utilities/relay/`, `server/src/lib/mobile/`,
`server/src/modules/mobile/`, `tools/mobile`.
