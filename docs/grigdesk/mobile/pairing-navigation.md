# Завершение привязки и навигация

`link.add()` меняет признак `paired` до завершения асинхронного обновления связи.
`App.vue` сразу открывает рабочую оболочку, и человек уже может выбрать раздел.
Безусловный `router.replace('/relays')` в завершении `PairForm.add()` возвращал его
к посредникам после перехода в чаты. В браузерном сквозном тесте шапка «Чаты» успевала
появиться, а следующий кадр уже показывал посредников.

Первая привязка поэтому не выполняет запоздалый переход из формы: оболочку открывает
`App`. При добавлении ещё одного посредника форма возвращается к их списку только
если текущий адрес совпадает с адресом на момент нажатия. Выбранный человеком
раздел не заменяется результатом старой операции.

`tests/mobile/ui-regressions.test.js` задерживает завершение привязки, меняет маршрут
и проверяет его сохранение. Там же проверяется обычный возврат при добавлении
посредника из `/relays/add`. Browser E2E проходит настоящую привязку через посредника.
