# Язык оболочки телефона

Решение задачи №93001: язык принадлежит установке :client и сохраняется независимо
от профилей машин. `ClientLocale` читает private SharedPreferences до первых сообщений
Activity; общий `ShellLocale` получает JSON, хранилище и системную Locale через порты.
Глобальная Locale, Activity, Context и постоянный WebView не пересоздаются.

`shared/i18n/assets` подключён отдельным assets root Gradle рядом с прежним `ui/`.
Проверка целостности встроенного UI не ослабляется и не включает посторонние каталоги.
Сканер, разблокировка, сохранение и собственные отказы получают строки из `native.json`.

Снимок `/__shell/state` дополнен optional `locale: {preference, systemLanguage}`.
Локальный POST `/__shell/locale` принимает только зарегистрированное предпочтение.
Он доступен без машины и при отсутствии связи; успешный commit публикует новую ревизию,
отказ сохраняет предыдущий выбор. Обработчик работает на существующем worker трубы и
не выполняет навигацию. Cookie, Host/Origin и ограничения тела запроса остаются общими.

Чистый JVM-тест запускается только через подготовленную Node-обёртку с явно заданными
`GRIGDESK_ANDROID_JDK` и `GRIGDESK_ANDROID_HOME`. Без них результат — «не проверено».
Установленное обновлённое приложение после публикации проверяют на устройстве: язык
телефона, явный выбор и перезапуск, офлайн, QR, разблокировка и сохранение файла.
Старый :app и mobile/src не входят в эту миграцию.
