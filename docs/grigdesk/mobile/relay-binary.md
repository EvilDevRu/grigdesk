# Посредник одним файлом: сборка и выпуск

`bin/grigdesk-relay` содержит посредник и официальный Node.js 24.21.0 для Linux x64.
На машине запуска не нужны Node, npm и исходники. Протокол, сертификаты, токены и настройки
`RELAY_*` совпадают с вариантом из исходников; существующий `relay.env` сохраняет личность
посредника и привязки телефонов.

## Сборка

Из корня репозитория:

```bash
tools/relay build
```

Скрипт находит совместимый Node тем же способом, что и `grigdesk-ctl desktop`: явный
`GRIGDESK_NODE_DIR`, затем общий runtime helper. Если esbuild или postject отсутствует,
ставит зависимости через `npm ci --include=dev`. Сама сборка равна команде:

```bash
npm --prefix relay run build
```

Результат — `bin/grigdesk-relay` с правами 0755, исключённый из git. Сборка печатает путь,
размер в байтах и SHA256. Локально отдельный `.sha256` не создаётся. Другой каталог задаётся
через `npm --prefix relay run build -- --out-dir /path/to/output`; относительный путь
отсчитывается от рабочей папки процесса сборки, при запуске через npm это `relay/`.
Неизвестные аргументы, пустой или повторный `--out-dir` дают код 2.

Версия, платформа и SHA256 архива Node закреплены в `relay/build/node-runtime.json`.
Архив `node-v24.21.0-linux-x64.tar.xz` хранится в `relay/.cache/`; хэш проверяется при каждой
сборке. Исправный кэш позволяет собирать без сети. Каталог исключён из git и из контекста
Docker (`relay/.dockerignore`). Загрузка идёт во временный файл,
с проверкой суммы и не более пяти попыток через десять секунд. Промежуточный `build-*`
удаляется и при ошибке. Новый исполняемый файл сначала проверяется командой `--version`
с пустым окружением, затем публикуется через временную копию и rename в целевом каталоге.
Ошибка подготовки сохраняет прежний файл.

## Ручной запуск

Положите готовый файл и свой защищённый `relay.env` в выбранный каталог. Команда читает
настройки из окружения; исходники и инструменты сборки рядом не требуются:

```bash
set -a; . ./relay.env; set +a; ./grigdesk-relay
```

| Команда | Результат и код |
|---|---|
| Без аргументов | Запуск сторожа; штатный SIGTERM/SIGINT — 0, сбой ребёнка или запуска — 1, неверный `RELAY_WATCHDOG_MS` — 2 |
| `--healthcheck` | TLS health на `127.0.0.1:$RELAY_PORT`, по умолчанию 7443; без вывода, 0 при успехе, 1 при отказе, срок до 3 секунд |
| `--version` | `grigdesk-relay 0.1.0 (Node v24.21.0, linux x64)`, код 0 |
| `--help`, `-h` | Русская справка, код 0 |
| `--license` | Встроенная лицензия Node.js целиком, код 0 |
| Неизвестный аргумент или несколько аргументов | Фиксированная ошибка без повторения аргумента, код 2 |

Справка, версия и лицензия работают без `RELAY_*` и сети, в том числе при пустом PATH.
Закрытый канал вывода не вызывает трассу EPIPE. `NODE_OPTIONS` не действует на готовый файл.
Внутренний `--worker` запускается сторожем через IPC; без IPC он даёт код 2. Ошибка настроек
в рабочей части также даёт 2.

Сторож и рабочая часть — два процесса из одного файла. Heartbeat идёт через IPC; при сбое
или зависании рабочей части сторож завершает её и выходит с 1. При штатной остановке он
передаёт сигнал ребёнку и ограничивает ожидание. Если сторож внезапно погиб, рабочая часть
получает потерю IPC, закрывает свои соединения и освобождает порт.

## Выпуск общим комплектом

Отдельный workflow `relay-release.yml` снят. Новые версии посредника раздаются
внутри [подписанного комплекта GrigDesk с сайта](../server/site-release-channel.md):
файл находится в `release/bin/grigdesk-relay`. Прежние GitHub Releases остаются
историческими выпусками, новая отдельная раздача через них не выполняется.

Общий workflow «Релиз GrigDesk» собирает посредник вместе с остальными частями.
На машину посредника он ничего не устанавливает; замену файла и сохранение
`relay.env` выполняет владелец. Мобильные и v1-потребители используют файл из
общего комплекта, их протокол обновления в этой поставке не меняется.

## Проверенный файл и ограничения

Контрольная сборка версии 0.1.0 весит 126 815 424 байта, две последовательные сборки
побайтно совпали. Это ELF x86-64 с динамическим загрузчиком Linux. По `ldd` требуются
`libdl.so.2`, `libstdc++.so.6`, `libm.so.6`, `libgcc_s.so.1`, `libpthread.so.0`, `libc.so.6`
и `ld-linux-x86-64.so.2`. Наибольшая требуемая версия символов glibc — `GLIBC_2.28`.
Alpine/musl и другие архитектуры этим файлом не поддерживаются.

Node и его OpenSSL находятся внутри файла: обновление установленного системного Node
не обновляет посредник. Для обновления Node или OpenSSL нужна новая сборка.

`npm --prefix relay test` проверяет исходники и сборочные контракты. Отдельная
`npm --prefix relay run test:sea` проверяет копию готового файла с пустым PATH: команды,
TLS, туннель, разные сертификаты, журнал, сигналы, watchdog и потерю IPC. Она не входит
в общий прогон и падает с подсказкой собрать файл, если его нет. Абсолютный путь другого
файла задаётся через `GRIGDESK_RELAY_TEST_BINARY`.
