# Поиск, архив и вид разговора

**Совместимость с прежним v1.** Этот документ относится к отдельному клиенту `:app`
и его инструментам. Полное приложение `:client` описано в [контракте клиента](client-app.md).

С версии 0.1.8 список чатов повторяет структуру веба: поиск и тумблер
«Показывать архив». Выключенный тумблер показывает активные чаты, включённый —
только архив. Три прежние кнопки и отдельная строка «Найдено» удалены из чатов.
Число рядом с тумблером относится к загруженным архивным чатам; при неполной
странице добавляется `+`. Поиск проверяет название, модель, доступное превью
и черновик текущей сессии. Ограничение страницы и «Показать ещё» остаются явными.

На планшете отдельного заголовка «Чаты» над поиском нет. С 0.1.9 шапки имеют
естественную высоту, без прежнего общего минимума 109 CSS px. Предупреждение о неполной
странице находится в прокручиваемом списке. Название занимает одну строку; модель
остаётся рядом, время расположено с превью ниже названия. Кнопка «+» создаёт чат.
Новые настройки и плотность описаны в [управлении чатом](chat-controls.md).

Кнопка «Вид чата» в шапке разговора открывает общую модалку. На планшете доступны
сворачивание списка и его ширина; на всех устройствах — высота ввода. Изменения
применяются подтверждением, «Отмена» не меняет раскладку. «Обычный вид» возвращает
значения формы по умолчанию. Эти размеры сохраняются локально, без текста чатов
или данных привязки. Повреждённая настройка игнорируется.

Скрытие списка применяется только к планшету с открытым разговором. При переходе
к списку без выбранного чата он снова доступен. Ширина ограничена так, чтобы самому
разговору осталось 350 CSS px. На телефоне сохраняются одна колонка и кнопка возврата.
В окне ниже 600 px инструменты ввода встают рядом с текстом: клавиатура не заставляет
большое поле занимать почти всю ленту. Увеличение шрифта не компенсируется его уменьшением.

## Представление хода

Соседние сообщения с одинаковым ненулевым `turnId` объединяются после первого ответа
агента. Общая линия продолжается через действия, уточнение человека и итог. Начальный
запрос остаётся снаружи; следующий ход и история без идентификатора не объединяются
на основании догадки. Порядок сообщений API не меняется. Полнота хронологии по-прежнему
ограничена [мобильной проекцией](tablet-chat.md).

Знак исполнителя виден в шапке живого хода. Сохранённому ходу без данных об исполнителе
показывается нейтральная шапка: текущая модель чата не присваивается прошлым ответам.
Иконки команд, чтения, правок и размышлений отделены от статуса результата. Превью команд
моноширинное, обычного начертания и цвета `ink-low`; интерактивные строки имеют
минимум 28 CSS px на планшете и 44 px на телефоне. Неактивные невыбранные аватары приглушены.

Текущий незавершённый шаг определяет подпись «Читаю…», «Выполняю команду…»,
«Вношу изменения…» или другую соответствующую роль. При ожидании решения показывается
«Жду вашего ответа». Без данных используется нейтральное «Агент работает…».
Кнопка остановки перенесена к отправке и сохраняет прежнее подтверждение и actionToken.

Поведение архива и возврата проверяется `ui.test.js`, группировка и состояние —
`chat-presentation.test.js`. Сценарий `chat-tablet-layout` проверяет диалог на всей матрице;
планшетные взаимодействия проверяют плотность шапок, видимость модели и индикаторов, сворачивание, ширину,
сохранение после reload и ограничение высоты при модели клавиатуры.
Сквозной DevLink-сценарий ждёт доступный переключатель архива: отдельный заголовок
«Чаты» на планшете скрыт и больше не служит признаком готовности списка.
