# Журнал контейнера посредника

Compose использует Docker logging driver `local`, один файл с размером до `1m` и
`compress: "false"`. Compression выключен явно: Docker отклоняет запуск с включённым
сжатием и `max-file: "1"` ещё до старта relay.

Журнал просматривается через `docker compose logs --tail 50` с теми же приватным env-файлом
и именем проекта, которые использовались при запуске. В журнал не записываются role-токены,
QR-коды, содержимое внутреннего TLS или привязанные устройства.

Сквозная проверка `tools/mobile-phone/e2e-local.mts` действительно собирает контейнер,
дожидается healthy, замораживает собственный дочерний relay и проверяет восстановление
Docker после watchdog, отсутствие OOM и пределы памяти/PID.
