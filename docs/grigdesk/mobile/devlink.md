# Браузерный телефон DevLink

**Совместимость с прежним v1.** Этот документ относится к отдельному клиенту `:app`
и его инструментам. Полное приложение `:client` описано в [контракте клиента](client-app.md).

DevLink — постоянный инструмент разработчика: настоящий интерфейс приложения в браузере
мозга и Node-эмулятор телефона вместо нативного `GrigDeskLink`. Эмулятор держит оба
pinned TLS-слоя, проходит через настоящего посредника и обращается к живому мобильному
входу GrigDesk. Ответы не подменяются fixtures. Это не доказательство Android-части:
Keystore, биометрия, жизненный цикл и установка проверяются на устройстве.

`PhoneEmulator` также проверяется в desktop node-link тестах. Нынешнее
[локальное окно для компьютера](../web/desktop-window.md) загружает веб GrigDesk;
[модули личности прежнего клиента](../web/desktop-window.md#сохранённые-модули-прежнего-клиента)
сохранены отдельно.

```bash
tools/mobile devlink start    # собрать dev-интерфейс и поднять user-юнит
tools/mobile devlink status   # адрес и последние строки журнала
tools/mobile devlink stop     # закрыть соединения, привязка остаётся
```

`start` поднимает `systemd --user` юнит `grigdesk-mobile-devlink`: процесс переживает ход
агента и перезапуск GrigDesk, но не перезагрузку машины. Адрес — `http://127.0.0.1:8150/`;
порт меняется через `GRIGDESK_MOBILE_DEVLINK_PORT`. Оба HTTP-входа — интерфейс и API
эмулятора — слушают только IPv4 loopback. Журнал без секретов пишется в
`<папка данных>/state/mobile-apk/devlink.log`, путь меняется через `GRIGDESK_MOBILE_DEVLINK_LOG`.

Синтетический ключ телефона, сохранённый QR с токеном посредника, привязка и durable
очередь лежат в `GRIGDESK_MOBILE_DEVLINK_DIR`, по умолчанию `~/.config/grigdesk/mobile-devlink`
с правами 0700, вне дерева проекта. Каждый запуск создаёт новый токен API эмулятора и
заново собирает интерфейс в этот же каталог: токен не позволяет чужой странице браузера
отправлять команды через loopback. Повреждённое хранилище останавливает запуск.

## Привязка и работа

Первое открытие показывает «Добавить мозг». В GrigDesk «Настройки → Доступ → Приложение
на телефоне» выдаёт QR для телефона; его текст вставляется в поле «Вставить код».
Устройство появляется в списке телефонов под именем `DevLink в браузере`
(`GRIGDESK_MOBILE_DEVLINK_NAME`). Отзыв в GrigDesk сразу показывает экран отзыва.

Разблокировка в DevLink не спрашивает биометрию: кнопка «Разблокировать» открывает окно
на 10 минут, как нативный срок; смена посредника срок не продлевает. По истечении и
после `stop`/`start` приложение снова заблокировано. Новая вкладка или перезагрузка
страницы получает `ready` уже открытого потока событий и сразу показывает «В сети».
