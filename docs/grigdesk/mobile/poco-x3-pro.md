# Совместимость с POCO X3 Pro

Проверка 22.10.2026: полное Android-приложение `:client` по объявленным требованиям
совместимо с POCO X3 Pro. Установка и работа на физическом телефоне не проверены.
Вывод относится к мобильному клиенту, подключающемуся к машине с GrigDesk;
локальный запуск сервера и исполнителей на Android этой проверкой не охвачен.

## Основания

- В `mobile/android/variables.gradle` установлен `minSdkVersion = 30` — Android 11.
  Модуль `:client` использует это значение в `mobile/android/client/build.gradle`.
- По [официальной спецификации Xiaomi](https://www.mi.com/tw/product/poco-x3-pro/specs/),
  POCO X3 Pro выпускался с MIUI 12 на Android 11, Snapdragon 860 и 6 либо 8 ГБ памяти.
  Версию Android конкретного экземпляра нужно смотреть в настройках телефона.
- Проверенный debug APK полного клиента от 19.10.2026 содержит пакет
  `local.grigdesk.mobile`, версию 0.1.0/versionCode 100 и `minSdkVersion: 30`.
  Это подтверждено `aapt2 dump badging`; `apksigner verify` завершился успешно.
  В APK есть встроенный интерфейс `assets/ui/` и нет библиотек `lib/*.so`,
  поэтому у проверенного пакета нет ограничения по ABI нативных библиотек.
- `targetSdkVersion = 36` задаёт целевое поведение Android, а не минимальную версию ОС.

## Установка и проверка на телефоне

APK устанавливается через системный установщик с разрешением установки для выбранного
источника. Для привязки и разблокировки должна быть настроена защищённая блокировка
экрана: PIN, пароль или графический ключ. Код допускает системные учётные данные
наряду с сильной биометрией, поэтому отпечаток не является обязательным условием.
Следует использовать актуальный Android System WebView.

Физическая приёмка должна проверить установку, запуск интерфейса, системную
разблокировку и Keystore, привязку к доступной машине, отправку сообщения и получение
потока ответа, а также возврат после сворачивания. Проверка метаданных APK
не подтверждает эти сценарии на конкретной прошивке MIUI.
