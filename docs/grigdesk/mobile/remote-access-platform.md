# Платформа мастера удалённого доступа

Принятое правило задачи 100000000016: первая платформа удалённого ретранслятора —
Ubuntu/Debian x64 с systemd. Мастер должен появиться одновременно в ctl и на существующей
странице «Настройки → Подключения → Доступ к серверу».

На VPS устанавливается готовый проверенный файл: Docker, Node, npm и исходники там
не требуются. Восстановление использует сохранённую дома личность ретранслятора и
не отвязывает телефон. При прежнем DNS и порте новая привязка не нужна; смена маршрута
телефона является отдельным действием с сохранением его доверия и ключа.

Это граница реализации мастера. Текущая ручная настройка описана в
[развёртывании посредника](relay-deploy.md); граница VPN для публичных и локальных адресов
остаётся прежней: [безопасность транспорта](native-security.md#граница-vpn).
