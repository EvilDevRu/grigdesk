# Грабли настоящего Android

Эти ошибки не воспроизводятся в DevLink, mock и JVM-тестах: их показал только запуск
APK на устройстве. Проверки устройства после правки `mobile/` и нативного кода нужны
именно поэтому.

## Прокси плагина Capacitor — не thenable

`registerPlugin()` возвращает Proxy, который на любое имя свойства отдаёт обёртку
нативного метода, в том числе на `then`. Такой объект, отданный из `async` функции или
`Promise.resolve`, принимается за thenable: движок вызывает несуществующий нативный
`then`, обещание не завершается никогда. Приложение висело на «Подготовке». Мост
`mobile/src/link/nativeLink.ts` поэтому скрывает `then`; браузерные мосты — обычные
объекты и ошибку не показывали.

## Сокеты закрываются не на main thread

Закрытие TLS-сокета отправляет `close_notify`, то есть пишет в сеть. Блокировка
приложения вызывается с main thread: уход в фон, истечение окна разблокировки, отзыв
телефона. Синхронное закрытие пулов OkHttp и пар пересыльщика там завершало процесс
`NetworkOnMainThreadException`. `closeTransport()` снимает ссылки на транспорт сразу,
а сами сокеты закрывает отдельный поток; поколение сессии меняется до этого, поэтому
старые соединения не обслуживают новые запросы.

## Conscrypt не инвалидирует кэш TLS-сессий

На Android `SSLSession.invalidate()` для сессии из клиентского кэша Conscrypt бросает
`UnsupportedOperationException`; настольная Java в JVM-тестах так не делает. Закрытие
клиента мозга поэтому не считает это ошибкой: SSLContext создаётся заново на каждую
разблокировку и после закрытия не используется. Уборка старого поколения в отдельном
потоке перехватывает сбои закрытия: процесс приложения из-за неё не завершается.

## Интерфейс под системными панелями

С `targetSdk` 35+ Android рисует окно под строкой состояния и жестовой панелью, а
Capacitor 8 передаёт WebView настоящие `env(safe-area-inset-*)` при `viewport-fit=cover`.
Экраны без шапки (привязка, блокировка, запуск) сами отступают от верхнего выреза,
а полоса цвета шапки закрывает строку состояния, чтобы прокрученная лента не уходила
под системные значки. Матрица визуальной проверки содержит измеренный на устройстве
размер окна планшета: [проверки](checks.md).
