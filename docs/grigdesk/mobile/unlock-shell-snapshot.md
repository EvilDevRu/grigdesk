# Снимок подключения после разблокировки

`POST /__shell/unlock` полного Android-клиента после успешного системного подтверждения
запускает подключение и возвращает полный `ShellState`: ревизию, выбранный профиль,
список машин, статус и возможности. Ответ может ещё иметь статус `connecting`;
окончательный результат приходит обычным long-poll.

Прежняя реализация Android возвращала только `{ok:true}`, а общий store применял ответ
как снимок. Это стирало профиль и ревизию: статус становился `none`, вход выключался,
нижняя панель телефона оставляла только «Разделы», хотя нативный транспорт был online.

Store проверяет форму снимка до применения и сохраняет предыдущий при некорректном
ответе. Для старых APK, отвечающих подтверждением действия, `unlock()` выполняет
отдельный GET состояния. Запоздалый снимок старой ревизии не возвращает блокировку.
Изменение не меняет срок системной аутентификации и не обходит подтверждение Android.

Контракт проверяют `ShellApiTest` и `tests/web/shell-store.test.js`, включая прежний
ответ `ok`, сохранение машины и отказ применять подтверждение действия как снимок.
