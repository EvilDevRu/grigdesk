# Ревизия политики в producer и host

`deepseek/compatibility/glm.json` задаёт ревизии, которые `buildPayload.mts`
включает в metadata нового ELF. Изменение только серверного host-контракта
не обновляет producer: пересборка продолжит выпускать несовместимый бинарник,
а живой smoke остановится на binary probe до обращения к модели.

При смене политики синхронно обновляются серверный контракт, адаптер GLM и
producer compatibility. Допуски прежней политики удаляются; новый список
заполняется только успешным живым smoke с `--admit` и включается следующей
сборкой в metadata ELF. Пустой admission не мешает проверке host-совместимости,
но не разрешает обычную установку и запуск GLM.

`tests/deepseek/metadata.test.mts` сверяет ревизии producer с host-контрактом
и адаптером, чтобы рассогласование обнаруживалось до сборки и live smoke.
