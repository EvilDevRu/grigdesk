# Монохромные иконки действий

`StepList.vue` рисует значки инструментов контурным SVG с `stroke="currentColor"`
и `fill="none"`. Общий цвет столбца значков — `--ink-mid`, без акцентных цветов
по типам инструментов. Цветные emoji в служебных значках ленты не используются.

Терминал, агент и настройки берут контуры из `web/src/shared/navIcons.ts`;
остальные контуры заданы в фиксированном наборе компонента. Неизвестный MCP-вызов
получает значок подключения, другой неизвестный инструмент — нейтральную точку.
SVG скрыт от чтения с экрана: название инструмента уже есть рядом.

Живая и сохранённая ленты используют один набор. Ширина столбца значков остаётся
15 px, зазор до текста — 7 px, как у [общей линии хода](turn-rail.md).
