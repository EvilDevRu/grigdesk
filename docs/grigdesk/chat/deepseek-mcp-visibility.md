# DeepSeek: MCP в запуске и списке настроек

У DeepSeek есть поддержка MCP. Чатовый адаптер читает проектные `.mcp.json`, объединяет
их со служебными серверами GrigDesk и передаёт в запуск DeepSeek. Формат, приоритет слоёв
и ограничения stdio описаны в [руководстве DeepSeek](../guide/deepseek.md#проектные-mcp-серверы).
Список перечитывается на каждом ходу; изменение файла подхватывается следующим сообщением.

Блок «MCP-серверы» реализован через `mcpStatus` адаптера. Раньше отсутствие этого
метода скрывало панель, хотя передача MCP в чатовый запуск уже работала. Общий каталог
по-прежнему вычисляет `mcp` по наличию метода, а интерфейс показывает блок при
`mcp && installed`. Ключ модели для списка не требуется.

Панель читает проектные файлы для явно заданной абсолютной папки GrigDesk, поэтому
в другой папке чата список может отличаться. Карточки содержат только публичные имена
stdio-серверов, выбранных reader для запуска, и показывают «Настроен» без проверки
соединения. Команды, args, env, пути и сырые ошибки наружу не попадают.
Частичный список сохраняет хорошие записи; полная ошибка отличается от пустого успеха.
Пустое состояние поясняет отсутствие выбранных для запуска серверов.

Кнопка «Обновить» перечитывает конфигурацию через общий маршрут с прежним кэшем
60 секунд. Чатовый `run()` сохранил свою передачу MCP. Подробный контракт и
доказательства — [безопасный список DeepSeek](deepseek-mcp-status.md).
