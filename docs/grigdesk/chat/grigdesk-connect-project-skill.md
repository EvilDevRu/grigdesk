# Навык подключения проекта к конвейеру

Источник навыка `/grigdesk-connect-project` хранится в `tools/skills/grigdesk-connect-project/SKILL.md`.
Доставка до пользователей — встроенная: текст входит в комплект приложения.

Сервер сам устанавливает навык: при старте он зеркалит `tools/skills` комплекта в
`~/.agents/skills`, перезаписывая имена из репозитория и не трогая пользовательские
навыки ([контракт синка](harness-skill-menu.md)). Ручное копирование осталось только
для сред без сервера GrigDesk. Синк проверяет `tests/server/bundled-skills-install.test.js`,
распознавание источника — `tests/server/harness-skill-commands.test.js`; оба работают
без запуска сервера и без записи в настоящий каталог пользователя.

Оба allowlist ресурсов (`server/build/resources.json` и `server/build/binary-resources.json`)
включают `tools/skills`. Аудит автономного payload требует
`tools/skills/grigdesk-connect-project/SKILL.md` и не разрешает другие ресурсы `tools` вне `skills`.
Регрессия копирует настоящий ресурс из обоих allowlist в изолированный комплект,
устанавливает его и проверяет пункт меню; одной проверки установщика с выдуманным
источником недостаточно. После обновления установленного приложения нужен запуск
нового сервера; перечитывание каталога исполнителей обновляет меню навыков.

У Codex навык называется `$grigdesk-connect-project`, и меню ищет его после ввода `$`;
у GLM и DeepSeek — `/grigdesk-connect-project`, поиск начинается с `/`.

Навык различает паспорт проекта, профиль фабрики и опубликованный каталог маршрутов.
После разведки он проводит интервью по восьми пунктам
[инструкции подключения](../../engine/NEW-PROJECT.md), предъявляет файлы и diff,
запрашивает одно подтверждение пакета. Секреты не собираются; проект, профиль и маршрут
выбирает человек. Существующий профиль меняется только после показанного diff.

Проверки выполняются во временном хранилище и проверочной копии профиля; рабочая
capability включается последней по [контракту профилей](../pipeline/project-profiles.md).
Доказательство результата — launch-options и форма запуска, пробная задача требует
отдельного разрешения. Реальное подключение и платный прогон не входят в статическую
проверку файла навыка.
