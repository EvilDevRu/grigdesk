# Изображения во входе Qwen

Обычный ход Qwen принимает картинки из `attachmentPaths`; уточнение в текущий ход —
из проверенных `images`. Адаптер объявляет `inTurnInput.images: true`, поэтому картинка
с текстом или без него идёт работающему агенту при доступном канале уточнений.

`qwen/images.ts` читает файлы через общий `chatImages.ts:readChatImage` только из
server-owned `attachmentsDir`. Проверяются физический корень и открытый файл,
сигнатура и расширение PNG, JPEG, GIF или WebP. Лимиты: 10 картинок, 10 МБ на файл
и 32 МиБ суммарно. Отсутствующий, неподходящий или слишком большой файл даёт явный
отказ до передачи; отмена проверяется между чтениями и после них.

Обычный `session/prompt` получает части ACP `{type: 'image', mimeType, data}` с base64.
Runtime отдельно проверяет native `agentCapabilities.promptCapabilities.image` из
handshake: старый несовместимый CLI отказывает до prompt. Поддержка транспорта
не гарантирует vision выбранной модели; её возможностями и обработкой изображения
управляет Qwen CLI. GrigDesk не переключает модель и сервис ради картинки.

Уточнение передаёт те же части через `items[].content` ответа
`craft/drainMidTurnQueue`, сохраняя `messageId` и отображаемый текст. Текстовый `messages`
остаётся для совместимости; CLI с `items` использует структурированный вариант.
Обе формы строит `qwenPromptContent`; подсказка предлагает анализировать уже вложенную
картинку напрямую. Каталог вложений в песочницу не монтируется.

После асинхронного чтения готовность хода проверяется заново. Остановка до конца чтения
не будит CLI и не ставит позднюю картинку в очередь. Принятая очередь не переживает ход.

`qwen-runtime.test.js` проверяет ACP-байты, несовместимый CLI, границы каталога,
формат, размер, количество, отсутствие файла и остановку во время чтения.
`qwen-provider.test.js` проверяет публичную capability. Две пробы
`qwen-native-tools.test.js` запускают настоящий CLI 0.27.2 с локальным тестовым API и
vision-capability тестовой модели: в обычном ходе и уточнении в API приходит
`image_url` с точными байтами PNG. Пустой текст при картинке допустим.
Это проверка доставки без оплаченного запроса; распознавание реальной моделью и
браузерная приёмка после ручного перезапуска сервера здесь не проводились.
