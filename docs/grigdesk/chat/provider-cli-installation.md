# Установка CLI исполнителя в общем окне

Claude, Codex и Kimi объявляют установку в серверном адаптере через `installation(config)`.
Первая установка Claude использует native installer, Codex — `npm i -g @openai/codex`, Kimi —
официальный `install.sh`. Обновление Claude/Codex запускает прежнюю команду настроенного бинаря.
Kimi повторяет официальный installer в host; contained не предлагает обновление и сохраняет
прежний runtime gate. Повторная первая установка поверх установленного CLI запрещена.
Управляемая поставка DeepSeek/GLM этим механизмом не меняется.

Перед запуском общий диалог показывает имя и команду из карточки сервера. Браузер передаёт
только id в URL: `POST /api/providers/:id/install/start` или `update/start`, тело отсутствует
либо `{}`. Любые имена полей отвергаются 400 до admission. Общая авторизация `/api` действует
и на эти маршруты. Старый `POST /api/providers/:id/update` ждёт тот же сервис и возвращает
прежний финальный ответ: отдельного обхода блокировки у старого клиента нет.

Одна операция занимает весь GrigDesk, включая другие вкладки. Сервер сохраняет running до
ответа 202, а окно можно закрыть без остановки процесса. `GET /api/providers/installations/current`
и отдельное событие общего SSE `provider-install` возвращают атомарный снимок с revision,
активной операцией и последними исходами. Прогресс не отправляется через `providers-update`:
каждая строка команды не должна заново собирать реестр моделей.
Первое чтение сохранённых итогов также не запускает пересборку. Один refresh нужен при
завершении увиденной активной операции; подробности — [вывод и сообщения](provider-install-output-and-messages.md).

Скачивание и установка — одна честная фаза: внешний installer выполняет их одной командой.
Затем идут проверка версии и обновление списка моделей. Все три фазы используют бегущую полосу
без процентов. Объединённый stdout/stderr очищается от терминальных управляющих последовательностей
и ограничен 200 строками и 32 КиБ, включая незавершённую строку. Публикация вывода объединяется
с интервалом 100 мс, смена стадии и итог сохраняются сразу.

Успех требует нулевого кода команды и распознанной версии именно настроенного CLI. Итоги:
установлен, обновлён с прежней версии на новую, уже последняя версия, отказ или прервано.
Если известная свежая версия новее действующей копии после команды, показан отказ проверки.
Сбой обновления списка моделей сохраняет успех CLI с отдельным предупреждением и не обещает
пересборку каталога.

Приватное состояние лежит в `provider-installs/state.json` папки данных. Записи атомарны и
синхронизируются на диск; ownership worker хранится приватно до разрешения запуска supervisor.
При следующем обращении после рестарта running становится interrupted, команда не повторяется.
Чужой PID не завершается: несовпавшая identity или повреждённое состояние блокируют новые старты.
При остановке сервера сервис прекращает admission и завершает только собственный worker.

Команды работают с правами и HOME сервера, без sudo и входа в аккаунт. npm выбирается только
из абсолютных каталогов PATH; в packaged собственный npm поставки исключён. Созданный объявленный
native bin-каталог добавляется в конец PATH перед probe, без замены настроенного bin.
Ранее открытый PTY сохраняет прежнее окружение: после первой установки окно подсказывает
переоткрыть терминал, если shell сообщает «команда не найдена».

После успеха «Войти» передаёт только login-команду встроенному терминалу. При отказе доступна
прежняя запасная команда через «Открыть в терминале». Ни установка, ни эти действия не отправляют
Enter. Переход из открытых настроек проходит общий dirty-переход; отказ сохраняет окно и черновик.
Все собственные надписи окна есть на русском и английском. Перезагрузка и hello/reconnect
перечитывают снимок; поздний ответ старой машины отбрасывается по client scope.

Проверки используют fake adapters/models/runner и собственные временные процессы. Настоящие
installers меняют окружение общей машины; повторный запуск внешнего Kimi installer проверяет
владелец после публикации. Автоустановки нет: фоновые проверки версий только сообщают о релизе.
