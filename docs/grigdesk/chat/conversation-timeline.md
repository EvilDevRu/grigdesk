# Ответы в хронологии хода

`web/src/views/chat/chatTimeline.ts` строит общую проекцию истории и текущего хода для
`ChatSession.vue`: старт, действия, реплики человека и агента, следующие действия, итог.
Массив истории не переставляется и не получает служебных сообщений интерфейса.

Порядок реплик внутри запуска задаёт `sequence`. Текстовый шаг с тем же
`assistantMessageId` определяет место ответа среди действий; если такого шага нет,
используется `startedAt`. Уточнение привязывается по серверному `receipt.acceptedAt`.
Для старой истории без времени и вытесненных шагов место ограничивается соседними
известными репликами; ответ не переносится перед начальным `start`.

Показанный ответ заменяет текстовый шаг с тем же id. Черновик и завершённый блок имеют
один ключ, поэтому при переносе в историю не меняют место и не дублируются. Обновления
инструмента и его результат остаются рядом с первоначальным вызовом, даже если между
ними пришло уточнение. Группы разных запусков не смешиваются.

Служебные заметки подготовки между запросом человека и первой репликой агента
остаются перед стартом запуска. Это относится и к сообщению о новой сессии после
смены профиля или папки. Пока агент только размышляет и вызывает инструменты,
растущий ход не вставляется перед заметкой: она не удерживается под индикатором
у поля ввода. Первая реплика и завершение хода не меняют место заметки.

После завершения участки действий сворачиваются на своих местах. Строка старта остаётся
видимой перед ответами. Промежуточная реплика не повторяет шапку агента и не имеет
собственной рамки: [общая линия и колонка иконок](turn-rail.md) связывают весь запуск.
Превью ограничено четырьмя строками; фактическое переполнение
показывает «Показать полностью». Итоговый ответ остаётся полным, без такого ограничения.

Проверки: `tests/web/chat-timeline.test.js` — порядок, восстановление, отсутствие дублей,
инструменты через границу реплик и несколько запусков; `chat-in-turn.component.test.js`
— тот же порядок в настоящем `ChatSession`, переход из живого хода в историю.

Действия субагента относятся к участку его вызова и стоят выше поздней реплики или
уточнения: [правило расстановки вложенных шагов](subagent-step-placement.md).
