# Проверяемый архив поставки DeepSeek

`deepseek/scripts/packagePayload.mts` упаковывает проверенную generation, обычный
worker Node, его `NODE-LICENSE` и bootstrap worker. Полный license inventory generation
обязателен: проверяются notices и SHA256 каждой указанной копии лицензии. Родительские
каталоги сборки, настройки и homes не обходятся.

Стандартный ZIP через fflate хранит только файлы. Отдельный индекс сохраняет каталоги,
относительные ссылки, modes, размеры и SHA256 байтов. Сжатие потоковое, записи отсортированы,
дата ZIP фиксирована. Временное расположение сборки и порядок создания файлов не входят
в индекс или архив. Повторное чтение источников при сжатии сверяет их с индексом.

`deepseek/src/runtime/payloadIndex.ts` проверяет типы записей, канонические относительные
имена, родителей, цепочки ссылок и замкнутость индекса. При чтении ZIP неизвестная или
повторная запись, неверные bytes/размер, пропущенный файл или изменённый архив дают отказ.
Хеш всего ZIP защищает также его окончание. Потребитель не доверяет одному имени файла.

Manifest поставки включает индекс и хеш ZIP. Поэтому его packageId охватывает payload
вместе с generation, worker, launcher, admission и binaryVersion. Адреса исходной сборки
в manifest не записываются; посторонние файлы UI не являются входами этой упаковки.
