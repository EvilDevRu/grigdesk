# Исчезнувший профиль задачи и сохранённая папка

Доверенный профиль задачи задаёт корни разговора, если его регистрация есть в каталоге
или помечена tombstone. Неизвестный профиль без tombstone пропускается: разговор
использует сохранённый выбор папки, как до добавления удаления регистрации.
Пропавший профиль сам по себе не означает удалённую регистрацию.

Tombstone сохраняет доверенный ID для проверки исторического снимка корней. Он не
разрешает новый выбор проекта; рабочие инструменты по-прежнему фильтруют профиль
через доступный каталог. Рабочие копии задачи имеют высший приоритет.

Общий порядок и проверки путей описаны в [рабочей папке чата](chat-workspace.md).
