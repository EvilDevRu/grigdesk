# Постоянная высота окна установки исполнителя

Общий диалог установки и обновления CLI имеет высоту 480 px, ограниченную доступной
высотой окна минус 40 px. Правило задано у поверхности `UiDialog` в общих стилях
`overlays.css`, по `data-role="provider-install-dialog"`.

Появление вывода, раскрытие «Деталей», смена фазы и итог операции сохраняют внешние
размеры окна. Шапка и нижние действия остаются за пределами прокручиваемого тела;
длинное содержимое и хвост команды прокручиваются внутри существующих областей.

При ширине экрана до 600 px сохраняется общий полноэкранный режим `UiDialog`.
В низком окне ограничение высотой viewport сохраняет доступ к закрытию и действиям.

Браузерная проверка на экранах 1280×800, 1280×420 и 390×780 подтверждает одинаковые
высоту и положение диалога при ходе установки, раскрытых деталях, успехе и отказе.
Компонентные проверки окна продолжают покрывать действия и раскрытие вывода.
