# Компактное меню моделей на десктопе

Навигация исполнителей в каталоге моделей одинакова на desktop и touch: видны цветные
знаки без подписей и счётчиков. Каждый знак сохраняет имя исполнителя в `aria-label` и
`title`. Кадр знака — 16 px; площадка desktop использует `--toolbar-control-h` (28 px),
а сенсорный режим увеличивает её до 44 px. Кнопки остаются controls общего UI-kit.

Предпочтительная ширина меню — 360 px с прежним ограничением по `visualViewport`.
Поле поиска использует ту же toolbar-высоту, рабочий фон `--surface-2` и скругление 4 px.
В этом компактном меню фокус поиска обозначен тонкой акцентной рамкой без внешнего
ореола: общий `--control-focus-ring` для поиска переопределён в `fields.css`.

Проверка `SELECT-CHAT-BROWSER` измеряет ряд иконок, высоту, скругление и фокус поиска
на десктопе и сенсорных размерах. Вместе с полными снимками сохраняется отдельный кадр
меню, чтобы знаки и поле можно было оценить без уменьшения всего desktop-экрана.
