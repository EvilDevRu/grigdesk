# Ошибки в ленте чата

Сообщения с ролью `error` показываются отдельной карточкой `UiInlineMessage` с тоном
`danger`: значок, переводимый заголовок «Ошибка», исходная причина и действие
«Как решить проблему» в следующем ряду. Цветом выделены значок и левая граница;
текст причины использует обычный цвет для чтения.

Карточка занимает ширину содержимого до 680 px и ограничена шириной ленты.
Причина выводится целиком как обычный текст: HTML и ключи перевода не интерпретируются,
переводы строк сохраняются, длинные пути переносятся внутри карточки.
Закрытия и автоматического повтора операции у карточки нет.

Кнопка помощи использует общий `UiButton` с вариантом `ghost` и открывает статью
`troubleshooting` поверх разговора. Это не отправляет запрос модели и сохраняет
черновик. Семантика `role="alert"` принадлежит общему `UiInlineMessage`.

Разметка — `ChatSession.vue`, оформление — контекст `chat-turn-error` в общем
`feedback.css`. Ошибка загрузки истории остаётся отдельным
[уведомлением под шапкой](message-load-notice.md).
