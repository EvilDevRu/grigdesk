# Удаление проекта и восстановление чата

Создание записи истории проверяет только явно выбранную регистрацию проекта. Оно не
читает стенд или попытки фабрики: историю задачи можно открыть ещё до появления стенда.
При разрешении файлов пустой ответ `readEnv()` означает отсутствие стенда, а непустой
повреждённый env по-прежнему даёт `invalid_sandbox_env`.

Перед удалением регистрации снимок корней перечитывает профиль без допускающего ошибки
кэша. Ошибка исполнения профиля, неполный ответ или ошибка доступа к каталогу прекращают
операцию в фазе «снимок корней». Регистрация остаётся архивной; после исправления профиля
повтор сохраняет корни и завершает удаление. Успешно прочитанный пустой профиль допустим.

После восстановления SSE стор чатов сверяет `defWorkdir` и `recentWorkdirs` с сервером.
Несохранённый локальный выбор сохраняется. Изменение во время запроса, событие меты или
удаления и более новый запрос не позволяют позднему ответу откатить выбор. Полученная
по SSE мета считается серверной, поэтому следующая сверка не принимает её за черновик.
Рабочие папки существующих разговоров этой сверкой не меняются.
