# Перевод пояснения host-политики Kimi

`directSshPolicy().note` и host-ветвь `settings()` адаптера Kimi сообщают одну фразу:
«Host-режим проверяет команды перед запуском; сбой проверки оставляет команду запрещённой».
Её русский текст, включая конечную точку, совпадает со значением
`settings.builtinProviderText.kimi.hostPolicy`. Английская запись описывает ту же проверку
команды перед запуском и сохранение запрета при отказе проверки.

`providerMetadataMessage()` распознаёт собственную подпись точным сравнением с русским
каталогом. Поэтому устаревшее пояснение о невозможности обеспечить запрет ломает перевод
сразу в двух местах; `check:i18n` сообщает две находки для одной отсутствующей фразы.
Изменение каталогов исправляет пояснение и не меняет действующую политику команд.
