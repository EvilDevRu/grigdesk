# Цельные текстовые блоки Qwen

ACP передаёт `agent_thought_chunk` и `agent_message_chunk` как дельты. Один ответ
мог стать десятками карточек «Размышление» и строк с отдельными словами, поскольку
адаптер отправлял каждую дельту непосредственно в общий sink как готовый шаг.

`qwen/steps.ts:createQwenTextSteps` собирает последовательные дельты одного рода
в один блок. Пробелы и переводы строк между кусками сохраняются. Пустой текст и
служебные metadata-события не разрывают блок. Смена рода текста, вызов или результат
инструмента, запрос разрешения, final guard и drain уточнений закрывают накопленный
блок до действия.

Время блока — первая дельта; его id обозначает именно смысловой блок. Память буфера
ограничена `STEP_THINK_LIMIT` либо `STEP_TEXT_LIMIT` с маркером сокращения. Полный
ответ собирается runtime отдельно и этим ограничением не обрезается. Завершение,
ошибка и отмена выпускают хвост ровно один раз; replay загрузки сессии остаётся скрытым.
Перед prompt публикуется `start` с подтверждённой моделью, папкой и режимом.

В чате законченный текстовый блок также публикуется как `onAssistantMessage` с тем же
id. Реплика видна отдельно от свёрнутых шагов; последний полный блок становится
финальным ответом. Предыдущие ответы в том же ходе остаются в журнале и не дублируются
в финале. Без callback публикации, например у factory runner, результат сохраняет
собранный текст всего хода. [Доставка уточнений](qwen-in-turn.md).

## Старые сохранённые ответы

Qwen объявляет `legacyTextStepDeltas`; `/api/providers` передаёт этот признак в
`capabilities`. Общая лента склеивает соседние `think` или `text` без id только при
этом признаке. Граница инструмента и другой род шага сохраняются; новые блоки с id
не склеиваются. Ветвления Vue по вендору нет.

Это проекция отображения: JSON истории и тексты реплик не переписываются. Существующие
длительности и ключ первой строки сохраняются; раскрытие не теряется при пересчёте.
Без capability поведение остальных исполнителей остаётся прежним.

Проверки: `qwen-stream.test.js`, `qwen-runtime.test.js`, `qwen-provider.test.js`,
`qwen-cli-contract.test.js` и `step-list.test.js`. Они покрывают живую и сохранённую ленту,
лимиты, ошибку потока, отмену, reader lease и отображение прежних токеновых шагов.
