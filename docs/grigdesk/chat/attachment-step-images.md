# Вложения в миниатюрах шагов

Агент и окно читают вложение разными путями: агент открывает файл инструментом,
а раскрытая строка `Read` запрашивает его через `GET /api/chat/:id/image?path=`.
Успешное чтение агентом не гарантирует, что маршрут окна разрешает этот путь.
Подпись «Изображение недоступно» при успешном итоге `Read` относится к миниатюре.

Маршрут изображений включает общий каталог `<chatsDir>/attachments/` в `imageRoots`
рядом с артефактами и каталогами исполнителя. Он работает для всех исполнителей и
сохранённых шагов независимо от расположения рабочей папки разговора. Отсутствие
каталога вложений не мешает читать картинки из остальных корней.

Вся папка чатов этим не открывается: соседние файлы, каталог с похожим префиксом,
выход через `..` и symlink на файл за пределами разрешённых корней отклоняются.
Сохраняются общий auth guard, проверки realpath и открытого fd, формата и размера
изображения, а также `private, no-store`.

Проверка: `CHAT-IMG-06d` в `tests/server/chat-images.test.js` воспроизводит запрос
миниатюры вложения вне workdir и проверяет перечисленные границы. До добавления
каталога маршрут возвращал `403 outside_workdir` для существующего вложения.
