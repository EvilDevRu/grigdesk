# Свёрнутые детали установки CLI

В общем окне установки и обновления исполнителя вывод команды скрыт по умолчанию
под кнопкой «Детали» со стрелкой. Правило одинаково для активной операции, успеха,
отказа и прерывания. Краткий итог и фазы остаются видимыми.

`UiDisclosureButton` управляет показом хвоста, `aria-expanded` и связью `aria-controls`.
Повторное нажатие сворачивает вывод. Новые строки и смена статуса той же операции
сохраняют выбор человека; новая операция и повторное открытие окна сбрасывают его.
Сырой вывод остаётся текстом и не переводится; подпись кнопки доступна на RU/EN.

Компонентные проверки покрывают раскрытие, повторное сворачивание, новое открытие,
смену операции и конечные статусы. Браузерная проверка покрывает успех и отказ
на узком и широком экранах в обоих языках.
