# Старые ответы на границе типов чата

Клиентский `web/src/shared/chatContracts.ts` проверяет используемые поля, сохраняя
совместимость частичных ответов. Для загруженного файла обязательны строки `file`, `name`
и `url`. Отсутствующий `mime` допустим: файл остаётся в черновике и отправляется обычным
путём после текущего хода. Присланный `mime` должен быть строкой; произвольное значение
не превращается в достоверные метаданные вложения.

Предпросмотр рабочей папки требует строки `transfer` и `workspaceKey`. Числовая `revision`
необязательна для старого ответа: подготовка отправки использует ключ папки, а подтверждение
перехода передаёт revision, если она получена. Отсутствие revision не должно скрывать
обычное требование подтвердить перенос при `reseed` или `unavailable`.

При инициализации неявного выбора подтверждённая недоступность папки по-прежнему выбирает
GrigDesk. Сетевая ошибка сохраняет выбор и выбрасывается исходным значением, включая
тип `Error`. Внутренняя проверенная проекция статуса и тела нужна для выбора этой ветки,
но не заменяет саму ошибку, которую получает вызывающий код.

Поведение закрепляют `tests/web/chat-in-turn.component.test.js` и
`tests/web/chat-workdir.test.js`; неверные загрузки дополнительно проверяет
`tests/web/webViewBoundaries.component.test.mts`.
