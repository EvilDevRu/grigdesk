# Изображения DeepSeek в ленте действий

Harness читает изображения отдельным инструментом `read_image` с аргументом
`file_path`. Нормализатор `server/src/lib/deepseek/steps.ts` приводит его к общей
строке `Read`: `title` содержит имя файла, `sub` — исходный путь. Правило общее
для web-потока и ACP, которые используют `deepSeekToolStep`.

До исправления `read_image` попадал в fallback неизвестного инструмента. Его строка
содержала JSON аргументов без `sub`, поэтому общий просмотрщик ленты не получал
путь изображения и показывал только текст результата с `[изображение]`.

После успешного результата раскрытие строки показывает миниатюру через маршрут
картинок чата. Ошибка инструмента остаётся текстом без миниатюры; байты изображения
в шаги не записываются. Ограничения форматов и каталогов остаются общими для
[изображений ленты](step-images.md). Преобразование имени не меняет допуск
инструментов GLM и возможности модели.

Изменение применяется к новым вызовам после ручного перезапуска сервера GrigDesk.
Сохранённые шаги прежних ходов не переписываются.

Проверки: `tests/server/deepseek-steps.test.js` проверяет каноническое имя,
`tests/web/step-list.test.js` передаёт настоящему компоненту шаги нормализатора
и проверяет адрес миниатюры, путь с пробелом и кириллицей, отсутствие байтов
в ленте и текст отказа инструмента.
