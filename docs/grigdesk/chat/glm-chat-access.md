# Доступ в чате GLM

Кнопка рядом с полем ввода открывает сведения о текущей рабочей папке, модели, поиске,
доступных вкладках и проектных MCP. Сервер разрешает сохранённый чат и его рабочую
область. Запрос не запускает модель или проектные процессы. Сводка ошибок считает
связанные пары вызова и результата в загруженной истории без вывода аргументов.

## Инструменты

Политика v5 проверяет вызовы до эффекта. Та же конфигурация запуска ограничивает
схемы, отправляемые модели, ещё до записи заголовка запроса Harness. Дополнительные
каталоги остаются доступными только для чтения. Возможность читать изображения
соответствует входам закреплённых моделей Z.ai. Вкладки перечисляет действующий
брокер для владельца этого чата.

Для веб-поиска в чатах GLM используется отдельная переменная службы
`GRIGDESK_GLM_SEARCH_API_KEY` с ключом DeepSeek для Anthropic-совместимого поиска.
Если ключ пуст, схема `web_search` исключается. `web_fetch` остаётся доступным.
Настроенный ключ означает наличие конфигурации. Доступность проверяется при вызове.

Вызов `/mcp имя запрос` в обычном сообщении предлагает подтвердить запуск одного
stdio-сервера из `.mcp.json` текущей рабочей папки или корня её репозитория. После
решения человека запись сверяется ещё раз. Каждый вызов инструмента требует отдельного
подтверждения. Native gate связывает решение с конкретным вызовом и его аргументами.
Субагент без прямого канала подтверждения не получает проектный MCP.

## Цели

Явная команда `/goal описание цели` открывает штатные инструменты создания и изменения
цели в этом запуске. `/goal resume` возобновляет сохранённую цель через RPC Harness.
При активной цели после штатного завершения очередного хода сервер ждёт нативный раунд
в том же процессе и с теми же правами. Счётчик и завершение выводятся из событий Harness.
Предел — 16 автоматических раундов. Ожидание старта следующего раунда ограничено 15 секундами.
«Стоп», ошибка и исчерпание лимита закрывают запуск. Работу после остановки возобновляет
новое явное сообщение. Обычный ход может прочитать цель и завершается как прежде.

Политика этапов конвейера и список их инструментов не меняются. Для установки нужна
совместимая поставка Harness и новый допуск нужного режима GLM.

Интеграционные тесты выполняют цели и MCP на собранном Harness. Поисковый провайдер
и модель отвечают синтетическими данными. Живая проверка с ключами пользователя
относится к допуску отдельного выпуска.
