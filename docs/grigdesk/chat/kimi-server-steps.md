# Лента серверного транспорта Kimi

Серверный адаптер `server/src/lib/kimi/serverTurn.ts` переводит кадры
Kimi в нейтральный контракт [ленты хода](agent-turn-feed.md). Vue и ядро чата не знают
формат поставщика. ACP использует собственный нормализатор и сохраняет прежнее поведение.

## Размышление и порядок

Последовательные `thinking.delta` основного агента собираются в один `think`.
Внутренние пробелы и переводы строк сохраняются; края обрезаются. Блок из одних пробелов
не публикуется. Буфер ограничен, опубликованный текст подчиняется `STEP_THINK_LIMIT`.

Границы блока: вызов или результат инструмента, непустая реплика, вопрос/разрешение
и его разрешение, начало/конец шага или хода, передача принятого уточнения в активный ход.
Уточнение закрывает блок до ожидания HTTP-доставки: пришедшие во время ожидания дельты
относятся к следующему блоку. Отказ доставки не отменяет уже принятую реплику человека.
Usage и частичные статусы не делят мысль. Новое размышление после границы — отдельный блок.
Шаг получает время первой дельты, чтобы отложенная публикация не переносила его за
уже принятое [уточнение](conversation-timeline.md).

При завершении, отмене, ошибке и закрытии потока непустой хвост выпускается до выхода.
Буфер очищается перед публикацией: повторное завершение не создаёт дубль.
После завершения драйвер не принимает поздние кадры этого хода.

## Инструменты

`tool.call.started` становится `tool` с тем же `toolCallId` (или `tool_call_id`) в `id`:

- `name` — непустое имя из `name`/`tool_name`, запасное — «Инструмент»;
- `title` — описание `display.description`, первая строка команды, путь, поисковый запрос
  или имя инструмента, в этом порядке;
- `command` — команда из `display.command` либо `args.command/cmd/script`, доступная
  в раскрытии с существующим ограничением длины и сохранением начала и конца;
- `sub` — путь из `display.path`, `args.path/file_path` либо поисковый glob;
  пробелы по краям пути сохраняются, в том числе в `files/changes`;
- `preview` — ограниченные аргументы для подробностей неизвестных и MCP-инструментов;
- `files/changes` — прежняя форма правки с путём и точной парой `diff: {old, new}`.

MCP сохраняет исходное имя: общая лента умеет показывать сервер и название метода.
Незнакомый инструмент остаётся подписанным. `tool.result` публикует отдельный `res`
с тем же `id`, `ok` и текстовым выводом; компонент присоединяет его к своему вызову,
в том числе при обратном порядке результатов и реплике между вызовом и результатом.
Два разных id остаются разными действиями. Полный мультимедийный viewer сюда не входит.

## Сохранение и применение

Общий sink одинаково передаёт нормализованные шаги в callback живого хода и в `steps`
для сохранения. Повторное открытие читает тот же формат. Старая история не переписывается.
Проверки используют синтетические кадры через `kimiUsageWire` и настоящий `StepList`:
`tests/server/kimi-server-feed.test.js`; прежний серверный lifecycle проверяется
в `tests/server/kimi-server-turn.test.js`.

Изменение касается отображения. [Политика команд](kimi-command-policy.md), native Bash,
SSH/БД, broker, режимы разрешений, модель, настройки и версия Kimi остаются прежними.
Применение серверных изменений выполняет человек ручным перезапуском; исполнитель
не перезапускает живой сервер из чата.
