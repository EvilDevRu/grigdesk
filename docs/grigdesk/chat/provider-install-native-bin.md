# Проверка нативного npm-bin исполнителя

Исполняемый файл npm-пакета может быть JavaScript или готовым Linux ELF. В частности,
нативная поставка Claude Code использует bin `bin/claude.exe` и на Linux: расширение
файла не определяет платформу и не означает, что его нужно открывать через Node.

`externalVersion` читает только четыре первых байта установленной копии. ELF с magic
`7f 45 4c 46` запускается непосредственно с `--version`; остальные входы сохраняют
проверку через закреплённый внешний Node. Обе формы получают внешнее окружение операции,
ограничение времени и размера вывода. Затем выполняется обычный probe адаптера.
Привязка bin сохраняется только после обеих успешных проверок.

Прежний безусловный `node <bin> --version` отвергал рабочий нативный файл после успешного
npm-install. Распознавание формата исправляет эту проверку без повторной загрузки пакета
на этапе определения версии и без изменения пользовательского PATH.

Проверки: `provider-install-environment.test.js` покрывает ELF с именем `.exe` и JavaScript
с недоступным shebang, который обязан использовать выбранный Node. Сквозной тест сервиса
в `providers-install-npm.test.js` проверяет нативный bin настоящим Claude probe и сохранение
проверенной привязки. Нативной заглушкой служит Node ELF на временном пути; npm и реальные
пакеты владельца в тестах не запускаются.
