# Прочтение чата во время загрузки ленты

При открытии непрочитанной шапки адресная загрузка сообщений и PATCH `unread:false`
могут выполняться одновременно. В задаче №93038 они согласуются внутри одной
singleflight-загрузки; собственная отметка прочтения не требует ручного повтора.

Перед применением detail окно дожидается уже поставленного в очередь PATCH этого чата.
Если последнее принятое поколение принадлежит его собственному PATCH, совпавшая версия
полной ленты принимается. При несовпадении окно автоматически перечитывает только эту
ленту, сохраняя состояние загрузки. Повторный ответ обязан соответствовать подтверждённой
версии; устаревшая лента не становится основанием записи или ссылок на steps.

Поколение чужой правки, удаления или dispose по-прежнему запрещает применять поздний
ответ. Несохранённая разница метаданных сохраняется поверх принятой ленты: например,
снятая метка непрочитанного не возвращается, если GET успел раньше дебаунса PATCH.
Серверная копия остаётся основанием dirty-проверки, поэтому местные правки затем сохраняются.
