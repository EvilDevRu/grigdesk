# Служебная информация в ленте

`StepList.vue` показывает названия инструментов (`Bash`, `Read`, `Edit`) цветом
`--ink-mid` с насыщенностью 500. Превью команд, подписи размышлений, сводки действий
и строки старта используют `--ink-low`. Модель в строке старта использует
`--ink-mid` с насыщенностью 500. Все значки действий используют нейтральный
`--ink-mid`; их [монохромные контуры](activity-icons.md) не зависят от emoji-шрифта.

Цвет модели, пути и доступных лимитов в строке текущего хода задаёт
[контракт активной строки](active-run-status.md). Нейтральный класс `muted` у лимитов
наследует цвет этой строки: глобальный `.muted` иначе возвращает прежний `--ink-mid`.

Проверять результат нужно по вычисленным цветам текста в настоящем браузере,
включая названия инструментов, превью команд и доступные лимиты. Один снимок
модели и пути не проверяет иерархию всей технической ленты.
