# Просмотр картинки в черновике

Миниатюра и имя неотправленного изображения в `ChatSession.vue` — одна кнопка общего UI.
Клик, Enter или Space открывает существующий `MediaViewer.vue` через
`stores/documentPreview.ts`, как и изображение из истории сообщений.

Стрелки просмотрщика перебирают только изображения текущего черновика в порядке чипов.
Картинки истории в этот набор не входят; при открытии картинки из истории черновик тоже
не добавляется в её галерею. Используется тот же адрес вложения через `api.url`.

Крестик остаётся отдельной кнопкой: удаляет вложение, не открывая просмотр.
Открытие и закрытие просмотра сохраняют текст и список вложений черновика.
Остальные файлы показываются прежними чипами с именем и кнопкой удаления.
