# Строка состояния только во время работы

Сведения о модели, папке и лимитах дополняют существующий индикатор активного хода.
Они собраны компактно у правого края через `·`, как в топбаре; кегль и ступени цвета —
в [контракте базовой линии](run-status-baseline.md). Правые сведения используют
`--ink-low`, на 30% смешанный с фоном `--surface`; доступные лимиты наследуют этот цвет. Между фактами
нет растянутых колонок; строка остаётся одним рядом.
Недоступные лимиты, загрузка и окна без числовых данных скрыты вместе с разделителем;
нулевой остаток остаётся виден. Сведения об ошибках доступны во всплывашке исполнителя
в топбаре. Не поместившиеся модель, путь и окна лимитов уходят целиком во всплывашку
«+N» ([размещение](run-status-placement.md)), полные значения есть и в общей подсказке `v-tooltip`.
Правый блок — обычный текст; уровень надписей совпадает с левым блоком
по [контракту базовой линии](run-status-baseline.md). Время и счётчик токенов слева
сохраняются целиком: обрезание счётчика создавало лишнее троеточие после числа. От десяти
тысяч счётчик записан коротко — «113 тыс.», «1,2 млн» с округлением вниз, чтобы цифры не
мельтешили на каждом тике; точное число — в подсказке значка.

На узкой панели скрываются декоративные точки индикатора и сокращение «ток.»;
значение счётчика не обрезается, а его смысл объясняют значок и подсказка.

В простое, при отправке, ожидании очереди и переносе папки строки нет. Обычная работа,
фоновый запуск со снимком и запуск без подтверждённых метаданных используют прежний хвост
текущего хода; неизвестные параметры не заменяются настройками следующей отправки.
«Фоновая активность» остаётся для событий старого сервера без `runId` и запуска со
`snapshot: null`. Фон с полным снимком показывает модель и папку своего процесса.

При сжатии контекста в конце ленты остаётся только спиннер слева от «Сжимаю контекст».
Правого блока и обычного индикатора `ChatThinking` в этом состоянии нет. Кольцо контекста
в верхней панели сохраняет свою анимацию. После завершения сжатия строка исчезает.

Размещение внутри ленты определяет [контракт расположения](run-status-placement.md).
Переходы работы, сжатия и простоя проверяет `tests/web/chat-status.component.test.js`;
геометрию, целый счётчик токенов и общую базовую линию нужно проверять в браузере.


Подсказки различают метрики: счётчик — «Выход текущего хода», кольцо — «Контекст сессии»,
квоты — «Осталось по аккаунту». Для каждого доступного окна общая подсказка показывает
срок сброса и время замера, если они известны. Во всплывашке исполнителя обратная шкала
подписана «Израсходовано». Истёкший срок помечает прежние значения устаревшими;
отказ вендора по-прежнему скрывает квоты активной строки, оставляя их во всплывашке.
