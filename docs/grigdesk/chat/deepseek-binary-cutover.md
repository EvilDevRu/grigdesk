# Первый переход на автономный Harness

DeepSeek переносит home чата из `generations/<legacyBuildId>/chat/<chatHash>/home` в стабильный
`chats/<chatHash>`. Legacy buildId читается из `server/runtime/deepseek/current` целевой
установки. BuildId нового ELF может отличаться и для поиска прежней памяти не используется.
GLM переносит home из `<compatibility[:16]>/<chatHash>` в `chats/<chatHash>` по неизменной
compatibility допущенной поставки.

Перенос выполняется под отдельной блокировкой через rename. Журнал и native settings
сохраняются; marker заменяется на `{format: 1, provider}`. Receipt позволяет закончить
перенос после прерывания между rename и публикацией marker. Если новый home уже есть,
используется он, а старый остаётся на месте. Соседние identities не затрагиваются.

Адаптер временно объявляет прежние security profiles через `legacySecurityProfiles`.
Ядро сохраняет sessionId и переписывает профиль через CAS, только если совпадают провайдер,
папка, модель, ключ и прежняя формула с актуальными правами. Смена прав или модели по-прежнему
ротирует сессию. Адаптеры без hook сохраняют обычное поведение. Hook предназначен только
для первой поставки; во второй его можно удалить после завершения перехода всех установок.

Проверка версии журнала выполняется и после переноса: читаемый журнал продолжается,
несовместимый начинает новую сессию с заметкой и сохранением ленты. Отсутствующий журнал
даёт отказ, а не скрытый сброс. Откат бинарника на совместимый ELF поддерживается;
возврат с новой схемы homes обратно на embedded не поддерживается.
