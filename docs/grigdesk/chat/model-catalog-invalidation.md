# Инвалидация каталога учитывает ВСЕ входы

- **Инвалидация каталога учитывает ВСЕ входы.** `CATALOG_SCHEMA` в `_meta` — версия правил
  отбора: меняется вместе с логикой, иначе у работающих экземпляров GrigDesk останется список, собранный
  по старым правилам. Локальный Claude-каталог пересобирается по версии CLI, схеме и
  executor-owned `catalogCacheKey(config)` — отпечатку влияющего окружения (сейчас это
  состояние `CLAUDE_CODE_DISABLE_1M_CONTEXT`); живой Codex-каталог — ещё и по минутному кэшу.
  Простого рестарта достаточно, чтобы новое значение env вступило в силу: ручной
  `?refresh=1` для этого не требуется.

Источник до переноса: docs/grigdesk/chat-agents.md § Инвалидация каталога учитывает ВСЕ входы.
