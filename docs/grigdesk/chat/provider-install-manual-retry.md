# Кнопка повтора установки CLI

После отказа или прерывания установки и обновления общий `ProviderInstallDialog`
показывает кнопку «Повторить» / «Retry». Она доступна также после отказа запуска,
сохранённого отдельно от серверного итога. Успешная и выполняющаяся операции эту
кнопку не показывают.

Повтор сохраняет исполнителя и вид действия: первая установка снова вызывает
`install/start`, обновление — `update/start`. Используется общий `requestInstall`
с подтверждением актуальной команды из карточки сервера; отмена сохраняет прежний
итог. Введённая вручную команда и терминал для повтора не требуются.

Пока серверная установка занята, отправляется запрос, исход запуска неизвестен
или сервис заблокировал новые операции, кнопка отключена. Запасное действие
«Открыть в терминале» остаётся рядом; «Повторить» служит основным действием окна.
Автоматические сетевые повторы внутри одной операции сохраняют прежний контракт.

Проверки: `tests/web/provider-install-dialog.component.test.js` и
`tests/web/provider-install.browser.test.js`. Они проверяют запуск через общий
протокол и доступность действий на узком экране без настоящей установки CLI.
