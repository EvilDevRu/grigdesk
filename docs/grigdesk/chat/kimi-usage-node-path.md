# Проверка лимитов Kimi сохраняет путь к Node.js

`requestKimiManagedUsage` запускает `kimi web` с окружением из `usageBrokerEnv`.
Раньше эта функция задавала `PATH` как каталог выбранного Kimi и системные каталоги
`/usr/local/bin:/usr/bin:/bin`, теряя каталог пользовательского Node.js.

Проверено на npm-поставке `@moonshot-ai/kimi-code` 2.3.3: entry `dist/main.mjs`
начинается с `#!/usr/bin/env node`. Если Node.js установлен только в пользовательском
каталоге, тот же CLI работает в терминальном окружении, но даже `--version` с окружением
брокера сразу завершается с кодом 127 и `/usr/bin/env: 'node': No such file or directory`.
Обнаруженная установка Kimi и совпадение с командой терминала этого не исключают.

Теперь брокер передаёт неизменённый родительский `PATH`. В подготовленном внешнем запуске
`externalCliProcess` сохраняет вместо него `PATH` пользовательского shell-снимка; собственные
`HOME`, каталог Kimi, кэш и флаги брокера остаются адресными переопределениями. Ограниченный
системный PATH используется только при отсутствии родительского. Копировать Node в npm-prefix
или подменять внешний CLI серверным ELF не требуется.

Раньше `error` и `close` завершали ожидание готовности значением `null`, а общий обработчик
выдавал `startup_timeout` и при раннем выходе. Теперь они дают `spawn_failed` с сообщением
«GrigDesk не смог запустить локальную проверку лимитов Kimi». Сохраняются ошибка spawn,
stderr либо код/сигнал завершения. Только истечение срока ожидания даёт `startup_timeout`;
производственное умолчание — 30 секунд. Ошибка получения статистики сама по себе не
подтверждает исчерпание квоты.

Источники: `server/src/lib/kimi/usage.ts`, `usageBrokerEnv`, `requestKimiManagedUsage`,
`classifyKimiUsageResponse`. Регрессия `tests/server/kimi-usage-startup.test.js` запускает
настоящий npm-shebang с Node в отдельной папке и проверяет прямой/подготовленный запуск,
ошибку spawn, ранний выход, сигнал и настоящий таймаут с остановкой своего процесса.
Живая read-only проверка npm Kimi 2.3.3 исправленным адаптером получила окна и ресурсы
без запуска модели.
