# Уведомление о загрузке истории

`ChatSession` показывает состояние адресной загрузки истории под шапкой разговора.
Название и настройки чата сохраняют своё положение при загрузке и отказе.
Пока история не подтверждена, приглашение пустого разговора не показывается.

Загрузка использует нейтральный `UiInlineMessage` со спиннером. Отказ использует
предупреждающий тон, иконку, переводимый заголовок и исходную причину из стора.
Кнопка «Повторить» с иконкой повторяет существующий `ensureChatMessages`:
состоянием попытки и защитой от параллельных загрузок по-прежнему владеет store.
После успеха уведомление исчезает.

Оформление принадлежит общему `feedback.css`, контекст `chat-message-load`.
При ширине контейнера до 480 px кнопка переходит под текст. Длинная причина
переносится внутри блока. Внешние отступы задаёт раскладка чата.
