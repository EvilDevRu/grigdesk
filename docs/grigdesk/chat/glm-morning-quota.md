# Утренний расход квоты GLM

03.11.2026 повторно сверены [обзор Coding Plan](https://docs.z.ai/devpack/overview)
и [обновление планов](https://docs.z.ai/devpack/notice/usage-revision), расчёт тарифа
и ответ работающего API GrigDesk. Модельные запросы не выполнялись.

## Часы и скидка

Пик по-прежнему идёт по будням с 14:00 до 18:00 по Сингапуру (UTC+8), то есть
06:00–10:00 UTC. Для зоны UTC+7 это 13:00–17:00. До 13:00 и после 17:00 действует
расход вне пика; суббота и воскресенье по Сингапуру целиком относятся ко времени вне пика.

Для текущих кредитных планов, индивидуальных и Team Plan, одинаковый модельный расход
токенов вне пика стоит 0.5×, в пик — 1×. Это дополнительно сверено по отдельной странице
[Team Plan](https://docs.z.ai/devpack/teamplan). Для прежних планов из объявления
GLM-5.3 использует 1×/3×, GLM-5.3-Flash — 0.4×/1.2×.
Поэтому меньший утренний расход согласуется с опубликованными условиями. Отдельного
дополнительного утреннего окна скидки эти страницы не объявляют.

Число сообщений не позволяет сравнивать списания: важны модель, количество входных,
кешированных и выходных токенов каждого запроса. Проверка правил и текущего ответа
не доказывает правильность каждого списания провайдера.

## Результат проверки

Свежие Markdown-страницы разобраны штатными `parseGlmPricingPage()` и
`compareGlmPricingPage()`: оба источника дали `verified`, без расхождений часов,
дней, часового пояса и коэффициентов. Константы тарифа не изменялись.

`glmTariffResource()` проверен в зоне `Asia/Novosibirsk` на раннем утре, непосредственно
перед началом и окончанием пика, на обеих границах, после пятничного пика и в выходные.
Начало пика входит в окно; с 17:00 уже действует расход вне пика.

Утренний `GET /api/providers/usage` работающего сервера вернул свежий успешный GLM
и ресурс «Тариф» со значением «вне пика до 13:00». Проценты квот по-прежнему приходят
от Z.ai: локальный расчёт пика их не умножает.

HTTP-тест кредитных окон явно задаёт успешный `probe`: он проверяет передачу квот,
а не наличие установленного GLM на машине. Без этого независимая проверка наличия
runtime останавливала опрос до вызова подменённого транспорта кабинета.

После исправления прошли все 72 профильные проверки тарифа, сторожа документации,
кредитных окон, адаптера usage и общего компонента интерфейса.

Контракты: [тариф](glm-tariff.md), [кредитные окна](glm-credit-windows.md),
[индивидуальный и командный планы](glm-plan-variants.md), [наличие CLI](provider-cli-presence.md).
