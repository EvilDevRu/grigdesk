# Правка и запись файла в запросе разрешения

Карточка `ChatPermission.vue` принимает две формы предпросмотра правки: готовый
`diff: { old, new }` и исходную пару строк `old_string` / `new_string`. Обе формы
показываются в существующем двухколоночном диффе. Пустая строка допустима с любой
стороны, поэтому удаление и вставка сохраняют предпросмотр.

Строковое `content` показывается как содержимое записываемого файла, если запрос
не содержит готовых `details`. Переводы строк, пробелы и полный текст сохраняются;
HTML в содержимом остаётся текстом.

Готовые `diff` и `details` имеют приоритет. Исходные поля исключаются из запасного
JSON только когда использованы для предпросмотра. Неполная пара, неверные типы,
неизвестные параметры и исходные поля при готовом предпросмотре остаются видимыми
в подробностях. Разбор общий для исполнителей и не изменяет исходный запрос или
решение политики.

Это обработка в интерфейсе: сохранённый запрос получает тот же предпросмотр в окне
с обновлённым [пакетом приложения](../web/packaged-ui.md). Одна сборка `web/dist` не
обновляет встроенный интерфейс уже установленного окна. Проверки двух форм правки,
удаления, вставки, записи и запасного JSON находятся в
`tests/web/chat-permission.component.test.js`.
