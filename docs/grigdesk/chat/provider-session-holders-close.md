# Живые сессии держат копию: инспекция holders и подтверждение закрытия

Живая сессия чата с внешним CLI (Codex, Claude, Kimi) удерживает reader lease
на выбранную копию: обновление и переустановка обязаны сначала освободить её.
Раньше занятая копия выражалась только отказом `provider_in_use` с текстом
«Живой процесс не освободил копию за отведённое ожидание», а протухшая запись
мёртвого holder-а блокировала exclusive до первого acquire.

## Метка разговора в lease-записи

Открытие живой сессии чата оборачивает spawn адаптера в `withExternalCliLeaseJob`:
helper `external-cli-lease` получает `--job <chatKey>` и пишет его полем `jobId`
lease-записи. Probe, usage и прочие короткие запуски пишут запись без метки —
окно установки видит только PID и возраст. Метка проходит валидацию журнала и не
содержит окружения CLI.

## Инспекция и чистка журнала

`inspectCliLeases` берёт mutex провайдера, прогоняет `retainRecords` — мёртвые
записи исчезают из файла уже на этом проходе — и возвращает живых readers:
PID владельца (helper), PID CLI,sessionId, метку разговора и возраст процесса
по starttime из /proc. Preview `prepare` отдаёт список полем `holders`, отказ
старта с `provider_in_use` — тем же полем в теле 409.

## Подтверждение закрытия в окне

Модал установки при непустом `holders` до старта показывает отдельное
подтверждение: список разговоров и процессов с возрастом, кнопка «Закрыть
сессии и продолжить», отмена возвращает прежний вид. Подтверждение вызывает
`POST /api/providers/installations/v2/:id/sessions/close`: `terminateCliLeaseHolders`
шлёт SIGTERM (через 5 с — SIGKILL) группе владельца записи и записанному child,
сверяя starttime перед каждым сигналом, чтобы переиспользованный PID не получил
чужой сигнал. Ответ отдаёт остаток живых: непустой список оставляет окно на
повторе вместо старта.

## Верхняя граница helper-а

Цикл release после выхода CLI ограничен двумя минутами: осиротевший потомок в
сессии CLI больше не держит helper вечно. Запись при таймауте остаётся и
снимается следующим inspect или подтверждённым закрытием.

## Проверки

- `tests/server/provider-install-leases.test.js` — holders с меткой разговора,
  чистка протухшей записи, terminate живой цепочки holder/CLI.
- `tests/web/provider-install-store.test.js` — подтверждение закрытия до старта,
  отмена и остаток живых после close.
