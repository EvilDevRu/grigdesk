# Параметры разрешения вместо сырого JSON

Native gate GLM передаёт в `input` карточки исходные параметры инструмента. Это уже
разобранный JSON: прежний запасной блок показывал `justification`, `sandbox_permissions`
и `timeoutMs` как неизвестные поля.

Общая карточка `ChatPermission.vue` отображает строковое `justification` отдельным
обоснованием, без повторения описания, команды или подробностей. Строковое
`sandbox_permissions` показывает уровень доступа: только чтение, запись в рабочую папку
или полный доступ. Незнакомое строковое значение сохраняется буквально.
Конечный неотрицательный числовой `timeoutMs` отображается в секундах, включая ноль.
Подписи переводятся общими каталогами RU/EN; текст агента остаётся исходным.

Неизвестные параметры и неверные типы этих полей остаются в запасном JSON-блоке.
Отображение не меняет исходный запрос, решение политики или разовое подтверждение.
Разбор общий для всех исполнителей, без проверки имени GLM в Vue. Он применяется
и к уже открытой карточке после обновления интерфейса; перезапуск сервера не требуется.

Проверки формы native-запроса, неизвестных полей, неверных типов и нулевого таймаута:
`tests/web/chat-permission.component.test.js`.
