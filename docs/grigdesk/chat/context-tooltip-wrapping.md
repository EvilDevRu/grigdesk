# Перенос длинных значений в подсказке контекста

`ChatSession.vue` показывает значения метрик в правой колонке подсказки контекста.
Сохранённый замер во время нового хода дополняется подписью «прошлый ход, ждём замер»;
она может быть шире колонки в панели с шириной содержимого 260 px.

Все значения `.ctx-pop-value` разрешают перенос строк и имеют `min-width: 0`.
`overflow-wrap: anywhere` удерживает в колонке и длинные непрерывные фрагменты.
Выравнивание по правому краю и табличные цифры сохраняются. Отдельного исключения
для строки кэша нет: одинаковое правило действует на каждую метрику.

`white-space: nowrap` здесь выводит текст за границы подсказки даже при
`minmax(0, 1fr)` в сетке строки: ограничение колонки само по себе не переносит текст.
