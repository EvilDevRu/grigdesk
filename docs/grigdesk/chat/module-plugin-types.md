# Типы плагинов при отдельном импорте модуля чата

Модуль чата явно подключает типы `@fastify/multipart` и `@fastify/websocket` через
`import type {}`. Эти пакеты расширяют объявления Fastify: добавляют `request.file()`
и перегрузку маршрута с `websocket: true`, где первый аргумент обработчика — сокет.

Веб-фикстуры импортируют модуль отдельно от серверного приложения. Поэтому наличие
расширений в общей серверной проверке типов не гарантирует их наличия в
`npm --prefix web run typecheck:tests`. Явные импорты сохраняют типы обеих программ
без приведения запросов к сокетам и без ослабления проверок.

Импорты типов удаляются при исполнении. Регистрацией обоих плагинов по-прежнему
владеет `server/src/app.ts`; отдельный импорт модуля её не выполняет.
