# Смена ИИ внутри чата

- **Смена ИИ внутри чата** (Claude ↔ Codex): sessionId прежнего исполнителя несовместим — фронт
  сбрасывает контекст автоматически (история чата остаётся). Конфликтов между ИИ нет: каждый
  запуск — отдельный процесс, сессии в реестрах своих CLI. Это ручное переключение чата,
  не аварийный failover конвейера.
- Настройки → «Исполнители»: у недоступного показана команда установки (из `executor.install`);
  клик по ней открывает Терминал с уже введённой командой. Команда кладётся в exact-once
  intent-очередь `stores/dock.ts` до открытия route/dock; живой Terminal принимает её сразу,
  закрытый создаёт ровно один reconnect, параллельные команды делят connecting socket.
  В PTY текст отправляется только после первого вывода shell и без Enter — запуск остаётся
  за человеком.
  Папку конкретного разговора выбирают кнопкой 📁 рядом с задачей; общего списка
  доверенных каталогов в настройках больше нет.
- Справочные подсказки используют `UiTooltip`, интерактивные — `UiPopover`; оба приходят
  только из `web/src/ui.ts`. Топбар (исполнители, IP, CPU/RAM, хост) и микрофон чата не
  используют системный `title` как единственный канал. Provider-popover закрепляется кликом
  (повторный клик, клик мимо или Esc закрывают). Раньше клик по иконке уносил в настройки, и на
  планшете (ховера нет) тап показывал полосы лимитов ровно до перехода на другую страницу —
  прочитать их было нельзя. В настройки теперь ведёт кнопка «Настройки исполнителей»
  внутри самой всплывашки.
- Codex: `codex app-server` по stdio JSON-RPC; новый чат использует `thread/start`, продолжение —
  `thread/resume`, затем `turn/start`. `sandboxPolicy` задаёт `workspaceWrite`, writable roots
  и сеть, `approvalPolicy` равен `never`. Notifications нормализуются в ленту в реальном
  времени; summary рассуждений виден, если его отдал сам CLI. Авторизация = наличие
  `~/.codex/auth.json`.
