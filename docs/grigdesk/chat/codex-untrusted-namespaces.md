# Codex: декларации инструментов в недоверенном ходе

`server/src/lib/executors/_codexUntrusted.ts` запускает одноразовый app-server
с пустым списком сред, sandbox read-only без сети и выключенным code-mode host.
Перед отправкой пользовательского ввода проверяются подтверждённые CLI среды,
источники инструкций, рабочие корни и политика разрешений. Запрос инструмента
через server request завершает transport с отказом.

Отключённый host сам по себе не означает пустое описание code-mode оболочки.
CLI 0.162.1 добавляет декларации встроенных инструментов даже при пустом списке
сред. Поэтому `features.code_mode.excluded_tool_namespaces` содержит и `clock`,
и `functions`. Это исключает вложенные декларации, сохраняя выключенный host.
Внешняя оболочка exec остаётся; попытка исполнения получает `code-mode host is disabled`.

Проверка `tests/server/codex-untrusted.test.js` запускает установленный CLI
с временным состоянием и локальным HTTP-приёмником вместо модели. Она проверяет
фактические отправленные инструменты, отказ exec, отсутствие правил и MCP из
тестового config, изображения байтами и очистку временных данных. Assert на
отсутствие `declare const tools:` сохранён: его нельзя заменять предположением
об изоляции по одним launch flags.
