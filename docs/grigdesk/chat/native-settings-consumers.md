# Области дополнительных настроек

Каталог protocol 1 совместимо поддерживает области `grigdesk-chats` и
`grigdesk-chats-and-pipelines`. Необязательные `appliesTo` и `consumerSupport`
показывают подтверждённую поддержку поля для чата и конвейера.

У встроенного candidate DeepSeek каталог объединяет настоящие web- и ACP-схемы.
`llm-deepseek.maxTokens` подтверждён в обоих профилях;
`subagent-model-selection.enabled` присутствует только в web. У внешнего runtime
без проверенного частного settings-контракта сохраняется область чатов.

Отказ ACP discovery означает непроверенную совместимость. Чатовая форма сохраняется,
но новый узел с таким override останавливается до prompt. Доказанно чатовые поля
не передаются конвейеру. Несовместимые схемы не становятся редактируемыми.

Ownership и secret-запреты объединяются до проекции. Secret-предок или leaf любого
профиля скрывает значения, defaults и enum также из другого профиля. Известные
ACP-запреты сохраняются при последующем отказе discovery.

Оба consumers используют прежний контейнер `nativeSettings` format 1 в PrefsStore.
Подготовленный снимок неизменяем; новое сохранение действует со следующего запуска.
Consumer, cwd, mode и runtime входят в identity подготовки. Другие исполнители
получают настройки конвейера только при явно объявленной capability.
