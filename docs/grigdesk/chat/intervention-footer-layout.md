# Длинный запрос не сжимает кнопки решения

У `ChatIntervention.vue` тело и нижняя панель — соседние элементы вертикального flex.
Карточка ограничена по высоте, поэтому длинная команда, план или список вопросов должны
сжимать прокручиваемое тело. Нижняя панель использует `flex: none`: её высота определяется
действиями и ограничением `max-height: 190px`, без участия в flex-сжатии.

При `flex-shrink: 1` у нижней панели длинная команда забирала почти всю доступную высоту:
от панели оставались отступы, а кнопки оказывались внутри её скрытой области прокрутки.
Проверка в Chromium с командой из 250 строк воспроизводит это на широком, узком и низком
экранах, с галкой разрешения на сессию и без неё.

Прокрутка нижней панели сохраняется для собственного длинного списка вариантов решения,
который превышает 190 px. Обычная пара кнопок целиком видна без прокрутки панели.
