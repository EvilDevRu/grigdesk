# Управляемая поставка исполнителя

`distribution(config, probe?)` синхронно описывает поставку из конфигурации и готового
результата проверки. Без probe возвращаются только способ доставки и подсказка входа;
файлы и процессы этот метод не проверяет. `bin(config)` также только выбирает путь.
Версии, packageId и ошибки доступны карточке после асинхронного probe.

DeepSeek и GLM объявляют `managed: true` для embedded и binary. Реестр провайдеров
использует этот признак: скрывает установку и login, запрещает update-route с кодом
`no_update`, не вызывает latestVersion и не показывает предложение автообновления.
Остальные исполнители сохраняют собственные проверки и команды обновления.

GLM читает входы compatibility из metadata binary descriptor либо через асинхронно
проверенный legacy артефакт. Чистое описание
поставки не даёт допуска к запуску; список допуска и формула compatibility проверяются
отдельно. Синхронное описание generation остаётся только у legacy CLI.
