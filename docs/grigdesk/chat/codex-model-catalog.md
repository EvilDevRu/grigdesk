# Список моделей Codex — ИЗ ОФИЦИАЛЬНОГО APP-SERVER

- **Список моделей Codex — ИЗ ОФИЦИАЛЬНОГО APP-SERVER** (`model/list`, `includeHidden:true`):
  это модели, доступные именно установленному CLI и текущему ChatGPT-аккаунту, вместе с
  display name, поддерживаемыми effort, default, hidden и рекомендацией `upgrade`. Вызов
  read-only: thread/turn и обращение к модели не создаются, `OPENAI_API_KEY` не нужен.
  **Окна контекста в контракте `model/list` нет.** Запись Codex поэтому помечена
  `contextRuntimeOnly` и не подставляет паспортное окно API либо прежнюю заглушку 400k:
  это другие величины, а заглушка выглядела проверенным свойством модели. До первого хода
  picker честно пишет, что рабочее окно появится после него; затем выбранная модель и кольцо
  показывают точный `tokenUsage.modelContextWindow` этой thread. Внутренний fallback 200k
  нужен только для безопасной арифметики до замера и человеку как факт не показывается.
  Каталог живой (`catalogLive`): сервер перечитывает его при обновлении минутного кэша,
  а открытый UI раз в минуту перечитывает `/api/providers`. Новый rollout появляется без
  релиза GrigDesk; кнопка «Перепроверить» делает это немедленно.
