# Фильтр доступности в выборе модели

`ChatSession.vue` строит группы селекта только для исполнителей с `available === true`
и `chatEnabled !== false`. Наличие прежних моделей в каталоге не заменяет положительный
статус доступности. Поэтому недоступный Claude с сохранёнными моделями не получает
ни вкладку со знаком, ни строки в выбранной группе, «Все» и поиске.

Проверка доступности общая для групп и текущего native option. Если скрытый исполнитель
сохранён в разговоре, закрытое поле продолжает показывать прежнее имя, а его native option
становится скрытым. Модель, `modelRef`, память и история не меняются автоматически.
Если скрыты все исполнители, открытый каталог пуст и не показывает запасные модели.

Установленный исполнитель без вариантов получает в подвале адресное действие с причиной
и переходом в его карточку. Общей кнопки «Настроить исполнителей» в списке нет;
без адресных действий подвал отсутствует. Действие не является моделью, не меняет выбор
и не сбрасывает память. Имена моделей не содержат оговорок о размере контекста:
неизвестное или неточное окно объясняется в подсказках модели и индикатора контекста.

После обновления реестра положительный `available` возвращает вкладку и модели через
обычную реактивность. Дополнительный API, опрос или поток событий для этого не создаётся.
Серверный каталог и возможность разрешить сохранённую модель не изменены.

Компонентная проверка покрывает скрытие соседнего и текущего исполнителя, пустой каталог,
поиск и отсутствие сброса памяти. Браузерная фикстура хранит модели Claude при
`available: false` и проверяет отсутствие его вкладки и моделей на desktop и touch.
