# Приватный кэш распаковки DeepSeek

`deepseek/src/launcher/extract.ts` материализует индексированную поставку в
`packages/<packageId>/` выбранного приватного cache root. По умолчанию это
`dataPath('deepseekRuntime')`. Явный абсолютный путь допускает пробелы; ошибки
доступа и относительный путь дают отказ без выбора другого каталога.

Индекс целиком проверяется до файловых эффектов. Приватный staging получает
сначала каталоги и файлы, затем внутренние symlinks. Modes, полный список файлов,
байты и цели ссылок проверяются до публикации одним rename. Файлы поставки имеют
права 0444/0555, каталоги — права владельца. Marker хранит kernel fingerprints;
тёплый запуск сверяет полный состав и lstat каждой записи. Любое изменение включает
полный контроль bytes, links и modes; `--verify` выполняет его всегда.
Повреждённое готовое поколение остаётся на месте и вызывает отказ.

`shared/node/directoryLock.ts` сериализует распаковку одного packageId. Lock хранит
PID, время старта Linux-процесса и token; release снимает только свою запись.
SIGKILL во время staging позволяет следующему владельцу удалить незавершённый
staging и начать заново. Reclaim сериализован внутри старого lock и повторно читает
владельца. Живой, неизвестный или недоступный владелец не считается мёртвым;
ожидание ограничено. Неизвестная ownerless запись также даёт ограниченный отказ.

Тесты используют собственные процессы и IPC-барьеры. ENOSPC воспроизводится
через seam записи, ошибка доступа к PID — через probe seam. Ни реальные данные,
ни полный диск для этих проверок не нужны. Прежние готовые поколения сохраняются.
