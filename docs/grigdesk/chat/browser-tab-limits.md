# Общий лимит вкладок браузера

В одном окне GrigDesk одновременно открывается не больше 20 вкладок. Лимит общий
для человека и всех агентов; переключение раздела сохраняет вкладки. Повторное открытие
того же URL тем же владельцем переиспользует вкладку и работает при заполненном окне.

Действие `list` показывает только вкладки с действующим разрешением текущего агента.
Пустой список не подтверждает, что окно пусто или в нём есть свободное место.
Вкладки других владельцев, приостановленные и отозванные вкладки могут занимать весь лимит.

`browser_tab_limit` означает отказ создания вкладки до её открытия. Рабочие tools и MCP
добавляют фиксированные `scope: "window"`, `limit: 20` и `message` с объяснением.
URL, названия, идентификаторы и владельцы чужих вкладок при этом не передаются.

Агент может закрыть собственные ненужные доступные вкладки. Если таких вкладок нет,
человек освобождает место в разделе «Браузер» или передаёт подходящую существующую
вкладку. После освобождения места открытие можно повторить. Чужие вкладки автоматически
не закрываются; перезапуск окна для освобождения одного места не требуется.

Проверки: `tests/desktop/browser-native-runtime.test.mts` и
`tests/server/browser-tab-limit.test.mts`. Число вкладок и служебная подсказка заданы
в `shared/browser/browserLimits.ts`; оба транспорта используют одну подсказку.
