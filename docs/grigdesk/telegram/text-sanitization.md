# Гигиена текста

Plain text, `parse_mode` не отправляется (в карточках недоверенное содержимое: названия
задач B24, вопросы агента, команды инструментов). Управляющие символы схлопываются в
пробел; лимиты — заголовок 200, карточка 1000, вопрос 1500, превью команды ~300; номер
задачи/этап не отбрасываются никогда (режется тело, не шапка). План сохраняет переносы,
но также чистит управляющие символы и всегда отправляется без `parse_mode` и превью
ссылок. Не едут в Telegram никогда: дифы, произвольные файлы, пути state и токены;
узкое исключение — только `plan.md` по явному тапу подтверждённого владельца. Ссылок
на GrigDesk в карточках нет: он слушает только loopback, внешнего адреса у него нет.
