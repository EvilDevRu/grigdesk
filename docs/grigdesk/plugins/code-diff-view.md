# Просмотр diff без редактора исходников

`CodeDiffView.vue` владеет standalone-редакторами Monaco. В парном виде обе модели содержат
сырые исходные стороны, в единой колонке составная модель содержит контекст, удаления и
добавления. Карта каждой строки хранит исходные old/new номера; переход из PatchReview
обращается к исходной стороне и строке. Все модели только для чтения.

`codeDiffWorker.ts` вычисляет блоки и диапазоны детализации отдельно от UI. Поколение
каждого запроса защищает от поздних ответов прежнего файла и настроек. Уничтожение
компонента завершает поток, подписки и модели. Таймаут сравнения виден как ошибка
с возможностью повторения, а не как отсутствие различий.

`monacoDiffAdapter.ts` изолирует Myers и общий лимит времени установленного Monaco 0.56.0.
Зависимость закреплена точной версией. Пробельная нормализация меняет только сравнение;
координаты символов переводятся обратно в исходные UTF-16 позиции. Отдельная граница
`setHiddenAreas` использует runtime-метод CodeEditorWidget этой версии, отсутствующий
в публичном monaco.d.ts. Обновление Monaco требует проверки этой границы, а также двух
внутренних импортов алгоритма.

Адаптер явно подключает соседний `monacoDiffInternals.d.ts` через type reference.
Поэтому декларации внутренних модулей доступны и при транзитивном импорте из тестов,
чья конфигурация TypeScript не включает всё дерево исходников интерфейса.

Подсветка строк, слов и символов создаётся decorations. Обзорная линейка получает метки
блоков. Пустые view zones выравнивают высоты соответствующих блоков без вставок в текст;
раскладка пересчитывается при переносе и resize. Синхронизация прокрутки независима от
выравнивания: при отключённых зонах используется соответствующий исходный якорь.

`codeDiffPreferences.ts` проверяет версию, enum и boolean настроек устройства и читает
старое предпочтение trim-whitespace. Повреждение либо отказ хранилища не мешает открыть
сравнение. Временная единая колонка при узком контейнере или A/D не перезаписывает выбор
расположения. Контекст и детализация не меняют Git patch и частичный индекс.

Навигация блоков в CodePanel отделена от прежних стрелок файлов. На границе используется
соседний файл той же показанной группы с сохранением range/work. Уже прочитанные стороны
берутся из кеша. F7/Shift+F7 и Alt+N/Alt+P не перехватывают поля ввода и другие диалоги.
