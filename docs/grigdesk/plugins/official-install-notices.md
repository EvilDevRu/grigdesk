# Предупреждения при установке официальных пакетов

Официальный плагин сохраняет нейтральную подпись происхождения и адрес репозитория.
Общие предупреждения о правах серверного кода и модуля интерфейса для него скрыты.
Предупреждения конкретной операции, включая понижение версии или смену источника,
остаются видимыми. Список изменений и отдельное подтверждение применения сохраняются.

Официальность плагина определяется существующей политикой каталога: свежий индекс,
совпавшие ID и источник фактического ready-задания, `origin: official`. Свойство
выбранной карточки само по себе не скрывает предупреждения. Если источник изменился
или каталог недоступен, действуют прежние сообщения external/unverified.

Для трекеров официальный список репозиториев находится в
`shared/trackers/driverSources.ts`. Сервер использует его для встроенных ярлыков,
а мастер сравнивает с ним источник подготовленного пакета. Эквивалентность публичных
GitHub HTTPS/SSH адресов берётся из общей политики каталога. Локальная надстройка
списка источников не делает добавленный репозиторий официальным.

Скрываются только известные общие сообщения о выполнении кода. Проверки пакета,
авторизация, токен просмотра и серверные условия применения не меняются.
