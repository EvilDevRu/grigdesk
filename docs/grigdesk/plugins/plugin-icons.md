# Иконки пользовательских плагинов

Иконку выбирает `nav.icon` манифеста `plugin.json`. Значение — ключ общей карты
`web/src/shared/navIcons.ts`, например `search` (поисковая выдача с лупой) или
`gauge` (спидометр). Новый ключ в карте доступен любому пользовательскому плагину;
идентификаторы локальных плагинов в ядре не нужны.

Правая панель, боковая навигация и список инструментов берут рисунок из этой карты.
Каталог плагинов и диалог настроек используют её через `pluginIconPath`: сначала
заявленную иконку, затем известную иконку по id, иначе нейтральный знак `plugin`.
Строка манифеста не интерпретируется как произвольный SVG.

Манифест читается сервером при старте. После изменения `nav.icon` человек
перезапускает API; новая иконка в карте требует также сборки web и обновления
открытого окна. Агент из чата сервер не перезапускает.
