# Иконки плагинов

Icon манифеста называет один файл PNG/JPEG/WebP до 256 КиБ. Расширение и сигнатура
должны совпадать, SVG не допускается. Один URL используется каталогом установленных,
карточкой, сайдбаром, рейкой и меню. Общий PluginIcon сохраняет размер и показывает
нейтральный знак при ошибке без повторяющихся запросов.

Иконка выключенного плагина выдаётся под auth без активации его кода. Адрес содержит
SHA-256 байтов, перед выдачей повторяются предел и no-link проверка. Старый digest
не раздаёт новую картинку. Встроенные PNG входят в статику окна; внутренние знаки
основной навигации и терминала остаются в navIcons.

Поля, пределы галереи и контракт detail — [манифест v1](manifest-v1.md).
