# Чувствительные файлы предпросмотра установки

По единому контракту v1, принятому в задаче 100000000008, список `changes.sensitive`
в предпросмотре обновления содержит только:

- объявленные серверные точки входа `entrypoints.server` прежней и новой версий;
- все файлы внутри прежнего и нового каталогов `entrypoints.web.dir`;
- файлы метаданных с именами `plugin.json`, `package.json` и `package-lock.json`,
  включая вложенные пакеты зависимостей.

Удалённый или перемещённый модуль остаётся чувствительным по прежнему каталогу.
Внутри каталога модуля учитываются любые файлы, в том числе CSS, переводы и
вспомогательные `.txt`, даже если сам каталог расположен в `docs/`.

Обычные файлы вне этих зон, например `web/index.html`, `docs/readme.md` или
необъявленный `server.js`, не попадают в чувствительные. Имя или расширение
само по себе не объявляет файл исполняемым кодом.

Эта отметка помогает просмотреть обновление и не является аудитом безопасности.
Общий payload digest по-прежнему обнаруживает ручную правку любого файла пакета.
Политика драйверов БД отдельная и этим правилом не меняется.
