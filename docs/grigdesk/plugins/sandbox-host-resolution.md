# Адрес стенда: прямой порт текущего хоста

`web/src/shared/sandbox.ts` (`sandboxUrl(port)`) строит ссылку
`http://<хост профиля или окна>:<порт>/`. Пустой порт даёт `null`, отсутствие `location` —
fallback `localhost`. Явный IPv6-хост сохраняет квадратные скобки. Схема всегда HTTP:
стенды — обычные dev-серверы, ссылка открывается отдельной вкладкой.

Сервер читает `PROFILE_SERVICE_HOST` из `profile.sh` как буквальное присваивание,
без исполнения shell. Поле `serviceHost` передаётся в обзоре песочниц, графе конвейера
и каталоге целей презентаций; общий генератор ссылок учитывает его раньше hostname окна.
Схема, порт, путь и учётные данные вместо имени хоста не принимаются.

Без явного хоста используются hostname окна и прямой порт. Локальные адреса
`127.0.0.1` и `[::1]` в этом fallback заменяются на `localhost`: приложение может
выбирать по hostname локальную форму входа и зациклиться на серверном login-пути.
Это работает и со старым сервером без `serviceHost`, включая ссылки раздела Docker.
Удалённый hostname окна сохраняется, в том числе при HTTPS-origin. Порты и bind
самих стендов не меняются.

Проверки: `tests/web/sandbox-url.test.mts`, `tests/server/profile-service-host.test.js`,
обзор песочниц и каталог целей презентаций.
