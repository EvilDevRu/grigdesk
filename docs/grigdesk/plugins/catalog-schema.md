# Единый каталог v1

Первый релиз использует один расширенный контракт каталога: адреса
`/api/plugins/v1/index.json` и `/api/plugins/v1/<id>.json`, `schemaVersion: 1`.
Каталог допускает плагины с числовым `api: 1` и `api: 2` в одном индексе и
списке версий карточки как историю. Исполняемый контракт — только манифест v1 с api=1.

Отдельный канал v2, ограниченный API 1 reader, второй кеш сервиса и согласование
режима через `?api=2` удалены до первого релиза. Браузер и проверка происхождения
при установке читают один снимок. Неверный API, SHA, источник или несогласованная
карточка по-прежнему отвергаются целиком.

Публикации привязаны к стабильным тегам и полным SHA. Отсутствующее api в новом
манифесте недопустимо; исторические записи каталога остаются читаемыми.
Краткая запись выбирает старшую версию независимо от её API, карточка сохраняет
все версии. Публичный JSON сайта и локальный снимок допускают оба API.

Локальный API GrigDesk принимает только `refresh=1` для индекса. Детали не
принимают query; параметр `api` отвергается HTTP 400. Окно не повторяет запрос
при HTTP 400. Источники и согласование снимков описаны
в [выборе источника](catalog-failover.md).

Проверки: `plugin-catalog-contracts.test.js`, `plugin-catalog-modules.test.js`,
`plugin-catalog-local.test.js`, `plugin-catalog-routes.test.js`,
`plugin-catalog-store.test.js` и `plugin-marketplace.component.test.js`.
