# Источник рассказа ролика: один снимок, строгий git и выбор как вход сборки

Устройство выбора «О чём ролик» — для того, кто правит разбор, сборку или блок выбора.
Контракт для человека — в [разделе «Презентации»](../guide/ru/showcase.md), часть «Источник
рассказа». Код — `server/src/lib/showcase/script/source.ts`.

- **Один снимок на репозиторий.** Явный выбор сначала разрешает HEAD каждого выбранного
  репозитория (`prepareSelection`) и читает от него окно 200 коммитов линии по первому
  родителю. И проверка выбора, и куски diff берутся из этого снимка, а не из повторного
  чтения ветки. Перед возвратом контекста HEAD перечитывается (`assertSelectionCurrent`):
  сдвиг — `source_outdated`. Аренда стенда держит его жизненный цикл, но не git.
- **Строгий git только у явного пути.** `gitStrict`: тайм-аут 30 с, буфер 64 МБ,
  `core.quotePath=false` (кириллица в именах без восьмеричных кодов) и
  `GIT_OPTIONAL_LOCKS=0` (`status` не переписывает индекс). Ошибка — `source_unavailable`,
  а не пустой кусок. Умолчание песочницы по-прежнему идёт через `collectDiffContext` и
  нечитаемый репозиторий тихо пропускает. Оба пути отключают внешние diff/textconv и
  читают новые файлы [без перехода по ссылкам](showcase-source-reading.md).
- **Пустая история — не ошибка.** HEAD без коммитов (`rev-parse --verify --quiet`
  с кодом 1) даёт пустую линию; незакоммиченное такого репозитория читается от пустого
  дерева `git hash-object -t tree /dev/null`, которое годится и для sha256.
- **Новые файлы** явного пути читаются `ls-files --others --exclude-standard -z` и одним
  фильтром `excludedPath`; имя с управляющим знаком показывается строкой JSON.
  Содержимое читает общий `script/untracked.ts`: ограниченный префикс обычного файла,
  без символических ссылок. Обрезка по размеру или числу файлов поднимает `truncated`.
- **Канонический выбор.** `normalizeShowcaseSource` общего контракта сортирует
  репозитории по имени и коммиты по строке и обрезает пожелание. Служба хранит выбор в
  нём, `showcaseSourceEqual` сравнивает по нему; `repos: null` и явный список различаются
  всегда.
- **Допуск.** Сохранение выбора идёт через `requestScript` службы, как ручной разбор:
  проверка занятости и регистрация синхронны до первого await. Сохранение выбора и
  регистрация сборки взаимоисключаются с ответом `script_busy`: ждать сохранения внутри
  `prepareScript` поздно, снимок уже содержит прежний выбор. Ручного разбора без смены
  источника сборка по-прежнему дожидается. Подробности —
  [границы сохранения выбора](showcase-source-admission.md).
- **Выбор — вход сборки.** `buildRunSnapshotOf` добавляет нормализованный `source` в base
  снимка, только когда он не null: прежние сохранённые запуски не становятся «чужими».
  `briefSource` и `scriptSource` — результаты разбора и в снимок не входят.
- **Сцены и бриф прежнего выбора.** `scriptReady` службы и `ensurePrepared` сверяют
  `source` и `scriptSource` до короткого пути по proof; `generateScript` перестраивает бриф,
  `briefSource` которого не совпадает с выбором. Сборка принятых сцен при неизменном
  выборе историю не читает, поэтому rebase ветки ей не мешает.
- **Паспорт постоянного стенда** читается только когда нужен — список выбора или явный
  непустой выбор репозиториев. Пустой список `repos: []` не требует паспорта ни при
  сохранении, ни при разборе. Ошибка нужного паспорта — `source_unavailable` без пути.
- **Теги промпта** внутри вставленного текста обезвреживает `neutralized` в
  `script/prompt.ts`: задача, описания коммитов, diff, бриф модели и подписи экранов
  не открывают и не закрывают блоки.
