# Проверка изменений в панели «Код»

Общий CodePanel обслуживает страницу и док. Все модели исходников, исторических сторон
и конфликтов доступны только для чтения; редактируется только текст замечания агенту.

## Отметки просмотра

«Просмотрено» сохраняет fingerprint принятого lazy-ответа. Ключ включает проект,
репозиторий, точный корень рабочей копии, группу, ревизии, режим текущих правок и путь.
Staged и work одного пути — два сравнения. В историческом режиме прогресс считает
сравнения показанного диапазона, а не дополнительно рабочие группы того же пути.

Обновление проверяет hashes отмеченных сравнений порциями до 500, без загрузки сторон
остальных файлов. Изменённый либо исчезнувший файл теряет свою отметку. Восстановленные
из storage отметки учитываются после проверки сервером. Хранилище содержит до 4000 пар
ключ/hash без исходников; ошибка записи сохраняет ранее принятое состояние, но не
публикует новую отметку. Следующее непросмотренное сравнение открывается отдельно.

## Замечания и частичный индекс

Выделение Monaco переводится в исходные номера old/new; можно выделить текущий блок.
Корзина сохраняет снимок пути, группы, ревизий, fingerprint, стороны и фрагмента.
Изменение исходника помечает старое замечание устаревшим, сохраняя его фрагмент.
Текст заметки можно изменить или удалить; пакет перед созданием чата показан в
редактируемом поле. Передача создаёт обычный черновик без отправки сообщения агенту.
Корзины разных рабочих копий не смешиваются. Существующее действие для целого файла
продолжает работать отдельно.

Частичный stage/unstage запрашивает канонические raw atoms. Их fingerprint сверяется
с показанным lazy-ответом до подтверждения: изменение файла требует перечитать diff
и выделить строки заново. Предварительный состав содержит удаления и добавления;
submit передаёт только token и ids выбранных атомов. Настройки пробелов и подсветки
не меняют ids. Конфликт, история, binary, tooBig и неактуальное чтение не получают
частичную индексацию; отказ не превращается в операцию над целым файлом.

## Навигатор и операции

Фильтр пути нечувствителен к регистру, статусы разделяют новые, изменённые,
удалённые и конфликтные файлы. R относится к изменённым. Счётчик показывает
найденные и все файлы. Выбор хранится независимо от фильтра, открытия diff и раскрытия.
Ctrl/Meta переключает путь, Shift добавляет видимый диапазон группы; отдельная кнопка
выбора и Space позволяют работать без модификаторов мыши. Выбор папки разворачивается
в множество файлов с границей `/`, поэтому вложенный выбор не удваивает пути.

Раскрытие сохраняется при обновлении и переключении дерева/списка. Можно раскрыть
или свернуть группы каталогов и показать путь текущего файла. VirtualRows предоставляет
`reveal(index)`: сначала материализует нужное окно, затем потребитель прокручивает строку.
Виртуализация остаётся общей для дерева и списка.

Контур множественного выбора задаётся общим UI-слоем `actions.css` по
`data-context="code-tree-row"` и `aria-selected`. Он работает для файлов и каталогов
независимо от подсветки открытого файла через `aria-pressed`; локальный skin в SFC не нужен.

Контекстное меню открывается правой кнопкой, кнопкой «…» или Shift+F10/Menu.
Стрелки/Home/End перемещают фокус, Escape закрывает меню и возвращает его в источник.
Матрица действий одинакова для дерева и списка. История не предлагает мутаций; у папки
есть обзор вместо ложной истории файла. Конфликт имеет явное «Пометить разрешённым»
без разрушительного отката.

Групповые stage/unstage, откат и удаление сначала готовят точные server previews всех
порций, затем показывают пути, исключения и счётчики до единственного подтверждения.
Фильтр по умолчанию исключает скрытую часть выбора; её включение требует явного выбора.
Выполнение последовательно и сохраняет completed/failed/unattempted. Завершённые пути
снимаются с выбора; остаток сохраняется, ошибки не выдаются за успех. Неизвестный исход
запроса требует перечитать состояние, автоматического повтора мутации нет.

Удаление целой новой папки и удаление только новых файлов — разные команды. Сервер
проверяет полный inventory папки и запрещает удаление при tracked/staged/ignored либо
служебном содержимом. Откат возвращает только tracked work к индексу. Ignore явно выбирает
общий `.gitignore` либо локальный для репозитория exclude и сохраняет файлы на диске.

Обзор папки или выбранных путей использует scope до ограничений patch; заголовок
показывает область, а переход из строки сохраняет сторону и исходный номер.
Пакет выбранных путей также можно просмотреть и передать агенту одним черновиком.

## Конфликты

Сервер читает base/ours/theirs/work независимо, включая отсутствующие стадии.
Переключатели показывают пары base/ours, base/theirs и ours/work. Отсутствие версии,
ошибка чтения, binary и tooBig не подменяются обычным текстом. Переходы находят маркеры
конфликта в рабочей копии; ноль означает отсутствие маркеров, а не разрешённый индекс.
Контекст конфликта передаётся отдельным черновиком; stage после разрешения остаётся
явным действием человека.
