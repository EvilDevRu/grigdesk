# Выбор источника каталога

Каталог подключается автоматически. Прежний локальный GET без `api=2` читает только:

1. https://grigdesk.com/api/plugins/v1/index.json
2. https://grigdesk.ru/api/plugins/v1/index.json

Для запросов с `api=2` сервер использует отдельный сервис с независимым кешем:

1. https://grigdesk.com/api/plugins/v2/index.json
2. https://grigdesk.ru/api/plugins/v2/index.json
3. https://grigdesk.com/api/plugins/v1/index.json
4. https://grigdesk.ru/api/plugins/v1/index.json

V2 допускает api1/2, v1 — только api1; форма документов сохраняет `schemaVersion: 1`.
Сайт выпускает новый канал отдельной задачей, сохраняя прежние версии в v1.
V2 должен быть надмножеством v1, без пустой заглушки при непустом v1:
валидный пустой каталог не вызывает fallback. См. [контракт публикации](plugin-module-install.md).

Переменная окружения для подключения не требуется. Localhost не входит в список.
Каждое обновление индекса снова начинается с основного сайта. Если основной вернулся,
свежее чтение использует его. Сеть при boot не вызывается.

Сетевая ошибка, HTTP-отказ, неверный JSON, превышение размера или таймаут переводят
чтение на следующий сайт. Корректный пустой каталог считается успешным ответом.
Одна попытка сайта занимает до пяти секунд, включая чтение тела; redirects запрещены.
Если все источники режима отказали, последний проверенный снимок сохраняется со статусом stale
до суток. После общего отказа действует прежний cooldown тридцать секунд.
Ручная установка из Git остаётся доступной при недоступности каталога.
Modern index ограничен четырьмя попытками по пять секунд, окно ждёт двадцать пять секунд.
Прежний режим сохраняет два источника и бюджет окна пятнадцать секунд.

Кеш индекса хранит также сайт, с которого он принят. Карточка сначала читается там же.
При отказе карточки другой сайт должен вернуть полный индекс, совпадающий с принятым
снимком, и согласованную карточку. На пару индекс/карточка резервного сайта отводится
одна пятисекундная попытка. Общее чтение карточки ограничено двенадцатью секундами.
Успешное переключение не обновляет время свежести старого снимка.

Другой снимок зеркала даёт конфликт 409 и требует обновления каталога, не подменяя
выбранную версию. Обновление индекса во время чтения или закрытие сервиса запрещает
позднюю публикацию и прекращает попытки других сайтов. Общее чтение карточки делят
только запросы одного снимка: карточка нового снимка не ждёт незавершённое старое чтение.
Тело отвергнутого ответа (HTTP-отказ, не JSON) закрывается сразу; тип сверяется без регистра.

Проверки: plugin-catalog-failover.test.js, plugin-catalog-service.test.js и
plugin-catalog-routes.test.js. Сеть в них синтетическая; доступность публичных сайтов
не является условием прохождения тестов.
