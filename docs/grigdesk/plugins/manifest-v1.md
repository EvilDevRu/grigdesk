# Единый манифест плагина v1

Один файл иконки используется во всех местах
интерфейса; GrigDesk готовит данные каталога, сайт обновляется отдельно; команды
занимают место в схеме без исполнения. Темы и перенос регистрации встроенных
плагинов на внешний runtime в этот контракт реализации не входят.

## Вход автора

```json
{
  "id": "example",
  "api": 1,
  "name": "Пример",
  "version": "1.0.0",
  "description": "Сервер, панель и данные исполнителя",
  "icon": "assets/icon.png",
  "engines": { "grigdesk": ">=0.1.0" },
  "entrypoints": {
    "server": "runtime/main.ts",
    "web": { "dir": "ui", "entry": "panel.js", "css": ["panel.css"], "locales": {} }
  },
  "contributes": {
    "panels": [{ "title": "Пример", "group": "dock", "order": 10 }],
    "slots": [{ "slot": "provider.popover.after-bars", "kind": "provider-usage", "default": true }],
    "settings": [],
    "commands": [],
    "themes": []
  },
  "gallery": { "screenshots": ["assets/screen.webp"] },
  "install": { "npm": [] }
}
```

Обязательны id, api, непустой description до 4096 символов, icon, entrypoints и
contributes. Последние два могут быть пустыми объектами. Api всегда равен 1 и
обозначает поколение всего контракта. Scanner сохраняет fallback имени и версии;
установщик требует стабильную version, равную выбранному тегу vX.Y.Z.

Engines необязателен; единственный диапазон grigdesk — минимум `>=X.Y.Z` без
других условий. Scanner и installer сравнивают с одной фактической версией приложения.
Category, defaultEnabled и install.npm сохраняют свой смысл. Явный выбор в prefs
сильнее defaults. Ключи plugins, pluginSettings и pluginPlacements не меняются.

## Исполнение

Сервер загружается только из entrypoints.server: собственный обычный файл js, mjs
или ts. Наличие соседних server.js/server.ts не влияет на выбор. Расширенные
сервисы options.core доступны объявленному серверу; проверка возможностей методов
остаётся обязанностью автора. Серверный lifecycle включения сохраняется.

Единственная панель — готовый ESM-компонент Vue из entrypoints.web. Его dir —
подкаталог пакета; entry, CSS и JSON-переводы ru/en относительны ему. Entry имеет
расширение js/mjs. Декларация contributes.panels создаёт один пункт с адресом
/ext/идентификатор; title по умолчанию — name, group по умолчанию — dock.
Без декларации панели модуль не создаёт навигацию. Единственный ToolHost владеет
панелью и в доке от 900 px, и на маршруте узкого окна.

Слот provider.popover.after-bars с kind provider-usage требует серверного входа.
Он читает прежний readonly JSON из provider-usage и может сосуществовать с панелью.
Произвольные Vue-компоненты через внешнюю декларацию слота не подключаются.
Commands и themes — массивы объектов id/title; исполнения и нового UI у них нет.
Встроенные плагины получают ту же проекцию деклараций, регистрация остаётся build-time.

После входа каталог обновляется без импорта кода. Открытие панели или запрос слота
получает lease общего модуля и context. Необязательный start(context) вызывается
один раз на первый спрос. Последний release отзывает signal и вызывает cleanup;
поздний async cleanup также вызывается один раз. Скрытая панель сохраняет DOM и ввод.
Выход, offline, смена профиля/владельца и замена модуля отзывают доступ; online ждёт
свежий каталог. SSE, сессия, Vue и UI принадлежат окну; отдельного потока нет.

## Изображения и публичные данные

Icon — PNG, JPEG или WebP до 256 КиБ; расширение и сигнатура должны совпадать.
Gallery.screenshots необязателен: по умолчанию пустой массив, до шести разных файлов
по 4 МиБ. SVG не принимается, включая переименованный в PNG. Пути без URL, абсолютных,
скрытых и родительских компонентов, node_modules и символических ссылок.
Общие пределы пакета остаются 5000 файлов, 50 МиБ и 64 КиБ манифеста.

GET /api/plugins содержит compatibility, icon URL/null, публичные entrypoints.web
и contributes. Серверные пути не передаются. Nav, settings и placements — проекции.
Иконка доступна под общим auth независимо от enabled через
/api/plugins/идентификатор/icon/sha256. Перед выдачей повторяются файловая проверка,
лимит и digest; старый URL не отдаёт новые байты. PluginIcon показывает файл либо
нейтральный знак. Встроенные PNG поставляются в статике окна.

Detail каталога сохраняет icon `{path, sha, mediaType, bytes}`/null и
`gallery.screenshots` с такими же дескрипторами. SHA равен старшей версии карточки;
URL строится из проверенных repository/SHA/path на raw.githubusercontent.com.
Старый сайт без полей читается как null/пустая галерея. Краткий индекс не содержит
изображений, schemaVersion остаётся 1, README сохраняется. Сбор и показ скриншотов
сайтом выполняются в отдельном репозитории.

## Несовместимые пакеты

Прежняя структура манифеста получает manifest_incompatible, неизвестное поколение —
api_unsupported. Карточка сохраняется с причиной, enabled=false, nav=null и
needsRestart=false. Код не импортируется, toggle on возвращает 409 до записи prefs.
Установщик отказывает до npm. Переустановка из нового источника сохраняет prefs,
dataDir и резерв прежней копии; replaceModified требует явного согласия человека.
Откат сначала проверяет контракт кандидата до lease и перестановки файлов. Старый
backup сохраняется, но не может быть исполнен. Прежние коды ошибок сохранённого
журнала продолжают читаться как диагностика.
