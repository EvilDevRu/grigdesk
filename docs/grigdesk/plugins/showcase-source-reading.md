# Источник ролика читается без перехода по ссылкам и запуска команд репозитория

При чтении незакоммиченных файлов нельзя передавать пути из `git ls-files` напрямую
в `readFile`: символическая ссылка на чужой файл или исключённый `.env` приносила его
содержимое в промпт. Обрезка строки после чтения также не ограничивала память: большой
файл сначала загружался целиком.

Общий `script/untracked.ts` используется и явным выбором, и прежним разбором всей
ветки. Каждый вложенный каталог открывается относительно удерживаемого родителя
через `/proc/self/fd` с `O_NOFOLLOW`; файл — с `O_NOFOLLOW | O_NONBLOCK`, затем проверяется
обычный тип файла. Ссылки, исчезнувшие пути и специальные файлы пропускаются. Читается
ограниченный префикс и один лишний символ для признака обрезки, память от размера
файла не зависит. Обрезка размера или числа новых файлов отражается в `truncated`,
чтобы интерфейс называл неполноту разбора.

Оба вызова `git diff` передают `--no-ext-diff --no-textconv`. Без них настройки
репозитория запускали внешние обработчики при операции, которая должна только
читать изменения.

История использует `git log -z` и пять NUL-разделённых полей на коммит. Символ `0x1e`
разрешён в описании и поэтому разделителем записей быть не может: раньше он создавал
поддельную строку каталога. Полные идентификаторы принимаются и для SHA-1, и для
SHA-256, а принадлежность коммита всё равно проверяется по истории конкретной ветки.

Теги блоков промпта обезвреживаются также в брифе модели и подписях экранов:
недоверенный текст не может открыть ещё один блок пожелания человека.

Проверки: `tests/server/showcase-story-source.test.js`,
`tests/server/showcase-context.test.js`, `tests/server/showcase-script.test.js`.
