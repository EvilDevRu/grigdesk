# Tripo API v3: адаптер ядра

Адаптер использует отдельный снимок key/region/accountKey для каждой отправки.
Ключ остаётся в памяти процесса; публичная identity аккаунта односторонняя и
не раскрывает credentials. Чатовый transport у Tripo отсутствует. Оба региона, ошибки, uploads,
заказы, история и CDN проверяются поддельным сервером; это не живая проверка аккаунта.

## Каталог и API

Каталог закрепляет датированные имена: H `v3.1-20260211`, P `P1-20260311` и
`P2-20260801`, текстуры `v3.0-20250812`/`v3.5-20260815`, скелет
`v1.0-20240301`/`v2.5-20260210`, сегментация `v1.0-20250506`/`v2.0-20260430`.
Рекламные aliases не подменяют эти значения. Поля, incompatibilities и готовые
наборы лежат в catalog; неиспользуемые hidden поля удаляются при нормализации.

| Назначение | Ручки v3 |
| --- | --- |
| Модель/виды | `/generation/text-to-model`, `image-to-model`, `multiview-to-model`, `image-to-splat` |
| Картинки | `/generation/text-to-image`, `image-to-image`, `image-to-multiview`, `edit-multiview` |
| Обработка | `/models/texture`, `stylize`, `convert`; `/mesh/decimate`, `uv`, `segment`, `complete`, `smartsegment` |
| Скелет/движение | `/animations/rig-check`, `rig`, `retarget` |
| Опрос | `/v3/tasks/:id`, `/v3/tasks/list` с `{ task_ids }`, не GET query |
| Счёт | `/v3/account/balance`, `/v3/account/usage` |
| Файлы | `/v3/files` с multipart file |

Пакетный опрос делится по 100 номеров; decoder принимает документированные list/map
варианты, проверяет task identity/type/status и отдельно возвращает missed. Upstream
номер существует только при подтверждённом ответе. Native вход подходит текущей версии,
аккаунту и типу; файл даёт fallback только для операции, которая его объявляет.

Upload адаптера ограничен 150 МиБ для GLB/FBX/OBJ/STL, картинки — 20 МиБ PNG/JPEG/WebP.
Локальные проверки проходят до сети. Реальный размер body, заголовки файла и identity
открытого дескриптора проверяются отдельно. Пулы параллелизма разделяются по аккаунту
и семейству операции: generation-h/generation-p, animation, processing и mesh.
Пул картинок в адаптере допускает одну задачу. Для остальных семейств числовой потолок
не закреплён; занятость подтверждается ответом поставщика. Повторная загрузка не
переносит токен другого аккаунта.
Код 2000 означает отсутствие доступного quota/concurrency: подтверждённый отказ
можно поставить на ограниченное ожидание, unknown POST автоматически не повторяется.

HTTP 401/403/429/5xx имеют приоритет. Документация и CLI расходятся в кодах 1000/1001:
при 403 это ключ/права/регион, при 5xx — серверный отказ; неоднозначный исход отправки
остаётся unknown. Тело ошибки и секреты не публикуются; UI получает локальную причину.
История трат сохраняет фактическую сумму, дату, account и происхождение наблюдения.
Короткий ответ не стирает накопленное, неполнота явно видна.

## Цены и источники

Каталог расчёта сверялся с публичным [pricing](https://developers.tripo3d.ai/en/pricing)
11.10.2026; страница повторно прочитана 12.10.2026 без вызова API. Кредит соответствует
$0,01. Rig-check бесплатен; экспорт базового формата — 5 кредитов. Это оценка,
совпадение двух расчётов GrigDesk не доказывает списание. Actual берётся из receipt/usage.
Сменившаяся цена требует нового решения перед отправкой.

Первичные справки: [генерация H](https://developers.tripo3d.ai/en/docs/generation-text-to-model/standard),
[проверка скелета](https://developers.tripo3d.ai/en/docs/animations-rig-check),
[счёт](https://developers.tripo3d.ai/en/docs/account),
[ошибки](https://developers.tripo3d.ai/en/docs/error-handling).
Это датированный контракт адаптера; новые имена/API не включаются молча из маркетингового текста.

## Грабли формата и восстановления

Пакет движений в одном GLB может оставить только последнее; адаптер запрашивает
выбранные движения отдельно. Rig-check чувствителен к направлению +X; предположение
facing не считается доказательством взгляда. Human движения требуют подтверждённого
скелета v1; без версии/типа список не выдумывается.

`export_orientation` генерации не наследуется постобработкой. Лучше оставить исходную
ориентацию и преобразовать её последним экспортом; локальный поворот снимает native
происхождение. Проверка параметров не обещает качество результата поставщика.

CDN может оборвать TLS/поток или вернуть истёкшую ссылку. Адаптер получает новую ссылку
бесплатным опросом, не передаёт Bearer credentials на CDN и проверяет публичное
HTTPS/DNS/redirect назначение. Возобновляемое скачивание, долговечные намерения,
публикация версий и повторный запуск обработки принадлежат Studio3D и описаны в
`docs/README.md` установленного плагина. Граница адаптера —
[каталог и протокол](tripo-module-boundaries.md).
