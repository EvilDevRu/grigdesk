# Версия продукта и совместимость серверного ELF

Хост-скрипт `deploy/lib/runtime-env.sh` при выборе серверного ELF проверяет его
`--runtime-info --json` строгим декодером: контракт (`format`, `hostContract`,
`packagingVersion`), Node/ABI, capabilities, protocol движка и формат продуктовой версии.
Номер продукта меняется независимо от бинарного протокола и не закрепляется в host-скрипте.

## Грабля

После подъёма `VERSION` до `0.1.1` декодер продолжал ждать `0.1.0`.
Перенос ожидания в `GRIGDESK_EXPECTED_SERVER_VERSION` и тест равенства с `VERSION`
устранили только тот рассинхрон: при следующем подъёме до `0.1.2` ожидание снова устарело.
Сборка «Всё» успешно собирала сервер и AppImage, но «Окно: установка» падало
сообщением «Некорректное описание серверного ELF.».

Причина — расхождение host-декодера с `shared/runtime/serverBinary.ts`, который уже
проверяет формат версии через `parseProductVersion`, а совместимость — по полям протокола.
Повторная замена литерала потребовала бы той же ручной правки при каждом выпуске.

## Контракт

- Shell-bootstrap работает без Node, поэтому Python-декодер повторяет формат
  `parseProductVersion`: X.Y.Z либо X.Y.Z-dev.N, без ведущих нулей, с каждым числом
  не больше `Number.MAX_SAFE_INTEGER`. Переменной ожидания продуктового номера нет.
- Совместимость по-прежнему требует format 1, hostContract 1, packagingVersion 2,
  закреплённые Node/ABI, все capabilities и protocol движка. Новый номер продукта
  не разрешает несовместимый протокол.
- PackageId закрепляет конкретную сборку при подготовке и последующих запусках.
  Проверка формы metadata не заменяет проверку payload и не сверяет номер с исходниками.
- В параллельном «Всё» установка окна остаётся после всех цепочек и не конкурирует
  с атомарной заменой ELF в `install:binary`.

## Проверка

- Смоук: `source deploy/lib/runtime-env.sh && grigdesk_select_server_binary <root>`
  на собранном ELF возвращает packageId без ошибки.
- Тест: `bash tests/run-node-tests-safe.sh --test tests/server/runtime-env-version.test.mts`.
  Он вызывает настоящий shell-декодер для текущего и будущих stable/dev-выпусков,
  сверяет допуск с общим TypeScript-декодером и проверяет отказ неверного формата,
  небезопасных чисел и несовместимых полей протокола.
