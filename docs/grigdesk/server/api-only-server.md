# Сервер только API

Интерфейс встроен в приложение. Сервер не читает web/dist и каталог UI-версий, не
обслуживает /ui/<id>/ и /assets/. GRIGDESK_WEB_DIST и GRIGDESK_UI_RELEASES_DIR больше не
управляют серверной статикой. Предыдущие каталоги не удаляются автоматически.

GET или HEAD неизвестного документа с Accept:text/html показывает самостоятельное
сообщение «GrigDesk открывается в приложении». Это публичная инструкция без данных
машины. Неизвестные API, файлы и прежние UI-пути получают JSON 404 с no-store.

/api/* и WebSocket закрывает общий гард. /shots/* сохраняется и требует входа, включая
закодированный префикс. Страницы включённых плагинов /api/ext/<id>/web/ продолжают работать
под тем же гардом. [Vite dev](../web/browser-grigdesk-auth.md) передаёт /api и /shots
через локальный транспорт с собственной сессией по ключу окна.

Проверки: ui-releases.test.js, plugins-web-page.test.js, api-same-origin.test.mts.
Перезапуск установленного сервера после обновления окна выполняет человек.
