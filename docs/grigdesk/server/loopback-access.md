# Локальный доступ: один HTTP-сокет и вход по ключу

Основной HTTP-сервер слушает только `127.0.0.1:<GRIGDESK_PORT>`;
штатный адрес — `http://localhost:8140`. `GRIGDESK_PORT` по-прежнему выбирает порт.
Устаревший `GRIGDESK_HOST` игнорируется: его наличие вызывает одно предупреждение
через общий logger, которое подчиняется выбранному уровню журналирования.
Отдельный [клиентский TLS-вход](client-listener.md) выключен по умолчанию и включается
явным `GRIGDESK_CLIENT_LISTEN`. Он использует личность мозга и проверяет сертификаты устройств;
основной HTTP и прежний мобильный вход v1 сохраняют loopback. Встроенного шлюза нет.
Уже установленный внешний проброс проверяет и отключает владелец машины отдельно.

Fastify использует protocol/ip сокета и не доверяет `X-Forwarded-*`. Cookie входа ограничена выдавшим её хостом, без `Domain`; `Secure` определяется
`request.protocol === 'https'`, поэтому на локальном HTTP его нет. `HttpOnly`,
`SameSite=Lax` и `Path=/` сохраняются. Локальный вход использует ключ окна; общий гард закрывает
API/WebSocket и статику. CLI-токен сохраняется. Любой forwarded-заголовок запрещает обмен ключа.

Prefs `accessLocalHttps` и `accessGateway` не выдаются через `read()`.
Следующий успешный `write()` удаляет их из файла даже при patch старого клиента,
сохраняя соседние настройки и неизвестные ранее сохранённые ключи. `readStored()`
остаётся сырым чтением; при запуске или обычном чтении файл не мигрирует.
Нечитаемый файл по-прежнему запрещает запись, внутренняя speech revision сохраняется.

Автоматически выбранного публичного адреса у GrigDesk нет. GitHub connect требует явного
`GRIGDESK_GITHUB_WEBHOOK_BASE_URL`; запасного адреса из домена больше нет.
VPN-ворота запуска и Telegram-пульт сохраняют прежнее поведение.

Проверки: `tests/server/loopback-only.test.mts` (конфигурация, вход по ключу/cookie,
снятые пути и forwarded), `tests/server/app-boot-smoke.test.js` (настоящий старт и
адрес LISTEN через `/proc`), `tests/server/prefs-store.test.js` (соседние prefs).
Тестовый сервер использует временное состояние и отдельный свободный порт.
