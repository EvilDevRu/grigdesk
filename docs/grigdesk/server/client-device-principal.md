# Субъект устройства в общем гарде

`server/src/lib/clientAccess/principal.ts` связывает проверенный клиентским входом сокет
с `{ deviceId, fp }` через `WeakMap`. HTTP-заголовки не создают эту запись. Реестр не
удерживает сокет после завершения соединения.

Гард читает запись до публичных маршрутов, cookie и internal/CLI-токенов. Действующее
устройство получает `authKind: 'session'` и `authPrincipal: { kind: 'device', deviceId }`.
Cookie и токены этого запроса не участвуют в авторизации, даже если они действительны.

`markRevoked(fp)` меняет наблюдаемое поле `revoked` у всех записей данного отпечатка,
включая записи уже открытых соединений и последующие привязки сокетов. Общий гард отвечает
403 `device_revoked` также на `/api/auth/state` и `/api/auth/window-session`.

`isLocalRequest` для устройства всегда возвращает false, в том числе при loopback IP.
Fastify распознаёт переданный TLS-сокет как HTTPS, поэтому `isSecureRequest` возвращает true.
Нельзя пользоваться локальными правами по одному лишь адресу транспортного сокета.

`GET /api/auth/state` устройства возвращает `authenticated: true`, `configured: true`,
`method: 'device'`, `secure: true` и общий `clientScope` владельца данных. Запрос без записи
устройства и без сессии сохраняет прежний ответ без `clientScope`. Обмен ключа окна с
устройства запрещён: 403 `local_only`, без создания сессии и `Set-Cookie`.
