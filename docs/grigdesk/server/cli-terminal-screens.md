# Общие экраны терминальной консоли

Пакет `utilities/ctl/internal/terminal` задаёт палитру, строки выбора, подписи ввода и
прогресс Go-команды. `cli/distributionProgress.ts` использует ту же палитру и вид шкалы
для инструмента дистрибутива, который выполняется в Node.

| Экран | Управление и вывод |
| --- | --- |
| Меню и подменю | Стрелки меняют выделение, Enter выбирает пункт, Esc возвращает назад или выходит |
| Подтверждение уборки, доверие SSH и установка VPS | Сначала выделена отмена, стрелки меняют выбор, Enter подтверждает, Esc закрывает экран |
| Отчёт перед подтверждением | PgUp/PgDn листают подробности, Home/End переходят к краям отчёта Go-команды, выделение не меняется |
| Действия мастера | Подключение, задание и способ входа выбираются теми же клавишами |
| Имя, id, SSH-адрес и секрет | Enter завершает ввод, Esc отменяет. Пароль и парольная фраза не выводятся |
| Сборка, уборка и ожидание VPS | Индикатор показывает стадию и время. Процент показывается при известном числе шагов |
| Итог сборки | Строка состояния и подробности на экране меню. При сбое видны код, путь журнала и его хвост |
| Журнал и QR | Результат вызова из меню виден на том же экране до Enter или Esc |

Текстовые сокращения в мастере остаются доступны. Номер выбирает задание или подключение,
привычный ответ «да» подтверждает операцию, а ввод пароля с первого символа открывает
скрытое поле. Esc при ожидании удалённого задания завершает наблюдение.

`NO_COLOR` убирает цвет. `TERM=dumb` выводит новую строку при смене стадии без ANSI и
периодического обновления. В JSON и обычных перенаправленных потоках индикатор отсутствует.
Для сборки сохраняются полный журнал и опциональный канал событий fd 3.

Проверки Go-вывода выполняются через PTY с заглушками в
`tests/cli/checkout-go.test.mts` и `tests/cli/relay-setup.test.mts`.
