# Общие экраны терминальной консоли

Меню и результаты используют одну тёмную палитру. `cli/screen.ts` задаёт общую рамку:
название GrigDesk, действие, состояние, содержимое, разделитель и доступное управление.
Данные команд не смешиваются с ANSI-стилями; внешние последовательности очищает
`cli/terminal.ts` перед применением доверенных ролей интерфейса.

| Экран | Источник и поведение |
| --- | --- |
| Состояние | Снимок компонентов, отдельные причины и связи; подсказки общие с обычным текстом |
| Запуск, остановка, перезапуск, отзыв | Результат прежнего диспетчера и прежний код завершения |
| Журнал и команды разработки | Потоковые stdout/stderr через явный приёмник; ввод и сигналы сохраняются |
| Имя устройства и id | Выделенное поле ввода, видимый конец длинной строки, Enter и Esc |
| Устройства | Отдельные имя, id, доступ и признак отзыва; явный пустой список |
| Привязка | Матрица QR на белом поле, строка привязки и срок действия |
| Сборка | Прежние стадии, оценка прогресса, время и журнал в общей рамке |
| Итог сборки и ошибка | Полный итог или последние двадцать строк ошибки, путь журнала и прежний exit code |

`cli/output.ts` определяет явный приёмник вывода. По умолчанию он сохраняет прежние
stdout/stderr и подключение внешних команд. `cli/presentation.ts` передаёт экранный приёмник
в `runCli`, не подменяя глобальные потоки и `console`. Сторож, команды, параметры и запросы
данных остаются прежними. Предварительное определение корня поставки в shell не меняется.

В меню результат остаётся до Enter/Esc. Длинный результат просматривается стрелками,
PageUp/PageDown, Home/End; прокрутка не выполняет команду повторно. При resize позиция в
конце журнала сохраняется. Прямые команды в человеческом TTY используют рамку и завершаются
без ожидания клавиш, кроме успешного `build`: он предлагает
[открыть окно](cli-build-interaction.md). Полный итог сохраняется в истории прокрутки терминала.

История потокового экрана ограничена последними 5000 строками по 4096 символов; число
отброшенных строк видно на экране. Исходный поток для скриптов не ограничивается.
Полные журналы сборок сохраняются по прежнему контракту.

QR не обрезается и не переносится по модулям. Если ширины или высоты мало, экран показывает
необходимый размер окна и полную строку привязки. При увеличении окна QR появляется заново.
Белое поле включает исходную тихую зону матрицы; управляющие последовательности не берутся
из ответа сервера.

`--json` не получает рамку даже в TTY. Нетерминальный и агентский вывод сохраняют прежние
форматы и коды. `NO_COLOR` отключает стили, `TERM=dumb` также отключает очистку, позиционирование
и управление видимостью курсора. Собственные новые надписи находятся в общих каталогах RU/EN.
