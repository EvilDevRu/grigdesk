# Зависимости серверного SEA от хоста

Проверенный комплект — Linux x64 с Node24.21.0/ABI137. В нём есть собственный Node/npm,
production npm-зависимости и native bindings; системный Node для boot, helpers и CLI
не требуется. Отсутствующий вложенный Node считается повреждением, fallback запрещён.

SEA сохраняет системный ELF-загрузчик и библиотеки. Проверка `ldd` собранного сервера
показала загрузчик glibc `ld-linux-x86-64.so.2`, libc, libstdc++, libgcc, libm,
libdl и libpthread. Это не статический Linux-бинарник. Минимальные версии этих
библиотек и работа на иных libc/архитектурах этой приёмкой не установлены.
Manifest проверяет Node/platform/arch/ABI и файлы, а запуск остаётся проверкой
совместимости конкретного хоста.

| Возможность | Что предоставляет хост |
| --- | --- |
| Терминал | Python3 и shell; Python PTY helper входит в R. |
| Bash движка и запускалки | Bash и обычные системные утилиты; пути Node/helpers задаёт runtime комплекта. |
| Личность сервера и клиентский TLS-вход | OpenSSL с рабочей конфигурацией; сертификаты и ключи создаются в D. |
| Распознавание медиа | ffmpeg/ffprobe, Python-среда и модели речи соответствующей возможности. |
| Презентации и браузерные задачи | Установленный браузер/его runtime; библиотека playwright-core в комплекте не заменяет executable браузера. |
| Провайдеры моделей | Внешние CLI и их собственная авторизация; b24 и relay уже собраны в R. |
| Изолированная приёмка | bwrap и доступность user/net/pid namespaces. |

Модели, кэши, пользовательские плагины и их данные принадлежат D либо разрешённым
каталогам задач. Boot готового сервера не устанавливает пакеты и не пишет в R.
Установка дополнительных runtime остаётся отдельным действием соответствующей
возможности. Generation DeepSeek не входит в серверный R: нужен отдельный внешний ELF;
граница host helpers описана в [контракте DeepSeek для SEA](sea-deepseek-boundary.md).

Фактические протокольные проверки перечислены в [изолированной приёмке](sea-isolation.md).
GUI и настоящая служба проверяются владельцем отдельно по
[desktop](sea-desktop.md) и [launch](sea-launch.md); проверки на заглушках не
подтверждают доступность графического сеанса либо user systemd на другой машине.
