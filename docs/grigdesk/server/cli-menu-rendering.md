# Оформление терминального меню

В Go-версии `utilities/ctl/internal/menu/view.go` собирает строки из дерева команд.
Пакет `utilities/ctl/internal/terminal` оформляет экран, считает ширину ячеек, обрабатывает
клавиши и восстанавливает терминал. Меню и вложенные уровни используют один экран.

Шапка показывает GrigDesk, версию, вид поставки и короткие состояния сервера и окна.
Рабочие состояния отмечены `●`, ошибки — `✗`, остальные — `○`. В узком окне
состояния переносятся на отдельные строки.

Корневые пункты сгруппированы по назначению. Выход отделён от групп. Выбранная строка
выделена подложкой и маркером `›`. Стрелка справа указывает на подменю.
Под списком видны описание текущего пункта и клавиши управления.

Ширина области меню ограничена 80 столбцами. Последний столбец терминала зарезервирован.
При уменьшении высоты сначала убираются пустые строки, затем видимая часть списка следует
за выделением. При изменении размера экран обновляется даже без нажатия клавиш.

Цвета повторяют прежнее меню: фон `#1b1f26`, основной текст `#e0e5ed`, второстепенный
`#9aa5b5`, акцент `#8ccece` и подложка выделения `#293b43`. Стиль задаётся ANSI.
Управляющие символы из текста удаляются до отрисовки. В совместимом терминале экран
открывается поверх обычного вывода. Выбор, запуск действия и результат используют эту же
область. При завершении сеанса возвращаются обычный экран, курсор и исходный режим ввода.
`NO_COLOR` сохраняет текстовые маркеры и
позиционирование. `TERM=dumb` оставляет только последовательный текстовый вывод.

Те же строки выбора используются в подтверждении уборки и мастере удалённого доступа.
Текстовые подписи берутся из общих каталогов RU/EN.
Связанный контракт — [общие экраны консоли](cli-terminal-screens.md).
