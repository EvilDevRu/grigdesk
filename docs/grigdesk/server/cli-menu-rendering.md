# Оформление терминального меню

`cli/menuView.ts` собирает представление существующего дерева команд из `cli/menu.ts`.
`cli/terminal.ts` владеет очисткой данных и применением стилей. Стили не меняют команды,
их параметры, проверки допуска и доступность разработки в готовых поставках.

Шапка содержит GrigDesk, версию и вид поставки. Сервер и окно показаны отдельной строкой;
в узком окне их состояния переносятся на разные строки. Рабочие состояния отмечены `●`,
ошибки — `✗`, остальные — `○`; текст состояния остаётся виден без цвета.

Корневые команды разделены на «ПРИЛОЖЕНИЕ» и «РАЗРАБОТЧИКУ», выход отделён от групп.
Подменю показывают свой путь. Выбор выделяется фоном и маркером `›`, переход в подменю
отмечен справа `›`. Под списком выводится только описание текущего пункта. На узком экране
нижняя подсказка сокращается; Esc в корне обозначен как выход, в подменю — как возврат.
Все собственные надписи находятся в общих каталогах RU/EN.

Поле меню ограничено 80 столбцами с внутренними отступами. Последний столбец терминала
резервируется от автоматического переноса. При недостатке строк сначала убираются пустые
отступы. Описания и состояния переносятся без потери текста.

Тёмная палитра использует фон `#1b1f26`, основной текст `#e0e5ed`, второстепенный `#9aa5b5`,
акцент `#8ccece` и выделение `#293b43`. Состояния получают зелёный, жёлтый или красный цвет.
Рендер окрашивает экран через ANSI, не перенастраивая пользовательскую палитру терминала.
`NO_COLOR` и `TERM=dumb` отключают цвет; dumb также отключает позиционирование курсора.

`TerminalSession.draw()` принимает обычные строки либо структурированные строки с
фрагментами `text`/`tone` и признаком `selected`. При теме `dark` каждый фрагмент сначала
очищается и ограничивается через `terminalText()`, затем получает доверенный стиль рендера.
ANSI из входного текста не сохраняется. В конце вывода стили сбрасываются, чтобы следующая
команда не наследовала подсветку. Остальные экраны используют
[общую рамку консоли](cli-terminal-screens.md), включая прогресс и итоги сборки.

`terminalLines()` используется меню и прогрессом сборки для общего переноса очищенного
текста. Длина по-прежнему измеряется числом Unicode-символов, без вычисления ширины
терминальных ячеек; это ограничение нужно учитывать для широких и комбинируемых символов.
