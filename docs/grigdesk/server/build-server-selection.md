# Полная сборка и сервер следующего запуска окна

`grigdesk-ctl build` и `build all` после успешной установки сервера, веба и окна
связывают окно с `<корень исходников>/bin/grigdesk-server`. Ранее установка окна
сохраняла выбор прежнего `<корень>/release/bin/grigdesk-server`, хотя полная сборка
обновляла другой ELF. Повторное открытие запускало прежний сервер с новым интерфейсом.

## Публикация после установки

В полной сборке `desktop install --keep-runtime` сохраняет корректный descriptor любой
версии. Только после всех успешных стадий `server/scripts/ctlBuild.mts queue-desktop`
вызывает `queueBuiltServer` и публикует private `runtime.json.build-selection`.
Файл содержит версию формата, физический корень, путь ELF, его SHA256, папку данных и
точные прежние bytes descriptor. Публикация атомарна, с режимом 0600 и fsync, под тем же
select-lock и с тем же восстановлением транзакции, что обычный выбор сервера.

Автопривязка допускается только для этой копии исходников или её `release/` и той же
папки данных. Уже выбранный новый ELF не требует намерения. Другая установка или другая
папка данных сохраняется; CLI явно сообщает, что новый сервер ещё не выбран, и не обещает
его запуск после простого открытия окна. Самостоятельные `build server`, `build web`,
`build window` и `desktop install` не публикуют намерения полной сборки.

Отказ обязательной стадии не публикует новую привязку. SHA256 закрепляет именно результат
успешной полной установки: последующая замена ELF отдельной или неполной сборкой не
может незаметно использовать прежнее намерение.

## Применение окном

Настоящие `runtimeDependencies` вызывают `applyBuiltServer` перед чтением descriptor
в `loadServerRuntime`. Живой владелец папки данных откладывает применение без сигналов.
После освобождения папки данных общий `selectSeaServer` проверяет размещение и профили,
полностью проверяет ELF, сравнивает SHA256 до и после проверки и повторно сверяет primary
и намерение. Затем использует штатные journal, backup и атомарный commit descriptor v4.
Пользовательские `cliPaths` сохраняются; source Node переносится в этот список.

Применённое намерение удаляется. Явный ручной выбор отменяет очередь, включая повтор
того же descriptor. Внешнее изменение primary или смена `GRIGDESK_HOME` source v1 делает
намерение устаревшим: оно удаляется без перезаписи нового выбора. Повреждение private
файла, смена ELF, отказ verify или конфликт при commit оставляют прежний descriptor и
дают видимый отказ `server_selection_build_failed`. Обрыв между rename восстанавливается
обычным журналом выбора при следующей попытке.

Работающий сервер и открытые чаты сборка не останавливает. Для применения уже собранного
обновления владелец закрывает и снова открывает приложение; отдельный `use-server` для
автопривязки этой копии не требуется.

Проверки: `tests/server/ctl-build.test.js`, `ctl-build-events.test.js`,
`desktop-install-script.test.js`, `tests/desktop/build-selection.test.js` и
`tests/cli/build-session.test.mts`. Сборщики, установщики и ELF в них принадлежат
фикстурам; настоящие компоненты и настройки владельца не изменяются.
