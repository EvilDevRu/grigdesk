# StartLimitIntervalSec=0 в юните GrigDesk — не украшение

Дефолт systemd — «не больше 5 стартов за 10 секунд». При `RestartSec=5`
лимит выбирается почти мгновенно, и юнит уходит в `failed` НАВСЕГДА, без дальнейших попыток.
При включённых воротах VPN (ниже) это фатально: после перезагрузки туннель может появиться
через минуты — юнит к тому моменту давно сдался бы, и GrigDesk не встал бы уже никогда.
Поэтому в `[Unit]` стоит `StartLimitIntervalSec=0` — ждать столько, сколько нужно.
