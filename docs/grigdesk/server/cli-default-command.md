# Пустой вызов CLI

`grigdesk-ctl` без аргументов показывает меню, если stdin и stdout — терминалы и доступен
интерактивный режим. При перенаправлении любого потока или запуске из cgroup службы
команда выводит справку и завершается с кодом 0. В исходниках с установленным ELF отказ
проверки source Node переводит запуск на справку через автономный Node этого ELF.
Окно открывается по явному `grigdesk-ctl open` либо при выборе соответствующего пункта меню.

Чистый разбор пустого argv в `cli/args.ts` возвращает help. Это защищает исходный CLI и
собранный helper, включая прямой запуск helper после переноса установки. Bash-оболочка
дополнительно передаёт явный `--help` без двух терминальных потоков и при source fallback:
ранее установленный ELF с прежним helper также не открывает окно по умолчанию.

Справка не запускает окно, службу или контейнер и не запрашивает HTTP-состояние сервера.
Явный `open` сохраняет проверку графического сеанса, descriptor и сторожа ходов агента.

Проверки: `tests/cli/{entry,compatibility,menu-packaged,open}.test.mts` используют отдельную
установку, заглушки и PTY. Они покрывают три сочетания потоков без полного TTY, графический
и headless-сеанс, cgroup службы и scope окна, source fallback с Node 20 и установленным ELF,
передачу `--help` прежнему helper, перенос собранного helper и явное открытие окна.
