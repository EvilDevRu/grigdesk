# Совместимость сервера и установленного исполнителя при пересборке

`grigdesk-ctl build server` и `build all` вызывают общий установщик серверного ELF.
Перед заменой сервера установщик проверяет существующий соседний `bin/deepseek`:
metadata и bridges, ревизии профиля и политики GLM, допуск GLM по фактическим
входам сборки для режима потребителя, затем полный `--verify`. Требования берутся
из payload **кандидата сервера** через `--prepare`, а не из изменяемых исходников рядом с ним.
`--glm-mode api|coding-plan` переопределяет только режим admission, без изменения
ревизий и capabilities контракта; без флага остаётся режим host-контракта.
`grigdesk-ctl build` передаёт фактический режим из настроек:
[выбор режима проверки](server-install-glm-mode.md).

Несовместимость останавливает установку до изменения серверного ELF и receipt.
Старый сервер сохраняется; сообщение требует подготовить совместимую пару и
установить исполнитель через `deepseek install:binary` с контрактом целевого сервера.
Установщик не ослабляет runtime-проверки и не выдаёт допуск GLM новой сборке.
Проверенный кандидат исполнителя по-прежнему выпускается отдельным процессом.

На время проверки и публикации удерживается штатный lock установки DeepSeek.
SHA и файловый отпечаток исполнителя проверяются повторно перед публикацией сервера.
Подмена файла в обход установщика прерывает операцию. Preparation и временные home/cache
освобождаются и при отказе. Пробы не получают ключи провайдеров.

Если optional `bin/deepseek` отсутствует, первая установка сервера разрешена.
При нестандартном расположении передают `--deepseek-binary <абсолютный ELF>`;
явно выбранный, но отсутствующий файл вызывает отказ. `grigdesk-ctl build` передаёт
этот аргумент из `GRIGDESK_DEEPSEEK_BIN`, когда переменная задана. Из `.env`
извлекается только режим GLM; файл не загружается в окружение сборки.
Символическая ссылка вместо проверяемого ELF не принимается.

Обычная повторная сборка совместимого сервера не заменяет исполнитель и сохраняет
его доступность. Изменение контракта требует согласованного обновления пары;
остановка сборки защищает от прежнего сценария «сборка успешна, исполнители исчезли».
Работающие процессы не перезапускаются.

Проверки: `tests/server/server-binary-install.test.js` — отказы при новых ревизиях,
неподтверждённом admission и verify, сохранение ELF/receipt, подмена во время пробы,
освобождение lock/preparation и повторная совместимая установка.
