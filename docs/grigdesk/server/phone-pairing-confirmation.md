# Подтверждение привязки и состояние телефонных путей

Клиентский TLS-вход выбирает приложение один раз на соединение. Сокет, принятый до
привязки сертификата, остаётся в bootstrap даже после успешного pair. Поэтому успешный
`POST /api/client/pair` возвращает `Connection: close`. Следующий hello открывает новый TLS
и получает principal из устойчивого реестра. Повтор pair тем же сертификатом сохраняет
прежнее устройство; старые PAIR:1 и настольный клиент сохраняют формат и транспорт.

Телефонный QR выбирает только включённый ретранслятор с рабочим control и согласованной
capability `client-v2`. DNS перед выдачей приводится к нижнему регистру. IPv6-адрес
прежнего ретранслятора допустим в его реестре, но не в телефонном конверте: такой relay
пропускается с причиной `unsupported_address`, а доступный direct-QR продолжает выдаваться.

Административный статус содержит настроенные ретрансляторы даже до создания hub.
Поля `enabled`, `link.state`, `link.compatibility`, `link.lastError`, `phoneEligible` и
`phoneError` объясняют готовность. Ответ выдачи содержит `includedRelayId`: изменение
готовности relay само по себе не добавляет его в уже выданный QR.

Отказ валидации конверта возвращает `invalid_pairing`; переполнение строки либо матрицы
QR — `qr_too_large`. При неудаче сборки выданный телефонный код удаляется из памяти,
не занимая ограниченное место и не оставляя бесхозный действующий секрет.

Отказ привязки сохранённого адреса после смены сети объясняется недоступностью сети или
порта с предложением выбрать действующий интерфейс. Повреждение настройки остаётся
отдельной причиной. Отказ прежнего мобильного входа сохраняется в `server.error` и событии
`mobile_v1_start_failed`, даже когда client relay продолжает работать. Повторный start
при уже созданном hub не создаёт второе управляющее соединение.

При отсутствии живого control новый device получает `brain_offline`. Ошибка
`client_unavailable` означает живой control без согласованной capability. Массив
capabilities проверяется до смены control; прежний wire v1 сохраняется.
