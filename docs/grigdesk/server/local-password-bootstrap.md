# Первичная настройка пароля снята

Первичного setup и парольного входа в GrigDesk больше нет. Приложение подтверждает доступ
[локальным ключом](window-key.md), без формы и ручного ввода секрета. Старый файл учётной
записи сохраняется исключительно для переноса владельца локальных данных в `clientScope`.

Защита loopback, Host/Origin и запрет любого forwarded-заголовка действуют у обмена ключа.
Снятые пути с авторизацией возвращают JSON 404. Текущий контракт:
[интерфейс приложения](desktop-only-access.md).
