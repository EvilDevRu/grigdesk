# Условная правка значения в .env

`updateEnvFile(path, changes, { expected })` дополняет обычную точечную правку
проверкой прежних значений. `expected` задаёт строки или `null` для отсутствующей
переменной. Сверка выполняется под общей очередью писателя по тому же снимку,
из которого строится новая версия файла, и повторяется после конкурентной записи.
Несовпадение даёт `env_file_conflict` без изменения файла и без раскрытия значений.

Удаление привязки CLI использует этот контракт, чтобы не стереть новый путь,
который человек записал во время удаления пакета. Прежние двухаргументные вызовы
сохраняют поведение. Проверка — `tests/server/env-file.test.js`.
