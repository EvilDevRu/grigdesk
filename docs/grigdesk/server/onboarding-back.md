# Возврат по шагам мастера

`POST /api/onboarding/back` принимает только `expectedRevision` и `sessionId`.
Общий auth, CAS, блокировка писателя, атомарная запись, `no-store` и событие
`onboarding-changed` совпадают с остальными мутациями мастера. Чужой проход и устаревшая
ревизия дают 409, лишние поля и возврат с первого шага — 400.

Переходы: `project → ai`, `workspace → project`, `summary → workspace`.
Отклонённый проход не возобновляется; завершённый итог возвращается в `active`.
Ответы, `projectId`, сохранённый intent и ревизия паспорта остаются прежними.
Для созданного проекта снимок ответов получает `complete=false`, следующее завершение
восстанавливает `complete=true`. Отключённый автоматический запуск не включается повторно.

Повторное продвижение с шага проекта при `projectSaved=true` только сохраняет
`step=workspace`. Оно не вызывает создание паспорта и не откатывает правки обычной формы.
Если создание ещё не было подтверждено, остаётся прежний безопасный повтор по intent.
Повторное прохождение шага ИИ обновляет `aiSkipped` и в снимке ответов проекта.
