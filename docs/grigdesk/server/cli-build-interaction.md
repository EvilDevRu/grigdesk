# Прогресс и итог сборки в терминале

`grigdesk-ctl build` и пункт «Сборка» используют один индикатор Go-версии. На экране меню
выбранная цель сменяется прогрессом, затем итогом. То же происходит при сборке дистрибутива.
Перед началом виден путь к полному журналу. Строка стадии обновляется и показывает прошедшее
время. При параллельной сборке в ней перечислены активные стадии. Если цель имеет
фиксированное число стадий, шкала считает долю успешно пройденных. Сборка DeepSeek может
добавлять шаги допуска в процессе, поэтому для неё показаны стадия и время.

Успешная сборка оставляет сообщение об установленных компонентах. Подсказки о сборке
окна после `web` и о привязке собранного сервера остаются в выводе. При ошибке CLI
показывает код, путь и последние 20 строк журнала. В меню Ctrl+C отменяет текущую сборку.
После успеха, ошибки или отмены Enter или Esc возвращает к той же цели. Стрелки и PgUp/PgDn
листают подробности. Оболочка показывается после выхода из меню. Прямая команда выводит
результат в обычный терминальный поток и завершается с кодом сборки.

`NO_COLOR` сохраняет обновление строки без цветов. `TERM=dumb` пишет стадии
отдельными строками без ANSI и обновления по таймеру. Вне человеческого TTY сборщик
передаёт обычный поток, а машинный наблюдатель может читать события fd 3.
