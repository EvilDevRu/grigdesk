# Обновление прогресса и открытие окна после сборки

В человеческом терминале `grigdesk-ctl build [all|server|web|window]` после успешной
сборки показывает итог и вопрос «Открыть окно GrigDesk?». Тот же выбор появляется при
сборке из меню. По умолчанию выбрано «Не открывать»: Enter подтверждает текущий пункт,
стрелки переключают выбор, Д/Y открывает окно, Н/N или Esc отклоняет запуск.
Ctrl+C завершает CLI с кодом 130, SIGTERM — 143; настройки терминала восстанавливаются.

Подтверждение вызывает существующую команду `open` с её проверками графического сеанса,
установленного окна и допуска действия. Код отказа открытия становится кодом CLI.
Успешное действие из меню возвращает подменю сборки сразу после выбора, без второго Enter.
Для `bundle` сохраняется обычный итог: комплект не устанавливается и окно не предлагается.
После ошибки сборки вопрос не появляется. Запуски вне человеческого TTY сохраняют поток
строк и завершаются без чтения ответа.

Предложение запуска не заменяет подсказки результата: после `web` по-прежнему требуется
`build window` для встраивания веба в окно; сохранённый выбор другой установки сервера
остаётся виден. Открытие не закрывает работающее окно и не перезапускает сервер.

`TerminalSession.draw()` записывает очистку и новый кадр одной записью. Экран прогресса
включает `incremental`: после первого кадра обновляются только изменившиеся строки,
короткие строки очищают прежний хвост. Одинаковый кадр ничего не пишет. При уменьшении
числа строк удаляется остаток прежнего экрана; resize и передача терминала внешней
команде сбрасывают снимок. Кадры, выходящие по высоте за экран, выводятся целиком,
поскольку прокрутка меняет абсолютные позиции строк.

`NO_COLOR` сохраняет обновление строк без стилей. `TERM=dumb` сохраняет простой вывод
без ANSI и таймерной анимации. Полный журнал и каналы сборочных событий не меняются.

Проверки: `tests/cli/terminal.test.mts` проверяет записи кадров, изменение строки,
удаление хвоста и сброс снимка; `tests/cli/build-session.test.mts` использует PTY
и заглушки для открытия, отказа, прерывания, меню, ошибок и нетерминальных запусков.
