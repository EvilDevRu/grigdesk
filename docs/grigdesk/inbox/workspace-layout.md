# Очередь и выбранная переписка

`/inbox` использует раскладку `workspace`: экран занимает доступную область без внешнего
поля страницы и ограничения ширины. Общая `UiPaneHeader` содержит название и обновление;
сворачиваемые каналы сохраняют независимые состояния подключения и приёма новых обращений.

Слева находится прокручиваемый каталог шириной 300–360 px, справа — одно выбранное
обращение. В строке каталога видны канал, время, заголовок, источник, последнее сообщение,
статус и число сообщений. Строки используют общий control `workspace-catalog-row`.
Текст заголовка, состоящий только из URL, заменяется первой содержательной строкой
сообщений; исходный URL остаётся доступен в переписке и описании источника.

Переписка показывает полный текст сообщений и вложения. Описание источника по умолчанию
свёрнуто, если есть сообщения: оно может повторять весь разговор. Если сообщений нет,
описание показывается сразу. Нижняя полоса действий находится вне прокручиваемой части,
поэтому создание задачи, пропуск и возврат к разбору доступны и в длинной переписке.

## Поиск и выбор

Поиск выполняется локально по заголовку, описанию, проекту, источнику, авторам и текстам
сообщений без учёта регистра. Фильтр канала применяется вместе с поиском и выбранной
вкладкой. Счётчики «К разбору» и «История» показывают размер соответствующих разделов
до фильтрации. При пустом результате можно сбросить оба фильтра.

Раздел определяется наличием нерешённых сообщений, а не одним статусом карточки.
Выбор сообщений хранится отдельно для каждого обращения и сохраняется при переходах
между строками. SSE перечитывает существующий API и сохраняет открытое обращение по
`ref`. Если оно уходит из видимого списка после решения, открывается соседняя строка.
Новые и пропущенные сообщения по-прежнему нельзя смешивать в одном действии.

## Узкая область

При ширине контейнера до 900 px список и подробности занимают одну колонку по очереди.
Сначала показывается список; нажатие строки открывает переписку и переводит фокус на
её заголовок. «К обращениям» возвращает список с прежними фильтрами и фокусом строки.
Адаптив зависит от ширины самой области и работает при сужении панели в большом окне.

## Проверки

`inbox-view.component.test.js` проверяет точные подмножества сообщений, историю,
сохранение выбора при навигации и SSE, фильтры, переход к соседнему обращению и свёрнутое
описание. `inbox-responsive.test.js` проверяет настоящий экран на ширинах 320–1920 px,
увеличенный текст, узкую область в широком окне, длинные ссылки, прокрутку и доступность
действий. Фикстуры содержат только вымышленные обращения.
