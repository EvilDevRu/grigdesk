# Отдельные окна карточек задач

В desktop с возможностью `windows` обычное открытие
задачи Б24 создаёт немодальное окно без родителя и без режима «поверх всех». Ключ окна —
origin машины, вид `task` и канонический номер задачи. Ограничения числа окон нет.
Повторное открытие поднимает тот же документ без перезагрузки: введённый текст сохраняется.
Открытие соседней задачи из карточки создаёт или поднимает её собственное окно.

Содержимое остаётся общим `TaskModal`: рамка `TaskCardFrame` выбирает диалог либо документ.
Системных кнопок у окна нет: его двигают за шапку карточки и закрывают её кнопкой
([оформление окна](desktop-titlebar.md)).
Документ регистрируется в общем стеке слоёв ниже дифа и подтверждений: первый Escape закрывает
верхний слой. «Конвейер» ждёт успешного перехода главного документа и лишь затем закрывает
карточку. При ошибке карточка остаётся открытой. В документе карточки нет чата, «Кода», Monaco
и терминалов: их действия адресуются главному документу. Отдельные окна инструментов
описаны в [своём контракте](tool-windows.md). Черновики не переносятся между окнами и не восстанавливаются после закрытия.
Закрывающий карточку Escape завершается после отпускания клавиши: оставшаяся часть нажатия
не попадает в следующее окно. Программная «Назад» не ожидает физического отпускания клавиши.
Заголовок и описание карточки обновляются её собственными действиями и новым открытием после
закрытия; повторное поднятие живого окна их не перечитывает.

Native принимает только закрытый target или назначение главного окна через существующую
защищённую трубу. URL и опции BrowserWindow строит главное приложение. Подтверждённый отказ
создания означает, что окно уже уничтожено: главный документ показывает прежний диалог.
Если запрос пришёл из карточки, диалог доставляется главному окну, собственная карточка
не подменяется. Потеря или неверная форма ответа означает неизвестный исход: показывается
подсказка повторить нажатие, без автоматического POST или диалога. Реестр дедуплицирует повтор.

У всех карточек общая последняя геометрия `surfaceWindows.task`, отдельная от `window` главного
окна; версия settings остаётся 2. Положение и размер сохраняются через прежнюю атомарную очередь.
Новое окно получает сдвиг 32 DIP, вписывается в доступную рабочую область и оставляет предыдущую
карточку видимой, в том числе у края или после maximized. Перед показом положение проверяется
повторно: загрузки могут завершиться в другом порядке.
При подборе сдвига проверяются позиции всех видимых карточек: шаг назад у края не должен
вернуть новое окно на позицию более ранней карточки.
Maximized применяется только к первому видимому окну, следующие открываются обычными.
Недоступный монитор заменяется доступным,
предпочтительно экраном главного окна. На Wayland окончательное положение выбирает композитор.

Закрытие карточки оставляет приложение работающим. Выход главного окна закрывает все карточки;
смена машины уничтожает окна прежнего origin, включая ещё загружающиеся. Автоматического
восстановления списка открытых карточек после запуска нет. Браузер, Android и старый пакет
без `windows` сохраняют диалог и прежнее действие «Назад».

Проверки: `surface-contract`, `surface-windows`, `surface-geometry`, `surface-launcher`,
`task-window-navigation`, `task-modal-edit`, `task-dialog-back.browser`, `task-window.e2e`.
Физический перенос между мониторами, Wayland и микрофон требуют проверки на устройстве.
