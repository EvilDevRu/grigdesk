# Значок успешного оповещения

Общий `UiInlineMessage` с тоном `success` показывает простую галочку без круга.
Она использует текущий цвет и общую толщину линий значков сообщения. Такой знак
применяется во всех сообщениях с заголовком или кнопкой закрытия, в том числе
в результате удаления плагина. Сообщения без этих параметров сохраняют только текст.

Текст результата, зелёный тон, доступная роль и закрытие сообщения не зависят
от рисунка. Галочка не пересекает круговую рамку и не образует похожий на банковский
логотип силуэт.
