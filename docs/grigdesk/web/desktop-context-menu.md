# Контекстное меню окна

В главном desktop-документе и окнах surface меню правки рисует общий
`UiDesktopContextMenu` из публичной UI-границы. Оно использует общую палитру,
компактные строки с иконками и правую колонку сочетаний клавиш. Копирование адреса
ссылки отделяется от правки разделителем. Меню ограничено видимым окном.
Внешней рамки и внутреннего светлого контура нет; панель отделяется от фона мягкой тенью.

Источник доступных действий остался `desktop/src/menu.ts`: editFlags Electron
и наличие ссылки. `desktop/src/contextMenu.ts` передаёт документу подписи, координаты
и обозначения команд через `executeJavaScript`, без preload, IPC и доступа к Node.
Документ возвращает индекс. Главный процесс проверяет его по исходному шаблону;
команды буфера исполняет webContents, адрес ссылки остаётся в callback главного процесса.
В документах без host сохраняется системное меню.

Щелчок не забирает фокус у редактора. Стрелки, Home и End перемещают выбор,
Enter и пробел исполняют команду; перед ответом восстанавливается фокус редактора.
Escape закрывает верхний слой через общий стек. Щелчок снаружи, прокрутка страницы,
потеря фокуса окна, изменение его размера и новый запрос закрывают прежнее меню.

Изменение требует пересборки desktop-пакета вместе с web: уже открытое окно
продолжает исполнять прежний главный процесс.

Проверки: `tests/desktop/{menu,context-menu}.test.js`,
`tests/web/desktop-context-menu.component.test.js`.
