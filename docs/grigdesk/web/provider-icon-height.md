# Высота знаков исполнителей в топбаре

`AppShell.vue` передаёт `equal-height` в `ProviderIcon.vue`. Codex и Claude получают
`size=14` с видимым рисунком около 13 px; остальные — `size=13` с рисунком около 12 px.
Кадр вычисляется из границ геометрии, измеренных через SVG `getBBox()`;
для Claude учтён штрих 2.4.
Исходный кадр центрирует рисунок по обеим осям с одинаковыми отступами.
В топбаре после этого применяется [привязка к физическим пикселям](provider-icon-pixel-snap.md)
через небольшой сдвиг без изменения масштаба.

Пропорции сохраняются: широкий знак DeepSeek получает больше ширины, чем квадратные
соседи. Масштабирование квадратного SVG без изменения его кадра не выравнивает
видимую высоту: у кита оставались большие вертикальные поля. Без `equal-height`
компонент сохраняет квадратные размеры и прежние кадры для аватаров и других мест.

Tripo использует двухцветный вариант из Lobe Icons: верхний контур `#F6D85A`, нижний
наследует цвет текста. На тёмном фоне это жёлтый и белый знак, как в
[логотипе сайта Tripo](https://cdn-web.tripo3d.ai/tripo-web/logo/tripo-logo1.webp).
У недоступного исполнителя оба контура наследуют приглушённый цвет.
Источник цвета — `packages/static-svg/icons/tripo-color.svg` в той же закреплённой
ревизии Lobe Icons, что и геометрия; MIT notice поставляется с web.

Проверка в браузере монтирует полный `AppShell.vue` с синтетическими хранилищами.
Нужно сравнивать высоту и центр самого рисунка через `getBBox()` и SVG matrix,
а также проверять сохранение пропорций, отсутствие обрезки и окраску обоих контуров.
