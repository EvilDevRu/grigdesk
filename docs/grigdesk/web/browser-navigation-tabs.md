# Поиск и управление вкладками браузера

В «Инструменты → Браузер» поле «Поиск по умолчанию» выбирает Яндекс или Google.
Умолчание — Яндекс, включая существующие настройки без поля `search`. Изменение
проходит общую staged-сессию и сохраняется на этом компьютере только по «Применить».

Адресная строка принимает HTTP(S) URL, домен без схемы, IPv4, IPv6 в квадратных
скобках и localhost с портом. Для loopback и localhost добавляется HTTP, для остальных
адресов — HTTPS. Обычный текст превращается в поисковый URL выбранной системы с
кодированием параметра. Пустой ввод, управляющие символы, credentials и альтернативные
схемы отклоняются. Строгая проверка URL для IPC и инструментов агентов сохраняется;
распознавание текста применяется только к адресной строке человека.

Правая кнопка на вкладке или Shift+F10 открывает общее `UiPopover`-меню: новая вкладка,
обновление, дублирование, закрытие, закрытие остальных и вкладок справа. Меню работает
с указанной вкладкой независимо от активной. Дубликат создаётся как человеческая
вкладка, без копирования агентских разрешений. Средняя кнопка закрывает вкладку.

Вкладки переносятся внутри полосы; половина вкладки под курсором определяет вставку
до или после неё. Native-операция `move` меняет порядок реестра без навигации,
пересоздания WebContents и изменения grants. Снимки состояния сохраняют этот порядок.
Клавиатурные стрелки общего `UiTabs` следуют текущему DOM-порядку после переноса.

Горизонтальная полоса прокрутки скрыта. Колесо, трекпад, прокрутка у краёв при переносе
и показ выбранной вкладки сохраняют доступ к переполненной полосе; «+» остаётся виден.

Оповещения не входят в стек Escape. `BrowserViewport` отдельно подписан на центр
тостов: наличие оповещения синхронно скрывает native-поверхность до DOM paint.
После закрытия последнего оповещения актуальная геометрия возвращает ту же страницу
с сохранённым состоянием. Пока открыт другой UI-слой, поверхность остаётся скрыта.
