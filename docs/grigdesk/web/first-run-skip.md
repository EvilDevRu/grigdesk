# Пропуск настройки

В постоянном подвале мастера на каждом шаге есть кнопка «Пропустить настройку»
(«Skip setup» в английском интерфейсе). Она заменяет прежнюю подпись «Настрою сам»
и позволяет закончить оставшуюся настройку, даже если поля проекта ещё пусты.

Действие ждёт сохранения ответов и подтверждения `/dismiss`, закрывает мастер
и открывает обычное место настройки. Автоматическое приглашение отключается;
мастер можно снова открыть кнопкой в топбаре. Если проект уже создан, он сохраняется.
Ошибка записи оставляет мастер открытым с введёнными ответами.

Отдельная кнопка «Пропустить шаг» на шаге ИИ пропускает только подключение исполнителей
и переводит к проекту. Пропуск оставшейся настройки на шаге проекта не создаёт
пустой паспорт и не переводит к выбору режима задач без проекта.
Обе кнопки используют один общий вариант `outline` с видимой рамкой на всех шагах.
