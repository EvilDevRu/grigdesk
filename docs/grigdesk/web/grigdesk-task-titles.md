# Названия задач на общей доске

Все строки принадлежат внешним трекерам. Кнопка названия использует публичный `UiButton`
и общий вход `ui.openTask` с номером и источником. Общий стиль действий разрешает перенос
текста и длинных слов; высота следует содержимому. Локального оформления control нет.

На телефоне название идёт первым; номер, проект и источник находятся в метастроке,
оценки и состояние конвейера — в следующем блоке той же строки. Прежний CSS-контекст
`grigdesk-task-title` не обозначает встроенный источник задач.
