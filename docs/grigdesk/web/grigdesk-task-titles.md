# Названия собственных задач на доске

Кнопка названия в группе «Задачи GrigDesk» использует публичный
`UiButton` с контекстом `grigdesk-task-title`. Общий стиль действий разрешает
перенос текста, увеличивает высоту кнопки по содержимому и ограничивает её шириной
строки. Длинное слово также переносится: название остаётся доступным в узком окне.

Контекст объявлен в `web/src/styles/components/actions.css`; локального оформления
control в `BoardView.vue` нет. Нажатие сохраняет общий вход `ui.openTask`.

На телефоне название располагается первым и использует основной цвет текста, как у
задач внешнего трекера. Полный номер, проект и источник находятся в отдельной
метастроке, оценки и состояние конвейера — в следующем блоке той же строки задачи.
Геометрия кнопки по-прежнему принадлежит общему actions.css.
