# Компактная доска задач

`BoardView.vue` разделяет постоянные действия списка и дополнительные параметры.
Поиск, кнопка «Фильтры», «Избранные» и «Новые» видны при любой ширине.
Сортировка, источники, проект, режим оценки, общий сброс и «Оценить все» находятся
в раскрываемой панели. По умолчанию она закрыта также на desktop. Число активных
параметров отражается на кнопке фильтров; поиск в это число не входит.

На desktop время последнего успешного снимка находится в общей шапке доски.
При отказе обновления рядом остаётся предупреждение об устаревшем снимке.
Телефон сохраняет постоянный подвал со временем и горизонтальные страницы списков.

При первом чтении внешнего трекера верхний каркас занимает только сводку
(`BoardLoading summaryOnly`). Общий список «Мои задачи», его поиск и фильтры уже
смонтированы ниже и показывают доступные снимки внешних драйверов. Второго каркаса списка
над ними нет. Полный каркас остаётся у оболочки до загрузки компонента доски.

Основной список получает больше места, чем боковая колонка контроля и поручений.
Колонки переносятся по доступной ширине; до 720 px внутри основного контейнера
поиск и фильтры переходят под заголовок. Дополнительные параметры в этом режиме
располагаются вертикально. Длинные названия задач переносятся без обрезания.

Строки разделены прямыми линиями. Невыбранные звёзды и метаданные приглушены,
выбранные звёзды сохраняют предупреждающий цвет. Оценка показывает сначала итоговое
кольцо, затем сложность, риск и размер без отдельных рамок; подробности доступны
в прежней подсказке, в том числе с клавиатуры. Цветовые шкалы не изменены.

Skin элементов управления принадлежит `styles/components/actions.css`.
Экран задаёт компоновку; `TriageBadge.vue` оформляет только метрики и пояснения.

Проверки: `board-filters.component.test.js`, `board-phone-pages.component.test.js`,
`board-stale-snapshot.component.test.js`, `triage-badge.component.test.js`.
Компонентные проверки не заменяют визуальную приёмку в приложении.
