# Новая установка и просмотр прежнего задания

Открытие «Установить из Git», новой карточки каталога или обновления пакета означает
новую операцию. `PluginInstallDialog.vue` очищает адрес, выбор версии, подтверждение
замены ручных правок, справку и результаты прежнего поиска. Завершённые задания
`done`, `failed`, `cancelled`, `interrupted` скрываются до чтения current и после него:
серверная история не подменяет новую форму и не мигает во время bootstrap.

`PluginWorkspacePage.vue` передаёт `resume` только для явного «Открыть задание установки».
Этот путь сохраняет прежний результат. Установка из Git и выбор каталога снимают `resume`.
Итог операции, завершившейся в открытом мастере, остаётся видимым до закрытия.

Незавершённый job, ожидание перезапуска, recovery, занятость и согласование неизвестного
исхода сохраняют приоритет. Если известная активная операция заканчивается во время
чтения current, её результат показывается. Закрытие или размонтирование лишает поздний
bootstrap права скрыть задание нового открытия и запускать поиск версий.

Общий мастер обслуживает плагины и драйверы БД. Проверки: `plugin-install-dialog.component.test.js`,
`db-engine-install-dialog.component.test.js` и `plugin-marketplace.component.test.js`.
