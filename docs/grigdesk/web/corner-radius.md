# Скругления интерфейса

В `web/src/styles/tokens.css` есть два общих токена: `--control-radius: 9px`
для базовых controls и `--radius: 12px` для части поверхностей.
Базовые кнопки, поля и поверхности всплывашек используют общий control-radius.

Полной шкалы радиусов и общего набора классов `rounded-*` нет. В таблицах стилей
и SFC остаются собственные значения: например, 8 px у ссылки настроек в топбаре,
14 px у диалоговой поверхности в `overlays.css`, 999 px у капсул и 50% у кругов.
Поэтому изменение двух токенов не меняет скругления всего интерфейса.

Общие компоненты и публичная граница `web/src/ui.ts` централизуют использование
controls, но сами по себе не означают, что все радиусы берутся из одной шкалы.
