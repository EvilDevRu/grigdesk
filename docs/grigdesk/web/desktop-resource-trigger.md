# Кнопка ресурсов в заголовке desktop

`SystemResourcesButton` находится непосредственно в верхней панели, рядом со сводкой
статусов. Кнопка включена в `no-drag` оболочки: участок с CPU/RAM принимает нажатие
и открывает общий диалог ресурсов, даже когда остальная шапка перетаскивает окно.
При переносе интерактивного элемента из `.status` это исключение нужно сохранить.

Красная метка тревоги расположена внутри кнопки: сверху 2 px, справа 0.
Высота desktop-кнопки — 28 px, справа оставлено 12 px под метку. Отрицательные
смещения поднимали метку к краю окна и обрезали её. Телефон использует собственный
контекст кнопки и прежнюю площадку второй полосы.

Компонентная проверка читает применяемые правила кнопки и проверяет принадлежность
к области `no-drag`. Она не воспроизводит нативную обработку мыши desktop-окном.
