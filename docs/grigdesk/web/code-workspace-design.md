# Рабочая область «Код»

Раздел использует плотную компоновку просмотра изменений по образцу IDE: дерево слева,
просмотр файла справа и отдельная форма коммита внизу навигатора. Одна панель CodePanel
обслуживает полноразмерную страницу и док; состояние файла, рабочей копии и Monaco
сохраняется при переключении представления.

## Общая сетка

У панели единый шаг служебной строки 40 px и боковое поле 12 px. Заголовок дерева
совпадает по высоте с путём файла, строка поиска — с навигацией сравнения, а заголовок
первой группы без активных фильтров — со строкой проверки. Границы считаются вместе
с padding и border через border-box; дополнительные статусы и активные фильтры
занимают собственные строки, сохраняя высоту базовых полос.

Заголовок группы не переносит итог строк на вторую строку. В навигаторе уже 360 px
скрывается декоративная полоска статистики, а уже 300 px — числовой итог группы.
Счётчик файлов и действия остаются в одной строке. Нижняя синхронизация использует
тот же шаг и боковые поля.

Команды diff разделены на группу сторон и блоков и группу файлов и вида. Счётчики
имеют фиксированное место и табличные цифры. В редакторе уже 760 px подписи вторичных
действий проверки скрываются, доступные имена и подсказки сохраняются. Уже 520 px
навигация занимает два ряда; прямое переключение колонок скрывается, а настройки
остаются доступны через «Вид сравнения».

## Навигатор

Строка поиска занимает доступную ширину, рядом находятся фильтр статуса и меню команд
дерева. Неактивные групповые команды скрыты до выбора файлов. Поиск, статус и выбранные
пути независимы: скрытые фильтром пути остаются выбранными и требуют явного включения
при выполнении операции. Команды дерева и проверки используют общие UiPopover,
UiButton и UiIconButton из публичной границы UI.

## Сравнение

Первый ряд шапки показывает путь и действия файла. Второй — стороны сравнения,
переходы по блокам и файлам, расположение колонок и кнопку-значок «Вид сравнения».
Настройки больше не повторяют название текущего расположения на постоянной панели.
Селект файлов появляется при скрытом навигаторе либо в узкой панели; при открытом
дереве файл выбирается в нём.

Строка проверки показывает отметку, числовой прогресс и переход к непросмотренному.
Дополнительные команды строк и блоков собраны в меню «Действия с кодом» и закрывают
его после выбора. Корзина замечаний остаётся отдельной кнопкой со счётчиком. На ширине
редактора до 520 px команды переносятся; парное сравнение при недостаточной ширине
по-прежнему временно становится одной колонкой. Перерасчёт зон diff отложен за пределы
текущей отрисовки Monaco, чтобы изменение ширины не разрушало его whitespace-снимок.

Сообщения о результатах Git-действий выводятся общими тостами окна, которые можно
закрыть. Уход из раздела не снимает признак выполняемого push. Нижняя полоса хранит
только состояние ветки; [контракт выполнения](../plugins/code-git-notifications.md).

## Проверка

Компонентные сценарии проверяют доступность команд через настоящие popover, сохранение
выбора, фильтры, заметки и частичный индекс. Изолированный предпросмотр с настоящим
CodePanel и Monaco использует демонстрационные API и не подтверждает обновление
установленного приложения.
