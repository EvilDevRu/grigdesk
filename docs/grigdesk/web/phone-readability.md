# Читаемость рабочих панелей на телефоне

При viewport до 600 CSS px рабочие области используют шкалу 16/15/13 px: поля и заголовки
групп, основной текст, метаданные и подписи. Служебная полоса панели или диалога использует
отдельную [компактную шкалу шапки задачи](phone-panel-headers.md). Финальный слой fields.css перекрывает
desktop overrides рабочего пути и включает UiNumberInput. Сенсорный минимум 44 px
сохраняется через существующие control-токены и `data-ui-touch`.

В CodePanel меняется только структура шапки: проект и рабочая копия располагаются
широкими строками с подписью слева и значением справа. Выбранное значение допускает две строки; полная подпись
остаётся в открытом UiSelect. Состояние контекста, события native change, Monaco и
ResizeObserver используют прежних владельцев. На 601+ сохраняется desktop-раскладка.

`phone-readability.component.test.js` проверяет вычисленный CSS настоящих controls и
UiPaneHeader на телефоне и desktop, `code-view.component.test.js` — структуру контекста
и прежние сценарии файлов. Компактные отступы описаны в [плотности телефона](phone-density.md). Эти проверки не доказывают геометрию, нативную клавиатуру
или удобство при повороте: для них нужна визуальная проверка актуального приложения.
