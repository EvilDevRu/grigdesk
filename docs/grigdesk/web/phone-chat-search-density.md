# Компактная шапка поиска чатов на телефоне

До 600 CSS px шапка `ChatList` получает высоту по содержимому вместо прежнего
`min-height: 108px`. Вертикальные поля составляют 6 px, промежуток между поиском
и архивом — 4 px. Пустой запас сверху и снизу больше не центрирует два ряда
внутри завышенной шапки. Поиск использует общую высоту однострочных полей.

На desktop и двухколоночном планшете действует прежний `--chat-head-h`, чтобы
разделители списка и разговора оставались на одной линии. Длинная подпись архива
может увеличить высоту по содержимому; фиксированного обреза нет.

На Android в двухрядной раскладке обе шапки используют ряды высотой от 44 CSS px
на touch, с промежутком 4 px и вертикальными полями 4 px. Поиск центрируется
на уровне названия и проекта, а «Активные / Архив» и воронка — на уровне модели.
Панель фильтров и чипы добавляют высоту ниже этих рядов. В двухколоночном окне
до 1024 × 600 CSS px, где выбор проекта занимает строку над поиском,
остаётся компоновка списка по содержимому.

Геометрия проверяется в общем интерфейсе на синтетическом списке разговоров,
без чтения переписки или состояния телефона.

Сам поиск использует публичный `UiSearchInput size="compact"`: 44 px до 600 CSS px,
32 px в широком окне и шрифт 13 px. Тот же вариант используют каталоги проектов и баз.
