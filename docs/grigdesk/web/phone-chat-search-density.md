# Компактная шапка поиска чатов на телефоне

До 600 CSS px шапка `ChatList` получает высоту по содержимому вместо прежнего
`min-height: 108px`. Вертикальные поля составляют 6 px, промежуток между поиском
и архивом — 4 px. Пустой запас сверху и снизу больше не центрирует два ряда
внутри завышенной шапки. Размеры и поведение поиска, создания чата и архива сохраняются.

На desktop и двухколоночном планшете действует прежний `--chat-head-h`, чтобы
разделители списка и разговора оставались на одной линии. Длинная подпись архива
может увеличить высоту по содержимому; фиксированного обреза нет.

Геометрия проверяется в общем интерфейсе на синтетическом списке разговоров,
без чтения переписки или состояния телефона.

Сам поиск использует публичный `UiSearchInput size="compact"`: 32 px и шрифт 13 px.
Этот же размер подключают каталоги проектов и баз без заимствования чатового контекста.
