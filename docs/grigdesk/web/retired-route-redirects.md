# Переходы со снятых адресов

Старый hash-адрес `/agents` переводит в `/routes`.
Это точный redirect без собственного экрана, названия и метаданных страницы.
Параметры query сохраняются, в том числе при открытии закладки и перезагрузке окна.
Правило одинаково для desktop и сенсорного интерфейса, русского и английского языка.

В меню остаётся пункт «Маршруты». Снятый адрес не входит в список страниц журнала окна
и не получает серверную подсказку UI-контекста чата.
