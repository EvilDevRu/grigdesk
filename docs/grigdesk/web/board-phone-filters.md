# Фильтры доски на телефоне

До 600 CSS px кнопка фильтров занимает 44 px рядом с поиском и показывает только воронку.
Полное имя и число активных фильтров доступны в aria-label, назначение — в подсказке.
На desktop видимые подпись и счётчик сохранены. Компактный loading использует такую же
колонку 44 px, чтобы поиск не менял ширину при первом ответе.

В раскрытой панели оценка представляет три равных сегмента в одном ряду: «Все»,
«Без оценки», «Нужны уточнения». Подпись может переноситься, все ячейки растут вместе;
высота сенсорного сегмента — от 44 px. Выбранное состояние использует общую заливку UI.
Выбор остаётся взаимоисключающим, поиск, независимые фильтры и сохранённые предпочтения
продолжают использовать прежнее состояние доски.

Телефонная навигация между тремя страницами визуально имеет сегменты от 32 px.
Прозрачная область расширяет касание на 6 px сверху и снизу; текущие зазоры отделяют её
от соседних controls. Контейнер навигации не обрезает эту область. Подписи на узком экране
могут увеличить высоту. Списки сохраняют собственную прокрутку и CSS scroll-snap.

board-phone-pages.component.test.js проверяет computed CSS, доступную подпись фильтра
и выбор оценки; board-filters.component.test.js сохраняет поведение фильтров и сброса.
