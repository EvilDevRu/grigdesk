# Меню инструментов

Меню в боковой рейке использует `UiTopbarPanel` из публичного `ui.ts`: фон,
ширина 352 px, отступы 16 px, заголовок и подвал общие с панелями топбара.
Отдельного оформления `.tools-popover` больше нет.

Параметры `attachment="trigger"`, `placement="right-start"` и
`trigger-mode="click"` сохраняют открытие справа от кнопки рейки по нажатию.
Панель [примыкает к рейке без зазора](tools-menu-attachment.md).
Обычная панель топбара по умолчанию остаётся привязанной к его нижнему краю.
Обе панели делят реестр: открытие меню закрывает панель топбара и наоборот.
`UiPopover` по-прежнему отвечает за границы видимой области, прокрутку,
Escape, клик снаружи и возврат фокуса.

Внутри меню `ToolsGrid` получает `layout="list"`: каждая строка содержит
иконку, полную подпись инструмента и счётчик при его наличии. Текущий раздел
обозначен `aria-current="page"`. Ссылка «Все на странице» находится в общем
подвале. Состав и порядок инструментов берутся из существующего каталога плагинов.

Без параметра `layout` компонент сохраняет сетку на странице инструментов.
Телефонные [«Разделы»](phone-sections.md) передают `layout="list"`, группы категорий
и opt-in `searchable`; по умолчанию поиск
выключен. Фильтр проверяет label без учёта регистра, сохраняя порядок, маршруты и badges.
Пустой результат имеет сообщение с `role="status"`. Общий диалог сначала фокусирует
`nav.tools-grid`, поэтому поиск не вызывает клавиатуру до явного ввода. При закрытии
дочерний каталог размонтируется и новый показ начинает с пустого запроса.
Оба вида используют `UiActionLink` с настоящим
`href` через custom-слот RouterLink; стили ссылок находятся в
`styles/components/actions.css`, структурная сетка — в `ToolsGrid.vue`.

Проверки: `ui-topbar-panel.component.test.js` покрывает разные привязки и
взаимное закрытие; `app-shell-controls.contract.test.js` — подключение общей
оболочки и списка в AppShell.
`tools-grid.component.test.js` проверяет фильтрацию, динамические пункты и badges,
единственный переход, initial focus и сброс запроса внутри настоящего UiDialog.
