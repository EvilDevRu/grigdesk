# Раскладка студии 3D

Панель использует подписанные вкладки «Создать», «Модели» и «Задачи» из общего UI-kit.
Вкладки поддерживают стрелки и связаны с областью содержимого через aria-controls.
Баланс, резерв и размер библиотеки находятся в шапке; предупреждение о свободном месте
сохраняет отдельный цвет. Стили controls принадлежат общим `patterns.css` и `actions.css`.

## Создание

Источник, описание и параметры генерации собраны в смысловые блоки. Имя, проект и
категория вынесены в блок «В библиотеке». Наборы параметров выбираются общим segmented
control, дополнительные параметры раскрываются отдельно. Переключатель текстуры или
материалов содержит собственную подпись рядом с дорожкой.

При ширине панели больше 859 px блок метаданных стоит справа; в узком доке он следует
после параметров. Раскладка зависит от ширины контейнера, а не окна браузера. Источники
и наборы переносятся, поля параметров переходят из двух колонок в одну, ракурсы получают
карточки с минимальной шириной 240 px, ограниченной доступным местом.

Прокручивается только тело создания. Нижняя полоса с расчётной стоимостью, объяснением
блокировки и действием постоянно видна. Бесплатный импорт использует ту же полосу.
Проверка цены, баланса, server validation и подтверждение всей пачки остаются у прежних
обработчиков. Переключение compact/expanded не перемонтирует форму и не стирает ввод.

## Библиотека, задачи и модель

Библиотека и задачи используют всю доступную ширину без пустых боковых колонок.
В библиотеке есть создание модели, фильтры, карточки с превью и два пустых состояния:
первая модель и отсутствие совпадений поиска. Задачи разделены на активные, недавние,
внешние и недельные расходы; неизвестные суммы и неполная история сохраняются явно.

Только открытая модель получает дерево версий, просмотрщик и подробности. На широком
экране это три колонки; ниже 1100 px подробности идут под просмотрщиком, ниже 760 px
всё складывается в одну прокручиваемую колонку. Обычный компактный док всегда использует
одну колонку. Узлы дерева и модели сохраняются при разворачивании. Ширина дерева из
настройки устройства действительно передаётся в CSS grid через `--studio-nav-width`.

Проверки: `studio3d-view.component`, `studio3d-create.component`, `studio3d-form.component`,
`studio3d-library.component`, `studio3d-tasks.component` и общие сторожа UI.
Изолированный браузерный стенд проверяет настоящие SFC с синтетическими данными;
он не отправляет заказы исполнителю.
