# Основа для визуального разбора интерфейса

Общие controls экспортируются через `web/src/ui.ts`. Их использование само по себе
не унифицирует заголовки, композицию страниц, внутренние отступы и поверхности.

## Существующая галерея

`web/ui-gallery.html` — отдельный dev/test entry. Его компонент
`web/dev/ui-gallery/UiGallery.vue` использует настоящие controls через публичную
границу UI и общие стили. Галерея не подключает store, API и авторизацию,
не входит в production build и не является маршрутом приложения.
Эти ограничения проверяет `web/scripts/check-ui-gallery-boundary.mjs`.

В галерее представлены:

- кнопки: четыре варианта и пять тонов, загрузка, недоступность, нажатое состояние;
- поля: текст, ошибка, пароль, поиск, число, выбор, многострочный ввод и файл;
- выбор: checkbox, switch, toggle, дискретный slider, сегменты, вкладки и список;
- обратная связь: раскрывающаяся строка, прогресс и встроенное сообщение;
- всплывашка и диалог;
- общий UiSelect с поиском, группами, пояснениями и действиями, включая группу двух полей;
- синтетические композиции: согласование SSH, ввод сообщения, выбор модели,
  действия дока и списка чатов, подвал задачи и действия панели топбара.

Композиции воспроизводят отдельные контексты controls, а не полные продуктовые
экраны. Длинная SSH-команда — намеренная проверка переполнения.
Атрибуты `data-geometry-*` использует `check-ui-geometry.mjs`.
Выпадающий выбор показывает общий popup вместо системного списка; hidden native
select сохраняет контракт формы. API описан в [общем выборе](select-control.md).

## Где задаётся визуальный язык

| Область | Источник |
| --- | --- |
| Палитра, шрифтовые семейства и общая геометрия | `web/src/styles/tokens.css` |
| Базовый текст 14 px и межстрочный интервал 1.55 | `web/src/styles/base.css` |
| Кнопки и контекстные варианты | `web/src/styles/components/actions.css` |
| Поля | `web/src/styles/components/fields.css` |
| Checkbox, switch, radio и slider | `web/src/styles/components/selection.css` |
| Вкладки и другие составные controls | `web/src/styles/components/patterns.css` |
| Общая шапка панели и компоновка рабочих полей | тот же `patterns.css`, [UiPaneHeader](pane-header.md) |
| Подсказки, панели и диалоги | `web/src/styles/components/overlays.css` |
| Заголовки и компоновка отдельных страниц | scoped CSS соответствующих SFC |

В `actions.css` остаются контекстные варианты по `data-context`: одинаковый
компонент кнопки может иметь разные размеры и оформление в разных местах.
Смысловые роли компактного toolbar и обычного поля различаются намеренно;
сами по себе разные размеры не означают дефект.

## Проверенные различия

Обе шапки проектов используют `UiPaneHeader` с заголовком 13 px,
заголовки списков агентов и маршрутов — 13.5 px. Это разные роли: оценивать согласованность следует
вместе с окружением, а не требовать одинакового кегля по одному числу.

Внешней рамки у проектов нет; встроенные сообщения используют `--radius` (6 px),
у полей и кнопок — 4 px. Вне рабочей области роли пока сохраняют 12 и 9 px.
У поверхности общего диалога — 14 px, у части поверхностей редактора маршрутов —
10 px. Полная миграция ещё не выполнена; подробнее — [скругления](corner-radius.md).

Семейство основного текста — системный стек `--sans`; реальный шрифт зависит
от платформы. При переносе образцов в редактор дизайна нужно фиксировать
использованный шрифт, чтобы замена гарнитуры не выглядела изменением продукта.

Дополнительные проверенные наблюдения о знаках действий, типографике switch и
вариантах кнопок — в [разборе текущих элементов](ui-design-refinements.md).
