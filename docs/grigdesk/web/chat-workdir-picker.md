# Выбор рабочей папки чата

`ChatWorkdir.vue` объединяет селект проекта и кнопку с именем текущего каталога и
контурной иконкой. Полный путь доступен в подсказке. До получения пути подпись — «Папка».
На телефоне оба поля находятся в настройках чата.
Пустой чат показывает текущий путь и подсказки ввода отдельными строками. Выбор папки,
включая недавние варианты, находится в меню рабочей папки в шапке: кнопки и инструкция смены
папки в центре разговора не дублируются.

Выбор открывается общим модальным диалогом, на телефоне — прямо в настройках чата.
Текущая папка показана под списком. При выбранном проекте каталог с поиском показывает
его основной и дополнительные репозитории. Для чата без проекта доступны папка GrigDesk,
недавние произвольные папки и действие «По пути». Устройство, адаптив и проверки
описаны в [диалоге рабочей папки](chat-workdir-dialog.md).

Контракты самого перехода описаны в [рабочей папке разговора](../guide/ru/chat-workdir.md).
Подпись кнопки и приоритет подтверждённого пути — в [контракте шапки](../chat/header-controls.md).
Оформление кнопки принадлежит `styles/components/actions.css`, строки — общему UI-набору.
