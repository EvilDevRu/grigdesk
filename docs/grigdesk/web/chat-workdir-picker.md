# Выбор рабочей папки чата

`ChatWorkdir.vue` открывается кнопкой с именем текущего каталога и контурной иконкой из
общей карты навигации. Полный путь доступен в подсказке; до получения пути подпись — «Папка».
На узком экране кнопка остаётся в строке названия, а задача переносится ниже.
Пустой чат показывает текущий путь и подсказки ввода отдельными строками. Выбор папки,
включая недавние варианты, находится в меню рабочей папки в шапке: кнопки и инструкция смены
папки в центре разговора не дублируются.

Выбор открывается общим модальным диалогом, на телефоне — нижней панелью.
Текущая папка показана отдельно; каталог с поиском объединяет проекты и недавние папки
без повторов, ручной ввод пути находится в режиме «По пути». Устройство, адаптив и проверки
описаны в [диалоге рабочей папки](chat-workdir-dialog.md).

Контракты самого перехода описаны в [рабочей папке разговора](../guide/chat-workdir.md).
Подпись кнопки и приоритет подтверждённого пути — в [контракте шапки](../chat/header-controls.md).
Оформление кнопки принадлежит `styles/components/actions.css`, строки — общему UI-набору.
