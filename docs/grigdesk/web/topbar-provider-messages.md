# Сообщения исполнителя во всплывающей панели

Всплывающая панель исполнителя в топбаре показывает строку результата установки CLI
только при ошибке. Успешная установка, обновление, отсутствие смены версии и готовность
команды в новом терминале не добавляют служебных строк в сводку лимитов.

Полный итог операции остаётся в общем окне установки и под действиями на странице
исполнителя в настройках. Кнопка просмотра результата, требующего внимания, сохраняется.
Сообщения об ошибках получения лимитов и состоянии провайдера показываются по прежним
правилам независимо от результата установки CLI.
