# Простые настройки речи и общая сессия

Страница «Речь» (`SpeechPage.vue`, `speech.dictation`) открывается с тремя блоками:

1. «Распознавание речи»: одна строка готовности/ошибки и кнопки установки, обновления,
   удаления. Установка готовит Whisper и выбранную модель одной серверной операцией.
2. «Модель»: Быстрее → small, Обычное → medium, Точнее → large-v3-turbo.
   Простой выбор меняет quality и videoQuality вместе, сбрасывает model и videoModel.
   При готовом окружении недостающая модель скачивается автоматически через model jobs;
   статус и прогресс видны здесь. Ошибка не зацикливает запросы, доступен явный повтор.
3. «Язык»: Авто, Русский, Английский.

Всё остальное находится в одном свёрнутом «Расширенном»: движок браузер/сервер,
раздельное качество и явные модели диктовки/видео, ручной выбор CUDA для установки,
каталог моделей со скачиванием/копированием/отменой, device, computeType, beamSize,
vadSilenceMs, conditionOnPreviousText, browserProcessing, словарь и готовые термины,
videoInitialPrompt, фактический путь обработки, диагностика и бенчмарк.
Поиск любого поля кроме языка раскрывает этот блок и фокусирует нужный control.
Закрытие блока не отменяет операции и не останавливает опрос на видимой странице.

SpeechInstallation монтируется один раз. В простом виде нет списка технических
идентификаторов моделей, команд установки и тумблера CUDA. При отсутствии системной
зависимости рядом со статусом есть [ссылка установки в терминале](../media/speech-dependency-links.md). Детали установщика
свёрнуты отдельно; содержат вывод и решение автоматической NVIDIA-пробы.
В ходе установки выбор простого пресета заблокирован, и виден один прогресс.
Завершённая установка сначала перечитывает capabilities, затем показывает «Готово».
Существующий каталог venv без рабочего окружения или выбранной модели не считается готовым.

## Черновик и операции

Черновик принадлежит общей сессии настроек. Язык, пресеты, словарь и остальные поля
сохраняются только через общее «Применить». Установка и модельные задания действуют
сразу, не применяют черновик и не записывают его побочные поля.
Согласие браузерной обработки не редактируется и не появляется при проверке возможностей.
Нет локальной модели браузера — сохранённый local остаётся local; fallback виден отдельно.

Адаптер POST настроек отправляет только whitelist изменённых полей, включая
conditionOnPreviousText. Сброс videoInitialPrompt передаёт null вместо текста дефолта.
createSpeechResource сохраняет opaque revision/epoch: старый GET после save и старый
POST после внешнего SSE не меняют новый baseline. Конфликт сохраняет введённое значение.
Изменение кэша модели не делает настройки устаревшими; частичные capabilities дополняются.

Контроллеры операций принадлежат открытию настроек и не содержат отдельного черновика.
Переход прекращает таймеры и чтения; возврат сразу читает прежние задания и серверный
current установщика. Закрытие освобождает контроллеры, не отменяя серверную работу.
Двойной старт не дублируется. Потерянный ответ установки уточняется GET без повтора POST.
Автоскачивание не повторяет неудачный запрос при каждом обновлении страницы/снимка.

Бенчмарк получает модель, язык, устройство и compute type из неприменённых полей.
SSE использует существующий мультиплексор; подписки снимаются при dispose открытия.
Страница плагина «Видеовстречи» остаётся отдельной.

Контракт сервера — [установка Whisper](../media/speech-installation.md).
Проверки: `settings-speech.component.test.js`, `settings-speech-session.test.js`.
