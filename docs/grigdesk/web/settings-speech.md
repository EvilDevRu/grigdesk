# Речь в общей сессии настроек

SpeechPage содержит пять тематических страниц. Каталог объявляет только редактируемые
поля; capabilities, browserAutoConsent, revision и задания доступны для чтения отдельно.
Черновик принадлежит общей сессии. Адаптер POST отправляет только whitelist изменённых
полей, включая conditionOnPreviousText; сброс videoInitialPrompt отправляет null, а не
копию серверного текста по умолчанию.

createSpeechResource сохраняет проверенные правила opaque revision и epoch. Старый GET
после save и старый POST после внешнего SSE-снимка не меняют новый baseline. При конфликте
введённое значение остаётся в форме. Изменение одного кэша модели не делает запись настроек
устаревшей. Частичные capabilities дополняются прежним публичным снимком.

Контроллер чтений и операций живёт в приватной карте store открытия. Он не содержит
отдельного черновика. Возврат страницы сохраняет jobId, немедленно перечитывает состояние
серверного задания и возобновляет UI-опрос. Уход останавливает таймеры и текущие чтения;
закрытие освобождает контроллер, продолжая серверный job по его прежнему контракту.
Двойной старт и отмена не дублируются. Поздний опрос после отмены игнорируется.

Замер — самостоятельная операция. Перед POST он получает модель, язык, устройство и
compute type из текущих неприменённых полей; настройки при этом не записываются.
Согласие браузерной обработки не редактируется и не появляется при проверке возможностей.
Нет локальной модели браузера — сохранённый local остаётся local, фактический fallback
показывается отдельно. Downloadable и downloading показываются явными состояниями.

SSE использует имеющийся мультиплексор. Подписки и чтения снимаются по dispose открытия.
Проверки: settings-speech-session.test.js и сохраняемые до очистки прежние
settings-speech.component.test.js. Браузерные фикстуры не запускают реальное скачивание.
