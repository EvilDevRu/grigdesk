# Размер кнопки результата установки в топбаре

Кнопка «Показать результат» во всплывающей панели исполнителя имеет ту же геометрию,
что действия установки, обновления лимитов и настроек: 22×22 px и скругление 6 px.
В режиме `data-ui-touch` у всех этих кнопок сохраняется площадка 44×44 px.
Предупреждающий цвет и открытие сохранённого результата остаются прежними.

Кнопка использует собственный `data-context="topbar-popover-result"` и общее правило
размеров в `web/src/styles/components/actions.css`. Локальных стилей в `AppShell.vue`
для её размера нет.
