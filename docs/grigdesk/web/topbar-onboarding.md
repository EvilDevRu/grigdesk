# Мастер настройки в топбаре

Кнопка «Мастер настройки» находится в общей группе действий `AppShell`, между историей
уведомлений и настройками. Она доступна из любого раздела при активном подключении
и выбранном компьютере. До входа, без машины и при потере связи кнопка не показывается.

Общий `UiIconButton` использует `variant="link"`, роль `rail` и контекст `topbar-action`:
размер, сенсорная площадка и оформление совпадают с соседними действиями. Значок мастера,
доступное имя и переведённая подсказка сохранены. На странице мастера стоит
`aria-current="page"`.

На экранах до 360 px поле знака приложения сужается до 28 px. Это оставляет место
для всех действий, сохраняя общие сенсорные площадки 44 × 44 px.

Нажатие открывает `/onboarding?new=1`. Существующий серверный контракт ручного запуска
продолжает незавершённый проход; перезагрузка не создаёт новый проект. Страница проектов
больше не дублирует кнопку в своём заголовке.
