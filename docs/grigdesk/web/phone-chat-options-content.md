# Наполнение настроек чата на телефоне

До 600 CSS px полноэкранный диалог разделяет настройки на три секции:

- «Агент»: модель, доступный режим доступа с видимой подсказкой и усилие рассуждения.
- «Рабочая область»: задача и рабочая папка со встроенным каталогом выбора.
- «Контекст»: заполненность до рабочего порога, состояние замера и действия с памятью.

`EffortSlider` получает `expanded`: короткий трек заменяется кнопками уровней из каталога
модели, до трёх в строке, с площадками 44 px. Неподдерживаемые уровни не добавляются.
Пустой выбор не выделяет первую кнопку; пояснение показывает умолчание исполнителя.
Выбранный уровень подсвечивается, его описание берётся из `effortHints`.
На компьютере остаётся прежний тонкий слайдер.

Локальные стили настольной шапки ограничены `.cs`, поэтому перенесённые через Teleport
поля оформляет общий UI-kit. Подписи не дублируются; полоса контекста занимает ширину
строки, процент сохраняется справа. Три цели Teleport разделяют рабочую область,
управление агентом и контекст, сохраняя экземпляры controls при закрытии и смене ширины.

«Сжать контекст» и «Сбросить память» вызывают прежние операции только после подтверждения.
Во время хода, сжатия и переходов действия недоступны; без сессии они также выключены.
Описание различает сохранение рабочей выжимки и сброс памяти при сохранении переписки.
Нижняя панель сообщает о применении изменений сразу; «Готово» закрывает диалог.
Заголовок и нижняя панель остаются вне единственной прокрутки содержимого.
