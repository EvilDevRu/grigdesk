# Равные интервалы действий топбара

Подключение телефона, история уведомлений и настройки используют `UiIconButton`
с ролью `rail`: область каждой кнопки — 28 × 28 px, SVG — 16 × 16 px.
В общей flex-группе `gap: 0`, поэтому центры соседних иконок отстоят на 28 px.
В сенсорном режиме общий контракт UI увеличивает области действий до 44 × 44 px.

В компактной шапке выбор машины также занимает квадратную площадку
`--toolbar-control-h`; скрытая обёртка подписи не участвует во внутреннем gap.
На телефоне машина, колокол и настройки сохраняют одинаковый шаг центров.
[Выравнивание поля чата и шапки](phone-control-alignment.md).

Контекст `topbar-action` задаёт размер SVG телефона и настроек в `actions.css`.
История уведомлений сохраняет свой контекст `alert-history` и те же размеры.
