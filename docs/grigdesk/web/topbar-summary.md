# Рабочая сводка топбара остаётся короткой

- **Рабочая сводка топбара остаётся короткой:** иконка таймера + число активных B24-таймеров,
  затем через разделитель иконка конвейера + тройка `в работе / ждут решения / проблемы`. Слово «Таймеры»
  в строке не дублирует понятную иконку; полные подписи остаются в `aria-label` и заголовке
  popover. Его шапка одной компактной строкой показывает активное число и дневной итог;
  «Сегодня отработано» берётся напрямую из `today.hours` того же снимка
  `GET /api/b24/dashboard` и форматируется так же, как плитка «Отработано» на доске:
  таймеры задач заново не суммируются и отдельного запроса нет.
  Индикатор конвейера — триггер `UiTopbarPanel`, а не ссылка: нажатие оставляет человека
  на текущей странице и показывает числа работающих, ожидающих решения и проблемных прогонов,
  а также суммарный `done/total`. Поимённо остаются только первые три прогона, требующие
  внимания, с короткой причиной; обычные работающие задачи не дублируют страницу конвейера.
  Переход в `/pipeline` остаётся отдельной кнопкой в подвале. Тройка и строки панели
  считаются из одного `notify-watch.topbarItems`: `running / waiting / error`, поэтому
  значения снаружи буквально повторяют значения внутри. Проекция использует тот же
  классификатор, что `notify-watch.badgeSummary` для счётчика внимания в навигации. В нём
  `attentionCount` по-прежнему объединяет ожидание и проблемы, но топбар сохраняет их
  отдельными числами. Поэтому показатель виден даже без B24-таймеров и не требует второго
  опроса фабрики.

Топбар высотой 36 px занимает всю ширину окна; [геометрия](desktop-ui-density.md).
Слева остаётся знак GrigDesk; имя ПК и точка связи не показываются.
Оболочка больше не запрашивает `/api/health` ради имени. Ниже 900 px скрыты
второстепенные CPU/RAM. Публичный IP доступен только во всплывающей панели сети;
в самом топбаре остаётся флаг страны. Состав живой сводки и её подписки не меняются.
