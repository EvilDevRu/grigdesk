# Поиск и навигация настроек

`features/settings/search.ts` — чистый поиск по подписи, описанию, пути группы и явным
синонимам. Нормализация убирает внешние пробелы, регистр и различие ё/е. Индекс не читает
значения ресурсов и не запускает API или компоненты страниц.

Публичные метаданные динамических каталогов проходят `publicFieldMetadata`: белый список
адреса, подписи, описания, синонимов и доступности. Незагруженные доступные параметры
представляются переходом с `load: true` и объяснением продолжения поиска после загрузки.
Удалённый между выдачей и кликом адрес открывает безопасную страницу с пояснением.

`SettingsNavigation` использует общий UiPressable и ARIA tree с одним tabindex=0.
Стрелки меняют фокус; Enter/Space и клик выбирают страницу. В storage сохраняются ID
последней страницы и раскрытых групп, без формы и поисковой строки.

Результат записывает `revealTarget`. `SettingsField` после монтирования/обновления и при
изменении цели сравнивает полный адрес по сегментам, прокручивает и фокусирует control,
отмечает data-revealed и очищает цель. Таймеров в Workspace нет. Общий wrapper также
показывает ошибки и конфликт с выбором текущего или введённого значения.

Проверки: settings-search.test.js и settings-navigation.component.test.js. Helper
settings-consistency.js сравнивает адреса каталога с data-settings-field смонтированной
страницы; статические поля добавляются только при переносе конкретной страницы.
