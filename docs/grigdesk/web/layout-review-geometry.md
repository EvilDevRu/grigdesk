# Геометрия страниц и меню инструментов

Проверено 17 октября 2026 на текущих Vue-компонентах в изолированном
Vite/Chromium со синтетическими ответами API. Это наблюдения реализации,
а не новый контракт дизайна и не проверка установленного пакета приложения.

## Внешняя ось страниц

При ширине окна 1440 px `AppShell .content` начинается с x=36 и имеет
внешний padding 16 px. Страницы добавляют собственные отступы и ограничения:

| Заголовок | Левый край, px |
| --- | ---: |
| Проекты | 52 |
| Полка | 68 |
| Настройки | 75 |
| Входящие | 135 |
| GitHub | 225 |
| Инструменты | 305 |

`ToolsView` центрирует полосу с `max-width: 820px`; другие страницы имеют
свои внутренние padding и ограничения ширины. Поэтому одного изменения
`--page-gutter` недостаточно для согласования всех внешних осей.

Рабочие маршруты с `layout: workspace` используют отдельное правило
`AppShell .content.is-workspace`: без внешних полей, с локальными областями
прокрутки. Читаемая колонка документа также имеет отдельную смысловую роль;
различие её ширины само по себе не доказывает дефект.

## Меню инструментов при малой высоте

В `AppShell.vue` функция `placeToolsPopover()` задаёт верхнюю координату как
`max(62, rect.top)`, а CSS ограничивает высоту через `calc(100vh - 74px)`.
Ограничение высоты не учитывает фактическое смещение панели вниз.

В окне 844×390 при четырёх синтетических инструментах измерено:

- верх панели: 346 px;
- высота: 244.42 px;
- нижняя граница: 590.42 px при высоте окна 390 px;
- `scrollHeight` и `clientHeight`: по 242 px.

Нижние плитки оказываются за видимой областью. Внутренняя прокрутка в этом
состоянии не появляется: содержимое помещается внутри самой панели,
но панель не помещается в окно. Один `overflow: auto` этого не исправляет.

Для воспроизведения достаточно синтетического списка из четырёх инструментов,
окна 844×390 и открытия `.tools-trigger`. При изменении размещения нужно
повторить проверку после поворота/resize и изменения числа инструментов.

## Границы доказательств

Пустое состояние не доказывает пригодность заполненного редактора или списка.
Ошибки неполных API-фикстур необходимо исправлять перед визуальной оценкой:
например, ответ `/api/code/:project/git` должен содержать поля контракта Git,
иначе снимок содержит диагностический баннер, не относящийся к layout продукта.

Эмуляция touch и уменьшение высоты окна не заменяют проверку системной
клавиатуры и видимой области на настоящих iOS/Android-устройствах.
