# Обновление большого списка чатов

Проверено 29.10.2026 на синтетическом каталоге из 310 активных и 1474 архивных
чатов. Фикстура с 80 активными чатами не пересекала прежний предел кэша превью
в 256 записей и не обнаруживала вытеснение по кругу.

## Превью текущего каталога

Перед построением строк store передаёт кэшу id текущего активного или архивного
списка через `retain`. Кэш удаляет записи другого списка и устанавливает предел
не меньше числа текущих id. Неизменённый последовательный обход более 256 чатов
больше не вытесняет начало списка и не разбирает весь Markdown повторно.

Исходник одной записи по-прежнему ограничен 1024 символами, результат — 240.
Без переданного каталога действует прежний LRU из 256 записей. Смена текста
заменяет одну запись; `remove` и `clear`, загрузка и dispose сохраняют прежнюю
очистку. Полнотекстовый поиск на сервере не меняется.

## Строки

`ChatList.vue` применяет `v-memo` на том же элементе, где находятся `v-for` и
устойчивый ключ id. В зависимости входят все данные его поддерева: тексты,
модель и исполнитель с цветом, задача, архив и черновик, состояния хода,
прочтение и ожидание, сон, выбранность, редактор с вводимым именем и отображаемое
относительное время. Правка шаблона должна учитывать этот список зависимостей.

Обновление одного чата сохраняет DOM и VNode неизменённых строк. Новые данные,
перестановка, выбор, переименование и подсказки остаются реактивными. Отключения
строк вне экрана нет: весь список доступен прокрутке, клавиатуре и поиску браузера.
Условия использования директивы — [контракт Vue](https://vuejs.org/api/built-in-directives#v-memo).

Проверки: `chat-list-preview.test.js`, `chat-list-sleep.component.test.js`,
`chat-list-loading.component.test.js` в `tests/web/`. Проверяются каталог больше
256 записей, ограничение памяти, изменения отображаемых полей, выбор, ввод имени,
сон, занятость, непрочитанное и ожидание. Адресный браузерный стенд измеряет
обновление ожидания, прогресса и нового блока отдельно от сохранения.
