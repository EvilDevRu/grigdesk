# Местный сервер под заставкой

Для выбранной машины local окно ждёт соединение online и завершение входа в загруженной
странице трубы: `.shell` есть, `.workspace-waiting` отсутствует, прошли два кадра и повторная
проверка соединения. Работающая служба используется без запуска второго сервера.

Бюджет — 30 секунд от show заставки, включая подготовку переносимой папки и VPN.
Отказ запуска или срок открывают главное окно с причиной и кнопкой машин. Отменяется только
наблюдение готовности: supervisor, проверка бинарника и повторы соединения продолжаются.
Закрытие заставки человеком по-прежнему завершает приложение и штатно останавливает свой сервер.

Удалённый профиль и пустой старт без установки и выбора сохраняют минимум около двух секунд.
Явный местный URL и сохранённый local считаются выбранной машиной даже без установки.

Правило обнаружения, принятое в задаче №93019: местный сервер обнаруживается только по файлам
установки (descriptor или сервер рядом с переносимым окном). Без этих файлов живой порт
не опрашивается и профиль автоматически не создаётся. Явный URL — выбор человека,
а не автоматическое обнаружение.

Подписи проверки, запуска, подготовки и VPN берутся из общих каталогов RU/EN; изображение,
размер, раскладка и документ заставки без скриптов сохраняются.
Проверки: ST-L01…04, SV-STAGE, SH-START-REASON, SE-13/16/17 и UC-E01…03.
