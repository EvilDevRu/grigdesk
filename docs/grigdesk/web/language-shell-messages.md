# Язык открытых сообщений и служебных подписей каркаса

Задача №93001: производитель общего тоста или подтверждения передаёт `MessageRef`.
Getter, возвращающий перевод, становится строкой при постановке в очередь и поэтому
не сохраняет язык открытого сообщения. Подтверждение отзыва текущего устройства хранит
весь вопрос с предупреждением одним descriptor; имя устройства остаётся параметром.
Переключение языка не повторяет действие и не отправляет отзыв.

Собственные статусы доступа переводятся одной чистой проекцией `providerLocale.ts`
в настройках и верхней панели. Она сопоставляет только зарегистрированные подписи
внутри ID исполнителя. Команда входа сохраняет kind, command и остальные поля;
переводится только её известная подпись. Неизвестные статусы и действия остаются данными,
исходный DTO не меняется.

Названия диагностических проверок речи переводятся отдельно от результата проверки:
ffmpeg, ffprobe, faster-whisper, состояние Python и кэша моделей принадлежат приложению.
Пути, неизвестные проверки, серверные reason и fix сохраняются исходными строками.
Выбор языка интерфейса не меняет параметры речи и не запускает диагностику повторно.

Метрики компьютера форматируют видимые числа через общий Intl-помощник, число ядер —
через plural-сообщение каталога. Расчёт метрик и числовые значения CSS не зависят от языка.
Общая страница инструментов входит в переводимый каркас, включая пустое состояние;
содержимое страниц самих инструментов переводится отдельно.

Правило доступных надписей включает `alt`: новая собственная подпись изображения
в переводимой области добавляется в каталоги всех зарегистрированных языков.
`check:i18n` проверяет статический текст и строковые ветви привязанного `alt` так же,
как видимые надписи и `aria-label`. QR обеих привязок использует каталожные подписи.
