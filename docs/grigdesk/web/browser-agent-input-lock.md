# Блокировка ручных действий во время команды агента

Пока `agentWorking` выбранной вкладки равен `true`, пользователь не может нажимать
элементы сайта, вводить текст, прокручивать страницу, менять адрес, историю или масштаб,
обновлять, закрывать, дублировать, перетаскивать вкладку и передавать её другому агенту.
В существующей полосе управления над сайтом отображается спиннер с сообщением
«Агент работает. Управление вкладкой временно заблокировано» вместо подписей владельца.
Высота полосы сохраняется; индикатор не меняет viewport во время команды. Панель страницы
имеет `aria-busy="true"`. Текст есть в каталогах RU/EN.

Блокировка относится к выполняемой браузерной команде, включая чтение и открытие.
Наличие grant, ожидание следующего запроса модели и фоновая загрузка сайта сами по себе
не блокируют ручное управление. Завершение, отказ и таймаут снимают `agentWorking` через
существующий `finally`. После паузы или отзыва ручной ввод ждёт завершения текущего эффекта.

## Native-слой и фокус

HTML не перекрывает `WebContentsView`. `browserInputGuard.ts` создаёт один прозрачный
`WebContentsView` с собственным пустым `about:blank`, без preload и Node. Первая команда
ждёт готовности пустого документа. Затем реестр синхронно поднимает перехватчик над
прямоугольником сайта до публикации snapshot. Клавиатура, мышь, колесо и контекстное меню
попадают в этот слой. Повторный фокус guest возвращается основному документу приложения.
Чужое активное окно при этом не активируется.

Страница остаётся показанной и продолжает получать CDP-ввод агента напрямую. Перехватчик
не отключает ввод глобально и не открывает временные окна для синтетических событий.
Переключение вкладки и скрытие viewport снимают слой; возвращение к занятой вкладке
снова поднимает его. Runtime закрывает перехватчик при `dispose`.

## Действия оболочки

Native IPC повторяет проверку `agentWorking`: отключённую кнопку нельзя обойти горячей
клавишей, старым snapshot или ручным запросом. Отказ — `browser_tab_busy`. Передача grant
отвергается до помещения в очередь. Vue также проверяет состояние в обработчиках.
Групповое закрытие пропускает занятые вкладки; новая вкладка и выбор другой доступны.

Экстренные «Приостановить» и «Отозвать доступ», а также возобновление остаются доступны:
управление разрешением сохраняет существующий синхронный контракт grant epoch.

## Проверки

`tests/desktop/browser-input-guard.test.mts` проверяет порядок слоёв, запрет ввода,
фокус и освобождение ресурса. `tests/desktop/browser-native-runtime.test.mts`
(BR-N-lock*) проверяет отказ ручных IPC-мутаций, продолжение команды, переход между
вкладками, отзыв и снятие блокировки после ошибки. `tests/web/browser-ui.component.test.js`
(BR-U23–BR-U24) проверяет индикатор, controls, горячие клавиши и групповое закрытие.

Проверка DOM через Vite доказывает состояние интерфейса; физический ввод поверх
настоящего native compositor требует отдельной ручной приёмки после установки сборки.
