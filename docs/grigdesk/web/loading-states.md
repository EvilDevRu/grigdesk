# Общие состояния загрузки

`UiLoadingState` — представление ожидания данных, доступное через `web/src/ui.ts`.
Сети, таймеров, повторов и состояния запроса в нём нет. Потребитель отвечает за условие
показа, сообщение об отказе и своё действие повтора.

## Представление

Параметры: `label`, необязательное пояснение `description` и `variant`:

| Вариант | Когда применяется |
| --- | --- |
| `rows` по умолчанию | Списки проектов, подключений, истории и настроек |
| `cards` | Доска, конвейер, входящие и библиотека моделей |
| `document` | Текст документа, паспорт проекта, описание задачи и формы |
| `inline` | Небольшая область или обновление с уже видимыми данными |

Подпись объявляется одним `role=status`; спиннер и четыре декоративные строки
скрыты от средств чтения с экрана. Силуэты не выдают себя за данные или численный
прогресс. При `prefers-reduced-motion: reduce` спиннер и пульсация неподвижны.
Размеры и оформление принадлежат `styles/components/feedback.css`, тексты — потребителю.
Без подписи используется общий перевод `core.loading`; собственный текст остаётся данными.

## Где применяется

| Область | Состояния ожидания |
| --- | --- |
| Оболочка и отдельные окна | Подключение рабочей области, получение инструмента и карточки задачи |
| Ленивые инструменты | Общий каркас `asyncView`, если потребитель не передал специальный |
| Доска и конвейер | Первая загрузка, документ этапа, отложенные замечания |
| Входящие, GitHub, Telegram | Очередь, состояние подключения, правило источника |
| Проекты и песочницы | Каталог, паспорт проекта, список стендов |
| Маршруты | Каталог, схема выбранного маршрута, политика узла |
| Документы и дифф | Разрешение ссылки, чтение документа, первый снимок diff |
| Полка | Первое чтение задач |
| Код | Рабочая копия, история файла, поиск, git и коммиты |
| Docker | Контейнеры и расчёт занимаемого места |
| SSH и базы | Получение списка подключений и профилей, чтение схемы базы |
| Настройки | Раздел, устройства, MCP, параметры, процессы, речь, диагностика, исполнители и каталог плагинов |
| Презентации | Доступные стенды и история репозиториев выбранного источника |
| 3D | Библиотека моделей, в том числе компактное обновление готового списка |
| Карточка задачи | Описание, варианты редактирования и комментарии |

Входящие при повторном чтении сохраняют уже показанные обращения. Подключения SSH
и профили баз не заменяют готовый список силуэтами при обновлении. Ошибка первой
загрузки параметров, речи, процессов, инструмента и конвейера прекращает показ ожидания.
Отказы и кнопки повтора остальных областей принадлежат прежним владельцам запросов.

## Специальные состояния

Начальный каркас Кода сохраняет геометрию дерева и редактора, включая выбранную ширину.
`asyncView` продолжает принимать этот специальный компонент и сохраняет общий `LoadFailure`
после отказа или истечения срока загрузки чанка.

Нативная заставка приложения показывается до Vue и использует собственные локальные assets.
Чаты имеют [собственный экран загрузки](../chat/loading-screen.md). QR-коды, подключение
телефона и установка плагина используют постоянные области с отдельными жизненными
циклами; их каркасы сохраняются. Просмотрщик модели показывает настоящий прогресс передачи
и разбора. Расшифровка, триаж, анализ презентации, установка исполнителя и отправка файлов
обозначают работу, а не первоначальное чтение экрана. Их индикаторы остаются у операции.

Примеры четырёх вариантов есть в галерее UI. Контракт статуса, смену языка, смену вида,
успех и отказ ленивой панели проверяет `ui-loading-state.component.test.js`.
Отказ первого чтения форм проверяет `loading-recovery.component.test.js`, сохранение
обращений при обновлении — `inbox-view.component.test.js`.
