# Обновление интерфейса приложения

Интерфейс поставляется внутри [пакета приложения](packaged-ui.md). Новая версия применяется
после установки нового AppImage и повторного запуска. Рабочая пересборка web и обновление
сервера не меняют файлы уже открытого окна.

Service worker, precache и установка PWA сняты. Store `device` отвечает только за
уведомления и Screen Wake Lock. Кнопки reload, команда меню «Обновить» и сообщение
`reload-main` удалены; Ctrl+R, Ctrl+Shift+R и F5 перехватывает Electron.
После серверного рестарта настройки перечитывают карточку процесса, сохраняя документ.

Старую PWA удаляет человек в браузере. Её закэшированная оболочка не получает данные
сервера со старой cookie. Доступ для проверок — через
[изолированный стенд](../testing/desktop-window-e2e.md).
