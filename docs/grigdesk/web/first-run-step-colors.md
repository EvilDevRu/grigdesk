# Цвет будущих шагов мастера

В мастере первого запуска будущие шаги «Разбор проекта и стенд»,
«Маршруты» и «Включение конвейера» отмечены `aria-disabled="true"` и показаны серым
цветом общего токена `--ink-low`. Первые три шага сохраняют основной цвет текста.

Правило действует на первом шаге и на итоге, на русском и английском языках, в широкой
и узкой рабочей области. Токены палитры определены в `web/src/styles/tokens.css`;
неопределённая CSS-переменная делает декларацию цвета недействительной, и будущий шаг
наследует основной цвет, теряя визуальное отличие.
