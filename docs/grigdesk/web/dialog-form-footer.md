# Каркас и подвал диалогов

Эталон оформления — [окно «Настройки»](settings-modal.md). `UiDialog` из `web/src/ui.ts`
владеет рамкой, шапкой, прокручиваемым телом, подвалом и модальным слоем. Размеры
`compact`, `content`, `workspace` и `media` выбираются по содержимому. На телефоне
применяется полноэкранное окно или нижняя панель по параметрам диалога.

| Слот | Содержимое |
| --- | --- |
| `title`, `description` | Заголовок и короткое описание. `closeLabel` добавляет общую кнопку закрытия. |
| `header-actions` | Дополнительные действия шапки. `header` принимает составную шапку рабочей поверхности. |
| `default` | Поля формы, просмотр или содержимое рабочего окна. |
| `footer-status`, `footer-details` | Статус и подробности слева. Текст с индикатором можно передать через `footerStatus` и `footerPending`. |
| `footer` | Кнопки и группы действий справа. |

- Подвал занимает всю ширину окна. Тонкая верхняя линия и фон `--sidebar` отделяют
  его от прокручиваемых полей. Слот действий находится после области прокрутки.
- Короткий статус и индикатор изменений располагаются слева. Подробности результата
  помещаются под ним в ограниченной по высоте области. На узком экране статус занимает
  отдельную строку.
- Действия выровнены вправо с промежутком 8 px. «Отмена» и дополнительные действия
  используют нейтральную контурную кнопку. Справа стоит основное действие с
  `variant="solid"` и `tone="accent"`. В рабочем диалоге кнопки занимают 32 px
  по высоте, на узком или сенсорном экране — от 44 px. Длинные подписи и группы
  действий могут переноситься.
- Подписи, доступность и результат действий определяет владелец окна. Для «Нового проекта»
  это «Отмена» и «Создать проект». Для «Настроек» — «Отмена», «Применить» и «ОК».
  Кнопка отправки проекта использует `type="submit"` и атрибут `form` с ID формы в теле.
  Поэтому Enter и нажатие
  проходят общую валидацию.
