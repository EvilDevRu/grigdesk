# Общая кнопка создания

`UiCreateButton` экспортируется через `ui.ts` и повторяет круглый плюс списка чатов:
видимый круг 32 px, тонкая рамка, непрозрачная `--surface-2` и знак `＋` размером 16 px.
На touch прозрачная область расширена до 44 px; боковые поля по 6 px резервируют
место и исключают пересечение с соседним действием. Общий контекст — `workspace-create`.

`label` задаёт доступное имя и общую подсказку. `expanded` необязателен: для раскрытия
формы он задаёт `aria-expanded` и заменяет плюс минусом. Без него кнопка не объявляется
раскрытием. Обработчик, disabled и связь `aria-controls` принадлежат потребителю.

Компонент используют новый чат, новый проект в `ProjectSwitcher`, черновик маршрута,
сервер SSH и профиль базы. Локальные размеры и отдельные знаки плюса им не нужны.
В шапке SSH обновление предшествует созданию. В «Базах» между обновлением и плюсом
стоит короткая кнопка «Драйвер»: доступное имя и подсказка сохраняют полное действие
«Установить драйвер из Git…», а установщик работает по прежнему контракту.

Геометрию общего компонента проверяет `phone-readability.component.test.js`, действия
и порядок — профильные тесты панелей. Нативную работу телефона проверяют отдельно.
