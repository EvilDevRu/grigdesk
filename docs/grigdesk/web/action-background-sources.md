# Общая поверхность кнопок и ссылок

`--control-background` в `styles/tokens.css` ссылается на `--surface-2` (`#1c222c`).
Обычные outline-кнопки, ссылки-действия и иконки используют эту поверхность через
`--ui-action-background` в `styles/components/actions.css`. Disabled сохраняет фон
и меняет общую прозрачность. Рабочая и сенсорная области используют ту же палитру;
Teleport не возвращает почти чёрный фон.

Раньше корневой токен ссылался на `--ground`, поэтому общие кнопки вне явно помеченной
рабочей формы сохраняли старую чёрную заливку. Это было наследием токена UI-kit,
а не отдельными native-кнопками конвейера. Фон страницы остаётся `--ground`.

Ghost, text и link остаются прозрачными. Solid использует семантический тон действия:
акцент, предупреждение, опасность либо нейтральную поверхность. Изменение базовой
поверхности не меняет эти варианты, фокус, загрузку или обработку нажатия.

Поля имеют собственный [токен поверхности](field-background-sources.md), поэтому
их контракт не зависит от будущих изменений кнопок. Проверки ACTION-SURFACE в
`ui-field-backgrounds.component.test.js` монтируют настоящий UI-kit с общим CSS
в обычном, рабочем и сенсорном окружении.
