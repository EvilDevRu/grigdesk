# Страница под меню и боковой панелью

`WebContentsView` расположен вне DOM главного документа. Прежний `BrowserViewport`
при любом блокирующем слое вызывал синхронный hide: меню было доступно, но вся
область сайта становилась пустой. Mounted-проверка подтвердила этот путь для
`dialog`, `popover` и `dock`; tooltip по-прежнему не является блокером.

Для перекрытия используется операция `cover`: до скрытия native-поверхности
главный документ получает последний показанный кадр выбранной вкладки. Vue
рисует его обычным `img` под DOM-слоями. Поэтому меню, диалоги, боковые панели
и оповещения могут перекрывать изображение, сохраняя свой порядок и ввод.
Подложка статична: страница работает в фоне, но её изображение и взаимодействие
восстанавливаются после закрытия последнего блокирующего слоя.

## Получение кадра и границы

Только прикреплённая видимая вкладка подписывается на
[`beginFrameSubscription`](https://www.electronjs.org/docs/latest/api/web-contents#contentsbeginframesubscriptiononlydirty-callback).
Хранится один полный `NativeImage`, заменяемый следующим представленным кадром.
JPEG создаётся только при `cover`, с ограничением ширины 1280 px и размера 2 MiB.
При скрытии и закрытии подписка снимается, изображение освобождается; поздние
callbacks прежней подписки игнорируются. Навигация и смена размеров очищают кадр.

Этот путь не вызывает `capturePage`, CDP screenshot или служебный capture-host,
не меняет grants и не заменяет агентский screenshot сохранённой картинкой.
Передача идёт только по проверенному IPC главного документа с текущими
document epoch, viewport instance и revision. Другие окна и iframe кадра не получают.

Повторный слой поверх уже открытого не стирает подложку. После закрытия всех
слоёв текущий layout возвращает живой native-view. Unmount, pagehide и скрытие
главного документа удаляют изображение; следующая вкладка его не наследует.
Если вкладка ещё не представила ни одного кадра либо копирование недоступно,
подложки нет: native-view всё равно скрывается, чтобы не перекрыть меню.

## Проверки

Профильные тесты проверяют подложку меню и dock, вложенные слои, очистку при
скрытии документа, текущие instance/revision, сохранение grant, снятие подписки
и отказ позднего кадра. Проверка в настоящем окне после установки пакета требует
визуальной приёмки; Node-фикстура не доказывает отрисовку compositor Electron.
