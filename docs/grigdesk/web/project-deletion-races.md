# Удаление проекта при открытых формах

Ответ DELETE закрывает паспорт только в том поколении страницы, из которого начато
удаление. Если человек перешёл к другому проекту, его выбор и черновик сохраняются.
Переход туда и обратно тоже создаёт новое поколение.
Если за время DELETE появились правки самого удаляемого паспорта, они остаются
в форме для чтения. Успешный ответ не стирает этот текст.

Форма запуска задачи подписана на общий SSE. `projects-changed` и `hello` инвалидируют
летящие запросы `launch-options` и перечитывают список. Удалённый выбранный профиль
сбрасывается сразу; после reconnect отсутствие подтверждает свежий каталог. Соседний
профиль автоматически не выбирается, даже если он остался единственным.

Критерии человека сохраняются при сверке, включая правки во время запроса. Пока каталог
не проверен или чтение завершилось ошибкой, запуск недоступен. Закрытие формы, смена
задачи и уничтожение компонента запрещают применение прежних ответов.

См. [открытый паспорт](project-deletion-open-form.md) и
[жизненный цикл проектов](../guide/ru/projects.md).
