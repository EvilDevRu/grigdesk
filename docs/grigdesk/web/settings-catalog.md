# Каталог страниц настроек

`features/settings/catalog.ts` содержит публичные подписи и порядок семи групп и
23 страниц. Каталог не импортирует Vue-компоненты, не обращается к браузеру при импорте
и не содержит пользовательских значений. Поля страниц добавляются при их переносе.

`resolveSettingsPage` принимает явный ID страницы, ID из query и порт хранилища.
Приоритет: явный ID, query, `grigdesk-settings-page`, однократный перенос старой вкладки,
`interface.behavior`. Неизвестные ID пропускаются. Перенос выполняется при вызове,
только если новый ключ отсутствует; он записывает новую страницу перед удалением
`grigdesk-settings-tab`. Отказ хранилища оставляет выбор доступным в памяти.

`FieldAddress` хранит страницу, необязательные сущность/вкладку и массив сегментов поля.
Сравнение выполняется по сегментам: точки и слеши внутри имени не разбираются.
Разрешение адреса проверяет страницу и копирует путь; динамическое наличие поля
проверяется владельцем соответствующего каталога после загрузки сущности.

Проверки: `tests/web/settings-catalog.test.js` (CAT01–CAT05).
