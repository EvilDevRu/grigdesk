# Настройки драйверов трекеров

`TrackerSettingsDialog.vue` открывает каталог драйверов по образцу исполнителей:
слева установленные драйверы и действия, справа параметры выбранного. При открытии
выбран драйвер текущего подключения, при его отсутствии — первый установленный.
Сохранённая операция установщика не перехватывает вход. Контракт точки входа —
[настройки с доски](board-settings-entry.md).

Каталог использует общий `data-ui-settings-catalog`, колонку 240 px и редактор
рядом. При ширине содержимого до 680 px каталог заменяется общим `UiSelect`,
кнопки остаются видимыми. Оболочка — `UiDialog` с `data-ui-workspace`, шириной
до 980 px, постоянным подвалом и общим полноэкранным режимом на телефоне.

Выбор строки меняет только редактор. Флажок «Включить» независимо включает
каждый драйвер, а «Доска по умолчанию» выбирает основной из включённых. Запись выполняется
только по «Сохранить» с expectedRevision.
Зелёный чип «Включён» отмечает каждый сохранённый включённый драйвер; отдельный чип
«По умолчанию» — основной. У основной доски видны оба чипа. Они показаны в каталоге
и заголовке редактора; в компактном селекте статусы дописаны к названию.
Открытие другого редактора, несохранённый флажок и черновой дефолт не меняют чипы:
они обновляются после подтверждённого сохранения по каталогу сервера.
Unavailable и restartRequired можно просматривать, но нельзя включать на доске.
Выбранное недоступное подключение можно отключить. Deleted не входит в каталог.

В редакторе видны версия, сохранённый результат проверки и «Обновить».
«Проверить обновления» и «Добавить трекер» находятся под каталогом. Установка
и обновление проходят [мастер операций](tracker-install-wizard.md); «Другие действия»
открывает прежний менеджер для выбора версии, отката и удаления.
Подробности обновлений — [обновления из каталога](tracker-driver-updates.md).
В подвале находятся «Закрыть» и «Сохранить».

В секции подключения «Проверить соединение» проверяет текущий ввод выбранного
редактором драйвера. Проверка не сохраняет реквизиты и не включает драйвер на доске.
Результат называет драйвер и сбрасывается при изменении полей или выбора. До завершения
проверки редактирование, сохранение и закрытие заблокированы. Серверная изоляция и API —
[проверка соединения](../b24/connection-test.md).

Поля задаёт схема драйвера. Секреты не подставляются при чтении; пустое поле сохраняет
прежний секрет, подсказка видна возле поля. Черновики разных драйверов и скрытых
режимов хранятся только в памяти формы. Сохранение передаёт черновики посещённых
драйверов, фильтруя скрытые поля каждой схемы. Ошибка записи сохраняет ввод.
Поля токенов имеют подсказку об API-токене вместо пароля и ошибку возле поля. Явно
неверный формат блокирует проверку и сохранение; новые токены дополнительно проверяются
сервером до записи. Длина токена не фиксируется; контракт —
[валидация токенов](../b24/token-validation.md).

Собственные задачи не представлены отдельным внешним драйвером. Просмотр,
установка и обновление пакета не включают его автоматически на доске.
Переход к параметрам из результата выбирает драйвер в редакторе и сохраняет
отдельный флажок подключения. Форму и установщик не показывают друг поверх друга;
смена содержимого оставляет несохранённые параметры в родительском компоненте.

Во время записи действия и внешнее закрытие заблокированы. Подтверждённое сохранение
показывает сообщение об успехе; изменение полей снимает его. Удаление выбранного
драйвера синхронизирует редактор, подключение и ревизию по каталогу.
