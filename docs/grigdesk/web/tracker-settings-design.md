# Оформление настроек трекера доски

`TrackerSettingsDialog.vue` использует общий `UiDialog` шириной до 560 px и рабочий
режим `data-ui-workspace`. Поля и кнопки наследуют общие размеры и сенсорные площадки.
На телефоне действует общая полноэкранная оболочка.

Форма содержит выбор установленного трекера и поля его схемы; секреты остаются пустыми
при чтении. Значение без подключения подписано «Не подключён». Отдельного трекера
GrigDesk, его карточки и статуса «Всегда включён» в этой форме нет.

«Установить» — отдельное действие под формой, открывающее окно «Установка трекера».
Оно сохраняет введённые реквизиты настроек. На узком экране кнопка переносится под
пояснение. Способ получения пакета показывается уже внутри установщика.

Закрытие и акцентное сохранение находятся в постоянном подвале. Во время записи
кнопка показывает спиннер, действия и внешнее закрытие заблокированы. Подтверждённое
сохранение показывает сообщение об успехе; изменение полей снимает это сообщение.
Ошибка записи сохраняет выбор и введённые значения.
