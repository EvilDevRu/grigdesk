# Прерванные оценки в топбаре

`AttentionAlerts.vue` показывает предупреждение через общий `UiTopbarPanel`. Триггер
использует `UiButton` с `variant="link"`, `tone="warning"` и контекстом
`analysis-attention-topbar`: его геометрия совпадает с таймерами и конвейерами в
`styles/components/actions.css`. В покое и при наведении рамка и фон прозрачны;
при открытии панель сохраняет общую подложку на всю высоту топбара.

Пояснение в панели оформлено обычным вторичным текстом. В каждой строке номер задачи
стоит над причиной остановки, справа остаются общие иконки перезапуска и скрытия.
Длинная причина переносится внутри строки. Массовые действия находятся в общем подвале,
используют компактные текстовые кнопки; перезапуск всех доступен при нескольких оценках.

Оформление не меняет опрос, ручной запуск или скрытие оценок. Выключенный триаж
по-прежнему не показывает сохранённые ошибки и не запускает опрос из топбара.
