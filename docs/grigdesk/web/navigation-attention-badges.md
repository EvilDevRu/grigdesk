# Счётчики внимания в навигации

Общее правило описано в [цветных счётчиках боковых панелей](navigation-counts.md).
Карта `badges` в AppShell сохраняет контракт пункт → `{n, kind, title}`; ToolHost
использует такую же проекцию для полки. Число показывает требующие внимания объекты,
цвет — наиболее срочную причину: `stall > wait > info`.

Чаты объединяют непрочитанные и ожидающие ответа идентификаторы, включая архив.
Конвейер суммирует проблемы и ожидания из дедуплицированной сводки; обычная работа
остаётся в топбаре. Доска показывает только новые задачи. Полка считает ту же группу
«Требуют внимания», что её панель, без завершённых задач и обычного ожидания.
Inbox сохраняет `GET /api/inbox/summary`, singleton SSE `inbox-changed` и минутный poll.
Новых запросов и подписок для счётчиков нет.

Число занимает отдельную строку под иконкой, без подложки и пульсации. Рейка остаётся
36 px, кнопка — 30 × 30 px, предел — `999+`. Полные значения и причины есть в подсказке
и доступном имени кнопки. Размеры описаны в [геометрии счётчиков](sidebar-chip-geometry.md).
