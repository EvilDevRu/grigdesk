# Настройки после подключения к машине

В полном приложении шестерёнка верхней панели видна только при активной рабочей области:
машина online и серверный вход подтверждён. До выбора профиля, при connecting, offline,
locked и терминальных отказах кнопка скрыта. Одной сохранённой привязки недостаточно.
В обычном браузере открытие по-прежнему требует авторизации на сервере.

`AppShell.active` управляет видимостью кнопки. `stores/settings.ts` сохраняет общую проверку
входа для всех источников: ссылки, маршрут, нативное меню и кнопки не открывают окно до
подтверждения авторизации. Ранний запрос остаётся отложенным; потеря входа закрывает
текущее окно, очищает черновики, временные секреты и прежнее намерение открытия.
Отдельного режима локальных настроек без подключения нет.

Без выбранной машины боковая навигация также скрыта, её ширина освобождена для стартового
экрана. Выбор профиля возвращает навигацию; временная потеря связи сохраняет рабочие страницы
по общему контракту. Кнопка машин доступна во время ожидания подключения.

`settings-availability.test.js` проверяет настоящий App с синтетической оболочкой на телефоне
и планшете: пустой старт, выбранная машина connecting, подтверждённый вход, открытие настроек
и потеря связи. Нативный запрос до подключения не обходит проверку входа.
