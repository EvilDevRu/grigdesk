# Единое оформление селектов шапки чата

Задача, модель и режим используют один `UiSelect` с контекстом `chat-session-toolbar`.
В `styles/components/fields.css` для этого контекста задан один набор правил: фон
`--surface-2`, рамка `--line`, скругление `--radius-sm` (4 px), отступы 8/28 px и
одинаковое положение шеврона. Отдельного оформления по `data-role="chat-model"` нет.

Видимая высота — 28 px на desktop и 32 px в сенсорном режиме, где прозрачное расширение
сохраняет площадку касания 44 px. Она имеет собственную высоту toolbar и центрируется
по полю: рамка не уменьшает её до 42 px. [Компактные controls](chat-touch-controls.md).
При наведении и фокусе рамка меняет цвет целиком; у раскрытого селекта и при клавиатурном
фокусе используется акцент. Нижнее подчёркивание прежнего оформления чата заменено
общей рамкой. Контекст `code-head-select` сохраняет свой прежний вид.

`SELECT-CHAT-BROWSER` сравнивает вычисленные высоту, отступы, рамку, скругление, фон,
шрифт и положение шеврона всех трёх селектов на desktop и touch. В артефактах сценария
есть отдельные снимки шапки перед раскрытием меню.
