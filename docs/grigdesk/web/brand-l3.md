# Иконка L3 «Янтарь»

Шапка, desktop-пакет, системное окно и APK используют единый знак из
`docs/images/brand/grigdesk-app-icon.svg`. В шапке размер — 20×20 px,
знак центрируется в существующей левой рейке. Сайт и заставка desktop сохраняют свои ресурсы.

Лицевая часть — `#F5C44C`, торец — `#AD5839`, буква — `#20233B`.
Торец повторяет лицевую часть со смещением (24, 12) на холсте 256×256.
Контур G взят из первого символа wordmark без изменения данных пути;
применены только равномерный масштаб 0.51 и перенос (35.264, 54.763).

`python3 web/scripts/gen-icons.py` воспроизводит производные из мастеров репозитория.
PNG 1024 — утверждённый растр SVG. Maskable PNG содержит знак размером 320 px
по центру графитового холста 512 px: весь знак остаётся внутри безопасного круга.
Favicon и уведомления приложения также используют L3.

Android :client ссылается на mipmap adaptive-иконки обычного и круглого запуска.
Foreground переносит все три контура, цвета и вложенные преобразования SVG;
внешний масштаб 0.20 и перенос (28.4, 28.4) сохраняют знак в безопасном круге 66 dp
на холсте 108 dp. Фон — `#0B0D11`. Генератор также обновляет ресурсы прежнего :app.

Для изменения уже установленной иконки нужны пересборка пакета и новый запуск desktop
либо установка нового APK. Обновление исходников не меняет значок запущенного окна.
Проверки — `tests/web/brand-assets.test.mts`: исходная G, цветные компоненты,
Android :client, размеры растров и повторяемость генератора.
