# Сенсорный размер общих элементов

Контейнер с `data-ui-touch` включает высоту элементов 44 px через общий
`web/src/styles/tokens.css`. Product-компонент выбирает режим атрибутом; локальные
CSS-декларации `--control-*` остаются запрещёнными.

Страница доступа к серверу использует этот режим для полей и кнопок.
Диалог добавления ретранслятора и общий диалог привязки телефона получают
атрибут на собственном surface, поскольку Teleport выводит их за пределы страницы. Для общего `confirmDialog` опция
`touchTargets: true` включает тот же атрибут в `UiDialogHost`.

В touch-контейнере controls, toolbar и действия дока сохраняют 44 px. Ширина viewport сама по себе touch не включает:
при 600 px обычные элементы имеют 36 px. Fullscreen-диалоги сохраняются.

Режим действует в отмеченном контейнере. Полное приложение отмечает корень автоматически
при pointer: coarse; подробности — в [сенсорной раскладке](client-responsive.md). Проверки публичной границы и
стилей — `npm --prefix web run check:ui` и `check:ui-styles`; поведение настроек
проверяет `tests/web/settings-mobile.component.test.js`.
