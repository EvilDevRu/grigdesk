# Список и выбранный стенд

Решения задачи **93022**, принятые вместе с планом: внутри профиля номера идут по
возрастанию, форма подъёма открывается справа, ручной стенд без известного названия
называется «Ручной стенд», выделение давности начинается с семи суток.

## Список и фильтры

Рабочая область содержит каталог слева и один выбранный стенд справа. Строка показывает
номер, название задачи, слот, состояние словами, порт сайта и давность. Группы идут по
профилю; «Без профиля» — последняя. Номера сравниваются без потери точности. Занятые слоты
группы берутся из всего её реестра до фильтров: одинаковый слот у разных профилей независим.

Поиск учитывает название, номер с префиксом `t` и без него, профиль, репозиторий, ветку и
путь. Фильтры проекта и состояния имеют фасетные счётчики: оба учитывают поиск, каждый
учитывает соседний фильтр и исключает собственный. Вариант проекта сохраняется с нулём,
пока профиль есть в исходном списке; исчезнувший профиль сбрасывается на «Все проекты».
«Все конвейерные» — дополнительный срез владельца. Основные категории взаимоисключающие:
работа, ожидание решения, встал, ручные, неактивен, неизвестно.

## Сведения конвейера

`notifyWatch.check` публикует уже прочитанные задачи и категории в реактивный
`sandboxPipelineSnapshot`. Новый канал не делает запросов, не запускает watcher и не
подписывается на SSE. Полный успешный снимок заменяет предыдущий; ошибка сохраняет
последние сведения и показывает предупреждение об устаревании.

Приоритет берётся из общей проекции конвейера: авария, молчание, ожидание, работа.
Молчание относится к фильтру «Встал», строка говорит «Молчит». ReadOnly не считается
активной работой. Без активной категории при известном графе стенд «Неактивен»; без
задачи, первого снимка или доступного графа — «Состояние неизвестно». Известная активная
категория остаётся достаточной при недоступном графе.

Конвейерный стенд не получает сведения задачи с другим известным профилем. Ручной
получает известное название только при совпадении обоих известных профилей и сохраняет
состояние «Ручной». Совпадение одного номера не связывает его с чужой задачей.

## Выбор, подъём и давность

Выбор хранится строковым номером. Первый обзор выбирает первую видимую строку; замена
объектов и фоновое изменение состояния сохраняют выбор, даже вне фильтра, с пояснением.
Явное изменение фильтра выбирает первый подходящий стенд. При исчезновении выбранного
выбирается первый видимый либо очищаются подробности. Карточка имеет ключ номера:
поздний ответ журнала исчезнувшего стенда не попадает в соседнюю карточку.

Идущий подъём без записи реестра — отдельная строка без выдуманных портов, слота и прав.
Появление записи заменяет её с сохранением выбора. Текущий шаг виден и после появления
записи, пока задание идёт. Недавние задания без стенда остаются в закрытом по умолчанию
раскрытии под списком, независимо от фильтров.

Форма постоянно смонтирована под `v-show`, сохраняет выбор стенда и черновик. Первый
пустой успешный обзор открывает её; ошибка чтения — нет. Кнопка подъёма доступна и при
пустом реестре. Новый подтверждённый здесь подъём закрывает форму, сбрасывает фильтры и
показывает свою строку; чужой подъём и отказ операции форму не закрывают.

Точная давность доступна при подтверждённой привязке и текущем успешном задании `up`
того же профиля, от его начала. Иначе `updatedAt` даёт только оценку с `≈` и пояснением:
«Оценка по обновлению записи о стенде; точная дата подъёма неизвестна». Прогон или снос
не обнуляют возраст. Отсутствующая, битая или будущая дата означает неизвестную давность.
Порог выделения — не менее семи суток. Рядом с давностью появляется знак предупреждения
«⚠» с доступной подписью «Давно стоит»; строка использует общий тон `warning` у `UiButton`
без локального оформления control. Знак остаётся виден и у выбранной строки.
Часы обновляются раз в минуту внутри вида без сетевых операций.
Для текущего подъёма показывается время от начала задания.

При ширине контейнера до 1000 px видна одна панель, переключаемая кнопками «Список / Стенд».
Выбор строки открывает подробности, подъём — форму. Скрытие панели не размонтирует ввод.
На широкой области обе панели имеют независимую прокрутку; десять обычных строк двух
профилей помещаются на экране 1600×1000.
