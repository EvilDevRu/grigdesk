# Просмотр медиа поверх управления окном

Просмотр изображения или видео занимает весь экран, включая область кнопок приложения.
`MediaViewer.vue` не резервирует для них место: его собственная панель остаётся на всю ширину.
Кнопки приложения находятся в DOM под общим затемнением `UiDialog`, становятся `inert`
вместе с фоном и не принимают команды при открытом модальном слое.

В главном Electron-окне используется `frame: false`, а управление рисует
`DesktopWindowControls.vue`. Нативный Window Controls Overlay отключён, иначе системные
кнопки оказались бы над затемнением независимо от CSS-порядка страницы.
Механизм команд описан в [контракте управления окном](desktop-titlebar.md).

«Закрыть» в просмотрщике закрывает только медиа. После снятия слоя управление приложением
снова доступно; его закрытие сохраняет обычный диалог выхода и защиту несохранённых правок.

При проверке настоящего Electron нужны не только размеры. Предок кнопок приложения
должен быть `inert`, hit-test по их центрам должен попадать в модальный слой, а попытка
нажать фоновую кнопку — сохранять окно открытым. После закрытия просмотра проверяются
сворачивание, разворачивание, восстановление размера и обычный запрос закрытия.
