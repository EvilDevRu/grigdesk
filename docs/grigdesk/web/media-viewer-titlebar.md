# Панель медиа и системные кнопки окна

Шапка `MediaViewer.vue` ограничена безопасной областью системного заголовка:
слева используется `env(titlebar-area-x)`, справа — остаток ширины после
`env(titlebar-area-x)` и `env(titlebar-area-width)`. Поэтому действия просмотра,
включая «Закрыть», остаются рядом с системными кнопками Electron без пересечения.
Геометрия берётся из окна и учитывает масштаб страницы и сторону системных кнопок.

Ограничение действует только на шапку. Затемнение и сцена картинки или видео занимают
прежнюю область экрана. В браузере без Window Controls Overlay значения по умолчанию
оставляют шапку на всю ширину; мобильные отступы сохраняются.

Проверка требует настоящего Electron: все действия шапки должны лежать внутри
`navigator.windowControlsOverlay.getTitlebarAreaRect()` после завершения ресайза и
смены масштаба. При кнопках справа правая граница безопасной области должна стать
меньше ширины viewport; промежуточное значение на всю ширину не доказывает отсутствие
пересечения. Снимок renderer не содержит системных кнопок — для визуальной сверки
нужен снимок дисплея, как в [проверке топбара](desktop-titlebar.md).
