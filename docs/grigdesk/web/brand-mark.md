# Знак GrigDesk

В общей верхней панели используется монохромная надпись GRIG. Значки приложений
используют L8 «Графит» с исходной G. В README показана полная надпись GrigDesk.

## Источники и воспроизведение

Мастера лежат в `docs/images/brand/`: `grigdesk-wordmark{,-reversed}.svg`,
`grigdesk-stacked.svg`, `grigdesk-gd{,-reversed,-small}.svg`,
`grigdesk-g-small{,-reversed}.svg`, `grigdesk-favicon-tile.svg`,
`grigdesk-app-icon.svg`, `grigdesk-app-icon-1024.png`, `grigdesk-maskable-512.png`.
Геометрия буквы G и утверждённые растры сохраняются побайтно. Производные надписи
`grigdesk-wordmark-light.svg` и `grigdesk-wordmark-graphite.svg` отличаются только заливкой:
`#F2F3F5` и `#0B0D11`. В [публичном README](../overview/public-readme.md) светлая надпись
встроена в графитовую обложку рядом со знаком; `picture` выбирает широкую или мобильную
композицию этой обложки.

Из корня запускается `python3 web/scripts/gen-icons.py`. Обычный запуск читает мастера
репозитория, поэтому не требует локального комплекта. Явный `--kit <папка>` импортирует
утверждённый комплект перед генерацией. Pillow уменьшает готовый PNG методом LANCZOS;
повторный запуск сохраняет те же байты результатов.

Генератор создаёт:

- веб: PNG 96/192/512 и maskable 512, встроенный favicon из SVG и base64 для уведомлений;
- окно: `desktop/build/icon.png` 512 и `window-icon.png` 64;
- команду: `bin/grigdesk.png`, побайтную копию веб-значка 512;
- Android `:client`: client_icon.png и адаптивный фон и контуры L8 на холсте 108 dp
  для обычного и круглого значка;
- `GrigDeskMark.vue`: полный цветной L8 из мастера app-icon.

В `GrigWordmark.vue` первые четыре буквы из светлого мастера сохраняют исходные
контуры и заливку `#F2F3F5`. Ширина надписи в шапке — 48 CSS px, боковые поля — по 8 px.
Кнопка обновления показывает надпись и индикатор доступной версии.
Палитра и безопасные поля иконки описаны в [контракте L8](brand-l8.md).

## Проверка

`tests/web/brand-assets.test.mts` проверяет состав, размеры, встроенные копии, геометрию
компонентов и повторяемость генератора. Проверки SFC и шапки проверяют использование знака.
Малые размеры нужно также смотреть на светлом и тёмном фоне: наличие файла не доказывает
читаемость. Для заставки используется отдельный утверждённый комплект в `desktop/assets/splash/`;
генератор значков его не изменяет.
