# Открытие настроек в основном документе

`shared/settingsNavigation.ts` — общий вход кнопок, ссылок, старого маршрута и нативного события.
Шестерёнка AppShell является UiIconButton с aria-haspopup и pressed, а не router-link.
Открытие кнопкой не меняет текущий маршрут. Существующий `/settings` перехватывается во всех
режимах: работающая страница сохраняется, первый вход заменяется `/board`. Query page проходит
чистый каталог и ждёт подтверждённой авторизации в одном pending request.

Слушатель `grigdesk:open-settings` ставится в main.js до mount. Он читает только факт события,
не detail; повторная установка снимает предыдущую, HMR удаляет guard и listener.
Браузерной комбинации клавиш не добавлено. Потеря входа очищает сессию и отложенное открытие.
SettingsModal расположен внутри прежнего SpeechProvider рядом с остальными модалами;
router-view, AppShell и единственный ToolHost не зависят от состояния настроек.

Входящие выбирают плагин из существующего каталога по nav.path своего раздела, так как public
DTO очереди не содержит plugin id. 3D передаёт ID из строки исполнителя. Доска открывает Б24,
презентации — плагины. Значения форм и секреты не участвуют в этих целях.

`createSettingsActions` проверяет строку терминала и ключ чата до выбора судьбы dirty.
Продолжение редактирования отменяет переход. Применение с ошибкой оставляет форму открытой;
отказ доставки также сохраняет модал. Успех открывает инструмент в том же документе и закрывает
настройки один раз. Вставка терминала не добавляет Enter. Во время доставки форма занята.
