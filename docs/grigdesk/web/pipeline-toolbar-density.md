# Компактная панель конвейера

Панель `PipelineView.vue` использует высоту элементов `--toolbar-control-h` (28 px),
сама занимает 36 px и оставляет 12 px до первой карточки. Отрицательные верхний и
боковые отступы берутся из `--page-gutter` оболочки; дополнительного запаса высоты
после панели нет. При прокрутке панель остаётся закреплённой сверху.

Проекты выглядят как плоские вкладки: выбранный выделен цветом и нижней линией.
Скрытый измерительный ряд использует тот же `data-context`, что видимые кнопки,
поэтому меню `+N` учитывает настоящую ширину элементов. Обрезание ряда по горизонтали
не скрывает нижнюю линию выбранного проекта.

Не выбранные состояния имеют нейтральные подписи и счётчики. Цвет остаётся у точек
без ореола, а выбранное состояние получает мягкую подложку своего тона. У «Все» нет
точки; нулевые состояния остаются доступными. Две кнопки вида имеют размер 28 × 28 px.
Оформление controls живёт в `styles/components/actions.css`, а не в стилях страницы.

На экранах шире 600 CSS px адаптив зависит от ширины контейнера `pipeline-view`:

- До 1160 px у состояний остаются точки и числа; подпись «Все» сохраняется.
- До 760 px состояния собираются в общий `UiPopover` с текущим значением и числом.
- До 620 px у кнопки меню скрывается служебная подпись «Состояние:».
- До 420 px скрывается название текущего состояния; полное имя остаётся доступным
  через `aria-label` и подсказку.

На сенсорном устройстве общий токен увеличивает элементы до 44 px и панель до 52 px.
До 600 CSS px вместо этого ряда появляется [телефонная панель](phone-pipeline-controls.md)
с выбором проекта, состояния и подписанным меню управления.
Классификация, числа внутри проекта, сохранение фильтров и независимость двух
переключателей вида не меняются. Проверки поведения —
`tests/web/pipeline-filters.component.test.js`.
