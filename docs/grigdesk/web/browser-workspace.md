# Встроенный браузер

Раздел «Браузер» доступен в настольном приложении Linux. Каждая вкладка — отдельный
Electron WebContentsView. Адрес, история, обновление, масштаб и закрытие работают
через узкий preload главного документа. Переход между разделами скрывает поверхность,
сохраняя документ и форму. Вкладки после перезапуска не восстанавливаются; cookies
и хранилища сайта сохраняются в session владельца.

Компактные панели, пустые состояния и управление агентами описаны
в [оформлении браузера](browser-design.md).

## Открытие стендов и настройки

«Инструменты → Браузер» задаёт правило этого компьютера: встроенное открытие либо
внешнее приложение. По умолчанию используется системный внешний браузер, доступ
агентов выключен. Выбор внешнего приложения хранит opaque ID из native-каталога;
ручной выбор файла регистрирует executable. Произвольная команда из формы не принимается.
Настройки публикуются после успешной сериализованной записи на диск.
На этой же странице выбирается поиск Яндекс/Google для текста в адресной строке;
распознавание адресов и меню вкладок описаны в [управлении вкладками](browser-navigation-tabs.md).

`openStand` и `StandLink` применяют одно правило к конвейеру, песочницам и портам Docker.
Меню позволяет разовый выбор; повторное открытие стенда учитывает deduplicate.
Средняя кнопка и обычная веб-страница сохраняют поведение ссылки. Android и web без
native capability показывают недоступность встроенного режима.

Выключатель доступа агентов независим от выбора браузера для человека. Отключение
сначала отзывает native-доступ, затем требует подтверждения сервера; потеря ответа
оставляет честное состояние неизвестного результата. Работа с доступом описана
в [контракте чата](../chat/browser-access.md), запуск этапов —
в [контракте конвейера](../pipeline/browser-transport.md).

## Native и DOM

BrowserViewport получает геометрию после подтверждения текущего instance/revision.
Верхний блокирующий UI-слой синхронно скрывает native-поверхность до paint:
WebContentsView находится вне DOM и иначе перекрыл бы модал. Под слоем остаётся
[последний показанный кадр страницы](browser-overlay-preview.md). Поздний layout
ACK прежнего экземпляра не возвращает поверхность. Переключение раздела сохраняет
живую страницу. Оповещения используют ту же подложку через подписку на центр тостов,
сохраняя прежнюю политику Escape и тот же документ после закрытия оповещения.

`grigdesk:browser` проверяет точные sender/mainFrame, UI origin, document epoch
и shutdown. Гости и дочерние окна не получают preload. У гостей выключен Node,
включены sandbox/contextIsolation и отдельная session: human и каждый agent-owner
не делят cookies, localStorage и service worker. Доступ к local shell pipe запрещён.

Управление принимает закрытый набор операций. Сырые JS, evaluate и CDP method
не входят в публичный инструмент. Driver использует фиксированный isolated world;
refs наблюдения теряют силу при навигации. Каждый следующий эффект сверяет owner,
grant/page/host epoch, origin и deadline. После timeout мутации автоматически
не повторяются; потерянный ответ может означать outcome_unknown.

## Host и проверки

Один главный документ владеет bounded long-poll очереди. Новый EventSource не создаётся;
logout, смена машины и shutdown снимают подписку. Сервер допускает одну активную
машину: lease 15 секунд, heartbeat 5 секунд, второе окно требует явного takeover.
Привилегированные native-операции не доступны через HTTP shell.

Публичные browser capability/preferences входят в shared/client/clientShell.ts.
После изменения этого контракта обновляется общий API fingerprint; до первого выпуска
номер остаётся 0.1. Правило описано в [контракте версии API](../server/api-version.md).

Node-тесты лежат в tests/desktop/browser-*.test.mts и tests/web/browser-*.test.mts.
Отдельный tests/desktop/e2e/browser-workspace.e2e.mjs запускает настоящий Electron
с собственными сервером, сайтом, HOME/XDG и профилем. Он проверяет сохранение формы,
модал поверх скрытого guest, CDP/input/JPEG, dedupe/revoke, cookies и shell isolation.
Этот IPC smoke дополняет серверные и engine authority-тесты.
