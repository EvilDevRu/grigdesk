# Действия программы в обзоре исполнителя

На вкладке «Обзор» настроек исполнителя блок «Копии программы» не показывается.
Доступные действия установки, просмотра хода, обновления, переустановки и удаления
собраны в одну горизонтальную строку. Если места мало, строка прокручивается по горизонтали.

Кнопка «Удалить программу» использует общий `UiButton` с `tone="danger"`.
Перед удалением общий `confirmDialog` показывает имя исполнителя, версию и сохранение
авторизации, настроек и истории одной короткой строкой. Команда и перечень затронутых
путей из серверной подготовки доступны под свёрнутым disclosure «Подробности». Диалог использует красное
подтверждение и значок удаления; отмена не отправляет запрос старта операции.

Распознанные npm-копии и копии из официального installer используют те же действия
и общее окно прогресса. Терминал предлагается только как запасной выход после сбоя.
