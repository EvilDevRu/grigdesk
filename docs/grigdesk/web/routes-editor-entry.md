# Вход в редактор маршрута

«Редактировать» — главное действие шапки корректного опубликованного маршрута.
Кнопка доступна для обоих источников каталога, включая просмотр исторической ревизии.
Она не переключает источник публикации и не открывает редактирование по клику на схеме.

При нажатии интерфейс заново читает черновики проекта и рассматривает только `editing`
этого проекта: сначала последний изменённый, при равной дате — по ID по возрастанию.
Наличие показанного маршрута проверяется в полном документе. Черновик без этого маршрута
пропускается; чужие документы не изменяются. Старая основа допустима, перенос остаётся явным.
Ошибка чтения списка или документа показывается человеку и не запускает создание копии.

Первый подходящий черновик открывается с тем же маршрутом. Если подходящего нет,
копируется полный показанный каталог: при историческом просмотре — его точный хеш.
В историческом просмотре подходящий начатый черновик может иметь другую основу;
для намеренной новой копии ревизии служит отдельное действие в истории.
«+ Черновик» также сохраняет смысл явного создания новой копии текущего каталога.

Адрес открытого черновика содержит проект, ID документа, прежний маршрут и `tab=graph`;
параметры просмотра каталога, начальной разведки и старого этапа удаляются.
Повторный вход находит начатый документ. До завершения запроса повторный клик заблокирован.
После смены проекта, маршрута, адреса или закрытия страницы поздний ответ не переводит
человека обратно. Создание в разных вкладках не имеет общей клиентской блокировки.

Контракт проверяют компонентные тесты `routes-editor-view.component.test.js`;
раскладку панели этапа и старые ссылки описывает [рабочая область](routes-design.md).
