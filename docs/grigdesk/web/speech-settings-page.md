# Единая страница речи

Раздел содержит страницу «Речь» (`speech.dictation`) и отдельную существующую
страницу плагина «Видеовстречи» (`speech.videoTasks`). Каталог и реестр компонентов
не содержат прежних `speech.video`, `speech.language`, `speech.models`,
`speech.advanced`. Сохранённый выбор, query и прямой вызов со старым ID разрешаются
в `speech.dictation`; адрес поля сохраняет сегменты `fieldPath`.

Все редактируемые поля речи сохраняются в каталоге с адресом единой страницы.
Переход к инженерному полю из поиска или ошибки применения раскрывает
«Расширенное», после чего общий SettingsField прокручивает и фокусирует control.
Обычное открытие оставляет этот блок свёрнутым.

SpeechInstallation монтируется один раз. SpeechModelRow используется в «Расширенном» для каждой
модели; подпись выбора различает диктовку, видео и общую модель обоих пресетов.
Явные `model` и `videoModel` по-прежнему имеют приоритет над качеством.
Закрытие «Расширенного» не останавливает model jobs, установку или их опрос;
уход на другую страницу останавливает только опрос до возвращения.

Проверки: `settings-catalog.test.js`, `settings-speech.component.test.js`,
`settings-speech-session.test.js` и `settings-language.component.test.js`.

Итоговая простая структура и общий пресет описаны в [настройках речи](settings-speech.md).
