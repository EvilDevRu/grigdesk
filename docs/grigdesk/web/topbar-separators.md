# Разделители групп в топбаре

`AppShell.vue` разделяет CPU и RAM, рабочие индикаторы, исполнителей и сеть пустыми
`span.sep` с `aria-hidden="true"`. Линия имеет размер 1 × 12 CSS px и цвет `--line-2`.
Flex-строка центрирует её по высоте и оставляет по 8 px до соседних элементов.
Такая же раскладка применяется внутри блока метрик.

Текстовые точки и отрицательные поля убраны: положение разделителя больше не зависит
от метрик шрифта. Когда узкий экран скрывает CPU/RAM, внешний разделитель этого блока
тоже скрывается, чтобы в начале строки не оставалась отдельная черта.
