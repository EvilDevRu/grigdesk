# Разделители групп в топбаре

`AppShell.vue` разделяет блок CPU/RAM, рабочие индикаторы, исполнителей и сеть пустыми
`span.sep` с `aria-hidden="true"`. Линия имеет размер 1 × 12 CSS px и цвет `--line-2`.
Flex-строка центрирует её по высоте и оставляет по 8 px до соседних элементов.
После RAM линия отделяет кнопку ресурсов от следующей группы статусов.

Текстовые точки и отрицательные поля убраны: положение разделителя больше не зависит
от метрик шрифта. Разделитель ресурсов виден от 601 px при выбранной машине.
На телефоне CPU/RAM находятся во второй полосе, а этот разделитель не выводится.
