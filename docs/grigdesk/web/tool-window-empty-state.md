# Отсутствующий снимок после перезагрузки окон

Задача 93020. После перезагрузки главного документа координатор принимает существующие
native окна через status. Снимки прежнего координатора были только в памяти, поэтому
принятое окно может получить `init` с пустым состоянием `{}`.

Для Кода пустой снимок означает отсутствие выбора для восстановления. Панель завершает
обычную загрузку каталога и сохраняет полученный выбор; поиск рабочей копии по отсутствующим
repo/root не выполняется. Это не ошибка недоступного пути и не повод показывать `undefined`.
Следующая команда открывает точный файл и строку обычным путём.

Непустой снимок по-прежнему восстанавливает переданный выбор. Если указанная рабочая копия
или файл исчезли, панель показывает именованную ошибку и не подставляет другую копию.
Окна и снимки после запуска приложения автоматически не восстанавливаются.

Проверки: Electron — reload главного и дочернего документов, отсутствие ошибки до и после
новой команды, повторный reload и возврат в колонку; `code-view.component.test.js` —
сохранение снимка и диагностика исчезнувших рабочей копии и файла (TW-C01/TW-C02).
