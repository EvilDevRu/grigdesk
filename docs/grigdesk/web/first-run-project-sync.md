# Синхронизация папок мастера между окнами

Событие `onboarding-changed` передаётся через общий SSE вкладки и приводит к чтению
серверного черновика. На шаге проекта каждое окно самостоятельно запрашивает локальные
ветки новых или изменённых папок. Список веток принадлежит проверке конкретного пути:
результат прежней папки не используется для новой, удалённые строки очищаются.

Фоновая проверка сохраняет выбранную на сервере ветку и не записывает ветку по умолчанию
в ответ на синхронизацию. Локальный ввод по-прежнему выбирает текущую совместимую ветку,
если человек ещё не сделал выбор. «Далее» доступно после проверки всех выбранных веток.

Названия и пути приходят из того же черновика, что и ветки; перезагрузка окна для
продолжения не требуется. Изменение только названия или выбранной ветки не повторяет
проверку уже известного пути.
