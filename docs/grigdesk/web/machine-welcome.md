# Начальный экран выбора компьютера

До первого входа, если оболочка обнаружена и профиль не выбран, внутри `AppShell` виден
`MachineWelcome.vue`: заголовок «Выберите компьютер», пояснение, действия и инструкция.
Пустой список не открывает окно добавления автоматически. Кнопка «Добавить машину»
открывает существующий `AddMachineDialog`; закрытие возвращает к начальному экрану.

При сохранённых машинах или доступной локальной установке основное действие открывает
полный список через `shell.showConnections`. Без них главным остаётся добавление.
Инструкция учитывает capability `scan`: QR и строка при наличии сканера, строка без него.
Начальный экран не запускает транспорт, сканер или собственные запросы серверных данных.

При ширине контейнера от 700 px пояснение с действиями и инструкция образуют две колонки;
на телефоне следуют друг за другом. [Мобильная компоновка](machine-welcome-mobile.md)
использует всю рабочую область и помещается в обычном высоком окне без прокрутки.
В маленьком окне или с крупным текстом прокрутка принадлежит самому экрану, текст и кнопки
переносятся. Кнопка машин остаётся в верхней панели; настройки скрыты до подключения
и входа, боковая навигация — до выбора профиля. После первого входа потери
связи сохраняют рабочие страницы по прежнему контракту, не возвращая начальный экран.

`machine-welcome.test.js` проверяет настоящий App в Chromium: 320–1280 px, текст 100/130%,
добавление по нажатию, закрытие окна и переход к сохранённым машинам. API и оболочка в этой
проверке синтетические; внешний сервер и камера не используются.
