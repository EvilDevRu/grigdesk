# Действия установки в обзоре исполнителя

В настройках на вкладке «Обзор» исполнителя нет отдельной кнопки «Показать результат»
после завершения установки или обновления CLI. Последний итог остаётся текстом под
действиями, а общий диалог показывает результат запущенной операции.

Во время активной операции кнопка «Ход установки» позволяет снова открыть общий диалог.
Во всплывашке исполнителя в топбаре просмотр сохранённого итога остаётся доступен,
когда результат требует внимания.
