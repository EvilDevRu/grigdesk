# Диалог выбора рабочей папки

`ChatWorkdir.vue` использует общий `UiDialog`: на компьютере это окно шириной до 480 px,
на экране до 600 px — нижняя панель `mobileSheet`. Полное Android-приложение получает тот
же компонент из общего web-клиента; пути относятся к подключённому компьютеру. Нативный
выбор файлов телефона для рабочей папки не используется.

В настройках мобильного чата каталог [раскрывается на месте](phone-workdir-inline.md):
`ChatWorkdirPicker` выводит то же содержимое обычной секцией без модального слоя.
Настольный режим использует диалог, а отдельное подтверждение переноса памяти
появляется только при требовании серверного протокола.

Подтверждение показывает целевой путь в компактном окне, на телефоне — в нижней панели.
Действие с выжимкой выделено основным цветом. Во время запроса в теле окна виден статус
со спиннером. Если прежняя сессия несовместима, в окне остаются причина отказа,
отмена и явный переход без выжимки.

Под заголовком стоит поиск и, в чате без проекта, кнопка «По пути».
Текущая папка, её источник и дополнительные репозитории находятся под каталогом.
Каталог проекта показывает основной и дополнительные репозитории из общего каталога.
Без проекта каталог объединяет текущую папку, недавние произвольные папки
и каталог приложения GrigDesk. Повторы определяются через `sameChatWorkdir`.

Поиск фильтрует названия и пояснения, включая полные пути, без учёта регистра. Список имеет
собственную прокрутку, а длинные названия и пути переносятся. У репозиториев видны пути
из паспорта. Пустой результат предлагает изменить запрос. Загрузка каталога отмечена
общим спиннером.

Кнопка «По пути» открывает ручной ввод и передаёт фокус полю. Поле связано с подписью
через `UiField`, Enter отправляет форму. Обратная кнопка возвращает каталог с прежним
поиском и сохраняет черновик пути. Нужен
абсолютный путь на компьютере агента. Отказ остаётся в диалоге; успешный выбор закрывает
его. Перед подтверждением переноса памяти первый диалог также закрывается. Чат задачи
или companion показывает сведения без редактирования.

Начальный фокус попадает на кнопку закрытия, поэтому открытие на телефоне не вызывает
экранную клавиатуру. Общая оболочка держит фокус, обрабатывает Escape и системный «Назад»,
возвращает фокус к кнопке папки. Высота нижней панели ограничена `--app-viewport-height`,
тело прокручивается при низком окне и клавиатуре; отступы учитывают safe area. Сенсорные
размеры controls наследуются от общего `data-ui-touch`.

Компонентные проверки находятся в `tests/web/chat-workdir.component.test.js`; протокол
выбора и переноса остаётся в `tests/web/chat-workdir.test.js`. Тексты выбора входят в общие
каталоги RU/EN. Оформление controls принадлежит UI-набору, геометрия оболочки —
`styles/components/overlays.css`, раскладка содержимого — самому компоненту.

Поля и действия используют [общий рабочий стиль](chat-workdir-controls.md),
как в разделе «Проекты»; сенсорный размер остаётся общим.

Раскладка и фокус при смене способа — в [компоновке выбора](chat-workdir-layout.md).
