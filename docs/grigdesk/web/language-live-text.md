# Язык сохранённых вопросов и проверка источников текста

Задача №93001: собственный вопрос, кнопка, ошибка или результат операции хранит `MessageRef`
до отображения. `t()` подходит для реактивного вычисления подписи, но его результат,
сохранённый в ref или очереди диалогов, уже не меняется при выборе языка. Обычные строки
ответов сервера и пользовательские параметры сохраняются исходными данными.

Параметр сообщения может содержать вложенный `MessageRef`. Снимок рекурсивно копирует
и замораживает его параметры, а переводчик разрешает всё дерево на текущем языке.
Так подтверждение перезапуска сохраняет собственное пояснение режима сервера и число
идущих ходов без фиксации языка. Переключение языка не повторяет запрос или действие,
не меняет подтверждаемую цель и не пересоздаёт открытый диалог.

Производители в настройках передают descriptors для собственных вопросов и кнопок,
включая процессы, ключи исполнителей, откат плагина и прежнюю привязку телефона.
Сохранённые локальные ошибки и результаты разрешаются при показе. Готовый словарь
распознавания остаётся значением настройки; перевод интерфейса не меняет его термины.

Общий popover конвейера получает текущую локаль через существующий порт UI. Статусы
проецируются из тех же данных, а число активных конвейеров использует plural каталога.
Название задачи, причина ожидания и порядок записей не переводятся.

Собственные отказы desktop-трубы берут язык из предпочтения установки и системного
языка. При прямом старом вызове без системной локали сохраняется русский контракт.
Ранний отказ из-за относительного каталога данных использует язык системы. Валидация,
HTTP-коды, авторизация трубы и неизвестные внешние ошибки от перевода не меняются.

Сторож новых надписей связывает видимый binding Vue с его локальным объявлением,
включая aliases, `ref` и `computed`. Оба аргумента desktop `showErrorBox` и текст Android
`Toast.makeText` входят в ту же проверку RU/EN. Внешние данные не исполняются и не
считаются ключами. Техническое исключение для конкретного источника содержит `file`,
`text` и причину в `i18n-scope.json`; оно не разрешает такую надпись во всей области.
