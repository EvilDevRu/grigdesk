# Шапка, шаги и ввод чата на телефоне

До 600 CSS px название, возврат, карандаш переименования и раскрытие настроек
занимают общий верхний ряд. Карандаш — контурный SVG с приглушённым цветом вторичных
деталей доски и площадкой 44 × 44 px. Переименование доступно и при закрытых
настройках, сохраняет прежние фокус, выделение, Enter, Escape и запись названия.

Настройки открываются [отдельным экраном](phone-chat-options.md) с подписанными полями
на всю ширину. Teleport сохраняет прежние экземпляры controls и выбранные значения.
Предупреждения о модели остаются видимыми в шапке.

В сенсорном режиме `data-ui-touch` Enter в композере не вызывает отправку и не выбирает
команду в открытом меню. Браузер выполняет перенос строки; поле передаёт
`enterkeyhint="enter"`. Кнопка отправляет прежним маршрутом: в активный ход либо в
очередь. На desktop Enter сохраняет отправку, Shift+Enter — перенос; композиция IME
по-прежнему защищена. Подсказка пустого чата учитывает сенсорный режим.

У раскрывающих строк технической ленты высота 28 px; между блоками хода на телефоне
4 px. [Плотность ленты](phone-chat-density.md) не уменьшает основные действия композера.

`chat-in-turn.component.test.js` монтирует настоящий композер: проверяет перенос без
отправки, многострочную отправку кнопкой, меню команд, доступное переименование,
сохранение экземпляра модели и вычисленные размеры строк. Проверки Happy DOM
подтверждают обработчики и CSS, но не геометрию WebView и системную клавиатуру.
