# Пропорции страницы «Чаты» — тоже настройка устройства

- **Пропорции страницы «Чаты» — тоже настройка устройства**: ширина списка чатов
  (`grigdesk-chats-list-width`) и высота поля ввода (`grigdesk-chat-composer-h`) двигаются
  разделителями и живут в localStorage — рядом с шириной дока и
  дерева «Кода», по той же причине: серверные prefs навязали бы планшету раскладку монитора.
  Пустая настройка означает «решает CSS»; правила и границы — [чат с агентами](../chat/README.md).

[Геометрия оболочки](desktop-ui-density.md) сохраняет оба предпочтения.
Лента получает отступы через токены. На телефоне до 600 px высота композера определяется
CSS, разделитель скрыт; сохранённая высота вновь применяется на более широком экране.
[Телефонная раскладка](phone-workspaces.md) увеличивает размер текста для чтения.
