# Машины и связь в приложении

При наличии оболочки экран «Машины» доступен без сервера: выбор, добавление строкой или
QR, подключение, отключение, смена адреса и удаление через общий диалог подтверждения.
«Этот компьютер» показывается только при `localAvailable`. Смена адреса относится к
существующему профилю; проверку закреплённого пина выполняет оболочка.

До первого online, без профиля и при unpaired/revoked/identityMismatch/incompatible
показывается экран машин. После первого online переходы offline/connecting сохраняют
смонтированный рабочий интерфейс. Locked добавляет постоянный диалог разблокировки и
`inert` рабочему дереву. Разблокировка отправляется только оболочке.

При несовместимости видны версии приложения и сервера; ссылка GitHub появляется только
при непустом `RELEASES_URL`. Строка привязки очищается при закрытии диалога и не идёт в журнал.
Переход online вызывает `auth.load('shell-online')`. В оболочке 401 обновляет состояние
связи без reload; обычный вход сохраняет прежнюю ограниченную перезагрузку.

Проверки: `connections-view.component.test.js`, `app-shell-gate.component.test.js`.

Первое действие в `.topbar-actions` — кнопка связи с именем машины и состоянием.
На узкой ширине остаётся значок с цветом состояния, полная подпись доступна подсказкой
и aria-label. Меню позволяет выбрать машину, добавить новую, отключиться или открыть
весь список. Оно использует общую поверхность topbar и `useUiLayer` для Escape.
Иконка приходит из ICONS главной оболочки. Проверка — `connection-button.component.test.js`.
