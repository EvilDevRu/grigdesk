# Установка трекера на телефоне

Мастер использует общий полноэкранный `UiDialog`: заголовок и действия закреплены,
содержимое прокручивается одной областью. Мобильная строка шага показывает номер
слева и название текущего шага справа. Длинная desktop-шкала скрыта.

Сетка содержимого выровнена к началу и не имеет минимальной высоты 300 px.
Она не растягивает промежуток между номером шага и карточкой операции.
Карточка подготовки объединяет спиннер, статус, текущий этап, прогресс и пояснение
о работе после закрытия окна. Процент показан только для определённого fetching.
Пока операция выполняется, преждевременная подсказка о подтверждении пакета скрыта.

В подвале телефона действия занимают две равные колонки; единственное действие
занимает всю строку. Закрытие сохраняет операцию, отмена проверки использует прежний
серверный переход. Подготовка и применение остаются отдельными действиями.

Общие предупреждения для официальных пакетов описаны в
[контракте происхождения](../plugins/official-install-notices.md).
