# Панель MCP: отображение отделено от загрузки

[ProviderPage](../../../web/src/views/settings/pages/ProviderPage.vue) показывает панель
при `mcp && installed` на вкладке MCP выбранного исполнителя. Явный watcher посещения
не подписывается на ответ опроса. Запрос идёт через общий store, refresh обходит кэш;
собственного таймера и опроса скрытых исполнителей нет.

[ProviderMcpStatus](../../../web/src/views/settings/ProviderMcpStatus.vue) получает
`providerId`, `providerName` и `status` (ответ со store-флагом `loading` либо `null`).
Кнопка отправляет событие `refresh` без аргументов; запрос выполняет родитель.
Компонент использует Vue и публичный UI facade, отображает снимок без API, store,
SSE, таймеров или веток по имени исполнителя.

Группы вычисляются через `computed`: базовый порядок `user`, `project`, `account`,
переименования и подсказки адаптера, затем дополнительные области. Неизвестный
scope сохраняется с подписью из его id; пустой scope относится к `user`.
Входной снимок не меняется. Обновление prop или вложенных реактивных данных
пересчитывает группы. Статусы, тексты, `emptyText` и общий fallback сохранены.

Панель владеет scoped-стилями заголовка, списка, сообщения об ошибке и пояснений:
внутренние элементы не наследуют scoped CSS страницы. Control skin кнопки остаётся
в общем UI. Три вложенные сетки используют `minmax(0, 1fr)`, длинное имя сокращается,
а список прокручивается в пределах 360 px.

Проверки отображения — `settings-mcp.component.test.js`; выбранный исполнитель,
ленивость и отсутствие цикла — `settings-provider-session.test.js`. Браузерный стенд
`settings-modal.e2e.mjs` монтирует настоящий модал и страницы с общим CSS.

Серверные состояния и пределы диагностики DeepSeek описаны в
[безопасном списке MCP](../chat/deepseek-mcp-status.md).
