# Компоновка ресурсов компьютера

ComputerResourcesPanel отображается в [едином диалоге](resources-dialog.md).
Содержание разделено на вычисления, память и диски без повторной шапки CPU/RAM.
CPU и GPU, ОЗУ и подкачка получают компактные карточки по две в ряду.
Имя GPU вынесено на собственную строку; длинное название не вытесняет процент.
Дискам отведена отдельная группа с полной точкой монтирования, свободным местом,
температурой, полосой и занятым/полным объёмом.

Заголовки групп приглушены, основные значения выделены размером 24 px.
Свободное место диска имеет размер 18 px и прежний пороговый цвет.
Тонкая полоса использует тот же показатель, что числовая подпись.
Описание подкачки и примечание об общей памяти топбара сохраняют смысл.
Неизвестный GPU и неподготовленные показания имеют прочерк, нулевой размер полосы
и не подменяются нулевой нагрузкой.

Список устройств прокручивается под закреплённой шапкой диалога.
При stale сообщение со временем снимка находится над группами и имеет role=status.
Пороговые значения и источники не менялись; они описаны в computer-resources.md.
