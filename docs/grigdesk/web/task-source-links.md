# Ссылки на задачи с источником

Значение `openTask` — числовой номер либо `<driverId>@<accountScope>:<id>`.
Parser и formatter находятся в `shared/tasks/taskReference.ts`. UI хранит id, source и
признак недоступной исторической ссылки отдельно; кеш и watcher учитывают полную цель.

Обычный номер любой допустимой длины сразу читается через внешний трекер. Полный внешний
source подтверждается адресным контекстом; отказ не переводит запрос в default.
Неизвестный префикс запрещён. Старый `grigdesk:<12-значный id>` разбирается как
`unavailable: 'legacy-own'`, без активного source. Карточка показывает «Задача не найдена»
до чтения деталей, оценки и личных меток. Закрытие и новый выбор очищают признак.

Surface target допускает только kind/id, внешний source либо исторический marker.
Старый URL `source=grigdesk` переводится в этот marker. Formatter URL и ключ native окна
сохраняют отличие legacy от default и других внешних источников с тем же номером.
Capability `taskSources` разрешает адресное окно; старая оболочка главного окна использует
inline-карточку с полной целью. Доставка task-dialog также сохраняет marker.

Старые own-команды relay игнорируются до выбора внешнего default. Один поток SSE на
вкладку остаётся общим; события `grigdesk-tasks-changed` больше нет.
