# Ссылки на задачи с источником

Значение openTask может быть прежним числовым номером либо `<source>:<id>`, например
`grigdesk:100000000000`. Значение кодируется URLSearchParams или encodeURIComponent.
Чистый parser/formatter находится в `shared/tasks/taskReference.ts`; ui.taskId остаётся
числовой строкой, ui.taskSource хранится отдельно. Кеш и watcher учитывают полную цель.

Голая ссылка сохраняет прежнее диапазонное чтение. Явный grigdesk читает только собственную
запись, без fallback. Явный внешний source требует подтверждённого совпадения текущей доски;
другой портал не подключается автоматически. Неизвестный префикс не отбрасывается.

Surface target, URL и task-dialog передают optional source. Ключ native окна включает его.
Capability оболочки taskSources разрешает такие окна; старая оболочка получает inline диалог
с полной целью. Прежние targets из двух полей допустимы. Сервер создаёт новые sourceUrl
только при POST /api/grigdesk-tasks?sources=1; старому клиенту возвращается bare-ссылка.
