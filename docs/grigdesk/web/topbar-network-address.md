# Адрес сети во всплывающей панели

В `AppShell.vue` сетевой индикатор топбара при любой ширине окна показывает только
флаг страны. Публичный IP и название страны отображаются в содержимом `UiTopbarPanel`
«Сеть», без повторения адреса на её триггере.

Триггер использует прежний `UiPressable` с доступным именем «Сведения о сети».
Открытие панели мышью и с клавиатуры сохраняется. Данные берутся из `sys.net`;
при отсутствии сетевого снимка индикатор не отображается.
