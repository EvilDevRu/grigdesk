# Выбор исполнителя в настройках

Страница `agents.providers` показывает компактный список по типам и подробности одного
выбранного исполнителя. Выбор и вкладка принадлежат сессии настроек; смена объекта не
применяет и не стирает его черновик. API-адаптер не получает действия установки CLI.

Вкладки подробностей: «Обзор», «Доступ», «Параметры», «Модели», «MCP». Они показывают
capability из DTO: ключи и режим доступа, объявленные настройки, нативный каталог,
ресурсы, установку/вход/обновление и MCP. На узком экране список и форма используют
доступную ширину; параметры не превращаются в старый набор раскрытых карточек.

Нативный каталог читается при раскрытии. MCP читается при посещении его вкладки для
выбранного установленного исполнителя. Ответ не создаёт новый опрос. Общая сессия
сохраняет изменения после размонтирования формы; поздние ответы защищены номером открытия.

Контракт и проверки: [параметры исполнителей](settings-providers.md).
