# Баннер подключения внешнего трекера

`BoardView.vue` показывает плашку в общей панели доски только при
`ownTasks.trackerConfigured === false`. Текст объясняет отсутствие задач внешнего
трекера, а акцентная кнопка «Настроить трекер» открывает существующий
`TrackerSettingsDialog` через `trackerSettingsOpen`.

Шестерёнка в общей шапке доступна при любом состоянии подключения.
При `true` и `null` (чтение ещё не завершено) плашки нет. Ошибка
подключённого трекера показывается только в его панели с повтором и подробностями.
Внутренние задачи находятся внизу общей доски, а их создание — в общей шапке.

Текст и действие используют `core.trackerSetupBanner` и `core.trackerSetupAction`
из общих каталогов ru/en. Контейнер переносит содержимое на узкой доске и использует
её переменные поверхности, границы и скругления; оформление кнопки принадлежит `UiButton`.

Состояния подключения, загрузка и открытие диалога проверяются в
`tests/web/grigdesk-tasks-board.component.test.js`; незавершённое чтение удерживается
фикстурой, а диалог заменяется точечным стабом.
