# Баннер подключения внешнего трекера

`BoardView.vue` показывает плашку после успешного чтения каталога без включённых внешних
драйверов. Текст объясняет отсутствие подключения, а «Настроить трекер» открывает
существующий `TrackerSettingsDialog`. Ошибка каталога не считается пустым подключением.

Настройки в общей шапке доступны при любом состоянии. Форма создания также предлагает
подключение: действие закрывает форму и открывает тот же диалог. При подключённых
readonly/offline досках она объясняет недоступность создания и не подменяет цель.
Встроенной доски нет; задачи создаются только во внешнем трекере.

Текст и действие находятся в общих RU/EN каталогах. Контейнер переносит содержимое
на узкой доске; оформление кнопки принадлежит публичному `UiButton`.
