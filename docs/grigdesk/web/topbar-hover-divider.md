# Нижняя линия под подсветкой ресурсов

Нижнюю линию топбара рисует внутренняя тень оболочки. Непрозрачный фон дочерней кнопки
CPU/RAM на всю высоту перекрывал эту линию при наведении даже без раскрытой панели.

Skin `topbar-metrics` рисует подсветку фоновым изображением высотой `calc(100% - 1px)`
от верхнего края кнопки. Последний пиксель остаётся прозрачным для линии оболочки.
Размер площадки нажатия и вертикальный центр содержимого при этом сохраняются.
Правило применяется также при клавиатурном фокусе и открытом диалоге ресурсов.
