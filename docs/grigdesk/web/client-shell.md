# Клиент оболочки

Встроенный интерфейс обнаруживает оболочку по `GET /__shell/state`: нужен статус 200,
JSON с числовой ревизией и общей формой снимка: статус, профиль, списки машин и
возможностей, признак местной машины. Подтверждение действия `ok` снимком не считается.
HTML Vite и 404 означают отсутствие оболочки и не запускают цикл.
Контракт `shared/client/clientShell.ts` содержит состояния связи, профиль машины, версии
API, возможности `scan/save/unlock/windows` и русские подписи. Пустой `RELEASES_URL` скрывает ссылку.

В desktop `windows` объявляется только при подключённом native-адаптере. Закрытые POST
`/__shell/surfaces/open` принимают `{kind:'task',id}`, `/__shell/surfaces/main` —
`{destination:'pipeline'}` либо `{destination:'task-dialog',target}`. Лишние поля, URL,
опции окна и неканонический id отвергаются. Origin берётся из проверенной трубы;
сервер приложения этих действий не обслуживает. Ответ — `{opened:boolean}`;
неизвестный исход не повторяет мутацию автоматически.

Стор `shell` главного desktop-окна и обычной page держит один long-poll с `?rev=N`. После сетевой ошибки до следующего запроса
первые три раза проходит секунда, затем пауза растёт до 30 секунд. Abort останавливает запрос и
паузу. Surface запускает `start({poll:false})` и короткий refresh по сигналу main.
Контроллер находится вне состояния Pinia, ответ старой ревизии не откатывает новое
состояние. `everOnline` хранит факт связи до конца документа. Отказ уже обнаруженной оболочки
сохраняет её снимок и продолжает опрос; подробности — [восстановление связи](connection-recovery.md).

`web/src/shared/shellClient.ts` обращается к своему origin с cookie. Действия используют
`POST /__shell/profiles`, `PATCH/DELETE /__shell/profiles/:id`, `POST /__shell/select`,
`connect`, `disconnect`, `unlock`, `scan`. Мутации не повторяются автоматически.
Строки привязки не проходят через журнал прикладного API.
После разблокировки применяется полный снимок; прежний Android-ответ `ok` требует
отдельного GET состояния. Подробности — [контракт Android](../mobile/unlock-shell-snapshot.md).

Проверка: `tests/web/shell-store.test.js` — обнаружение, ревизии, пауза с подменёнными
часами и точные методы/пути действий.
