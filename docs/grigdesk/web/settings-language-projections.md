# Язык служебных метаданных настроек

Причины запрета обновления получают текущую локаль при показе в
`SystemPage.vue`. Чистый `blockReasonLabel` при вызове без локали сохраняет прежний
русский контракт.

Группы исполнителей переводятся в `metadataLocale.ts` по ID `universal` и `3d`.
`ProviderPage.vue` строит реактивную проекцию после группировки: порядок, состав и
доступность исполнителей сохраняются. Исходный `EXECUTOR_TYPES` остаётся общим
русским справочником для прежних потребителей. Сторож сверяет подписи и описания
типов с каталогом, в том числе у массивов с `as const`.

Имена внешних исполнителей принадлежат данным. Для неизвестного ID `ProviderIcon`
рисует первую букву имени; эта буква сохраняет алфавит исходного имени при смене
языка. Это часть представления данных, как полное имя, а не служебная надпись.
