# Стык меню инструментов с рейкой

`UiTopbarPanel` задаёт `offset=0` для обеих привязок. Меню инструментов
с `attachment="trigger"` и `placement="right-start"` начинается у правого
края кнопки, которая занимает всю ширину рейки. Зазора между рейкой и панелью нет.

Стандартный отступ `UiPopover` остаётся у обычных всплывашек. Общая панель
переопределяет его, как и при стыке с топбаром. Проверка
`ui-topbar-panel.component.test.js` сравнивает левый край панели с правым краем кнопки.
