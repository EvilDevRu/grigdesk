# Страницы доски телефона

До 600 CSS px «Мои задачи», «Контроль и поручения» и внутренние задачи занимают
отдельные горизонтальные страницы. UiTabs со счётчиками переключает те же страницы,
которые листаются пальцем через нативный CSS scroll-snap. При настроенном трекере все три
вкладки присутствуют и до ответа, и после него, включая пустой контроль. Пока внешний трекер
загружается, его страницы показывают компактный скелетон поиска и строк.
Счётчик показывает многоточие вместо ещё неизвестного числа. При ошибке первого чтения
или отсутствии настроенного трекера доступны внутренние задачи.
При единственном разделе переключатель не занимает место.

Каждая страница прокручивается вертикально внутри доступной рабочей области.
Страницы не размонтируются при перелистывании: поиск, фильтры и scrollTop сохраняются.
Неактивные страницы на телефоне получают inert, чтобы Tab и screen reader не уходили
в соседний список. Общая сводка, предупреждения, виджеты и активные таймеры находятся
над страницами в ограниченной прокручиваемой области. При первом чтении эта область
не содержит большого настольного скелетона: он не должен обрезаться над соседним списком.
Время обновления находится в постоянном подвале доски под страницами. Во время первого
чтения там показана загрузка; появление времени не сдвигает вкладки и начало списка.
Нижняя навигация приложения сохраняет своё место и не накрывает списки.

Локальный useBoardPhonePages отражает scrollLeft во вкладках, выравнивает страницу
после поворота и снимает resize listener при unmount. Обновление счётчика через SSE
сохраняет выбор; удаление текущего раздела выбирает доступный. При холодной загрузке
первый ответ показывает основной список, если человек ещё не выбирал страницу.
Выбранные во время загрузки внутренние задачи сохраняют выбор и прокрутку после ответа.
Переходы не фокусируют поиск, не открывают задачи, не записывают настройки и не вызывают API.

С 601 px переключатель отсутствует, inert снят, работают прежние настольные колонки.
Пустой контроль на desktop скрыт, время обновления остаётся над списком.
Новые stores, таймеры и EventSource не создаются.

board-phone-pages.component.test.js проверяет переключение, отражение свайпа, сохранение
DOM/поиска/scrollTop, холодный ответ, обновления каталога, поворот и настоящий CSS.
В unit-тесте задан только clientWidth для расчёта scrollLeft; computed style и media
не подменяются. Нативный жест и итоговая геометрия требуют проверки актуального APK.

Геометрия переключателя принадлежит общему patterns.css: равные сегменты, короткая
подпись «Контроль», единый счётчик во всех состояниях. Доступное имя сохраняет полную
подпись «Контроль и поручения» с числом задач. Компактная высота и область касания описаны
в [фильтрах телефона](board-phone-filters.md). На телефоне AppShell убирает внешние поля
только у маршрута доски; собственные боковые поля задаёт BoardView. Шапка прилегает
к верхней панели, её горизонтальные отрицательные margins компенсируют собственные
боковые поля доски. Отрицательного верхнего margin нет, чтобы кнопки не обрезались.
Настройки трекера находятся рядом с названием «Доска» в слоте meta, с полной площадкой
44 px. Кнопка создания расположена у правого края. DOM-порядок соответствует расположению;
на desktop настройки сохраняют прежнее место в группе действий. Общая кнопка настроек
монтируется только один раз в подходящем слоте.
У страницы списка нет отдельной растянутой рамки; разделение задаёт выбранная вкладка и строки задач.

Кнопка создания использует общую skin-роль board-new-task в actions.css: видимая высота
32 px, прозрачная псевдообласть расширяет касание до 44 px. Действие по-прежнему открывает
общий диалог, размер остальных кнопок не меняется.
