# Скругления всплывающих уведомлений

Общий стиль в `web/src/styles/components/feedback.css` использует шкалу радиусов:
карточка `.ui-toast` и строка «Ещё N» — `--radius-md` (6 px), кнопки действий
и блок подробностей — `--radius-sm` (4 px). Это действует для всех тонов уведомлений
на обычном и сенсорном экране. Значок тона не имеет отдельной круглой подложки;
цветовая метка также находится на левой кромке карточки.
