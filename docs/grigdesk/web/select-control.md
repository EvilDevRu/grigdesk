# Общий выбор UiSelect

Все одиночные выпадающие поля общего web-интерфейса используют `UiSelect` через
`web/src/ui.ts`. Внешние плагины получают тот же экспорт из `pluginRuntime/ui.ts`.
Полный Android-клиент собирает этот интерфейс; прежний клиент v1 имеет отдельный UI.

## Значения и совместимость

Источником вариантов остаётся default-slot с `option` и `optgroup`. Индекс относится
к исходной native-коллекции: фильтр не переписывает значения. Настоящий `disabled`
варианта или группы запрещает выбор; слова о недоступности в подписи группы служат
информацией. Скрытые варианты и группы исключены из видимого каталога.

`modelValue` означает контролируемый режим, включая явный `undefined` как пустоту.
Без binding используется локальное значение. Отказ асинхронного обработчика не
оставляет отвергнутую подпись на кнопке. Без `.number` выбор возвращает строку;
`.number` использует parseFloat, сохраняя пустую строку и нечисловые значения.
`.trim` убирает краевые пробелы. `null` отображается как пустое значение.

Видимое поле — кнопка. Скрытый native select с `aria-hidden` и `tabindex=-1` сохраняет
`name`, `form`, FormData, required и настоящий `change` Event с HTMLSelectElement
в target. Программный native change остаётся совместимым. Повтор того же значения
не дублирует update модели; выбор текущего варианта только закрывает список.
Reset формы восстанавливает значение модели без update/change. Правила required
остаются правилами HTML select, включая положение пустого placeholder вне optgroup.

`el` у экземпляра возвращает native select; `triggerEl` — видимую кнопку;
`focus(options)` фокусирует кнопку. Внешние id, label, hint и ошибки связаны с ней.
Native invalid предотвращает системную попытку сфокусировать скрытое поле и
переводит фокус на кнопку. Внешнее исправление значения, required или каталога
снимает прежний invalid. Внутренние поля и расширения получают нейтральный UiField
context; явный вложенный UiField может установить собственный.

## Поиск и представление

`searchable` принимает true, false или `'auto'` (по умолчанию). Auto включает поиск
при 10 нескрытых вариантах, включая disabled. Порог определяется полным каталогом,
поэтому поиск сохраняется после фильтрации. Фильтр без учёта регистра проверяет
подпись, value, описание и группу, не отправляет запросов и не меняет модель.
Описание берётся из `data-description`, затем `title`. Подписи и описания в списке
переносятся; закрытая кнопка сокращает текст по доступной ширине.

| Слот | Аргументы | Назначение |
| --- | --- | --- |
| default | — | Исходные option/optgroup |
| value | option, value | Представление выбранного значения |
| value-leading | option, value | Декоративный знак перед выбранным значением |
| group-leading | option | Декоративный знак группы; option — первый вариант группы |
| option-leading | option | Декоративный знак перед содержимым строки |
| option | option, selected | Содержимое строки без вложенных интерактивных controls |
| actions | value, disabled | Действия рядом с полем |
| header, footer | close, value | Расширения вне listbox; close не возвращает фокус |

Снимок option содержит index, value, label, groupKey, groupLabel, description, disabled.
Несколько полей с независимыми моделями и общими действиями объединяет `UiControlGroup`.
Общий компонент не добавляет предметных действий и не импортирует stores/API/router.

Опциональный `groupNavigation` добавляет кнопки групп и «Все». При наличии `group-leading`
видны только иконки, а названия сохраняются в доступных именах и подсказках; без иконок
группа показывает название и количество вариантов.
Открытие выбирает группу текущего значения, ввод ищет по всему каталогу, переход к группе
очищает запрос. Фильтры не меняют модель и исходные индексы. Этот режим использует рабочие
control-токены с высотой toolbar, предпочитает размер 360×520 px с ограничением по viewport и на touch
фокусирует список вместо поиска. Потребитель — [каталог моделей чата](../chat/model-picker.md).

## Клавиатура, слои и размеры

Enter/Space и стрелки открывают поле; DOM-фокус попадает в поиск либо короткий listbox.
Стрелки двигают активный доступный вариант, Home/End — границы короткого списка,
Enter/Space подтверждают выбор. Короткий список поддерживает буквенный набор.
В поиске Space и Home/End редактируют текст; IME Enter не подтверждает незавершённый ввод.
Активная строка задаётся через aria-activedescendant. Tab проходит расширяющие действия
и выходит из списка; Escape закрывает верхний список и возвращает фокус к кнопке.
Внешний клик сохраняет фокус на внешнем элементе.

Popup использует общий `UiPopover` с ролью dialog и отдельным listbox с группами;
поиск и дополнительные действия находятся вне listbox. Общий стек позволяет открыть
список поверх диалога и закрыть их двумя последовательными Escape.

Surface телепортируется в body. Локальные `data-ui-workspace` и `data-ui-touch`
переносятся с окружения кнопки; сенсорные строки получают минимум 44 px. Ширина
не меньше 280 px, если позволяет visualViewport; высота ограничена 360 px и доступной
стороной кнопки. Изменения размера, прокрутки и visualViewport пересчитывают метрики;
подписки существуют только при открытом списке. Unmount отменяет отложенное раскрытие,
чтобы оно не восстановило подписки после очистки. Общий skin находится в fields.css.

Галерея показывает две модели, группы, длинные названия, пояснения, соседнее и общее
действия, footer и вложенный диалог. Постоянные проверки: ui-select-options.test.js,
ui-select.component.test.js, ui-select.browser.test.js и видимый регресс настоящего
ChatSession в chat-model-availability.component.test.js. Браузерная матрица покрывает
узкие экраны, landscape, pinch и касания; системная клавиатура и сборка APK требуют
проверки установленного приложения.

Множественный выбор, серверный поиск, виртуализация, редактирование вариантов и
замена специализированных меню действий не входят в контракт этого компонента.
