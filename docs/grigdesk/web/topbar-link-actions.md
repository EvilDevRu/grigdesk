# Действия топбара без плашек

История уведомлений, настройки и подключение телефона используют общий
`variant="link"`. Фон и рамка прозрачны в покое, при наведении и открытой панели;
наведение меняет цвет, клавиатурный фокус сохраняет общее оформление UI.
Вариант объявлен в `uiActions.ts`, оформлен в `actions.css` и показан в галерее.

Подключение телефона в топбаре представлено одной иконкой экрана с беспроводной
связью. Доступное имя и строковая подсказка — переведённое «Подключить телефон».
Условия доступности и открытие общего диалога сохранены. В разделе доступа
остаётся подписанная кнопка подключения телефона.
