# Просмотр изображений и видео

Картинки и видео из чата и разбора встреч открывает `web/src/views/MediaViewer.vue` поверх
экрана, а не окно документов. Состояние общее — `stores/documentPreview.ts`: открыто ровно одно
из документа, картинки или видео; `DocumentModal.vue` показывает только документы.

Окно — `UiDialog` размера `media`: во весь экран, без поверхности и рамки, с глубоким
затемнением. Сверху имя файла и строка «ширина × высота · формат» (формат — из MIME, без него —
из расширения имени), справа «Исходный размер» (1:1), «Скачать», «Открыть отдельно» и
«Закрыть». Картинка сначала вписана в сцену целиком. На сенсорном экране два пальца
увеличивают её вокруг середины жеста, один перетаскивает увеличенную картинку до любого края.
После отпускания одного из двух пальцев перенос продолжается без скачка. Масштабируется
только картинка: шапка, стрелки и счётчик сохраняют размер и остаются доступными.

Двойное нажатие увеличивает выбранное место в 2–3 раза, повторное возвращает вписанный вид.
Кнопка «Исходный размер» включает 1:1; после любого увеличения она предлагает «Вписать в экран».
Мышью картинку можно перетаскивать и увеличивать колесом вокруг курсора. Масштаб ограничен
снизу вписанным видом, сверху — восьмикратным увеличением или 1:1, если исходник крупнее.
`touch-action: none` действует только на сцену изображения и исключает масштабирование всей
страницы средствами WebView. При изменении размера сцены смещение снова ограничивается краями.

Обычное нажатие по пустому месту во вписанном виде и Esc закрывают окно; завершение
переноса или pinch его не закрывает. Смена картинки и закрытие сбрасывают масштаб и захват
указателей. Видео стартует само и управляется своей шкалой без перехвата жестов картинки.

Чат передаёт вместе с картинкой набор картинок той же ленты в порядке показа: вложения,
картинки ответов и шагов. Тогда по краям появляются стрелки, внизу — «2 из 5», стрелки клавиатуры
листают так же. На краях шаг не перескакивает в начало. Набор принимается, только если в нём есть
открываемая картинка; видео и документ сбрасывают его. Адреса сравниваются полными: из DOM они
приходят абсолютными, из API — относительными.

На телефоне шапка уже, картинка во всю ширину, стрелки и счётчик внизу. Сцена обрезает
увеличенную картинку в своих границах, не перекрывая панели. Android получает это поведение
после пересборки APK: интерфейс встроен в приложение.

Проверки — `tests/web/document-preview-store.test.js` и
`tests/web/media-viewer.component.test.js`: pinch, продолжение одним пальцем, все края 1:1,
двойное нажатие, отмена жеста, сброс при листании и стандартный ввод видео.
