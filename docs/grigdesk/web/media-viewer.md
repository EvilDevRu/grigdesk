# Просмотр изображений и видео

Картинки и видео из чата и разбора встреч открывает `web/src/views/MediaViewer.vue` поверх
экрана, а не окно документов. Состояние общее — `stores/documentPreview.ts`: открыто ровно одно
из документа, картинки или видео; `DocumentModal.vue` показывает только документы.

Окно — `UiDialog` размера `media`: во весь экран, без поверхности и рамки, с глубоким
затемнением. Сверху имя файла и строка «ширина × высота · формат» (формат — из MIME, без него —
из расширения имени), справа «Исходный размер» (1:1), «Скачать», «Открыть отдельно» и
«Закрыть». Картинка вписана в сцену целиком; в режиме 1:1 сцена прокручивается. Клик по пустому
месту и Esc закрывают окно, видео стартует само и управляется своей шкалой.

Чат передаёт вместе с картинкой набор картинок той же ленты в порядке показа: вложения,
картинки ответов и шагов. Тогда по краям появляются стрелки, внизу — «2 из 5», стрелки клавиатуры
листают так же. На краях шаг не перескакивает в начало. Набор принимается, только если в нём есть
открываемая картинка; видео и документ сбрасывают его. Адреса сравниваются полными: из DOM они
приходят абсолютными, из API — относительными.

На телефоне шапка уже, картинка во всю ширину, стрелки и счётчик внизу. Проверки —
`tests/web/document-preview-store.test.js`; внешний вид сверяется замером в Chromium-стенде.
