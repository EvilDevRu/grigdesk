# Компоновка выбора рабочей папки

Окно начинает выбор с поиска и кнопки «По пути» в одной строке. Каталог занимает основную
часть тела: максимальная высота прокрутки — 340 px, вместо отдельного счётчика используется
только заголовок «Проекты и папки». Короткая подпись поиска «Поиск» помещается рядом с
действием на телефоне, доступное имя поля остаётся «Найти проект или папку».

Проект с основным репозиторием занимает одну строку. Дополнительное имя репозитория,
полный путь недавнего каталога и пояснение папки приложения остаются второй строкой.
Поиск продолжает учитывать полное пояснение каждого варианта. Текущая папка показана
под каталогом: значок, источник и полный путь, без отдельной карточки с заливкой.

Явное нажатие «По пути» фокусирует поле ручного ввода. Возврат «К проектам и папкам»
фокусирует кнопку «По пути», сохраняя фильтр и черновик. Открытие самого диалога
по-прежнему фокусирует закрытие и не вызывает клавиатуру. Закрытие и новый вход очищают
поиск и черновик. Эти переходы проверяет `tests/web/chat-workdir.component.test.js`.

Общие `UiSearchInput`, `UiButton` и `UiSelectableRow` отвечают за controls; компонент
задаёт раскладку и текстовые уровни. Общий компактный размер `UiSegmentedControl`
сохранён; неиспользуемый контекст `workdir-mode` удалён из общего CSS.
