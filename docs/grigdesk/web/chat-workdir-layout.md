# Компоновка выбора рабочей папки

Окно начинает выбор с поиска. В чате без проекта рядом доступна кнопка «По пути».
Каталог занимает основную часть тела с максимальной высотой прокрутки 340 px.
Заголовок показывает «Репозитории проекта» или «Доступные папки».
Подпись «Поиск» помещается рядом с действием на телефоне, доступное имя поля — «Найти папку».

Путь репозитория, полный путь недавнего каталога и пояснение папки приложения показаны
второй строкой. Поиск учитывает название и пояснение. В каталоге проекта совпадающий
с предпросмотром дополнительный путь получает подпись «Дополнительный репозиторий».
Под каталогом показаны подтверждённая текущая папка с источником и дополнительные пути,
которых нет в каталоге. Дополнительные пути оформлены строками со значком, меткой и путём.

Явное нажатие «По пути» фокусирует поле ручного ввода. Возврат «К списку папок»
фокусирует кнопку «По пути», сохраняя фильтр и черновик. Открытие самого диалога
по-прежнему фокусирует закрытие и не вызывает клавиатуру. Закрытие и новый вход очищают
поиск и черновик. Эти переходы проверяет `tests/web/chat-workdir.component.test.js`.

Общие `UiSearchInput`, `UiButton` и `UiSelectableRow` отвечают за controls; компонент
задаёт раскладку и текстовые уровни. Общий компактный размер `UiSegmentedControl`
сохранён; неиспользуемый контекст `workdir-mode` удалён из общего CSS.
