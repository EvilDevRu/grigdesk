# Дополнительные настройки: доступные действия

Полный нативный каталог может содержать значительно больше недоступных веток,
чем редактируемых полей. Их последовательный вывод превращал карточку исполнителя
в длинный справочник: рабочие controls оказывались ниже неизвестных типов,
параметров авторизации и веток из другой версии схемы. Маленький synthetic-каталог
не показывал эту проблему.

`pages/SettingsNativeEditor.vue` теперь сначала показывает поля с доступными действиями.
Поиск работает по подписи, пути и описанию; совпавшие группы раскрываются.
У групп указано количество конкретных полей; небольшие группы открыты сразу.
Недоступные параметры пока полностью скрыты в интерфейсе, включая поиск:
справочник с кнопкой раскрытия не выводится. Каталог и его read-only проекция
сохранены без удаления полей и без изменения прав сервера.

Проекция в `nativeSettingsFields.ts` сохраняет исходные field id и вложенность,
не меняет каталог стора и не выдаёт прав записи. Сохранённый выбор, черновик и
ошибка остаются в рабочей части при недоступном источнике. Неактивные overrides
по-прежнему имеют отдельное действие удаления. Поиск и раскрытие не вызывают
дополнительного discovery и не меняют черновики.

Параметры отделены строками с подписью, коротким пояснением и редактором.
Состояния выбора и действия описаны в [контракте состояний формы](native-settings-states.md).
Длинное описание, путь и значение по схеме открываются по кнопке «Подробнее».

Изменение значения правит общую сессию; «Применить» сохраняет выбор для следующего запуска. «Сбросить»
удаляет переопределение; исходное значение остаётся под управлением исполнителя.
Массив редактируется в том же черновике и сохраняется общим «Применить». Подтверждение сохранения
не означает подтверждённого применения в уже работающей сессии.

Регрессии: `provider-native-settings.component.test.js`,
`settings-native-settings.component.test.js`, `provider-settings-store.test.js`,
`settings-provider-settings.component.test.js`. Браузерная проверка использует
большой каталог с 80 дополнительными недоступными ветками: скрытие без удаления,
поиск, labels, клавиатура, set/reset и отсутствие overflow на 340/360/760/1200 px.
