# Выход из настольного приложения

Предупреждение и предварительная остановка относятся только к
показанному главному окну, выбранному местному профилю и серверу, которым действительно
владеет supervisor приложения. Местная служба, отдельно запущенный сервер и удалённая
машина сохраняют прежний выход. Повторное закрытие ждёт уже начатую операцию, не означает
согласия и не продлевает срок.

## Вопрос и остановка

Перед закрытием main запрашивает свежие `/api/chat/active` и `/api/tasks`. Идущие и фоновые
ходы объединяются с очередью по `chatKey`; неактивные сессии в список не входят. Конвейер
считается работающим при `daemonAlive === true && !readOnly`, как у существующей кнопки
«Стоп». Неподвижные ворота человека без процесса не останавливаются.

Если работы нет, окно закрывается прежним путём. При активности вопрос показывает названия
чатов, номера и названия задач. Отмена, Escape и закрытие вопроса оставляют работу идти.
«Больше не спрашивать» сохраняет только подтверждённое согласие. Следующий выход пропускает вопрос,
но заново проверяет активность и показывает остановку.

После согласия корневой `DesktopExitHost` показывает постоянный модал со спиннером. Он
расположен вне условий входа, связи и выбора машины: offline и 401 при сливе его не снимают.
Перед эффектами main ждёт ACK кадра, обновляет список активности и отправляет по одному
параллельному POST `/api/tasks/{id}/stop`. `stop_sent` проверяется по `daemonAlive` каждые
500 мс; неподтверждённый результат отображается явно. Это обычный Stop, сохраняющий открытую
попытку для «Продолжить», без abandon, close, down или автоматического Resume.

Затем захваченный supervisor выполняет штатный слив собственного сервера при ещё живых
трубе и окне. Сохранение ленты, sessionId и pending остаётся обязанностью существующего
server shutdown. После слива разрешается native close и прежняя уборка quitController.
Только в этой завершающей фазе `will-prevent-unload` снимает запрет страницы с несохранёнными
правками. При отмене, пустой активности и внешнем сервере прежняя защита правок сохраняется.

## Настройка устройства

`skipExitConfirmation?: boolean` хранится в settings v2 через прежний атомарный writer.
Отсутствие, false и мусор означают включённый вопрос. Общий preference-порт обслуживает
Remember и переключатель «Спрашивать перед выходом при активной работе» в
«Интерфейс → Поведение». Сохранение немедленное, вне серверного Apply и localStorage.
Ошибка записи возвращает прежний принятый выбор; ошибка Remember записывается в журнал,
а уже подтверждённый выход продолжается.

Shell snapshot объявляет optional `desktopExit: {skipConfirmation}` только с desktop-портом.
POST `/__shell/exit-preference` принимает ровно один boolean; без порта отвечает 404.
Изменение будит существующий long-poll, дополнительных SSE или опросов настройки нет.
Переключатель виден только в главном desktop-документе с этой capability, не в браузере,
телефоне или дополнительных окнах.

## Сроки и границы

- Inspect ограничен пятью секундами; быстрый ACK или decision — двумя.
- Живой pending не ограничивает время человека. Один промах decision сохраняет вопрос;
  потеря документа либо три последовательных промаха возвращают прежний выход.
- Остановка всех конвейеров имеет один общий бюджет 20 секунд, включая POST и polling.
- С момента согласия общий срок main составляет 90 секунд. Он включает запись Remember,
  слив сервера, сохранение геометрии и cookies, сохраняется в finishing до app.exit.
  По сроку окно выходит с записью в журнал, не объявляя неизвестную остановку успешной.

При частичном отказе основных списков inspect возвращает unavailable и используется
прежний выход без нового вопроса. Это ограничение выбранного варианта: известная часть
активности отдельно не показывается. Отказ только названия чата сохраняет его в списке с
переводимым запасным именем.

Общий срок фиксирован и не увеличивается вслед за `GRIGDESK_SHUTDOWN_TIMEOUT_MS`.
При большом настроенном grace приложение может выйти раньше завершения собственного
server drain; 90 секунд не являются подтверждением остановки сервера.

Bridge закреплён за главным frame, origin трубы, корневым документом, выбранным профилем,
supervisor и его поколением. Команды имеют requestId и expiresAt; просроченные и чужие
команды не запускают Stop. В main переходят только публичные идентификаторы и заголовки.

Before-quit, SIGTERM и SIGINT обходят вопрос и отменяют предварительную фазу. Общий restart,
ctl, systemd, дополнительные окна, браузер и телефон не начинают остановку конвейеров.
Подробности прежней уборки — [старт окна](desktop-startup.md).
