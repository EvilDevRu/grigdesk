# Навигация мастера настройки

В постоянном подвале «Назад» появляется на шагах проекта, места работы задач и итога.
Возврат ждёт очереди сохранения, затем отправляет `POST /api/onboarding/back` с последней
подтверждённой ревизией и идентификатором прохода. Ошибка оставляет текущий экран и ввод;
во время перехода действия заблокированы. Новый шаг сохраняется на сервере и продолжается
после повторного открытия. Фокус и прокрутка переходят к заголовку шага.

Возврат не удаляет созданный паспорт. При повторном просмотре его название, папки и ветки
сохраняются и доступны для чтения; подсказка направляет изменять паспорт в «Проекты».
Повторное «Далее» не создаёт копию и не перезаписывает правки обычной формы.
С итога можно вернуться к выбору режима задач и завершить тот же проход ещё раз.

«Пропустить настройку» на всех экранах и «Пропустить шаг» на шаге ИИ используют
одинаковые общие кнопки `outline`. Первое действие завершает настройку, второе переводит
к проекту. Пустой проект пропуском отдельного шага не создаётся.

Карточка готового к чату исполнителя окрашивает `ProviderIcon` фирменным `provider.color`.
Допуск один для цвета, статуса и продолжения: `available && chatEnabled !== false`.
Остальные иконки приглушены целиком, включая двухцветный Tripo без поддержки чата.
