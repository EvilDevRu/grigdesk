# Строки поведения и пояснения сочетаний клавиш

Общий `[data-ui-settings-field]` задаёт контейнер формы, ширину, разделитель и
вертикальные отступы 10 px. Выбор языка, немедленная настройка выхода и поля общей
сессии используют эту геометрию. У переключателя без собственной подписи нет
горизонтального padding: видимый правый край дорожки совпадает с краем соседнего селекта.

«Не гасить экран» доступно по наличию `navigator.wakeLock.request`, независимо от ОС.
Если API отсутствует и настройка выключена, строка скрыта. Ранее включённый параметр
остаётся виден, чтобы его можно было выключить. Отказ захвата экрана не отменяет
сохранённое предпочтение; пояснение отказа остаётся под строкой. Реализация —
`stores/device.ts` и `views/settings/pages/InterfacePage.vue`.

В строке сочетания клавиш название инструмента и пояснение выключенного плагина
составляют один блок с зазором 2 px. Пояснение находится сразу под названием;
кнопки справа центрируются относительно всего текстового блока. При достаточной
ширине пояснение занимает одну строку, в узкой форме допускает перенос текста.

Проверки: `settings-preferences.component.test.js` проверяет доступность Wake Lock и
сохранение через Apply; замер сочетаний в `settings-modal.e2e.mjs` учитывает общий
центр названия с пояснением и расстояние между ними.
