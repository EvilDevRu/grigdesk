# Повторное закрытие главного окна

Правило задачи №93029 дополняет [контракт выхода](desktop-exit.md): перед обычным native close
главный процесс отправляет `cancel` текущего запроса renderer и ждёт ответ не дольше двух секунд.
После этого освобождает свою операцию. Запрос страницы снимается до закрытия, потому что
`beforeunload` редактора с несохранёнными правками может оставить окно и документ открытыми.

Следующее закрытие в том же документе получает новый `requestId`, заново читает активность
и показывает вопрос, если появились ходы или конвейеры. Поздние команды отменённого запроса
отвергаются существующим списком завершённых идентификаторов renderer.

Повторный close во время ожидания отмены удерживается прежней операцией. Системный выход
снимает её; поздний ответ `cancel` не инициирует дополнительное закрытие. При подтверждённой
остановке завершающая фаза сохраняет модал и прежний общий срок до фактического выхода.
