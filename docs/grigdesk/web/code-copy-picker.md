# Компактный выбор рабочей копии

`CodePanel.vue` показывает рабочие копии через общий `UiSelect` с
`option-layout="inline"`. Репозиторий назван один раз над группой, в том числе
когда группа единственная. Основное дерево остаётся первым в порядке сервера.

Название копии и отличающаяся ветка занимают одну строку. Основная копия называется
«Основная», копия задачи — «Задача …», остальные используют имя worktree без
служебного префикса `Worktree`. Ветка, совпадающая с именем, не повторяется.
При совпадении имён внутри одного репозитория добавляется минимальный уникальный
хвост пути. Сопоставление выполняется до фильтрации, поэтому подписи стабильны
при поиске. Полные подписи модели `CodeContext` остаются доступны другим потребителям.

Шапка использует ту же короткую подпись и добавляет репозиторий, только когда его
не назвал соседний выбор проекта. Значение варианта по-прежнему содержит точную
пару репозитория и пути; сохранение контекста и Git-действия не зависят от подписей.

## Однострочное представление общего селекта

Опциональный `optionLayout="inline"` располагает описание справа от названия.
Обе части сокращаются многоточием; полные название, описание и `title` доступны
через общий tooltip и доступное описание варианта. `data-description` отделяет
ветку от пути в `title`, включая явное пустое описание. Поиск проверяет оба поля;
порог появления поиска остаётся общим — десять вариантов.

Шрифт, размеры строк, ширина меню и поиск используют
[единый стиль всех селектов](select-menu-style.md). Однострочная компоновка
не создаёт своего оформления поиска или отдельной шкалы размеров.

Skin принадлежит `styles/components/fields.css`, содержимое вариантов готовит
`buildCodeContextChoices` в `shared/codeTree.ts`. Проверки: `code-tree.test.js`,
`code-view.component.test.js`, `ui-select-options.test.js`, `ui-select.component.test.js`.
