# Внутренние задачи и доска трекера

`BoardView.vue` показывает задачи обоих источников в одном списке «Мои задачи».
Собственные строки всегда отмечены чипом GrigDesk, включая работу без трекера.
Сначала идут задачи с известной датой создания, от новых к старым; при равенстве даты
сохраняется исходный порядок. Строки без даты остаются в прежнем относительном порядке
после датированных. [Общий контракт](../b24/unified-board.md) описывает фильтры и метки.

Баннер подключения и общий список собственных задач видны одновременно.

«Новая задача» и шестерёнка находятся в общей шапке. Шестерёнка открывает
`TrackerSettingsDialog`, в том числе при загрузке и отсутствии внешнего трекера.
Доступная подпись и подсказка называют настройки трекеров.

Форма «Новая задача» содержит выбор GrigDesk или включённой внешней доски, поддерживающей
создание. Начальный выбор следует доступному дефолту. Справочник проектов и POST относятся
к выбранной доске; смена выбора отменяет прежнее чтение и сбрасывает проект.
После сохранения общий `ui.openTask` получает номер вместе с подтверждённым источником.
Собственные задачи обновляют свой store, внешние — общий снимок доски.

Отказ чтения внешней доски показывает краткое сообщение только в её панели.
«Повторить» вызывает `board.load(true)`, «Подробнее» раскрывает исходный текст ошибки.
Повтор блокируется на время загрузки. Изменение ошибки закрывает подробности.
Предупреждение и время прежнего снимка остаются видимыми при ошибке обновления;
без снимка время не показывается. Внутренние задачи и их создание остаются доступны
при отказе трекера. Ошибки собственных задач показаны в общем списке с отдельными повторами личных меток.

Кнопки, шапка, предупреждение и раскрытие подробностей принадлежат общему UI-каталогу.
Собственные надписи находятся в каталогах ru/en. Поведение покрывают
`grigdesk-tasks-board.component.test.js` и `board-stale-snapshot.component.test.js`.
