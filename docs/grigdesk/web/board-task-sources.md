# Внутренние задачи и доска трекера

`BoardView.vue` показывает задачи обоих источников на общей доске без вкладок.
Секция «Внутренние» завершает доску внешнего трекера; каждая её строка отмечена
флагом «Внутренняя». Внутренние задачи, оценки и статусы конвейера читаются
независимо от внешнего трекера. Новые задачи идут первыми, при равном времени —
по убыванию идентификатора. Пустая секция предлагает создать первую задачу.

Без подключённого трекера секция называется «Задачи GrigDesk», флаги скрыты.
Баннер подключения и внутренние задачи видны одновременно.

«Новая задача» и шестерёнка находятся в общей шапке. Шестерёнка открывает
`TrackerSettingsDialog`, в том числе при загрузке и отсутствии внешнего трекера.
Доступная подпись и подсказка называют настройки трекеров.

Отказ чтения внешней доски показывает краткое сообщение только в её панели.
«Повторить» вызывает `board.load(true)`, «Подробнее» раскрывает исходный текст ошибки.
Повтор блокируется на время загрузки. Изменение ошибки закрывает подробности.
Предупреждение и время прежнего снимка остаются видимыми при ошибке обновления;
без снимка время не показывается. Внутренние задачи и их создание остаются доступны
при отказе трекера. Ошибки внутренних задач остаются в своей секции.

Кнопки, шапка, предупреждение и раскрытие подробностей принадлежат общему UI-каталогу.
Собственные надписи находятся в каталогах ru/en. Поведение покрывают
`grigdesk-tasks-board.component.test.js` и `board-stale-snapshot.component.test.js`.
