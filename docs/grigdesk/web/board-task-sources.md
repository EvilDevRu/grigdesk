# Внешние источники доски

`BoardView.vue` объединяет включённые внешние доски в «Мои задачи». Встроенных строк,
счётчиков и переключателя GrigDesk нет. Без подключений виден баннер настройки;
ошибка чтения каталога показывается отдельно от пустого списка.

«Новая задача» и настройки находятся в общей шапке. Форма предлагает доступные внешние
доски с `create`; выбран доступный default, иначе выбор пуст. Подключение доступно из
баннера. Смена цели отменяет прежние context/groups, сбрасывает проект и сохраняет текст.
POST использует захваченное поколение и источник; после успеха общий `ui.openTask`
получает подтверждённую пару. Default при создании не меняется.

Отказ внешней доски сохраняет её последний успешный снимок. «Повторить» обновляет доску,
«Подробнее» раскрывает исходный текст. Остальные внешние источники продолжают работать.
Controls принадлежат публичному UI-каталогу, собственные надписи обновляются в RU/EN.

Подробности: [общий контракт](../b24/unified-board.md).
