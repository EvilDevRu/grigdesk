# Геометрия desktop-интерфейса

Desktop использует один вид без настройки плотности. Верхняя панель занимает всю ширину:
слева маленький знак GrigDesk, справа статусы, уведомления и настройки.
Левая навигация всегда состоит из иконок; широкого меню, переключателя раскрытия и нижней
плитки версии нет. Обновления доступны в настройках. Семейства шрифтов, палитра и размеры
текста переписки, кода и документов сохранены.

Служебный текст топбара — 12 px. Знаки навигации,
настроек и уведомлений — 16 px. Кадр логотипов исполнителей — 13 px по высоте,
видимый рисунок — около 12 px с сохранением пропорций, площадка кнопок — 28 px.
Настройки выровнены с правой
рейкой; связанные действия собраны в группы. Имя ПК и отдельная точка связи
не показываются. Фон топбара — плавный переход существующих цветов темы,
а счётчики навигации занимают отдельную строку под иконкой внутри кнопки высотой 30 px.
[Плоская подложка кнопки](sidebar-icon-surfaces.md) заполняет доступную ширину рейки
и имеет прямые углы.

## Размеры

Все размеры ниже — CSS px, источник `styles/tokens.css`.

| Роль / token | Размер |
| --- | ---: |
| Верхняя панель `--app-topbar-h` | 36 |
| Левая и правая рейки `--app-rail-w` | 36 |
| Высота кнопки навигации `--app-nav-row-h` | 30 |
| Обычный control `--control-height` | 36 |
| Control рабочей формы с `data-ui-workspace` | 32 |
| Плоский toolbar `--toolbar-control-h` | 28 |
| Действия дока `--tool-dock-action-size` | 30 |
| Минимум шапки чатов `--chat-head-h` | 80 |
| Минимум строки чата `--chat-list-row-h` | 56 |
| Аватар чата `--chat-avatar-size` | 32 |
| Поля страницы `--page-gutter` | 16 |
| Поля переписки `--chat-gutter` | 18 |
| Вертикальный margin ленты `--chat-flow-inset` | 12 |
| Интервал блоков `--chat-flow-gap` | 14 |

Правое поле ленты равно `max(0px, chat-gutter − 11px)` с прежней компенсацией scrollbar;
верхнее и нижнее поля остаются margin. Шапка может вырасти для переноса предупреждения.
У длинных названий остаются доступные имена и подсказки, сообщения об ошибке не обрезаются.

## Окна, размеры и инструменты

Общий модал настроек и Teleport в body получают те же CSS-токены. Для геометрии
нет собственного store, storage-listener, API или перезагрузки. Старые значения
`grigdesk-ui-density` и `grigdesk-sidebar` не читаются и не меняют раскладку; удалять
другие пользовательские настройки при старте не требуется.

Ключи ширины списка/дерева/дока и высоты composer сохраняются. ToolDock измеряет ресайз
от фактического правого края; ToolHost берёт ширину content из DOM. Store хранит желаемую
ширину отдельно от временного ограничения viewport: после расширения она восстанавливается.
Expanded, Escape, inert и единый render-site сохранены. Локальный `.compact` инструмента
или графа обозначает его presentation и не является режимом всего интерфейса.

Route metadata `layout: workspace` снимает внешний gutter у `/chats`, `/code`,
`/terminal`, `/ssh`, `/projects`, `/routes` и `/sandboxes`. Обычные формы и карточки
сохраняют `--page-gutter`. Ниже 900 px инструменты
открываются полноразмерными маршрутами, список чатов и разговор делят одну колонку.
Боковая навигация сохраняется на всех ширинах, нижнего меню нет.

При 600 px общие кнопки остаются 36 px. Рабочие формы с `data-ui-workspace`
используют отдельную роль `--workspace-control-h`: 32 px в
[«Проектах»](projects-design.md), [«Маршрутах»](routes-design.md) и
[«Песочницах»](sandboxes-design.md).
Fullscreen-диалоги, safe areas, переносы форм и многострочные карточки сохраняют свою роль.
Явный `data-ui-touch` включает 44 px,
в том числе на surface Teleport. Деревья, toolbar и смысловые карточки имеют свои роли.

## Проверки

`desktop-density-layout.component.test.js` и contracts чатов, настроек и ToolHost
проверяют границы поведения. `check-ui-geometry.mjs` измеряет девять ширин и touch600.
Синтетическая сцена настоящих компонентов лежит в `tests/web/fixtures/desktop-density`;
renderer требует отдельный абсолютный `DENSITY_RUN_DIR` и не проксирует рабочий API.

Сценарии DU-E01–07 в [Electron E2E](../testing/desktop-window-e2e.md) проверяют первый кадр,
общий модал настроек, повторный запуск, overlays/Escape, сохранение terminal/PTY,
узкую рейку, zoom125% и key-only recovery. Для приёмки нужен свежий отдельный web-dist.
Подготовка сборки не публикует интерфейс на рабочей установке.
