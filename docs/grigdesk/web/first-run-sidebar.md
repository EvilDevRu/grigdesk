# Боковая шкала мастера

В модальном мастере боковая шкала занимает 224 px. Основные три шага имеют одинаковую
высоту строки не меньше 52 px, отдельную колонку номера 20 px и короткое пояснение.
Названия используют общий `--workspace-text-size` (13 px), пояснения — 12 px.

Текущий шаг выделяется спокойной акцентной подложкой, полосой 2 px и заполненным номером.
Завершённый получает зелёную галочку; пропущенный ИИ — нейтральный минус и явную подпись.
Первые три пункта — кнопки перехода между доступными шагами. Возврат сохраняет ответы,
а переход вперёд использует проверки мастера без повторного создания проекта.
Ограничения и сохранение описаны в [контракте переходов по шкале](first-run-step-navigation.md).

Будущие шаги отделены линией и визуальным заголовком «Далее — вручную» со значком замка.
Они сохраняют `aria-disabled="true"` и цвет `--ink-low`. Пояснение про инструкцию находится
внизу боковой области и не растягивает строки шагов. Названия и номера сохраняют единые оси.

В узком окне компактная шкала остаётся над формой: три колонки, до 400 px — две.
Дополнительные заголовки, пояснения и акцентная полоса скрываются, названия всех шести
шагов остаются видимыми. Размер полей и действий мастера не меняется.
