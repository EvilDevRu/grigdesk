# Предупреждение об удалении проекта в маршрутах

Открытый редактор маршрутов сообщает об удалении регистрации через `UiInlineMessage`,
импортированный из публичной границы `web/src/ui.ts`. Тон `warning` даёт общий класс
оформления и `role="status"`; локальный тег или собственный стиль для этого не нужны.
Несохранённый документ остаётся для чтения с пояснением о невозможности сохранить его.

Устройство редактора описано в [рабочей области маршрутов](routes-design.md).
