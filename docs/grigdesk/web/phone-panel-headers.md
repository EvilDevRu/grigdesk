# Шапки панелей и диалогов телефона

До 600 CSS px общие `UiPaneHeader` и `UiDialog` используют служебную полосу по образцу
просмотра задачи: фон `--topbar`, нижняя граница `--line`, заголовок 12 px/500 приглушённого
цвета и строка 18 px. Шкала задаётся общими `--panel-header-*` в tokens.css;
панель использует её в patterns.css, диалог — в overlays.css.

Один ряд с действиями занимает минимум 48 px, включая границу. Кнопки иконок сохраняют
площадку 44 px; длинные заголовки и действия увеличивают высоту при переносе.
У диалога остаются safe area, собственный title ID, описание и прокручиваемое тело.
Ни фокус, ни закрытие, ни закреплённый подвал от этих стилей не меняются.
Настройки трекеров получают эту шапку через обычный UiDialog, без отдельной skin-копии.

Заголовки с собственным слотом header (настройки, мастер и установка плагина) покрыты
тем же правилом. Общая типографика этих окон и формы новой задачи хранится
в overlays.css; локальный scoped CSS оставляет только структуру. Это сохраняет общий
каскад: стили SFC без слоя не должны перекрывать общую телефонную шкалу.

Крупные названия документов и заголовки групп формы сохраняют собственную иерархию.
На desktop шапки диалогов также используют полосу задачи: 13 px/600, фон `--topbar`,
линию `--line` и минимум 36 px. Отступы панели и диалога задаются одними токенами
`--panel-header-inset-top` и `--panel-header-inset-bottom`.

Доска на телефоне использует рабочий фон `--surface`, как содержимое задачи.
Шапка остаётся отдельной тёмной полосой, строки задач разделены линиями без вложенных
растянутых карточек. Поля, переключатель страниц и метаданные сохраняют общие цвета UI.

phone-readability.component.test.js проверяет настоящие компоненты, равенство цветов
и шкалы панели/диалога, перенос действий и desktop. board-phone-pages.component.test.js
проверяет фон доски и геометрию её общих controls. Итоговый вид принимается по актуальной
сборке отдельно от unit-тестов.
