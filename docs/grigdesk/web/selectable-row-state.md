# Состояние нажатия составной строки

`UiSelectableRow` разделяет выбор строки и состояние кнопки. `selected` включает общую
подсветку `is-selected`; необязательный `pressed` передаётся в `UiPressable` одноимённым
булевым prop. Примитив сам выводит `aria-pressed` в DOM. При отсутствии `pressed` этот
атрибут не добавляется.

Передача только `aria-pressed` через attrs неверна: `UiPressable` задаёт его по своему
prop и перекрывает значение из attrs. Поэтому потребитель передаёт `:pressed`, а не
дублирует доступное состояние снаружи. Выбор исполнителя окна узла проверяет этот
контракт вместе со сменой текущей строки и сохранением открытого окна.
