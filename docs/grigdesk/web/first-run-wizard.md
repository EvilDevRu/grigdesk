# Мастер первого запуска

Мастер открывается общим модальным окном поверх текущего раздела.
Последовательность: ИИ, проект, место работы задач.
Разбор проекта и стенд, маршруты и включение конвейера пока показаны будущими шагами;
итог ведёт к поставляемой инструкции образца через просмотрщик документов.

Автопереход допускается только с начального маршрута `/` после подтверждения входа и
подключения машины. Экран выбора компьютера и отдельные окна карточек не запрашивают мастер.
Первый проход продолжается после создания собственного паспорта; ручной проход открывается
кнопкой со значком мастера в общем топбаре рядом с настройками. Её имя и подсказка —
«Мастер настройки»; в шапке «Проектов» отдельной кнопки мастера нет. Перезагрузка
окна сохраняет текущий раздел; повторное открытие мастера продолжает прежний шаг.
«Настрою сам» сохраняет отказ на сервере и открывает исполнителей либо обычный паспорт.
При ручном входе поля открываются после ACK. Старый параметр `new=1` обслуживается
guard без отдельного раздела; перезагрузка рабочего раздела сама не повторяет ручной start.

Ответы сохраняются сразу очередью PATCH. «Далее», вход через терминал и отказ ждут ACK;
ошибка оставляет локальный ввод и запрещает переход. Явное перечитывание позволяет принять
состояние сервера. Смена владельца или машины очищает ответы и отсекает поздние запросы.
Мастер подписывается на единственный поток SSE вкладки.

Системный выбор одного каталога доступен только desktop с локальной выбранной машиной и
capability `selectDirectory`. Браузер, телефон, удалённая машина и старое приложение используют
абсолютный путь на сервере. Ручной ввод доступен всегда. Выбор или проверка не изменяют Git.
Detached требует выбора ветки; unborn требует первого коммита. Для каждой папки выбирается
своя локальная ветка; несовместимые с образцом имена видны, но недоступны.

Созданный проект редактируется обычной формой. Ответы о ветке и режиме остаются отдельным
снимком для будущей части и пока не запускают профиль, стенд или конвейер.
