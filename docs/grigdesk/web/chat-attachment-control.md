# Скрепка в поле ввода чата

`UiFilePicker` с ролью `chat-attachment` показывает только скрепку без видимой подписи.
Текст «Приложить файл» остаётся в подсказке и доступном имени кнопки через visually hidden
`ui-file-picker__copy`. Скрытая подпись не занимает место перед textarea.

Ширина обёртки и обе стороны кнопки берутся из `--control-height`, как у микрофона:
36 px на обычном desktop и 44 px в сенсорном режиме. Цвет в покое — `--ink-mid`,
при наведении — `--ink` с фоном `--surface-2`. Скрепка и микрофон имеют одинаковый размер SVG 18 px.
Skin задаётся в `styles/components/fields.css`; локального оформления в `ChatSession` нет.

На desktop controls и textarea сохраняют прежний общий ряд; широкая текстовая ссылка
не сдвигает начало ввода. На телефоне текст занимает верхний ряд, скрепка и остальные
действия — нижний. Системный выбор файлов, несколько вложений и состояния недоступности
не меняются.
