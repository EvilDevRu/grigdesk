# Просмотр изменений задачи

Окно дифа задачи и маршрут `/diff` используют один `DiffPanel` с общим режимом
`data-ui-workspace`. Каталог шириной 288 px показывает число файлов и суммарные
добавления и удаления. Поиск закреплён над отдельной прокруткой дерева.
Строки используют общий `code-tree-row`, шапки — `UiPaneHeader`, действия —
`workspace-toolbar`, выбор раскладки — компактный `UiSegmentedControl`.

Репозитории подписаны по их настоящему имени. Только известные пары `be` / `backend`
и `fe` / `frontend` получают подписи «Бэкенд» и «Фронтенд». Произвольный репозиторий
не превращается во «Фронт». Группа показывает ветку и число найденных файлов;
её шапка закрепляется у верхней кромки при прокрутке.

Поиск учитывает путь файла, исходное и отображаемое имя репозитория и ветку.
Подходящие папки временно раскрываются, их переключение недоступно с пояснением.
Очистка поиска восстанавливает ручное сворачивание. Поиск не меняет выбранный файл
и модели Monaco; пустая выдача предлагает сброс запроса. Ключ выбора включает
репозиторий и путь, поэтому одинаковые пути в разных рабочих копиях независимы.

Шапка редактора показывает путь, статус, добавления и удаления выбранного файла.
Ниже указаны репозиторий и ветка. У сторон сравнения есть подписи «До изменений»
и «Рабочая копия». В узком редакторе первая подпись скрывается, когда Monaco
оставляет у исходной стороны только gutter шириной 38 px. Предпочтение «Рядом» /
«В строку» хранится в прежнем `grigdesk-diff-side` и не меняется при адаптации.

Бинарный и слишком большой файл показывают объяснение отсутствия текстового
предпросмотра; переключение раскладки для них недоступно. Обновление сохраняет
выбранный файл и существующий редактор. Если ошибка сняла хост редактора с экрана,
его экземпляр и модели освобождаются; повтор создаёт редактор на новом хосте.

До ширины панели 700 px каталог и редактор показываются по очереди, каждый на
полную высоту. Выбор файла открывает диф; кнопка «Файлы» в слоте навигации возвращает
каталог, а «К дифу» возвращает редактор. Поиск, раскрытие, выбранный файл и Monaco
сохраняются. В шапке узкого редактора остаётся имя файла, полный путь доступен
в подсказке. `DiffLoading` повторяет каталог, поиск и постоянные строки редактора;
на узкой панели сначала показывает только каталог.

`tests/web/diff-panel.component.test.js` проверяет принадлежность репозитория,
поиск и сворачивание, сохранение выбора и редактора при обновлении, раскладку,
бинарный файл и освобождение моделей перед повтором после ошибки. Общая подмена
UI в `compileBoundary` экспортирует настоящий `t` вместе с лёгкими контролами.
