# Источники почти чёрного фона полей

Почти чёрное поле не доказывает наличие legacy-компонента. Общие `UiInput`,
`UiNumberInput`, `UiTextarea` и `UiSelect` получают фон в `styles/components/fields.css`
через `--control-background`. В корневых `styles/tokens.css` этот токен равен
`--ground` (`#0a0c10`).

`data-ui-workspace` меняет значение на `--surface-2`. Поэтому более светлый фон
пока зависит от контейнера. Обычные поля без этой пометки используют корневой цвет.
`UiDialog` переносит поверхность в `body` через Teleport; пометка исходного раздела
не наследуется, если не установлена на самом слое. Так одинаковый общий primitive
может выглядеть светлее в форме и почти чёрным в диалоге.

Есть и явные переопределения в `fields.css`, которые не зависят от базового цвета:

| Селектор | Источник фона | Потребитель |
| --- | --- | --- |
| `.ui-textarea[data-role='task-launch-note']` | `--ground` | Поля запуска в `TaskModal.vue` |
| `.ui-input[data-role='chat-title']` | `--ground` | Переименование в `ChatSession.vue` |
| Поля `[data-context='settings-field']` | `--ground` | Потребитель отсутствует; одноимённая обёртка настроек использует класс |

Изменение только базового цвета не перекроет эти правила. Более светлые поиск
списка чатов, поиск общего селекта и toolbar чата также имеют отдельные правила
фона, поэтому их вид сам по себе не подтверждает миграцию базового оформления.

`--control-background` используется не только полями: на него ссылаются
`styles/components/actions.css`, `styles/components/selection.css` и плашки
параметров разрешения `ChatPermission.vue`. Изменение этого токена меняет несколько
семейств элементов, а не только текстовый ввод.

Текущие размеры и окружения — в [режимах controls](control-regimes.md).
[Поле переименования](chat-title-input.md) — один из примеров общего механизма.
