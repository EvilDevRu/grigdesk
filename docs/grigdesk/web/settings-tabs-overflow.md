# Прокрутка вкладок настроек

Строка `data-ui-settings-tabs` переносит вкладки по ширине. Высота каждой вкладки
определяется содержимым с сохранением минимального размера control, чтобы подписи
помещались при переносе строк.

Отрицательный нижний margin у вкладки создавал переполнение на 1 px. Унаследованный
от общего `UiTabs` стиль `overflow-x: auto` делал вычисленный `overflow-y` равным
`auto`, поэтому браузер показывал вертикальную прокрутку внутри строки вкладок.
Вкладки настроек сохраняют нулевой margin и не выходят за нижнюю границу строки.

Браузерная проверка V15 в `tests/web/e2e/settings-visual.e2e.mjs` открывает настоящую
страницу исполнителя на изолированном стенде при ширине 1280, 768 и 390 px.
Она проверяет обе оси переполнения и размещение подписей внутри кнопок вкладок.
