# Длинные списки строк рисует окно `VirtualRows`

`web/src/shared/VirtualRows.vue` рисует из длинного списка только строки у видимой
области ближайшего прокручиваемого предка, а высоту остальных занимают две распорки.
Арифметика окна — `web/src/shared/virtualRows.ts`, без DOM и Vue.

Порог — 200 строк (`VIRTUAL_ROWS_THRESHOLD`). Список не длиннее порога рисуется целиком,
как обычный `v-for`: без распорок, замеров и слушателей. Поэтому маленькие репозитории и
компонентные тесты на коротких фикстурах ведут себя как до появления окна.

Окно держится на одном допущении: все строки списка одной высоты. Шаг строки берётся
замером — расстояние от низа верхней распорки до верха нижней, делённое на число
нарисованных строк, — поэтому в него входят margin и gap контейнера, а строка другой
высоты на сенсорном экране не ломает расчёт. До первого замера используется `rowHeight`
(по умолчанию 28 px — строка дерева «Кода»). Инвариант: распорка сверху + нарисованные
строки + распорка снизу равны высоте всего списка, и полоса прокрутки не прыгает.

Распорки — соседи строк, а не обёртка: строки остаются прямыми детьми контейнера
потребителя, и его раскладка и селекторы не меняются. У распорок `overflow-anchor: none`:
якорь прокрутки браузера на распорке переменной высоты дёргал бы список.

Окно пересчитывается на четыре повода: прокрутка предка (сразу, в обработчике),
изменение размера предка или первой видимой строки (один `ResizeObserver`), появление распорки в кадре
(`IntersectionObserver`) и собственный рендер. Третий повод ловит сдвиг списка соседями
выше — например, свернули группу изменений над ним, — когда ни прокрутки, ни смены размера
предка нет. Скрытая панель (свёрнутый док) не имеет раскладки: окно остаётся прежним, а при
показе его пересчитывает наблюдатель размера. Новое окно присваивается, только если
поменялись границы, — прокрутка внутри тех же строк не перерисовывает список.

Наблюдение строки ловит смену высоты строки через CSS даже без рендера Vue и изменения контейнера.
При смене видимого окна наблюдатель переводится на актуальную строку; нового listener
геометрии у каждого списка нет.

Ключ строки — функция `itemKey`, заведённая в script потребителя, а не стрелка в шаблоне:
новая стрелка на каждом рендере была бы новым prop и будила бы окно впустую.

Цена окна, известная заранее: строки за пределами окна не существуют в DOM. Поиск браузера
(Ctrl+F) их не находит, Tab проходит только по нарисованным, а фокус уходит вместе со
строкой, прокрученной далеко за окно. Для навигатора «Кода» это приемлемо: у него свой
поиск по дереву.

Потребители — навигатор «Кода»: дерево файлов, дерево и плоский список групп изменений.
Проверки — раздел окна в `tests/web/code-tree.test.js`.
