# Настройка оповещений полки

Переключатель «Оповещать о событиях полки» управляет оповещениями о новых событиях
задач на полке. В окне GrigDesk появляется тост; когда окно скрыто или не в фокусе,
общий центр добавляет системное уведомление по [контракту оповещений](in-app-alerts.md).
Настройка относится к обоим каналам, поэтому её подпись не привязана к браузеру.

Сохранённый ключ `browserNotifications` остаётся прежним: переименование подписи
не сбрасывает выбор человека. Метаданные в `server/src/lib/pluginsRegistry.ts`
и каталоги `settings.json` для русского и английского содержат одинаковое пояснение
о каналах оповещений.
