# Нейтральные подписи карточки задачи

`TaskModal.vue` показывает собственную задачу как «Задача GrigDesk», внешнюю — как «Задача».
Подпись не привязана к конкретному драйверу. Одна разметка используется в диалоге и отдельном окне,
в том числе при открытии родительской задачи и подзадач.

Форма внешней задачи использует нейтральную кнопку «Сохранить» и подтверждение
«Изменения сохранены.». Тексты берутся из общих русских и английских каталогов.
Источник данных, доступные действия и правила сохранения от этих подписей не зависят.
