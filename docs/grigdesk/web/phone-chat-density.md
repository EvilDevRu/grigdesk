# Плотная техническая лента чата

В сенсорной раскладке команды, размышления, сводка действий и «Показать полностью»
имеют высоту 28 px. Это отдельное исключение для технической ленты: прежний минимум
44 px у самой кнопки сохранял большие интервалы даже при нулевом CSS gap.
На телефоне промежуток между блоками одного хода уменьшен с 8 до 4 px;
между соседними шагами дополнительного зазора нет. «+N» строки состояния также
получает высоту и минимальную ширину 28 px, чтобы не увеличивать всю строку.

Размер меняется у самих кнопок, без перекрывающихся прозрачных областей касания.
Раскрытие деталей, порядок шагов, клавиатурный фокус и общая линия хода сохраняются.
Основные действия композера, поля настроек и закрытие диалогов остаются сенсорными 44 px.

Карандаш переименования в сенсорном режиме использует цвет вторичных деталей доски:
70% `--ink-low` и 30% `--surface`. Непрозрачность остаётся полной, площадка — 44 × 44 px;
при наведении и клавиатурном фокусе цвет становится `--ink-mid`.

Сценарий `chat-in-turn.component.test.js` проверяет скомпилированные стили строк,
промежуток группы и раскрытие команды после уплотнения. Это проверка CSS и действий;
визуальные интервалы на Android принимаются отдельно.
