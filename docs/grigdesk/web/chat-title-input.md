# Общие поля переименования чата

В списке слева `ChatList.vue` заменяет строку на публичный `UiInput` при нажатии
карандаша или двойном нажатии на строку. Native input принадлежит общему primitive;
локальный класс `.edit` задаёт только ширину. Этот переход выполнен в коммите
`9b5659923`: прежний native input и его локальный skin удалены.

Фон редактора берётся из общего `--field-background`, равного `--surface-2`
(`#1c222c`). Список и его родитель `ChatsView.vue` не включают `data-ui-workspace`,
но цвет поля от этой пометки не зависит. Поиск сверху наследует тот же фон;
контекст `chat-list-search` задаёт только его геометрию и шрифт.

Переименование в шапке открытого разговора — другой экземпляр `UiInput` в
`ChatSession.vue`. Его `data-role="chat-title"` задаёт размеры и шрифт в `fields.css`,
но также наследует общий фон. Добавлять эту роль редактору списка ради цвета не нужно.

Прежний почти чёрный вид был следствием базового `--control-background: var(--ground)`
в списке и явного `background: var(--ground)` у роли шапки. Унификация выполнена
для всех полей UI-kit: [общий фон](field-background-sources.md).
