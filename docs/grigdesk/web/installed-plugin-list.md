# Компактный список установленных плагинов

Вкладка «Установленные» использует две колонки по образцу менеджера плагинов IDE.
Поиск и меню пересекающихся фильтров находятся над списком слева; правая колонка начинается
с названия, действия включения и версии выбранного пакета. Описание показывается
один раз. Длинная подпись ручной установки находится на вкладке «Источник».

Левая колонка занимает 38% ширины, не меньше 260 px. Категории имеют тихую подпись
и число найденных элементов. `UiSelectableRow` с контекстом `workspace-catalog`
даёт плоский фон, подсветку выбора и клавиатурный фокус. Знак берётся из общей
`pluginIconPath`; произвольный SVG из манифеста не исполняется.

Флажок — соседнее действие строки, отдельно от кнопки выбора. Он не открывает другой
плагин и меняет тот же `pluginEnabled:<id>` в общей сессии, что кнопка включения справа.
Перед первой правкой читается baseline ресурса; поздний результат закрытой сессии
отбрасывается, recovery блокирует оба controls. До «Применить» работающий плагин
не переключается. Выбор, фильтрация и переход между вкладками сохраняют намерения.

После шапки стоят вкладки «Параметры» и «Источник». Доступное
обновление, ожидание перезапуска, локальные изменения и ошибки проверки/отката
открывают источник автоматически. `PluginSourcePanel` в режиме `embedded` убирает повторный
заголовок и внешнюю рамку; проверки, привязка источника и откат сохраняют прежние guards.
Остальные потребители панели продолжают использовать прежний вид.

Вход в задание установки расположен в общей строке действий рядом с Git.
До ширины области 680 px список заменяется прежним выбором плагина, фильтры остаются
над ним, редактор располагается ниже. Системные страницы обходятся без списка.
Геометрия всей области — [цельные панели менеджера](plugin-manager-panels.md).

Проверки: `settings-plugins-catalog.component.test.js` покрывает флажок без смены выбора,
синхронизацию с редактором, отложенную запись, recovery и открытие источника при
обновлении. Профильные проверки сессии, размещений, системных страниц и установщика
проверяют сохранность прежних операций. Браузерный предпросмотр использует настоящий
модал и компоненты с демонстрационными ответами API.
