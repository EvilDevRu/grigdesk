# Редактирование задачи

Редактор внешней задачи находится во вкладке описания `TaskModal.vue`. Диалог и отдельное
окно используют одну форму. Название и описание занимают основную колонку, параметры —
боковую с разделителем. До 700 px колонки идут друг под другом; исполнитель, проект,
приоритет и срок располагаются попарно, до 480 px — в одну колонку.

Соисполнители и наблюдатели раскрываются через `UiDisclosureButton`, рядом видно количество
выбранных людей. Списки сохраняют выбор при сворачивании и ограничивают собственную высоту
200 px. Общие поля, селекты и множественный выбор берутся из публичной границы UI без
локального оформления controls. Новые подписи редактора имеют русские и английские переводы.

Прокручивается тело формы. Постоянный подвал содержит состояние черновика, «Отмена» и
акцентное «Сохранить». Во вкладке описания он заменяет обычные действия задачи; при переходе
к оценке или комментариям обычные действия снова доступны. Поля редактора при этом сохраняются.
На телефоне сообщение располагается над двумя равными кнопками.

Открытие фокусирует название. Ctrl+Enter и ⌘+Enter из любого поля формы вызывают прежнее
сохранение с проверкой обязательного названия и блокировкой повторной отправки. Enter без
модификатора в описании оставляет перевод строки. В API уходят только изменённые поля;
нетронутое HTML-описание и точный исходный срок сохраняют прежний контракт. Сбой справочников
оставляет текстовые поля доступными и показывает повторную загрузку. Отмена закрывает форму
без записи, сетевой отказ сохранения сохраняет черновик.

Проверки: `task-modal-edit.component.test.js`, `task-card-fields.component.test.js`,
сценарии загрузки справочников в `loading-surfaces.component.test.js`.
