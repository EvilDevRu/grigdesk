# Формат даты комментария

`TaskModal.vue` выводит время комментария через общий `formatDateTime()` из
`web/src/shared/format.ts`, который также используется для срока задачи.
ISO-дата показывается на текущем языке интерфейса и в часовом поясе устройства,
без секунд и смещения: например, «2 ноя 2026, 14:25».

Формат Jira со смещением `+0700` обрабатывается так же, как формат `+07:00`.
Готовые подписи старых драйверов, например «10:00», сохраняются без преобразования:
если хелпер не распознал ISO-дату, карточка показывает исходную строку.
