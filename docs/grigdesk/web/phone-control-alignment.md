# Выравнивание иконок шапки и поля чата

В компактной шапке до 1100 CSS px выбор машины использует квадратную площадку
`--toolbar-control-h`, как соседние действия. На сенсорном экране это 44 × 44 px.
Вместе с текстом скрывается `.ui-button__label`: пустая обёртка сохраняла внутренний
gap кнопки и смещала значок относительно центра. Индикатор связи остаётся у значка;
доступная подпись и открытие меню машин сохраняются.

На телефоне до 600 CSS px поле чата сохраняет два ряда: текст сверху, вложение,
микрофон, остановка активного хода и отправка снизу. Горизонтальный отступ текста
внутри textarea — 12 px; нижние действия центрируются по общей оси. Стрелка отправки
использует SVG общего размера кнопок, чтобы её положение не зависело от метрик шрифта.
Высота сенсорных действий и существующие пути отправки не меняются.

Компонентные проверки покрывают существующие действия оболочки и композера.
Вычисленные стили не заменяют визуальную приёмку в Android WebView.
