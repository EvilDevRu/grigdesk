# Счётчик новых задач под иконкой доски

Пункт «Доска» показывает одно синее число новых непросмотренных задач под иконкой.
Источник — `boardStore.activity.unseenCount`, учитывающий готовность серверной базовой
линии просмотренного. При нуле остаётся иконка по центру кнопки.

Общий `NavigationCount.vue` сокращает значения больше 999 до `999+`, а подсказка
и доступное имя сохраняют точное число. Подложки, точек и пульсации нет.

Работающие задачи и количество таймеров в счётчик доски не входят. Активные таймеры
и управление ими остаются в топбаре. Открытие задачи снимает признак новой;
переход на доску сам по себе его не меняет.
