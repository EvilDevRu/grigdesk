# Единая иконка обновления

Обновление и повторная загрузка используют `UiRefreshIcon` из публичного
`web/src/ui.ts`. Это SVG 24×24 с одной круговой стрелкой по часовой стрелке:
наконечник соединён с дугой, цвет наследуется от действия. Размер задаёт общий
контекст кнопки; доступное имя и подсказка остаются у самой кнопки.

Компонент используется в менеджере плагинов, браузере, песочницах, SSH, базах
и схеме БД, дифе, полке, карточке задачи, повторе загрузки чата, мастере настройки
и проверке лимитов исполнителей. Тот же знак обозначает повтор оценки, перезапуск
контейнера и восстановление подключения. `MachineGlyph` для `refresh` делегирует
рисунок общему компоненту. В галерее UI используется тот же SVG вместо символа шрифта.

Изменение рисунка выполняется в `UiRefreshIcon.vue`, без копий path в продуктовых
компонентах. Состояния загрузки, запреты действий и обработчики кнопок не зависят
от рисунка и сохраняются.
