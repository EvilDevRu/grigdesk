# Диалог установки из Git

`PluginInstallDialog.vue` разделяет источник, проверку пакета и подтверждение установки.
Шапка со шагами и нижний блок действий находятся вне прокрутки общего `UiDialog`.
Геометрия окна задана в `styles/components/overlays.css` по
`data-role="plugin-install-dialog"`: до 520 px на широком экране, полный экран на мобильном.
Scoped CSS потребителя не оформляет телепортированную поверхность диалога.
Постоянные места действий, ошибки и переходы описаны в [раскладке окна](plugin-install-layout.md).
Рабочие поля, плотность формы и палитра описаны в [оформлении установщика](plugin-install-design.md).

Первый запрос current показывает заглушку и не разрешает новую операцию. Ошибка чтения
оставляет отдельное состояние с повторной загрузкой. При повторном открытии известное
задание остаётся видимым, действия заблокированы до завершения чтения. Закрытие и
размонтирование не позволяют позднему bootstrap запустить поиск версий.

Поле версии и место под статус поиска существуют до ответа. Во время поиска выбор
и переход к проверке недоступны; адрес можно исправить, инвалидировав прежний ответ.
Enter в поле адреса запускает тот же поиск, что кнопка. SSH, локальные источники и
доступ к приватным репозиториям объясняются в раскрываемой справке. В режиме обновления
есть явное повторное чтение списка; повтор после неудачной установки также получает
версии исходного плагина заново.

`PluginInstallPreview.vue` показывает название, версию, источник, тег и полный SHA.
Коммиты и файлы раскрываются отдельно. Предупреждения, наличие изменений серверной
части или зависимостей и признак сокращённого списка видны до раскрытия. Применение
остаётся явной кнопкой; просмотр сведений не запускает установку.

`PluginSourcePanel.vue` объединяет адрес и версию, проверку обновлений и отдельную
строку возврата предыдущей версии. Предупреждения о ручных правках, требуемом
перезапуске и недоступности отката остаются рядом с соответствующими действиями.
Подтверждение отката и проверки revision/digest после него принадлежат прежнему
контракту установки.

Проверки: `plugin-install-dialog.component.test.js`, `plugin-source-panel.component.test.js`
и `settings-plugins-catalog.component.test.js`. Браузерная проверка с управляемыми
ответами на ширинах 340, 390, 600 и 1100 px подтверждает неподвижность окна и footer
при bootstrap и поиске версий, отсутствие горизонтальной прокрутки во всех состояниях
и доступность нижних действий. Реальные Git/npm-операции для проверки раскладки не нужны.
