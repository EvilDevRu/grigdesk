# Компактные действия откреплённого инструмента

Общая шапка `ToolWindowPage.vue` использует четыре `UiIconButton`: возврат инструмента
в колонку, сворачивание, разворачивание / восстановление и закрытие окна. Названия действий
берутся из существующих переводов `core` и `desktop` и остаются доступны через `aria-label`
и общую подсказку `v-tooltip.bottom`.

Контекст `tool-window-control` в общей таблице `styles/components/actions.css` задаёт
квадратную площадку по токену `--toolbar-control-h`: 28 px на desktop, 44 px в сенсорном
режиме. Размер рисунка — 16 px, промежуток между кнопками — 4 px. Кнопки исключены из
области перетаскивания окна; свободная часть шапки сохраняет перетаскивание.

Возврат доступен после готовности панели и блокируется во время передачи снимка.
Обработчики возврата и закрытия сохраняют [общий контракт окон инструментов](tool-windows.md).

Сворачивание и максимизация проходят через защищённый POST `/__shell/surfaces/tool`:
действия `minimize`, `toggle-maximize` и `window-state` требуют точных `id` и `instance`.
Реестр `surfaceWindows` проверяет текущий origin, живое окно и совпадение экземпляра.
Команды не обращаются к управлению главным окном. Ответ содержит актуальный `maximized`.

`useToolWindowControls.ts` сверяет состояние после действия, при готовности документа,
resize и focus. События объединяются задержкой 100 мс; отдельного постоянного опроса нет.
Поздние ответы не откатывают свежий результат. Во время мутации и под модальным слоем
повторное действие блокируется; ошибка мутации показывает общий тост.

Новые native-команды требуют пересборки desktop и повторного открытия приложения.
Одного обновления страницы старого пакета для них недостаточно.
