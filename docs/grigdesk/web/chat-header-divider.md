# Ровная граница шапок списка и чата

В двухрядных «Чатах» поиск и кнопка создания стоят на одной оси с названием
и рабочей областью разговора. Вкладки «Активные / Архив» и воронка стоят на одной оси
с моделью. Нижние границы шапок списка, разговора и каркаса загрузки совпадают.

`ChatsView` задаёт `--chat-head-row-h` и общий минимум `--chat-head-h`. Два ряда,
зазор 4 px, вертикальные поля по 4 px и нижняя граница 1 px дают 85 CSS px
на компьютере и 101 CSS px на сенсорном Android. На остальных сенсорных устройствах
обе шапки занимают 109 CSS px, включая поля вокруг 44-пиксельных вкладок списка.

Список карточек и лента прокручиваются независимо под шапками, поле ввода остаётся
внизу. Раскрытая панель фильтров и чипы добавляют высоту под основными рядами списка.
Предупреждения о модели и перенос настроек в узкой колонке могут увеличить шапку
разговора, чтобы все элементы оставались доступны.

В двухколоночном окне до 1024 × 600 CSS px выбор проекта занимает отдельный ряд
над поиском. При ширине меньше 900 CSS px список и разговор занимают экран по очереди.
На телефоне до 600 CSS px список использует [высоту по содержимому](phone-chat-search-density.md),
а разговор открывает настройки из [компактной шапки](../chat/header-controls.md).
