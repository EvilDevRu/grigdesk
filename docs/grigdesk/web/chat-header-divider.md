# Ровная граница шапок списка и чата

В двухколоночных «Чатах» шапки списка, разговора и его загрузочного каркаса используют
общий `--chat-head-h`. Минимум равен `max(80px, 2 × toolbar-control-h + 13px)`:
два ряда controls, зазор 4 px, вертикальные поля по 4 px и нижняя граница 1 px.
Поэтому на desktop минимум — 80 px, а при корневом `data-ui-touch` — 101 px.
Сенсорные площадки сохраняют размер 44 px.

У шапки списка зазор между поиском и архивом — 4 px, контейнер переключателя архива
имеет `display: flex`. Обычный блочный контейнер оставлял место под базовую линию
вложенного `inline-flex`, из-за чего содержимое перерастало общий минимум.
При стандартном тексте расхождение нижних границ составляло около 2,48 CSS px.

При viewport уже 900 px список и разговор занимают экран по очереди. На телефоне
до 600 px список использует [высоту по содержимому](phone-chat-search-density.md),
а разговор сохраняет отдельную компактную шапку;
настройки доступны в прежнем диалоге. Предупреждения о модели могут увеличить шапку,
чтобы текст оставался виден, как описано в [контракте шапки](../chat/header-controls.md).
