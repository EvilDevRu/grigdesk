# Одна строка фильтров конвейера на телефоне

До 600 CSS px панель конвейера содержит три колонки: проект, состояние и меню «⋯».
Панель использует общий `UiPaneHeader` и занимает минимум 48 px: площадки controls по
44 px, вертикальные поля 1/2 px и нижняя граница 1 px. Список прокручивается отдельно
под шапкой, отрицательных отступов нет. Desktop-toolbar использует тот же компонент.

Два общих `UiSelect` используют контекст `pipeline-phone-filter` без заливки и рамки
формы. Проект получает немного больше ширины. Длинное имя сокращается многоточием,
а отдельный счётчик не сжимается; полное имя доступно в подсказке и списке выбора.
Закрытый фильтр состояния показывает «Все», список — «Все состояния».
Выбранное конкретное состояние выделяется акцентным цветом.

Общий `UiIconButton` открывает прежнее меню управления. Иконка имеет подсказку и
доступное имя «Управление», а при массовой команде показывает прежний спиннер.
Настройки вида, области массовых команд, подтверждения и сохранение фильтров не меняются.
Палитра и геометрия controls находятся в общих `fields.css` и `actions.css`.

Браузерная проверка на синтетических данных покрывает 320, 390 и 600 px, длинное
имя проекта и раскрытие меню; первоначальное открытие desktop проверяется отдельно.
Компонентные проверки проходят через настоящие списки выбора и подтверждают сохранение
фильтров, счётчики, управление видом и массовые команды. Схема и её controls не меняются.
