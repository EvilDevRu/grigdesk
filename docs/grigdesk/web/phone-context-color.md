# Цвет линии контекста телефона

Линия `UiProgress` с `data-context="chat-header-context"` берёт цвет из `provider.color`
текущей модели через общий резолвер исполнителя. Отдельной палитры и ветвлений по
исполнителям нет: Codex, GLM, Claude, Kimi и остальные используют цвет своего адаптера.
При отсутствии цвета применяется общий `--ink-mid`.

Цвет передаётся через `--chat-context-color`, оформление задаёт UI-kit в `feedback.css`.
Только заливка имеет `opacity: 0.5`; дорожка остаётся обычной линией разделителя.
Цвет не меняется при росте заполненности, оценочном замере или сжатии. Длина,
анимация сжатия и доступное описание сохраняют общий контракт контекста.
Индикатор в настройках продолжает показывать уровень заполнения цветом состояния.
