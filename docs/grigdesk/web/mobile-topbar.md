# Сводка шапки на узком экране

При ширине окна до 1100 px общая шапка показывает кнопку «Состояние системы».
Она открывает сводку: ресурсы компьютера, таймеры задач, конвейеры, прерванные оценки,
исполнители и сеть. Подписанные пункты раскрывают прежние подробные панели.
Исполнители располагаются в двух колонках; длинный список прокручивается внутри сводки.
При тревоге ресурсов, необходимости решения в конвейере или прерванной оценке кнопка
получает цвет предупреждения.

Выбор машины, подключение телефона, история уведомлений и настройки остаются в шапке.
Подробности статуса не увеличивают её ширину. Действия текущего раздела сохраняют место;
длинное название документа сокращается внутри слота без горизонтального скролла.

На широком экране индикаторы остаются отдельными кнопками. `TopbarStatus.vue` меняет
представление по `matchMedia`, снимает подписку при размонтировании и закрывает сводку
при смене ширины. Переход между страницами также закрывает её. Закрытие сводки снимает
усиленный опрос лимитов исполнителей. Escape сначала закрывает подробную панель,
затем сводку; все поверхности используют общие controls и стек слоёв.

Левая рейка рисует разделитель внутренней тенью: её полезная ширина совпадает с токеном
`--app-rail-w`, поэтому сенсорная кнопка 44 px не выходит в рамку 43 px.
Горизонтальное переполнение исключено. Вертикальная прокрутка остаётся для действительно
длинного списка разделов в низком окне. До 600 px действует нижняя навигация телефона.

Браузерная проверка `topbar-responsive.test.js` использует десять синтетических исполнителей,
ширины 320–1280 px, сенсорный режим и увеличенный текст. Она проверяет доступность действий,
отсутствие горизонтального переполнения рейки, вложенное закрытие по Escape, настройки
и возврат к широкой шапке с открытой сводкой.
