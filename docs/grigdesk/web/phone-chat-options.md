# Отдельные настройки чата на телефоне

До 600 CSS px кнопка настроек в шапке открывает общий `UiDialog`: на телефоне он
полноэкранный, с названием, закрытием и одной прокруткой. Первичный фокус получает
содержимое формы, поэтому открытие не вызывает экранную клавиатуру.

Настройки идут одним столбцом: задача, рабочая папка, модель, доступный режим доступа,
доступное усилие рассуждения и контекст. У каждого поля отдельная подпись; выборы
и кнопка папки занимают всю ширину, текст полей — 16 px, площадки — 44 px.
Шкала усилия растягивается по ширине строки и сохраняет выбранную подпись справа.
Недоступные для модели режимы и усилия не создают пустых строк.

Используются прежние экземпляры controls и действия stores. Два Teleport переносят
группы из настольной шапки в HTMLElement-цели, полученные через refs содержимого
диалога. Пока цели нет или окно закрыто, перенос отключён. Закрытие и переход на
desktop возвращают те же узлы в шапку; условная цель не ищется заранее по селектору.
При смене чата и выходе из телефонной ширины диалог закрывается.

Предупреждение о модели остаётся в основной шапке, включая закрытые настройки.
Выбор папки, меню моделей, подсказки и подтверждение сжатия сохраняют прежние
общие поверхности и стек слоёв. Новых запросов, stores и таймеров для формы нет.
Выбор папки раскрывается [внутри настроек](phone-workdir-inline.md), без второго окна.
Подтверждение переноса памяти использует слой `confirm`, чтобы оставаться
[поверх настроек](phone-workdir-layer.md), независимо от порядка Teleport в DOM.

`chat-in-turn.component.test.js` проверяет настоящий UiDialog и Teleport, состав
полей, повторное открытие без дубликатов и возврат тех же узлов на desktop.
Все сценарии файла разделяют один document: Vue кеширует документ первого окна.
Составной сценарий выбора папки использует настоящий `ChatWorkdir`: встроенный каталог,
подтверждение переноса и возврат к настольному диалогу при смене ширины.
