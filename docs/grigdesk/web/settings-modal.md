# Оболочка настроек на общем диалоге

`SettingsModal.vue` использует управляемый `UiDialog` размера workspace, общий стек
слоёв, inert, scroll lock и возврат фокуса. Затемнение не закрывает настройки.
Крестик и Escape закрывают чистую форму; при изменениях `SettingsCloseDialog`
показывает единый выбор из трёх действий. «Отмена» сразу отбрасывает неприменённое.
Пока идёт Apply, закрытие и повторная запись запрещены. После двадцати секунд
доступно прекращение ожидания по контракту сессии.

Pinia store `stores/settings.ts` владеет одним открытием и публичным снимком ядра.
Адаптеры и секретный ввод остаются в замыкании. Запрос до входа откладывается;
потеря входа очищает сессию и отложенный запрос. Клавиша и пункт меню не открывают
скрытые настройки под чужой модалкой; повторное открытие сохраняет текущий ввод.
Публичная проверка `hasOpenModal` доступна через `ui.ts`, без deep import consumers.

Оболочка публикует UI-контекст settings слоя overlay только пока открыта.
В details находятся только page и необязательный entity, без значений и поиска.
Карта компонентов страниц отделена от чистого каталога и подменяется в тестах,
поэтому перенос новой бизнес-формы не меняет граф теста оболочки.

Проверки: `settings-modal.component.test.js` (MD01–MD09), `ui-dialog.component.test.js`.
