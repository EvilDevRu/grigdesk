# Порядок снимков доски

Главное окно может читать dashboard, пока человек меняет задачу в отдельной карточке.
Если снимок после действия уже принят, поздний ответ прежнего чтения не должен откатывать
таймер или другие поля доски ни в главном окне, ни в карточках.

`board.load` фиксирует `readAt` перед GET. Метка строго больше метки уже показанных данных,
даже при двух чтениях в одну миллисекунду. Ответ применяется только при `readAt` больше
текущего. Ошибка старого запроса также не заменяет состояние более нового снимка.
`loadedAt` означает время применения данных для обычного кеша; ожидание базовых отметок
просмотра не меняет `readAt` и не повышает свежесть снимка.

Успешный `load` возвращает метку принятого ответа. Связь окон публикует снимок только
при совпадении этой метки с текущей меткой доски. Отброшенный ответ не публикуется;
снимок другого окна, принятый во время GET или ожидания отметок просмотра, не получает эхо.
Дополнительного чтения dashboard при отбрасывании нет: обычный опрос остаётся в главном
окне, карточка читает доску после своего действия.

Реализация: `web/src/stores/board.ts`, `web/src/App.vue`; сообщения описаны в
[контракте связи окон](window-relay.md). Проверки зеркала и собственного действия —
`tests/web/board-mirror.test.js`, формы relay — `tests/web/window-relay.test.js`.
