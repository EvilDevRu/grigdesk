# Счётчик колокольчика

Счётчик пропущенных оповещений позиционируется относительно кнопки истории.
В сенсорном режиме top/right равны 2 px: плашка помещается внутри площадки 44 px
и не выходит за верхнюю границу окна. Обычный desktop сохраняет смещение -3/-4 px.
Внутренняя подпись этой кнопки допускает overflow, чтобы UiButton не обрезал плашку.
Оформление принадлежит actions.css, scoped CSS истории отвечает за сам список.

Ноль не создаёт плашку, видимый предел — 99+. Полное число остаётся в доступном имени.
История принадлежит окну и хранится только в памяти. Новый тост имеет состояние live;
missed появляется после его самостоятельного ухода по timeout или overflow.
Ручное закрытие тоста помечает его seen, устранение причины — resolved.
Открытие истории помечает missed как seen и убирает число с колокольчика.
Перезагрузка окна, включая запуск нового APK, начинает пустую историю.
alert-history-popover.component.test.js проверяет значения, доступное имя и настоящий CSS
отдельно для touch и desktop. Проверка с настоящим `createAlertHistory` подтверждает
появление плашки после timeout и исчезновение после открытия истории.
Геометрия настоящего приложения проверяется отдельно.
