# Рабочие области на узком экране

Рабочие разделы используют `UiPaneHeader` на полной ширине и layout `workspace`.
`UiWorkspacePage` объединяет эту шапку и тело с общими полями и отдельной прокруткой;
разделы со своей сеткой каталогов сохраняют собственную прокрутку панелей.
Контракт — [общий каркас разделов](section-panels.md). Читатель документа
сохраняет ограничение ширины текста, метаданные выровнены по этой колонке.

Каталог агентов, каталог/холст/инспектор маршрута и области SQL переключаются
по ширине контейнера. CSS скрывает неактивную область: черновик и соединение
остаются в существующем компоненте. Общий skin
`data-ui-workspace-tabs` задаёт размеры новых переключателей. Единственный ToolHost
и сохранённые пользователем размеры панелей не меняются.

Меню инструментов использует UiPopover и общий стек слоёв: позиция пересчитывается
при изменении окна и `visualViewport` (включая его смещение), высота и ширина
ограничены видимой областью, содержимое прокручивается,
Escape возвращает фокус триггеру. Оформление телепортированного меню находится в
`styles/components/overlays.css`.

На узком экране настройки выбираются одним UiSelect. До 600 px используется
[нижняя навигация](phone-workspaces.md), на более широком экране остаётся боковая рейка.
UiDialogHost поддерживает `multiline: false` для короткого ввода.
По умолчанию многострочное поле и Shift+Enter сохранены. Fullscreen диалогов на
телефоне сохраняется.

Проверки: компонентные тесты маршрутов, БД, каталога плагинов и
UiDialogHost; геометрия и состояния проверяются отдельным Chromium-стендом.
Матрица размеров и границы проверки настоящих устройств описаны в
[методике визуальной сверки](ui-design-refinements.md#как-проверять).
