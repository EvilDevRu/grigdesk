# Рабочие области на узком экране

Обычная страница получает внешний отступ от AppShell и общую ось `.ui-page` /
`.ui-page-head`. Внутренние карточки добавляют собственный отступ. Рабочие инструменты
сохраняют собственную прокрутку; Diff использует layout `workspace`. Читатель документа
сохраняет ограничение ширины текста, метаданные выровнены по этой колонке.

Каталог агентов, каталог/холст/инспектор маршрута, области SQL и модель/версии/сведения
3D переключаются по ширине контейнера. CSS скрывает неактивную область: черновик,
выбранная версия и соединение остаются в существующем компоненте. Общий skin
`data-ui-workspace-tabs` задаёт размеры новых переключателей. Единственный ToolHost
и сохранённые пользователем размеры панелей не меняются.

Меню инструментов использует UiPopover и общий стек слоёв: позиция пересчитывается
при изменении окна и `visualViewport` (включая его смещение), высота и ширина
ограничены видимой областью, содержимое прокручивается,
Escape возвращает фокус триггеру. Оформление телепортированного меню находится в
`styles/components/overlays.css`.

На узком экране настройки выбираются одним UiSelect; постоянные боковые рейки
оболочки остаются. UiDialogHost поддерживает `multiline: false` для короткого ввода.
По умолчанию многострочное поле и Shift+Enter сохранены. Fullscreen диалогов на
телефоне сохраняется.

В рабочем месте 3D просмотрщик получает оставшуюся высоту колонки. Его минимальные
размеры задаёт потребитель через `--studio-viewer-min-height`,
`--studio-canvas-min-height`, `--studio-canvas-height` и `--studio-canvas-flex`;
другие потребители сохраняют прежние значения по умолчанию. На низком экране модели
общая сводка ресурсов уступает место холсту; цена операций остаётся в их формах.

Проверки: компонентные тесты маршрутов, БД, библиотеки 3D, каталога плагинов и
UiDialogHost; геометрия и состояния проверяются отдельным Chromium-стендом.
Матрица и ограничения настоящих устройств записаны в журнале
`docs/plans/grigdesk-layout-execution-20261017.md`.
