# Поверхность поиска в селектах

Поле `UiSearchInput` внутри `UiSelect` помечено `data-context="select-search"`.
Базовое правило полей `fields.css` задаёт ему `--field-background` (`--surface-2`).
Это действует для обычного, компактного и рабочего селекта, навигации по группам
моделей и сенсорного режима. Высота, рамка, текст, placeholder, очистка и фокус
сохраняют общие правила UI-kit.

Teleport меню в `body` не меняет фон: [общий токен полей](field-background-sources.md)
определён на корне и не зависит от рабочего контейнера. Отдельного цветового правила
для `select-search` нет; контекст сохраняет отступ под иконку. Раньше поиск требовал
такого правила, поскольку обычный control использовал почти чёрный `--ground`.

Одиночные выпадающие поля `web/src` используют `UiSelect`; единственный native select
находится внутри его адаптера. `pluginRuntime/ui.ts` переэкспортирует тот же UI-kit,
поэтому модульным плагинам не требуется собственное исправление.

Поведение выбора, групп, клавиатуры, disabled и адаптера формы проверяется
`ui-select.component.test.js` и `ui-select-options.test.js`. Сравнение CSS-цветов в
DOM с настоящим Teleport полезно для проверки наследования, но не заменяет живую
браузерную проверку геометрии и фокуса.
