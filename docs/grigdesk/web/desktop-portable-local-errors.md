# Ошибка местной установки при запуске переносимого окна

Повреждённый `runtime.json` местного сервера не мешает открыть интерфейс с выбранной
удалённой машиной. Переносимое окно сохраняет выбранный профиль, его адрес и привязку.
Наличие соседнего ELF не разрешает перезаписать повреждённое описание установки.

Discovery заранее получает предварительный loopback-адрес из общих настроек окружения
с обычным портом по умолчанию. После чтения исправного descriptor адрес уточняется
по выбранной папке данных и её `.env`. Если чтение или проверка настроек местной
установки завершается ошибкой, предварительный адрес позволяет зарегистрировать
соседнюю машину в списке и открыть трубу интерфейса.

Ошибка местной установки сохраняется до попытки подготовки local: такой выбор
показывает причину недоступности и не вызывает verify, запись descriptor или запуск
сервера. Подключение remote не требует подготовки local.
