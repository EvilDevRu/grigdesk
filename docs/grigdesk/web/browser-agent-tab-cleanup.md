# Агентские вкладки: иконка сайта, активность и очистка

В полосе встроенного браузера показывается favicon сайта; при отсутствии или ошибке
изображения остаётся глобус. Рядом появляется синий робот, если у исполнителя есть доступ:
`grantee !== null || (owner !== null && grantOrigin !== null)`. Пауза сохраняет робота,
но приглушает его через `data-agent-state="paused"` и существующие токены цвета и opacity.
Без доступа остаётся глобус, даже если вкладку создал агент.

Иконка сайта сохраняет постоянный слот `.browser-tab-icon`: `flex: none`, 14×14 px.
Робот занимает дополнительный слот того же размера; название по-прежнему обрезается.
Обе иконки декоративные (`aria-hidden="true"`). Подсказка робота
использует `core.browserOwner` и `ownerName(owner)` для вкладки агента либо
`core.browserController` и `ownerName(grantee)` для человеческой вкладки с grant.

`agentWorking` приходит из native-реестра: он включён во время открытия агентом и
выполнения команды этой вкладки, выключается в `finally`, включая отказ. Человеческая
навигация, `list` и фоновая загрузка сайта не включают его. Робот с
`data-agent-state="working"` пульсирует по opacity; при паузе остаётся приглушённым,
при `prefers-reduced-motion: reduce` сохраняет цвет без анимации.

Во время команды ручные действия с этой вкладкой заблокированы; над страницей видна
полоса состояния. Native-перехватчик и экстренное управление доступом описаны
в [контракте блокировки ввода](browser-agent-input-lock.md).

Electron `page-favicon-updated` читает иконку в session гостя с ограничением 256 КиБ и
трёх секунд. IPC передаёт только проверенный image data URL, поэтому документ GrigDesk
не загружает адрес сайта со своими cookies. Ошибка, перенаправление или неподдерживаемый
тип оставляет глобус. Новая полная навигация и закрытие отменяют чтение; поздний ответ
не возвращает иконку прежней страницы. Переход внутри документа сохраняет иконку.

Пункт «Закрыть неиспользуемые» в контекстном меню закрывает по всей полосе только
остатки агентов: `owner !== null && grantee === null && grantOrigin === null`.
Выбранная вкладка и вкладка, на которой открыто меню, не ограничивают область очистки.
Человеческие вкладки, явный grant и доступ владельца через живой origin сохраняются,
в том числе на паузе. При отсутствии кандидатов пункт недоступен.

Меню закрывается перед действием. Список кандидатов фиксируется из копии snapshot до
первого `await`; новые вкладки в начатую очистку не попадают. Запросы `close` идут
последовательно до первого отказа native. После действия фокус возвращается выбранной
оставшейся вкладке, а при пустой полосе — в адресную строку.

Проверки: `tests/web/browser-ui.component.test.js`, сценарии BR-U16–BR-U22,
`tests/desktop/browser-native-view.test.mts` (BR-V-favicon*) и
`tests/desktop/browser-native-runtime.test.mts` (BR-N-activity).

Автоматическая очистка работает отдельно от пункта меню: native-реестр закрывает
созданные агентами вкладки после пяти минут без обращений к странице, даже если grant
сохранился. Незавершённая команда и показанная в панели вкладка защищены; после скрытия
начинаются полные пять минут. Человеческие вкладки сохраняются при любом grant.
`list`, heartbeat и фоновые события сайта срок не обновляют. Фиксированного лимита
числа вкладок нет. Подробности — в
[контракте времени жизни вкладок](../chat/browser-tab-limits.md), проверки —
`tests/desktop/browser-tab-lifetime.test.mts` и `tests/desktop/browser-native-runtime.test.mts`.
