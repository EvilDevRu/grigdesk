# Начальная настройка через рабочие разделы

После подключения к пустой установке открывается обычный интерфейс. Начальная
настройка не перехватывает навигацию и не открывает отдельный диалог автоматически.

Проект создаётся в разделе «Проекты»: пустое состояние `ProjectsView.vue` содержит
кнопку «Создать проект», открывающую обычную форму. Проверка папок и веток использует
общий API проектов и `server/src/lib/projects/repositoryCheck.ts`.

Исполнители подключаются через раздел настроек `agents.providers`. Каталог и карточка
`ProviderPage.vue` используют общий снимок `/api/providers` и прежний установщик.
