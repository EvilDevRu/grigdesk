# Соединённые сегменты переключателя

Базовые `UiSegmentedControl` и `UiTabs` используют одну внешнюю рамку без внутреннего
padding. Между соседними кнопками проходит разделитель толщиной 1 px. Скруглены
только внешние углы первой и последней кнопки; выбранный сегмент заполняется
`--surface-2`, без собственной рамки и тени. Геометрией владеет общий UI-kit
в `web/src/styles/components/patterns.css`.

Высота группы сохраняется: 36 px в обычном окружении, 32 px в рабочем, 28 px у
компактного переключателя и 44 px в сенсорном режиме. Кнопки занимают высоту группы
за вычетом 2 px внешней рамки. У компактного варианта длинный текст может увеличить
высоту. Клавиатурный фокус рисуется внутри сегмента и не обрезается прокруткой вкладок.

«Контроль / Поручения» на Доске использует этот общий вид. Его прежние локальные
переопределения активной рамки и зазора удалены. Контекстные навигационные полосы
карточки задачи, конвейера, настроек, Docker и студии 3D сохраняют своё оформление;
их вкладки с нижним подчёркиванием явно сбрасывают рамку сегмента.

Выбор, disabled и клавиатурная навигация не меняются. Их проверяют
`tests/web/ui-segmented-control.component.test.js` и
`tests/web/ui-selection-controls.component.test.js`.
