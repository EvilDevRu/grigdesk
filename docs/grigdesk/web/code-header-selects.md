# Прозрачный фон селектов шапки «Кода»

Выбор проекта и рабочей копии в `CodePanel.vue` использует общий `UiSelect`
с контекстом `code-head-select`. Эти элементы встроены в навигационную шапку:
фон видимой кнопки прозрачен, чтобы значение и шеврон оставались на поверхности
панели без отдельных прямоугольных плашек.

Исключение задано в общем `styles/components/fields.css` через
`background-color: transparent`. Оно сохраняет шеврон и геометрию контрола,
действует в полноразмерном разделе, доке и на сенсорном экране. Меню селекта
и поиск в нём используют общие поверхности UI-kit.

Обычные поля и селекты чата сохраняют [общий фон полей](field-background-sources.md).
Контракт шапки проверяет `chat-toolbar-selects.contract.test.js`, вычисленный
цвет в обычном, рабочем и сенсорном окружении — `ui-field-backgrounds.component.test.js`.
