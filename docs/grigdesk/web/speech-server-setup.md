# Готовность речи на выбранном сервере

«Диктовка» и «Расшифровка видео» показывают готовность окружения и выбранной модели
прямо на своей странице. Открытие читает серверный снимок настроек речи; «Проверить
на сервере» выполняет тот же GET с `refresh=1`, обновляя диагностику окружения и кэша.
Проверка не применяет черновик и не запускает установку.

Состояние окружения берётся из `environmentReady` и `environmentChecks` capabilities,
наличие модели — из `models[].cached`. Эти результаты разделены: окружение может быть
готово, пока конкретная модель ещё не скачана. Модель определяется по текущему черновику:
явный `model` / `videoModel` либо пресет `quality` / `videoQuality`. Статус сохранённой
модели диктовки не подменяет готовность выбранной модели видео.

Установленная модель не предлагает повторное скачивание. Отсутствие ответа о модели
и отказ диагностики кэша показываются как непроверенное состояние. При отсутствующем
Python или faster-whisper скачивание недоступно; рядом показан шаг исправления из отчёта
сервера. Системные зависимости устанавливаются оператором, страница не запускает sudo.

Скачивание и копирование доступны прямо здесь через существующие model jobs.
`SpeechModelRow.vue` показывает одинаковые действия, статус, ошибки и прогресс здесь и
в каталоге локальных моделей. Отмена обращается к текущему заданию. Переход в другую
настройку сохраняет задание; возврат в диктовку, видео, модели или дополнительные
настройки возобновляет опрос. После завершения обновляется серверный снимок кэша.

Настройка качества по-прежнему сохраняется через «Применить», скачивание начинается
сразу. Контракт общей сессии описан в [настройках речи](settings-speech.md).
Проверки: `settings-speech.component.test.js`, `settings-speech-session.test.js`.
