# Готовность речи на выбранном сервере

Единая страница «Речь» (`speech.dictation`) показывает карточку распознавания, общий пресет и язык. Список
моделей доступен в «Расширенном». Модели, выбранные для диктовки и видео, отмечены по текущему черновику.
Открытие читает серверный снимок настроек речи; «Перепроверить окружение и кэш»
в блоке «Расширенное» выполняет тот же GET с `refresh=1`, обновляя диагностику
окружения и кэша, а также перечитывает состояние установщика.
Проверка не применяет черновик и не запускает установку.

Карточка окружения показывает `installed` и текущую `job` из
`GET /api/settings/speech/installation`. Диагностика готовности распознавания и
доступность скачивания используют `environmentReady` и `environmentChecks`
capabilities; наличие модели — `models[].cached`. Эти результаты разделены:
окружение может быть готово, пока конкретная модель ещё не скачана. Модель определяется по текущему черновику:
явный `model` / `videoModel` либо пресет `quality` / `videoQuality`. Статус сохранённой
модели диктовки не подменяет готовность выбранной модели видео.

Установленная модель не предлагает повторное скачивание. Отсутствие ответа о модели
и отказ диагностики кэша показываются как непроверенное состояние. При отсутствующем
Python или faster-whisper скачивание недоступно; рядом доступны установка, обновление
и удаление штатного окружения Whisper. Команды из диагностики не показываются на
пользовательской странице. Для отсутствующих системных зависимостей есть
[ссылка в терминал с командой установки](../media/speech-dependency-links.md):
страница сама не запускает sudo и не отправляет Enter.

Управление окружением использует подтверждение общего UI, серверный установщик и
ограниченный журнал под «Детали». Модели и настройки сохраняются при удалении окружения.
Подробный контракт — [установка окружения речи](../media/speech-installation.md).

Простой пресет скачивает недостающую модель автоматически. Скачивание, копирование
и отмена по отдельным моделям доступны в «Расширенном» через существующие model jobs.
`SpeechModelRow.vue` показывает действия, статус, ошибки, прогрессбар и проценты
для каждой модели в едином списке. Отмена обращается к текущему заданию. Переход в другую
настройку сохраняет задание; возврат на страницу «Речь» возобновляет опрос.
После завершения обновляется серверный снимок кэша.

Сразу доступны распознавание, единый пресет и язык. Движок, раздельное качество,
словарь, явные модели, CPU/CUDA и остальные параметры находятся в свёрнутом блоке
«Расширенное». Полная структура — в [настройках речи](settings-speech.md).

Настройка качества сохраняется через «Применить», скачивание начинается
сразу. Контракт общей сессии описан в [настройках речи](settings-speech.md).
Проверки: `settings-speech.component.test.js`, `settings-speech-session.test.js`.

Совместимость старых адресов описана в [единой странице речи](speech-settings-page.md).
