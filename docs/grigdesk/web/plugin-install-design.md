# Оформление установщика плагинов

`PluginInstallDialog.vue` использует рабочий режим на собственной поверхности
`UiDialog`: `data-ui-workspace` и `ui-workspace` сохраняются после Teleport. Поля,
выбор версии и обычные действия получают общие 32 px, фон `--surface-2` и рабочее
скругление. Сенсорный токен поднимает площадки до 44 px без отдельного оформления controls.
Общая форма используется и для драйверов БД.

На desktop высота окна — `min(520px, 100dvh - 40px)` для всех состояний.
Заголовок, шаги и два постоянных места footer остаются вне прокрутки; длинный пакет,
справка и ошибки используют прежние области прокрутки. Общая мобильная оболочка
сохраняет полноэкранный режим.

Заголовок этапа использует знак 32 px, текст 15 px и минимальную высоту вместо
фиксированного пустого блока. Описание переносится без обрезания. В теле формы
промежутки 12 px; пояснение версии сохраняет место для двух строк. Справка об SSH
стоит в конце формы под тонкой линией; её общий `UiDisclosureButton size="compact"`
сохраняет сенсорную площадку. Кнопка поиска версии равна полю адреса по высоте.

Текущая версия, подготовленный пакет, источник и итог используют `--surface-2`.
`PluginInstallPreview.vue` сохраняет полный SHA, предупреждения и раскрытие изменений,
но использует ту же компактную типографику и интервалы, что форма.

Состояния bootstrap, поиска, проверки, применения, восстановления и результата,
подтверждения и обработчики запросов принадлежат прежнему
[контракту установщика](plugin-install-ui.md). Оформление не запускает Git/npm или
применение пакета само по себе.
