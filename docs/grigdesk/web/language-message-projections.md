# Сохранённые сообщения и служебные проекции языка

Задача №93001: собственные сообщения сессии настроек и адаптеров сохраняют descriptor,
когда получают реактивный `LocaleSource`. Публичные снимки и результаты остаются строковыми.
Смена языка разрешает сообщения заново без повторной валидации, HTTP или записи; намерения,
ошибки полей, адреса и результаты Apply сохраняются. Прямой вызов с обычной строковой
локалью сохраняет прежний контракт. Ошибки сервера остаются исходными строками.

Native wire пока не содержит машинного кода причины. Поэтому UI распознаёт только точные
собственные причины и владельцев из зарегистрированного русского справочника. Эта проекция
ограничена служебными полями встроенного источника, включая consumerSupport и неактивные
overrides. Подписи и описания внешней схемы CLI не переводятся. Неизвестная метаинформация
сохраняется исходной строкой. `check:i18n` сверяет таблицу с декларациями владельцев,
нормализатором схемы, проверкой значений и проекцией каталога без импорта серверного кода.

Сводки и заметки лимитов проецируются по паре ID исполнителя и ресурса. Собственный шаблон
целиком сверяется с русским каталогом, параметры получают формат выбранного языка.
Неизвестные ресурсы, сообщения сервера и внешние причины остаются данными. Баланс с числом
использует Intl; в денежных строках целая часть форматируется через BigInt, дробные цифры
не округляются. Эта проекция не меняет сумму, проценты, расписание, команду или payload.

Новое правило для этих служебных метаданных: новая собственная подпись добавляется в общий
каталог всех зарегистрированных языков и в область проверки своего источника. Перевод
не добавляется в серверный DTO и не подменяет содержимое внешней схемы или сообщения ошибки.

Тем же способом проецируются пояснения встроенных исполнителей: способ доставки,
подсказка ключей доступа, заметка о прямом SSH и собственные состояния MCP. Таблица
ограничена ID исполнителя; неизвестный вывод CLI и `error`/`problem.message` остаются
исходными строками. Дополнительное предупреждение Kimi о смене профиля сохраняется
в английском подтверждении вместе с общим предупреждением прямого SSH.
