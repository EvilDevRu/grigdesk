# Гармошка проектов SSH

Каждый проект каталога SSH — группа в общем списке, без собственной карточки.
В заголовке находятся имя проекта, число серверов словами, зелёная метка живых
сессий с числом и `UiDisclosureButton` с направлением раскрытия. Кнопка управляет
`aria-expanded` и ссылается через `aria-controls` на существующий список серверов;
подпись для чтения с экрана называет и серверы, и живые сессии. Заголовок закрепляется
у верхней кромки каталога, пока группа прокручивается.

Без поискового запроса открыта максимум одна группа. При первом показе раскрывается
проект выбранного сервера; открытие другого заголовка закрывает прежний. Повторное
нажатие закрывает текущую группу. Скрытие списка идёт через `v-show`: строки,
выбранное подключение и серверные сессии не пересоздаются. Само раскрытие проекта
не выбирает сервер и не очищает одноразовый пароль.

Выбор другой связи раскрывает её проект. Обновление объектов реестра при прежнем
идентификаторе связи сохраняет ручное сворачивание. Если открытый проект исчез,
раскрывается проект выбранного сервера либо первой доступной связи. Блок выбранного
сервера стоит вне групп и явно называет проект, когда строка скрыта свёрнутой группой
или поиском; у раскрытого проекта имя не дублируется над карточкой.

Поиск показывает раскрытыми все подходящие проекты, чтобы совпадения не скрывались
за заголовками. На время поиска заголовки недоступны для сворачивания, причина есть
в подсказке. Очистка запроса возвращает прежнее ручное раскрытие; выбор другого
сервера во время поиска становится новым раскрытием после его очистки.

Состояние раскрытия локально экземпляру панели и не записывается в профиль или
на сервер. Проверки `tests/web/ssh-panel.component.test.js` покрывают один открытый
проект, сохранность входа, поиск, обновление реестра, удаление раскрытого проекта,
подписи счётчиков и пустые состояния каталога.
