# Гармошка проектов SSH

Сохранённые серверы сгруппированы по проектам. Заголовок показывает число серверов
словами и число живых сессий. `UiDisclosureButton` использует `aria-expanded`
и `aria-controls`. Заголовок закрепляется у верхней кромки при прокрутке.

Без запроса открыта максимум одна группа. При первом наполнении открывается
проект активного сервера либо первая группа каталога. Открытие другого заголовка
закрывает прежний. Повторное нажатие сворачивает текущий проект. Обновление
сохраняет ручное сворачивание и открытый проект, пока тот есть в каталоге.
Если открытая группа исчезла, раскрывается проект текущей сессии либо первый
доступный проект. После создания сервера раскрывается его проект.

Поиск учитывает проект, метку, роль, адрес, пользователя и порт. Все совпавшие
группы раскрываются, пока введён запрос. Очистка возвращает прежнее раскрытие.
Промах предлагает сбросить поиск. Навигация в каталоге сохраняет текущий терминал.

Строка показывает метку, роль, адрес и следующее действие. Для нескольких живых
сессий в строке показано их число. Вход, переход к единственной сессии и выбор
одной из нескольких описаны в [рабочей области SSH](ssh-design.md).
Раскрытие групп хранится локально экземпляру панели.
