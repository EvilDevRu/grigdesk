# Интерфейс внутри пакета приложения

Web собирается в отдельный каталог, рабочий web/dist не меняется. В пакет Electron входят
resources/ui/release.json, api-version.json и все файлы интерфейса. Manifest содержит размеры
и SHA-256 файлов; перед запуском проверяются целостность и отсутствие посторонних файлов/ссылок.
Повреждение при старте вызывает фатальный диалог «Установка повреждена» и выход.

Труба читает пакет напрямую, публикация интерфейса в папку сервера не нужна. Каждая машина
получает свой loopback-origin. Статика не меняется от перезапуска/пересборки сервера, запросы
API и shots передаются машине. Маршруты приложения находятся в hash. Неизвестные ресурсы
возвращают 404. Настройки используют тот же origin, cookie и пакет, что главное окно.

Обновление интерфейса происходит установкой следующей сборки. Ctrl+R, Ctrl+Shift+R, F5 и
одиночный Alt перехватываются главным процессом; редактирование, масштаб и Ctrl+Alt+S сохранены.
PWA и service worker отсутствуют. Проверки: ui-release, pipe-server, client.e2e, packaged-smoke.

Сервер не обслуживает /ui/<id>/, web/dist или их assets даже с сессией. Корневой HTML
объясняет «GrigDesk открывается в приложении». API, закрытые shots и страницы включённых
плагинов сохраняются; встроенный UI обращается к ним через собственную трубу.
Android build использует тот же helper и manifest в client/src/main/assets/ui.

Ctrl+R, Ctrl+Shift+R и F5 перехватываются в главном процессе для главного окна
и обычных дочерних окон. Команда reload отсутствует в меню. Одиночный Alt
также заблокирован. Редактирование, масштаб и Ctrl+Alt+S сохраняются. Восстановление
сессии после 401 может программно перезагрузить тот же закреплённый документ.

Отсутствующие ресурсы возвращают 404, а не SPA HTML со статусом 200. Ошибка lazy-панели
показывает сообщение; ожидание ограничено 30 секундами. Ошибка навигации выводится общим
toast. PWA, service worker и кнопки обновления документа отсутствуют; Notification и
Screen Wake Lock находятся в `stores/device.js`. Исторические SW-события остаются только
в схеме старых диагностических журналов.

Проверки: `ui-release.test.js`, `ui-releases.test.js`, `menu.test.js`,
`settings-contract.test.js`, `runtime-config.test.js`; сквозной UI-E01 в
`tests/desktop/e2e/window.e2e.mjs` заменяет рабочий dist после открытия окна, загружает
разделы и встроенные панели, проверяет настройки и нативные клавиши.
