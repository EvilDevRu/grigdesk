# Язык интерфейса

Язык относится к устройству. Браузер хранит предпочтение
в своём профиле, оболочка компьютера — в настройках установки. Смена машины не должна
менять язык установки. Язык интерфейса отделён от языка диктовки и расшифровки видео.

## Чистое ядро

`shared/i18n/core.ts` принимает реестр и каталоги явно. `MessageRef` хранит ключ,
копию именованных параметров и необязательную запасную подпись. Строка остаётся данными:
совпадение с ключом каталога не превращает её в перевод. При отсутствии перевода
используется русский каталог, затем явная запасная подпись.

Проверенные серверные оповещения плагинов могут содержать буквальный LocalizedText:
frozen `{localized:{ru,en}}`, созданный через localizedText после decoder.
resolveText выбирает en для английского языка, иначе ru; snapshotText копирует обе
замороженные структуры. Ключи и фигурные скобки внутри этих строк не интерпретируются.
MessageParams сохраняет прежний тип и не принимает LocalizedText как вложенный параметр.

`formats.ts` использует Intl для дат, относительного времени, чисел и окончаний.
Размеры сохраняют порог 1024: КБ округляются до целой единицы, МБ и ГБ — до десятых. Чистые помощники при
пропущенной локали сохраняют русский язык прежних вызовов.

## Выбор на устройстве

`services/locale.ts` принадлежит UI: он не импортирует Pinia, shell или storage.
Product-код обращается к нему через публичную границу `ui.ts`. Адаптер `web/src/shared/uiLocale.ts`
подключается явно до mount и читает `grigdesk-ui-language`. Отсутствующее или неверное
предпочтение означает системный язык. Русская система выбирает русский, остальные —
английский. До явного bootstrap сервис сохраняет русский язык прямых вызовов.

Выбор языка — немедленная операция вне staged-ресурсов настроек. «Отмена» не откатывает
принятый язык; остальные неприменённые поля сохраняют прежний контракт. На время записи
control занят, старые shell-снимки не откатывают оптимистичный выбор. Отказ записи
возвращает предыдущий язык и показывает ошибку. Storage listener не пишет обратно.

## Собственные сообщения

Общие диалоги, тосты и история принимают строку или descriptor. Host разрешает descriptor
при показе; параметры копируются до постановки в очередь. Смена языка не повторяет
callback, не теряет ввод prompt и не отправляет системное уведомление заново.
Сессия настроек маскирует секреты в обоих буквальных переводах до публикации снимка.

Desktop хранит необязательное `uiLanguage` рядом с профилями и размерами окна. Локальный
POST `/__shell/locale` принимает только preference; настройки профилей остаются в том же
объекте сохранения. Снимок locale доступен без подключённой машины. Выбор читается до
заставки; её упакованные assets не меняются. Main выставляет текст и язык документа и
ждёт два кадра перед показом.

## Правило новых текстов

В переводимой области собственная надпись задаётся ключом общего каталога сразу для
всех зарегистрированных языков. Параметры и plural-ветвь `other` входят в контракт.
Третий язык добавляется переводами и регистрацией каталога, без условий в экранах.
Публичные метаданные проецируются по стабильным ID; DTO, enum values и пользовательский
текст не переписываются. Ответы агентов и переписка остаются исходными. Пользовательское руководство имеет полный
RU/EN корпус и следует активному uiLocale, включая system и откат неудачной записи.
ID открытой статьи сохраняется. Техническая документация остаётся русской; подробности —
[справка в окне и на сайте](help.md).

## Оболочка и собственные метаданные

В общей верхней панели нет кнопки поиска разделов и команд. Настройки открываются
собственной кнопкой; поиск настроек и локальные поиски разделов сохраняются.
Состав действий описан в [контракте топбара](topbar-actions.md).
Порядок системной навигации определяется исходными подписями и ID до перевода. Заводское
имя локальной машины переводится при показе; сохранённый профиль не переписывается.

Чистые сессии и адаптеры принимают необязательный `LocaleSource`: строку либо порт текущего
значения. Без аргумента действует прежний русский контракт. UI передаёт свой readonly ref,
поэтому переключение языка не пересоздаёт адаптер, не грузит ресурс и не стирает намерения.
`web/src/shared/uiLocalePort.ts` передаёт тот же readonly источник продуктовым stores, которые
читаются напрямую из Node; UI-компоненты и Vue он не импортирует.

## Проверка новых надписей

`npm --prefix web run check:i18n` включён в общий `check:ui`. Область задаёт
`web/scripts/i18n-scope.json`: каталоги проверяются целиком, новые файлы внутри переведённых
папок попадают под проверку автоматически. Сторож разбирает template и TS/JS AST, сравнивает
ключи и параметры всех зарегистрированных языков, требует `other` для plural и отвергает
видимые русские и английские литералы. Комментарии, ID, команды и внешние данные сохраняются.
Технические подписи перечислены с причиной; ключи зарегистрированных таблиц проверяются явно.

Область проверки включает собственные помощники каркаса и настроек,
сообщения desktop и нативные UI-вызовы :client. Вычисляемый ключ требует явной таблицы
выражений; метаданные системных плагинов, полей исполнителей, категорий и слотов сверяются
со стабильными ID исходной декларации. Смена русской подписи при прежнем ID также требует
обновления каталога. Заголовки секций, строковые ветви выражений, ошибки и доступные подписи
проверяются наравне с обычным текстом шаблона.

Справочники `messageLabels` сохраняют объект и разрешают перевод при чтении. Подписи
клавиш, состояний обновления и диагностики поэтому не застывают при импорте. Известные
подписи ресурсов лимитов и подтверждения проецируются по ID; их action/payload, значения
и внешние данные сохраняются. Открытое подтверждение читает текущую проекцию control.
