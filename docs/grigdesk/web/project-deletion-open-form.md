# Удаление открытого паспорта

Стор проектов хранит известные удалённые регистрации в реактивном `deletedIds`.
Страница сверяет с ним текущий адрес даже до получения первого паспорта. Удаление
во время загрузки сразу возвращает к каталогу; поздний ответ и повторный переход
по удалённому адресу не возвращают выбранный проект и не оставляют вечную загрузку.
Подтверждённое отсутствие в свежем каталоге использует тот же сброс регистрации.
Сведения об удалении не требуют отдельной подписки: действует общий поток SSE.

Если загруженный паспорт содержал несохранённые правки, его снимок и текст остаются
для чтения с сообщением об удалении. Источник репозиториев определяется сохранённым
`profile.pathsSource`: блокировка записи не превращает паспортные пути в профильные.
Пояснение о миграции показывается только для путей из профиля фабрики.

Общий вид описан в [карточке проекта](projects-design.md), серверный контракт —
в [проектах и репозиториях](../guide/projects.md).
