# Высота поля и кнопки добавления тега

В `TaskModal.vue` поле названия тега и кнопка «Добавить» используют обычный размер
UI-kit и общий токен `--control-height`. В рабочей области на компьютере это 32 px,
на сенсорном экране — 44 px. Правило одинаково для диалога и отдельного окна задачи.

Компактный размер кнопки использует `--toolbar-control-h`: на компьютере это 28 px,
поэтому рядом с обычным полем он не подходит. Дополнительные локальные стили не нужны.
