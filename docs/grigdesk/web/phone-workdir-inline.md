# Выбор рабочей папки внутри настроек чата

До 600 CSS px `ChatSession` включает встроенный режим `ChatWorkdir`. Нажатие текущей
папки раскрывает поиск, проекты, недавние папки и ручной ввод непосредственно под
кнопкой в настройках чата. Повторное нажатие сворачивает выбор. Дополнительный
модальный слой и затемнение для каталога не создаются; настройки остаются доступными.

`ChatWorkdirPicker` выбирает только поверхность для общего содержимого: обычную секцию
в настройках телефона либо прежний `UiDialog` на компьютере. Каталог, проверка пути,
предпросмотр и серверный переход принадлежат одному `ChatWorkdir` и не дублируются.
При раскрытии клавиатура не появляется, кнопка «По пути» явно фокусирует поле ввода.

Закрытие настроек, смена чата или переход на компьютер сворачивают каталог.
Следующий вход начинает выбор заново; прежний экземпляр кнопки и компонента сохраняется.
У встроенной кнопки есть `aria-expanded` и связь `aria-controls` с секцией; объявление
всплывающего диалога остаётся только у настольного режима.

Если переход требует сжатия или сброса памяти, остаётся отдельное явное подтверждение.
Его слой `confirm` расположен над настройками. Обычный выбор, не требующий решения
о памяти, не открывает это окно.

Составная проверка `chat-in-turn.component.test.js` использует настоящие компоненты:
один модальный слой при раскрытом каталоге, ручной ввод, применение папки, сворачивание,
повторное открытие настроек и возврат к настольному диалогу. Натурная визуальная
приёмка Android WebView выполняется отдельно.
