# Сессия черновика настроек

`features/settings/session.ts` создаёт независимую от Vue сессию с внедрёнными
ресурсными адаптерами из `contracts.ts`. Страница регистрирует полный перечень полей
ресурса с адресами, включая поля других страниц, и
вызывает `load` при первом посещении. Повторное посещение использует тот же baseline.
До загрузки ресурс нельзя редактировать.

`setField` и `unsetField` меняют только Map намерений, не вызывают запись и не
меняют работающие настройки. `null`, `false`, `0`, пустая строка и отсутствие override
различаются. Сброс доступен только ресурсам с `supportsUnset`. Возврат к baseline
снимает dirty. Объекты и массивы копируются, объекты сравниваются независимо от
порядка свойств.
Непрозрачный ключ сохраняется собственным свойством записи, даже если его имя
совпадает с `__proto__` или другим именем из `Object.prototype`.

Новый полный снимок обновляет untouched-поля и сохраняет dirty-ввод с ошибками.
Изменение dirty-поля относительно baseline создаёт конфликт. «Взять актуальное»
принимает внешний baseline и снимает намерение; «Оставить мой вариант» принимает
baseline и сохраняет намерение. Удалённое поле схемы с dirty остаётся адресуемым и
недоступным для записи до явного `discardField`.

Валидаторы принадлежат адаптерам, поэтому проверка всего dirty-набора не зависит
от наличия страницы в DOM. Ошибки содержат ресурс, ключ и отдельный `FieldAddress`.
`getSnapshot` возвращает копии публичного состояния; секретное поле содержит только
признак наличия ввода. Значения секретов и функции адаптеров остаются в замыкании.
Прямое чтение `getValue`/`getIntent` предназначено только для контрола и адаптера;
секрет из него нельзя переносить в Pinia state, storage, журнал или UI-контекст.

`begin` очищает прежнее открытие и меняет sessionId. `dispose` отменяет чтения и
освобождает ресурсы и временные секреты. Даже проигнорировавший AbortSignal ответ
не может обновить новую сессию. `discard` не делает HTTP и принимает последний
внешний снимок, отбрасывая только неприменённое.

Проверки: `tests/web/settings-session.test.js` (DR01–DR10 и граничные случаи).
