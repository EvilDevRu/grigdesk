# Права каталога доказательств браузера

`browser_evidence_invalid` при успешном JPEG может возникать до записи файла.
`createBrowserEvidence` проверяет каждый каталог между artifacts root и папкой run.
Общая папка `browser-workspace`, созданная прежними снимками с правами umask 0775,
не проходила требование приватных родителей 0700. Формат ответа, порядок команд
и квота в этом случае не являлись причиной отказа.

Проверка `E03` в `tests/server/browser-evidence.test.mts` воспроизводит прежнюю
папку 0775 и отказ до исправления. Теперь собственные каталоги закрываются до 0700
до подготовки evidence root и записи JPEG. Проверка владельца и типа выполняется
по открытому дескриптору с `O_DIRECTORY | O_NOFOLLOW`; symlink и чужой владелец
по-прежнему запрещены. Путь run и квоты 32 файла / 64 MiB не меняются.

Ошибка санитайзера ответа имеет другой код — `browser_result_invalid`;
превышение квоты — `browser_evidence_limit`. Их нельзя подменять общим диагнозом
«не работает screenshot».
