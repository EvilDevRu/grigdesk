# Оформление установки трекера из Git

`TrackerInstallDialog.vue` использует `UiDialog` шириной до 640 px с рабочим режимом
`data-ui-workspace`. Шапка с закрытием и подвал остаются вне прокрутки. На телефоне
сохраняется общая полноэкранная оболочка; действия переносятся на отдельную строку.

Выбор источника содержит карточки каталога с названием и доменом и вариант «Свой».
У официального источника поля репозитория нет; «Свой» открывает ввод ссылки на GitHub.
Общий `UiButton` отмечает выбор через `pressed`. Карточки идут тремя колонками,
на телефоне — двумя, при ширине до 360 px — одной.

При открытии выбирается сохранённый адрес или первый официальный источник. При отказе
или пустом каталоге доступен собственный URL. Его черновик сохраняется при переключении.
Выбор меняет только источник, без сетевых операций и подстановки тега; прежние найденные
версии сбрасываются. Кнопка поиска версий стоит рядом с тегом, найденные версии показываются
в отдельном подписанном селекте без автоматической подготовки.

Проверка пакета и применение используют акцентное действие в подвале. Подготовка недоступна
без адреса и тега. Для активного задания источник заблокирован, чтобы ввод не расходился
с проверенным пакетом. Закрытие окна по-прежнему не отменяет серверное задание;
отмена запускается отдельным действием. Подробности протокола — в
[общем установщике драйверов](../plugins/driver-installer-policy.md).

Задание, проверенный пакет и установленные драйверы оформлены отдельными блоками.
Полные SHA и digest доступны в сведениях пакета, изменения раскрываются общим
`UiDisclosureButton`, а ошибки и предупреждения используют `UiInlineMessage`.
Обновление, откат и подтверждаемое удаление сохраняют прежние HTTP-действия.

Серверные ошибки, включая отказ допуска браузерной сессии, показываются как получены.
Оформление не меняет авторизацию и не подменяет этот отказ сообщением об успехе.
