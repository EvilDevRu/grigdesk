# Оформление установки трекера из Git

`TrackerInstallDialog.vue` — оболочка шагов конкретной операции с драйвером.
Подробные переходы, отмена и восстановление описаны в [мастере трекеров](tracker-install-wizard.md).

Используется общий `UiDialog` с рабочим режимом `data-ui-workspace`. Заголовок и подвал
остаются вне прокрутки. На телефоне сохраняется общая полноэкранная оболочка;
вместо полной шкалы показывается номер текущего шага.

Начальное ожидание соответствует точке входа: добавление трекера резервирует
двухколоночный выбор источников (одна колонка на телефоне), восстановление операции — область её сведений.
При добавлении сразу видны заголовок и шаг источника, а переходы недоступны до
завершения начального чтения. Полученный серверный job сохраняет приоритет.
Пояснение под заголовком остаётся при чтении источников и версий, чтобы
содержимое не сдвигалось после ответа. При выполнении операции его заменяет статус этапа.
Ожидание версий резервирует одно подписанное поле с подсказкой. Если раскрыт ручной
ввод, он остаётся на месте с малым inline-индикатором. Ход подготовки и применения
сохраняет настоящий индикатор этапа и серверный прогресс.

Выбор источника, версии, подтверждение и результат отображаются последовательно.
Карточки источников содержат имя и репозиторий; собственный вариант открывает
обычное текстовое поле для HTTPS, SSH или локального Git-адреса. Контролы приходят
только через `ui.ts`; карточки не заводят собственный skin управляющих элементов.

Каталог установленных драйверов принадлежит настройкам и не дублируется в мастере.
Выбор версии, откат и восстановление запускаются из параметров выбранного драйвера.
Выход из мастера возвращает в эти настройки. Полные SHA и digest скрыты в сведениях.
Общее предупреждение о серверном коде не дублирует одноимённую серверную строку
и скрыто для официальных встроенных репозиториев.

Серверные ошибки, включая отказ допуска браузерной сессии, показываются как получены.
Оформление не меняет авторизацию и не подменяет этот отказ сообщением об успехе.
