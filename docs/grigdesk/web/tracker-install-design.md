# Оформление установки трекера из Git

`TrackerInstallDialog.vue` — единая оболочка списка трекеров и мастера операций.
Подробные переходы, отмена и восстановление описаны в [мастере трекеров](tracker-install-wizard.md).

Используется общий `UiDialog` с рабочим режимом `data-ui-workspace`. Заголовок и подвал
остаются вне прокрутки. На телефоне сохраняется общая полноэкранная оболочка;
вместо полной шкалы показывается номер текущего шага.

Выбор источника, версии, подтверждение и результат отображаются последовательно.
Карточки источников содержат имя и репозиторий; собственный вариант открывает
обычное текстовое поле для HTTPS, SSH или локального Git-адреса. Контролы приходят
только через `ui.ts`; карточки не заводят собственный skin управляющих элементов.

Список установленных пакетов показывается отдельно от мастера. Названия приходят
из runtime, неизвестное имя заменяется id. Основное действие карточки — настройка;
дополнительные операции раскрываются отдельно. Полные SHA и digest скрыты в сведениях.
Общее предупреждение о серверном коде не дублирует одноимённую серверную строку.

Серверные ошибки, включая отказ допуска браузерной сессии, показываются как получены.
Оформление не меняет авторизацию и не подменяет этот отказ сообщением об успехе.
