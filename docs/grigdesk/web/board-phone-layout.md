# Визуальная иерархия доски на телефоне

До 600 CSS px общий список «Мои задачи» и внешние «Контроль и поручения» располагаются
на страницах со свайпом; собственные задачи находятся в основном списке. Вкладки со счётчиками обозначают выбранный раздел,
внутри списка задачи отделяются линиями. Поля и строки используют одну ось текста
с отступом 12 px; названия задач — основной текст 15 px, метаданные — 12 px.
В шапке явно подписана «Доска», время обновления остаётся вторичным.
Рабочая область использует `--surface`, как содержимое задачи; общая служебная шапка
остаётся на `--topbar`, время обновления находится под списками.

Каждая внутренняя задача начинается с названия. Полный номер, проект и источник
собраны в метастроку; оценки и состояние конвейера используют общие колонки строки.
Между строками есть разделитель; выбранная задача открывается прежним ui.openTask.
Номера и исходные DTO сохранены; общий порядок учитывает даты создания.

Оформление названия задаёт общий control доски через UI-каталог,
структуру групп и строк — scoped CSS BoardView. Поля и действия сохраняют
общую сенсорную геометрию.

Проверки: phone-density.component.test.js проверяет вычисленный CSS секций и desktop;
grigdesk-tasks-board.component.test.js — отдельные название/номер/проект, состояние
конвейера и единственное открытие. Визуальный результат принимается по кадру
актуальной сборки отдельно от unit-проверок.

На телефоне эти группы размещены на отдельных [страницах со свайпом](board-phone-pages.md).
Название текущего раздела задаёт общий переключатель со счётчиками; повторный заголовок
внутри страницы скрыт. Содержимое страниц остаётся в единственном экземпляре.
