# Размер переключателя

`UiSegmentedControl` принимает `size="default"` (по умолчанию) или `size="compact"`,
как `UiButton`. Тип и нормализация общие: `UiActionSize` и `normalizeActionSize`.
Неизвестное значение даёт `default`. Размер выводится в `data-size` группы и передаётся
кнопкам, созданным из `options`; CSS группы также охватывает кнопки обычного слота.

У `compact` высота берётся из `--toolbar-control-h`: 28 px на компьютере и 44 px на
сенсорном экране. Рамка внутренняя, без внешнего padding, поэтому это высота всей группы.
Шрифт — 12 px, поля кнопок по бокам — 7 px. Многострочные подписи могут увеличить высоту.
Обычный размер сохраняет прежнюю геометрию.

Выбор рабочей папки использует `size="compact"`. Его контекст `workdir-mode` определяет
ширину по подписям, равные доли двух кнопок и акцент активного режима; высоту и размер
шрифта задаёт общий компактный режим. На узком экране ширина ограничена диалогом.

Проверки: `tests/web/ui-segmented-control.component.test.js` проверяет нормализацию,
смену размера, выбор и блокировку вариантов. Геометрия проверяется настоящим браузером
для desktop, touch и увеличенного текста, включая обычные slot-кнопки диалога.
