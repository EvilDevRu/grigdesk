# Проверки границ интерфейса перед выпуском

`web test` последовательно проверяет TypeScript, порядок SFC, UI-границу, стили,
читаемость и поведение компонентов. Ошибка любого сторожа останавливает выпуск.
Component- и browser-файлы выполняются через сторож памяти: два одновременно,
heap 1024 МиБ на Node worker и 4096 МиБ общего RSS с дочерними браузерами.

Продуктовые компоненты получают controls и переводчик через `ui.ts`. Чистые stores
и сетевые адаптеры, доступные напрямую из Node, используют `localeTranslator`
с `uiLocalePort`: текущий язык читается без подключения Vue-компонентов.

## Адресные исключения событий

`HelpBrowser` делегирует переходы по настоящим ссылкам внутри Markdown через capture
на `article`. `UiToastCard` тем же способом подавляет ложный click после свайпа закрытия.
Это обработка событий дочерних controls; сама карточка не становится кнопкой.
Сторож учитывает точные файл, тег, событие и имя обработчика.

`SystemResourcesButton` и строка выбора машины в `ConnectionsView` используют
семантический `UiPressable` с доступным именем. Они входят в явный список составных
кнопок, рядом с пунктами навигации и строками каталогов.

`StageDocument.title` — заголовок документа, потребляемый prop компонента. Он входит
в список заголовочных props сторожа; подсказки кнопок используют `v-tooltip`.

## Контекстное оформление

Рамка и тень `UiVideo` просмотрщика находятся в общем слое по
`data-context='media-viewer'`, отступ раскрытия SSH — по `ssh-project-toggle`.
Доменная разметка сохраняет компоновку. Размер SVG значка машины задан атрибутом,
а текст заголовка подключения телефона оформляется внутри собственной content-обёртки.
Правила доски ограничены `ui-workspace`, глобальные keyframes имеют префикс `ui-`.

Контрактные тесты сторожей проверяют production-граф, запрещённые controls и native title,
а component-тесты — ссылки справки, свайп тоста, выбор групп и восстановление оболочки.

Baseline стилей сверяется с фактической описью: удаление локального оформления удаляет
и прежнее исключение. Перед выпуском убраны 13 уже отсутствующих правил Inbox и Diff;
новых записей в baseline нет.
