# Компактные controls чата на сенсорном экране

При `data-ui-touch` селекты задачи, модели и режима в шапке чата имеют видимую высоту
32 px. Прозрачное расширение по 6 px сверху и снизу сохраняет площадку касания 44 px.
На desktop прежняя высота 28 px. Телефонные настройки по-прежнему открываются отдельным
экраном; выборы и текущие значения не пересоздаются.

`UiSelect` передаёт свой `compact` в `data-density` всплывающей панели. Компактный каталог
с группами предпочитает 360×420 px вместо 360×520 px, оставаясь в пределах viewport.
Шрифт и поиск используют [единый стиль всех меню](select-menu-style.md): высота поиска
28 px на desktop и 44 px на touch; строки сохраняют сенсорный минимум 44 px. Значки
групп выглядят как кнопки 32 px с полями по 6 px и площадкой 44 px.
Кнопка очистки поиска центрируется по полю.

Поиск списка чатов использует контекст `chat-list-search`: 32 px, поверхность `--surface-2`
и общее малое скругление. У контейнера шапки есть вертикальные поля 8 px, на телефоне —
6 px с [высотой по содержимому](phone-chat-search-density.md). Создание чата
и меню строки на touch имеют видимый размер 32 px и расширенную площадку 44 px.
Фон действий берётся из `--row-bg`, поэтому совпадает с обычной, выбранной и ожидающей
строкой. На desktop прежние быстрые действия сохраняются.

Прикрепление файла показывает только скрепку в цвет микрофона. Это прежний `UiFilePicker`:
сохраняются системный выбор, несколько файлов, disabled и состояние загрузки.
Подпись доступна экранным дикторам и через tooltip; [геометрия прикрепления](chat-attachment-control.md).

Skin принадлежит общим `actions.css` и `fields.css`, структура шапки списка — `ChatList`.
Компонентные проверки проверяют выбор, поиск, действия, вложения и диктовку; computed CSS
не подтверждает геометрию и работу аппаратного микрофона в Android WebView.
