# Справка в окне и на сайте

Компоновка и визуальные роли описаны в [оформлении справки](help-design.md).

Маршрут `#/help/:id?` показывает `overview` без ID и отдельное состояние неизвестной статьи.
Шаблон входит в WEB_LOG_ROUTES; имя параметра `id` соответствует normalizeRoute.
HelpBrowser содержит оглавление по разделам, поиск и существующий RichMarkdown.
Оглавление живёт на отдельной подложке с закреплённым поиском и своей прокруткой;
текущая статья отмечается акцентом и `aria-current="page"`. Ссылки каталога — `UiActionLink`
с общим контекстом `help-index-item`; Ctrl/Cmd-нажатие сохраняет штатное открытие ссылки.
Шапка чтения содержит раздел статьи и действия, не уезжает вместе с текстом.
Ширина текста ограничена 800 px; заголовки, абзацы и списки имеют отдельную типографику.
На ширине reader больше 1100 px справа виден список H2 «На этой странице»;
он использует те же уникальные якоря, что ссылки статей, и не содержит raw HTML.
Ссылки разрешаются только среди статей корпуса либо в явные внешние HTTPS-адреса.
Переход между статьями возвращает чтение к первому заголовку, фрагмент — к выбранному якорю.
Изображений в первой редакции нет; код, таблицы и Mermaid использует общий renderer.

HelpWorkspace получает весь ограниченный корпус через apiClient с выбранного сервера.
Для загрузки достаточно действующего входа и связи с выбранным сервером. Пустой
`clientScope` штатен на новой установке и не блокирует чтение; его смена по-прежнему
отменяет прежнее поколение запроса, как смена владельца или машины.
Загрузчик сбрасывает прежний текст перед новым чтением и игнорирует ответы старого поколения.
Смена auth scope/машины, logout, языка и закрытие компонента отменяют его результат.
Watch синхронно читает публичный uiLocale: RU использует прежний `/api/help`, EN —
`/api/help?locale=en`. ID/история сохраняются, настройки не перемонтируются.
Обычный 404 старого сервера предлагает обновление; EN + 404/help_locale_unavailable
запускает одно запасное RU-чтение того же поколения. Legacy 200/RU принимается для EN.
Оба варианта показывают пояснение, поиск идёт по фактическому корпусу. Отмена проверяется
до запасного запроса и применения; сеть, 401, повреждение и прочие несовпадения — ошибка/повтор. Справка не
кешируется в localStorage и не создаёт отдельный поток SSE.

Кнопка справки рядом с настройками и F1 открывают HelpDialog поверх текущего экрана.
Кнопка использует общий `UiIconButton` с контекстом `topbar-action`, SVG-знак `UiHelpIcon`
из публичной границы UI и переводимую подсказку. Этот же знак используется в `UiField`;
размер кнопки и иконки в шапке задаёт общая таблица действий, а не текстовый символ `?`.
Контекст настроек берётся из pageId, прочие разделы — из закрытой карты shared/help/helpLinks.ts.
Форма и её черновики остаются смонтированными. bindHelpAccess в App синхронно закрывает
диалог при потере авторизации или смене владельца/машины. Новая авторизация сама не открывает его.
Native F1 обрабатывается до страницы; фиксированное событие доставляется проверенному main
frame тем же механизмом, что настройки. Surface-документы глобальный F1 не получают.
Диалог передаёт `embedded` через HelpWorkspace: у reader нет повторной шапки «Справка».
Страница и самостоятельный сайт сохраняют собственную общую шапку `UiPaneHeader`.

Ошибки чтения истории и подготовки хода открывают troubleshooting без повтора запроса.
«Объяснить с агентом» создаёт отдельный разговор с ID, ссылкой, версией и фактической bundle.locale статьи в черновике.
Прежний draft остаётся; модельный ход не отправляется. Действие доступно после загрузки чатов.

На ширине reader до 700 px оглавление сворачивается общей кнопкой `UiDisclosureButton`.
Выбор статьи закрывает каталог и возвращает фокус в чтение; поиск сохраняется при выборе.
Открытый каталог ограничен по высоте, статья остаётся доступной ниже него.
Адаптив зависит от CSS-контейнера reader, поэтому работает и в узкой панели на широком экране.
Таблицы/код имеют внутреннюю прокрутку.
RU/EN корпуса содержат локальные статьи, разделы и поисковые слова. Ссылка на сайт
передаёт активную локаль устройства; старый якорь может вернуть к началу той же статьи.

Самостоятельный `web/help/HelpSite.vue` использует тот же HelpBrowser и готовые корпуса.
Его единственный selector выбирает system/ru/en: валидный URL locale важнее
`grigdesk-help-language`, затем system (ru-* → ru, иначе en). Выбор сразу обновляет UI,
URL и preference без изменения hash. Ошибка storage не мешает URL/system. Он читает
только соседние help.json/help.en.json без cookies, с прежним таймаутом; stores приложения, auth, API и SSE не подключает.
Hash сохраняет адрес статьи. latest.html/latest.js читают индекс своего канала
`api/releases/v1/<канал>.json` и переходят на каталог его версии с сохранением search и hash. Подпись latest использует то же правило выбора языка.
Ошибка канала остаётся видимой.

Компонентные проверки покрывают Markdown, поиск, состояния, draft, F1, смену доступа,
уникальные якоря, выделение статьи, сохранение поиска и сворачивание оглавления.
Фокус/Escape двух одновременно открытых диалогов и реальное окно проверяются отдельно после
установки новой версии, инструментом браузера выданного окна.
