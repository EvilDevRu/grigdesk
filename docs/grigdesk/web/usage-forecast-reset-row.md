# Прогноз лимитов без строки «Сброс окна»

Во всплывашке исполнителя блок «Прогноз» показывает темп расхода и оценку, хватит ли
лимита до следующего сброса. Строка «Сброс окна» с датой прошлого события, его
предполагаемой причиной и переходом процентов удалена. Подпись «сбросил вендор» была
выводом по замерам, без подтверждения причины провайдером.

Срок следующего сброса остаётся под полосой лимита. `ProviderUsageForecast.vue` строит
ряды только по прогнозам полос; у стоящих полос остаётся общий ряд «расход стоит».
Форматтер старого события и getter выбора последнего сброса удалены из клиента.

Сервер продолжает обнаруживать сбросы, сохранять их журнал и отдавать поле `resets`
в API/SSE. Расчёт текущего темпа по-прежнему берёт замеры после сброса, если он попал
в окно усреднения. Удаление строки не меняет расчёт прогноза и данные на диске.

Основной контракт: [прогноз лимитов](../guide/usage-forecast.md).
