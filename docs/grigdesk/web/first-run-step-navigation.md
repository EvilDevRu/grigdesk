# Переходы по шкале мастера

Первые три пункта боковой шкалы — общие `UiPressable`. Доступный пункт выбирается
мышью или клавиатурой. Текущий пункт сохраняет `aria-current="step"`; будущие шаги
четыре–шесть остаются недоступными.

Вернуться можно на любой предыдущий основной шаг, в том числе с итога сразу к ИИ.
Переход к проекту с ИИ разрешён без готового исполнителя и в этом случае сохраняет
`aiSkipped=true`. Шаг «Где работают задачи» открывается и с пустым проектом: режим
можно выбрать заранее, без создания паспорта. Пока проекта нет, вместо «Далее»
показана кнопка «Добавьте проект», возвращающая ко второму шагу. Выбранный режим
сохраняется, а незавершённый проект не получает галочку готовности.

Выбор пункта использует серверные `/back` и `/advance`, без локальной подмены
шага. Для просмотра режима до заполнения проекта `/advance` получает
`previewWorkspace=true`; завершение прохода всё ещё требует созданного проекта.
Перед первым переходом мастер ждёт последнего autosave. Если нужно пройти
несколько шагов, действия заблокированы до конца всей последовательности. Ошибка
останавливает переход на последнем подтверждённом шаге. Возврат и повторный проход
не создают копию паспорта и не меняют исходный раздел приложения.

Проверки `onboarding-navigation.component.test.js` используют настоящий host, store,
controls и HTTP-сервис с отдельными данными. `onboarding-actions.component.test.js`
также проверяет «Пропустить шаг → Проект → Пропустить настройку» при задержанном
autosave: незавершённые ответы сохраняются, пустой паспорт не создаётся, окно закрывается.
