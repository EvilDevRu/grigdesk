# Панель ввода чата без отдельной карточки

В `ChatSession.vue` оболочка `.composer` прозрачная, без рамки и скругления.
Textarea с ролью `chat-composer` также прозрачный. Вся нижняя панель `.cs-input`
имеет подложку `--surface-2` на полную ширину: текст, скрепка, микрофон и отправка
лежат на одной полосе. У оболочки нет внутреннего отступа, панель задаёт 8 px
по вертикали и `--chat-gutter` по горизонтали. Общий `--field-background`
обычных полей не меняется. Каркас `ChatLoadingPreview` использует ту же геометрию.

Верхняя линия `.cs-input` отделяет ввод от ленты и остаётся опорой разделителя
высоты. При фокусе внутри панели линия получает `--line-2`. Вложенный textarea
не рисует собственный focus-ring: замкнутая рамка не появляется и при наборе.
Кнопки сохраняют фокус из общего UI-kit.

На компьютере действия расположены рядом с текстом у нижнего края; на телефоне
до 600 px — отдельным нижним рядом. Вложения, диктовка и отправка используют
прежние controls и обработчики.

Без ручной высоты textarea использует `field-sizing: content`: растёт по строкам
и переносам по ширине, сжимается при удалении и очистке текста. Минимум — 36 px,
потолок на компьютере — 46vh, на телефоне — `min(160px, 28vh)`; дальше появляется
внутренняя прокрутка. В браузере без `field-sizing` остаётся обычный textarea
с теми же границами и ручным изменением высоты на компьютере.

Сохранённая ручная высота устройства имеет приоритет на компьютере. Двойной клик
по разделителю удаляет её и возвращает рост по тексту. На телефоне сохранённая
высота не применяется.
