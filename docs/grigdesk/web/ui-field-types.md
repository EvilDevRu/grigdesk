# Типы полей через публичную границу UI

Типы UI-kit, включая `UiFieldHandle`, доступны product-коду через
`web/src/ui.ts`. Импорт `type` подчиняется той же границе, что и импорт
компонента: прямой путь к `web/src/types/uiFields.ts` обходит фасад.

`BoardView.vue` и `views/chat/ChatList.vue` используют публичный реэкспорт
`UiFieldHandle`. Он сохраняет исходный контракт `el`, `focus` и необязательный
`select`; импорт типа не добавляет зависимости при выполнении.

У `UiSelect` метод `focus` фокусирует видимую кнопку, `el` возвращает скрытый
native select для совместимости, а `triggerEl` — видимую кнопку. Эти два элемента
имеют разные id; label и aria-состояния внешнего `UiField` связаны с кнопкой.
Подробности — [общий выбор](select-control.md).

Границу проверяют `npm --prefix web run check:ui` и
`tests/web/ui-dependency-boundary.test.js`; доступность типа проверяет
`npm --prefix web run typecheck`.

`UiField` поддерживает необязательный `help` с кратким пояснением и примером.
При его наличии рядом с label появляется `UiIconButton` со знаком вопроса и `UiTooltip`.
SVG-знак берётся из общего `UiHelpIcon`, также доступного через публичную границу UI.
Кнопка справки находится вне label; label по-прежнему связан с полем, а hint/error
сохраняют свой `aria-describedby`. Доступное имя справки включает название поля.
Наведение, клавиатурный фокус и касание показывают пояснение; Escape закрывает его.
Без `help` структура прежних полей сохраняется. В «Маршрутах» справка объясняет название,
тип, технические ключи, разведку и создание переходов.

Текст `hint` под полем использует общий цвет `--ink-low`, немного приглушённый
относительно подписи. Рабочий режим `ui-workspace` сохраняет этот цвет; размер и
межстрочный интервал задаёт его общий слой. Ошибка по-прежнему использует `--bad`.
