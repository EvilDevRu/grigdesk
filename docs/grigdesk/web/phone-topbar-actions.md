# Машины и мастер в шапке телефона

До 600 CSS px основной топбар содержит выбор машины, историю оповещений,
мастер настройки и настройки приложения. Выбор машины использует прежний
`ConnectionButton` с компактной иконкой и индикатором связи, без стрелки; имя и состояние
доступны через доступную подпись и подсказку. Кнопка существует при наличии
оболочки приложения и остаётся доступной без выбранной машины и при offline.

Мастер использует прежний `UiIconButton` с контекстом `topbar-action`, между
колоколом и настройками. Он доступен при активном подключении и выбранной машине,
запрашивает общий модал без смены маршрута. Сенсорная площадка остаётся общей.

Эти два действия находятся непосредственно в шапке и не перемещаются при открытии
«Разделов». Подключение телефона, контекст экрана и остальные системные действия
сохраняют перенос через `PhoneShellPortal`. Вторая полоса сохраняет постоянные
host-узлы CPU/RAM и исполнителей.

`phone-topbar.component.test.js` проверяет выбор машины в шапке без профиля,
открытие меню машин, единственную кнопку мастера, запрос ручного запуска без
перехода и отсутствие дубликатов в каталоге. При потере активного подключения
мастер скрывается, кнопка машин сохраняется.
