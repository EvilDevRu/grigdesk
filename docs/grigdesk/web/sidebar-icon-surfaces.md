# Подложки иконок боковых панелей

Левая навигация оболочки (`data-ui-shell-nav`) и правая рейка инструментов
(`data-context="tool-rail-item"`) используют общий скин в
`web/src/styles/components/actions.css`.

Подложки плоские, с прямыми углами и без теней. Площадка иконки занимает всю доступную
ширину панели до её разделительной линии: боковых полей у обеих реек нет. У неактивной
иконки фон прозрачный; при наведении используется прежний `--surface`. Активный пункт
сохраняет прежнюю подложку из 14% `--accent` и прозрачного фона. Значок сохраняет
акцентный цвет, в том числе при наведении на выбранный пункт.

Высота площадки берётся из общего `--app-nav-row-h`: 30 px на desktop и 44 px при
`data-ui-touch`. Размер рисунка в обеих рейках — 16 × 16 px: одинаковый для файловых
иконок плагинов и внутренних SVG, включая резервный знак при ошибке картинки.
Иконки остаются по центру, строка счётчика не меняется. Клавиатурный
фокус обозначается контрастной обводкой внутри площадки, чтобы края панели её не
обрезали. Внутренняя навигация плагина «Код» использует собственный контекст и этот
скин не наследует.
