# Подложки иконок боковых панелей

Левая навигация оболочки (`data-ui-shell-nav`) и правая рейка инструментов
(`data-context="tool-rail-item"`) используют общий скин в
`web/src/styles/components/actions.css`.

Неактивные встроенные иконки используют общий приглушённый цвет `--ink-mid`
(`#8a93a3`), как «Входящие» и кнопка инструментов. Точка входа `web/src/main.ts`
импортирует `styles/index.css` перед модулями компонентов: объявление порядка слоёв
должно предшествовать их scoped-стилям с `@layer components`. Иначе слой `base`
получает больший приоритет и его `a { color: inherit }` делает ссылки навигации
почти белыми, в отличие от соседних файловых иконок и кнопок.

Площадка иконки занимает всю ширину рейки. Внутри неё рисуется отдельная скруглённая
подложка 28 × 28 px на desktop и 36 × 36 px на сенсорном экране. На сенсорной
площадке остаётся по 4 px вокруг подложки. Наведённый пункт получает `--surface`,
активный использует общий с полосой проектов фон из 30% `--accent`. При касании,
удержании и наведении активный цвет остаётся в пределах подложки.

Высота площадки берётся из общего `--app-nav-row-h`: 30 px на desktop и 44 px при
`data-ui-touch`. Размер рисунка в обеих рейках — 16 × 16 px: одинаковый для файловых
иконок плагинов и внутренних SVG, включая резервный знак при ошибке картинки.
Иконки остаются по центру, строка счётчика не меняется. Клавиатурный
фокус обозначается контрастной обводкой внутри площадки, чтобы края панели её не
обрезали. Нижняя телефонная навигация использует собственное оформление.
На Android внутренняя рейка «Кода» использует ту же подложку 36 × 36 px
и поле 4 px, а выбранный раздел берёт состояние из `aria-pressed`.
Рисунок 19 × 19 px и счётчик изменений сохраняют свои размеры.

На Android у обеих реек и [полосы проектов](chat-project-navigation.md) скрыты
ползунки прокрутки, включая WebView с собственными полосами Chromium.
При появлении клавиатуры иконки сохраняют горизонтальную ось. Свайп по рейке
прокручивает пункты, которые не поместились по высоте.
