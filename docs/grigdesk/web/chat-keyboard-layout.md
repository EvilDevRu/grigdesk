# Раскладка клавиатуры у поля чата

В desktop-документе `ChatKeyboardLayout.vue` показывает монохромную клавишу с
обозначением текущей раскладки (`EN`, `RU` и другие). Она находится над скрепкой,
слева от первой строки текста. Рамка и буквы используют один `currentColor`.
Значок не переключает раскладку и не забирает клавиатурный фокус; доступное имя
и обычная подсказка переведены на русский и английский.

Обычная веб-страница, экран до 600 px и устройство с основным сенсорным указателем
не показывают индикатор и не запускают опрос. При видимом индикаторе минимум
высоты поля — 64 px: значок и скрепка не перекрываются. Рост поля по тексту и
сохранённая ручная высота продолжают работать. Разделитель использует тот же
минимум для перетаскивания, клавиши Home и доступных ARIA-границ.

Источник — `GET /__shell/keyboard-layout` защищённой локальной трубы окна.
Раскладка относится к компьютеру с окном, независимо от выбранного удалённого
сервера. Сервер приложения и язык интерфейса не используются для её определения.

Адаптер поддерживает Linux X11: системный `python3 -I` через стандартный `ctypes`
читает `XkbGetState` и `_XKB_RULES_NAMES` из `libX11.so.6`. Он не меняет раскладку,
не перехватывает и не записывает клавиши. Процесс ограничен 1200 мс и 4096 байтами
вывода; параллельные чтения объединяются, успешный снимок кешируется на 250 мс,
ошибка — на 5 секунд. Python и libX11 должны быть доступны в системе окна.

Опрос выполняется раз в 500 мс после завершения предыдущего чтения, только пока
документ виден и имеет фокус. Возврат в окно вызывает немедленное чтение. Скрытие,
потеря фокуса, переход в мобильный размер и размонтирование отменяют запрос;
поздний ответ игнорируется. При неизвестном состоянии показывается `?`, без
предположений по последнему символу или языку ОС.

Wayland (включая Xwayland), Windows и macOS пока возвращают неизвестное состояние.
Отсутствие Python, отказ X11 и старая версия оболочки также дают `?`.
`navigator.keyboard.getLayoutMap()` не используется: Chromium может выбирать
ASCII-совместимую карту вместо активной группы
([реализация Chromium](https://chromium.googlesource.com/chromium/src/+/master/ui/gtk/gtk_ui.cc)).

Проверки: `tests/desktop/keyboard-layout.test.js`,
`tests/web/keyboard-layout.test.js`, `tests/web/chat-keyboard-layout.component.test.js`.
Сценарий разделителя и регрессии отправки — `tests/web/chat-in-turn.component.test.js`.
Изменение native-порта требует пересборки и повторного открытия desktop-приложения.
