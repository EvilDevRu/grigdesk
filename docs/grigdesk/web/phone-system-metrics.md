# Прямой вход в ресурсы по CPU/RAM

CPU и RAM во второй полосе телефона — единая SystemResourcesButton.
Первое нажатие сразу открывает [диалог устройств](resources-dialog.md),
без сводки «Состояние системы» и второй кнопки внутри неё.
Высота полосы и control остаётся 30 px, unknown/stale и метка тревоги сохранены.
Отдельной кнопки состояния в «Разделах» нет.

PhoneStatusBar задаёт два host-узла: метрики слева и исполнители справа.
Кнопка и диалог читают тот же system store, без собственных запросов и таймеров.
Desktop использует ту же кнопку и тот же диалог, поэтому переход также занимает
одно нажатие. Оставшиеся телефонные индикаторы перенесены в меню разделов;
блок конвейеров на телефоне не выводится.

phone-topbar.component.test.js проверяет одно открытие на 390/800/1280 px,
отсутствие промежуточного popup, закрытие и возврат фокуса, лимиты исполнителя
и доступ к подключениям без выбранной машины.
