# Кнопки тостов на телефоне и планшете

Общий `UiToastHost` использует компактные кнопки с переносом длинной подписи.
На обычном экране минимальная высота — 28 px. В корневом режиме `data-ui-touch`
площадка нажатия остаётся не меньше 44 px, а фон и рамка рисуются отдельным
псевдоэлементом с отступами по 8 px: однострочная плашка имеет высоту 28 px.
Многострочная подпись увеличивает кнопку и плашку по содержимому.

Обычный переход «Открыть…» из `alertUser` имеет нейтральный тон. Контурные действия
получают мягкий фон поверхности вместо тёмной подложки поля ввода; нейтральная
подпись использует основной цвет текста. Явные смысловые тоны и варианты действий
сохраняются: например, разрешение и отказ остаются разными по цвету.

Закрытие тоста на сенсорном экране занимает 44×44 px в углу, а заголовок оставляет
для него место. Перенос кнопок, клавиатурный фокус и пауза таймера при фокусе
принадлежат общей карточке `UiToastCard` внутри хоста. Текст заголовка и тела
не заходит под крестик SVG. Режим уменьшенного движения сохраняется.

Карточки имеют спокойную поверхность и цветную левую кромку. Закрытие свайпом
и совместная пауза по касанию, наведению и фокусу описаны в [контракте жеста](toast-swipe.md).

Планшет и телефон полного Android-клиента используют общий `web/src`. Изменение
исходников или серверного `web/dist` не обновляет встроенную копию интерфейса
в установленном APK: требуется пересборка и обновление пакета приложения.
