# Вторичные детали доски на телефоне

До 600 CSS px шестерёнка настроек рядом с названием доски и время обновления под списками
используют `--board-secondary-color`: 70% `--ink-low` и 30% рабочего фона `--surface`.
Кнопка создания и названия задач сохраняют основной
акцент. Цвет не задаётся через opacity: значок остаётся активным, его сенсорная площадка
и фокусная рамка сохраняются. При наведении или клавиатурном фокусе шестерёнка переходит
в `--ink-mid`.

Skin кнопки задаёт actions.css по `data-board-tracker-settings`, цвет статуса — patterns.css
по роли в телефонном подвале. У статуса нет общего класса muted и локального цвета SFC:
utilities и стили без слоя перекрывают components независимо от специфичности.
Настольный цвет не меняется.
