# Рабочие экраны на телефоне

До 600 px оболочка отдаёт содержимому всю ширину. Боковая рейка заменяется нижней
навигацией «Доска / Чаты / Конвейер / Разделы». Последняя кнопка открывает общий
`UiDialog mobileSheet` с основными разделами и доступными плагинами, включая инструменты
дока. Повторяющиеся адреса убираются. Выбор закрывает меню; badges берутся из того же
снимка, что и у настольной рейки. Внешние страницы плагинов внутри iframe принадлежат
самим плагинам.

Нижняя навигация занимает отдельную строку сетки высотой 60 px. `content` и постоянный
`ToolHost` используют вторую строку: меню не накрывает их содержимое. При отсутствии
машины нижней навигации нет. Начиная с 601 px действует прежняя боковая рейка, с 900 px
доступен док. Настройки размеров desktop сохраняются.

В телефоне шапка чата показывает название, возврат и кнопку «Настройки чата». Задача,
папка, модель, режим и усилие раскрываются по кнопке; предупреждение о модели остаётся
видимым и при закрытых настройках. Скрытие через CSS сохраняет экземпляры controls.
Список чатов получает строки не ниже 72 px и более крупные названия. Ответы читаются
шрифтом 15 px, поле сообщения — 16 px. Поле занимает свой ряд на всю ширину, вложения,
диктовка и отправка находятся ниже. На телефоне ручное изменение высоты поля скрыто,
сохранённая desktop-высота не применяется, текст прокручивается внутри поля.

На доске название и метаданные задачи занимают широкую колонку, избранное — отдельную
площадку справа, оценка и время — строки ниже. Список прокручивается вместе со страницей,
без второго ограниченного окна. Порция содержит 40 задач, следующие доступны кнопкой
«Показать ещё». Поиск и сворачиваемые фильтры сохраняют прежние действия. Сводка дня
остаётся над списком; показатели раскрываются отдельно.

Общие отступы страниц уменьшаются до 10 px, шапки переносят действия. Мобильные диалоги
используют `--app-viewport-height`, установленную из `visualViewport`, поэтому клавиатура
уменьшает также область настроек, карточек и нижних панелей. В узком Docker-представлении
состояние соединения получает собственный ряд и не сталкивается с заголовком.

Регрессии: `client-phone.test.js` проверяет полную ширину, меню, переходы с сохранением
черновика, раскрытие настроек, геометрию доски, фильтры и загрузку следующей порции.
Вместе с `client-responsive.test.js` он проверяет увеличенный текст,
разрешения, вопросы, карточку задачи и уменьшение видимой области. Это проверки Chromium
с синтетическими API; системная клавиатура и нативные диалоги требуют устройства.

Для Android нужен новый APK: полный клиент загружает встроенный пакет UI,
поэтому обновление `web/dist` на сервере не меняет уже установленное приложение.
