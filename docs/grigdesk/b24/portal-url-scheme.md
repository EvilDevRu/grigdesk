# Схема адреса портала

Форма настроек распознаёт адрес по строковому несекретному полю с подписью
`{ key: 'core.trackerPortal' }`. Правило общее для драйверов, без проверки их id.

После выхода из поля адрес без схемы получает `https://`; внешние пробелы убираются.
Например, `portal.example.test:8443/path` становится
`https://portal.example.test:8443/path`, а `//portal.example.test` —
`https://portal.example.test`. Явно указанная схема, включая `http://`, сохраняется.
Пустое поле остаётся пустым, остальные реквизиты не преобразуются.

Та же нормализация применяется к видимым полям перед проверкой соединения и
сохранением всех посещённых черновиков. Поэтому отправка без события blur тоже
передаёт полный адрес. Это подготовка ввода в интерфейсе; HTTP-клиенты передают
адрес со схемой самостоятельно.

Реализация: `normalizeTrackerPortalInput` в `shared/trackers/settingsValidation.ts`
и `web/src/views/board/TrackerSettingsDialog.vue`.
Проверки: `tests/web/tracker-portal-url.component.test.js`.
