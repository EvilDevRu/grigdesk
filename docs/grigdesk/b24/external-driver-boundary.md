# Граница внешних драйверов

Код облачного и кастомного Битрикс24 находится в отдельных пакетах `grigdesk-b24`
и `grigdesk-b24-discript`. Ядро не регистрирует встроенных трекеров. Идентификатор `own` остаётся зарезервированным.
Сканер и установщик
не резервируют имена поставщиков; пакет проходит обычную проверку и выбор на доске.

Имена пакетов владельца: `grigdesk-b24` — стоковый REST, `grigdesk-b24-discript` — кастомный портал, `grigdesk-jira` — Jira Cloud.

Каждый пакет содержит манифест, точку входа, приватный клиент и снимок типов контракта.
Статусные подписи и семантику возвращает пакет в taskDetail/dashboard; мобильный
фасад читает statusText/statusLabel без интерпретации числовых кодов поставщика.

Необязательный host.fetch позволяет передать общий HTTP-транспорт в изолированных
проверках. При обычном запуске пакет использует системный fetch. Сервер не выбирает
транспорт или статусный алгоритм по id драйвера.
