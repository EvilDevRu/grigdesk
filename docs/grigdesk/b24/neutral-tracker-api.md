# Нейтральный API трекера

HTTP-модуль `server/src/modules/tracker/index.ts` обслуживает `/api/tracker/*`.
Старые адреса удалены осознанно: сервер и клиенты обновляются вместе, алиасов нет.
Обработчики сохраняют прежние операции, статусы HTTP, тела и коды ошибок.
Полка, избранное и просмотренное используют тот же новый префикс в собственных модулях.

Web и desktop через общий web обращаются к новым путям. Исходники команды в `b24/src/`
тоже используют `/api/tracker/*`; имя и публикация собранного бинарника — отдельный шаг выпуска.
При отсутствии бинарника в diff задачи агент не переименовывает установленный пользовательский CLI.

Мобильный фасад находится в `server/src/lib/mobile/facade/tracker.ts` и публикует
`/api/mobile/v1/tracker/tasks` с карточкой и действиями запуска. Телефонная копия схемы
и клиент обновляются одновременно. Старому APK нужна пересборка. Историческая baseline
схема в тестах остаётся неизменной; старые и новые имена схем сопоставляются только проверкой.

Флаг подключения собственных задач называется `trackerConfigured`.
Внутренние имена портов, сериализатора чтения и разбора task id нейтральны.
Внешнюю ссылку задачи возвращает драйвер через sourceUrl; ядро не собирает URL портала.

Поля прежних сохранённых снимков и правил, значения source и коды отказов сохраняют
формат данных. Их переименование потребовало бы отдельного решения о совместимости.
Текст и ключи изменённых надписей доски добавлены одновременно в русскую и английскую локали.
