# Порядок проверки реквизитов

Сохранение настроек нескольких драйверов сначала проверяет все схемы и форматы
видимых токенов. Только после этого начинаются временные сессии `testAuth`.
Ошибка у следующего драйвера не запускает сетевую пробу предыдущего, даже если
его новый токен имеет допустимый формат.

После успешных проб сервер повторно проверяет revision, записывает реквизиты
и выбор доски, затем публикует SSE. Отказ локальной проверки не импортирует
первый драйвер и сохраняет прежние credentials, revision и события.

Проверка: `tests/server/tracker-token-validation.test.js`.
