# Удаление встроенной доски

Решение человека в задаче №2: встроенная доска удаляется без миграции задач.
Исторический JSON сохраняется архивом в артефактах задачи; живые данные и внешние личные
метки не переносятся. Идентификатор драйвера `own` зарезервирован навсегда: установщик,
проверка пакета, настройки и HTTP не позволяют внешнему пакету занять его.

Удаление встроенной доски не меняет default машины: Discript CRM остаётся основной доской.
GrigTasks выбирается явно в форме создания либо адресной командой CLI. Недоступная цель
не заменяется другой доской.

Ошибка обязательного проекта GrigTasks исправляется отдельной соседней задачей внешнего
драйвера, которую заводит человек. В задаче №2 код драйвера не меняется; ядро не добавляет
автоматический проект или проверку по имени поставщика. В Б24 отсутствие группы допустимо,
в GrigTasks проект обязателен. Исправленный текст ошибки здесь не обещается.

Старые клиенты могут получить 404 от снятых own-маршрутов; требуется обновить интерфейс.
Старая ссылка `grigdesk:<id>` показывает «Задача не найдена» и не обращается к внешней доске.
