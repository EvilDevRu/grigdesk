# Каталог внешних драйверов трекера

`config.driversDir` выбирается непустой переменной `GRIGDESK_DRIVERS_DIR`.
Без неё сервер сканирует `<data>/drivers`, где `<data>` — текущая папка данных GrigDesk.
В `.env` задаётся абсолютный путь; пустое значение сохраняет умолчание.
Имя также учтено в `HOST_ENV_SUFFIXES` для диагностики прежнего префикса переменных.

Реестр читает пакеты из `<driversDir>/<id>`, git-установщик пишет в тот же каталог.
Own регистрируется ядром и не требует пакета на диске. Переопределение каталога
не переносит установленные пакеты и не меняет расположение журнала установки,
настроек выбора и credentials в `state/` папки данных.

Пути исходных пакетов для тестов задаются отдельно: `GRIGDESK_STOCK_DRIVER_DIR`
и `GRIGDESK_CUSTOM_DRIVER_DIR`. Они не переопределяют каталог действующего сервера;
подготовка описана в [контракте тестовых пакетов](../testing/tracker-driver-package.md).
