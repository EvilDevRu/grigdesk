# Маршрутизация чтения карточки задачи

Задача №93032. Собственная запись может иметь только 12-значный номер
`100000000000..999999999999`. Номера вне этого диапазона клиент читает сразу через
прежний `GET /api/tracker/task/:id`: штатное открытие Б24 не создаёт own 404 в консоли
и журнале окна, работает со старым сервером и не зависит от собственного хранилища.

Внутри диапазона `stores/tasks.ts` сначала читает `GET /api/grigdesk-tasks/:id`.
Диапазон выбирает порядок чтения, но собственный источник подтверждает только
проверенная запись с `source:'grigdesk'` и тем же номером. Только точный
`ApiError(404, {error:'grigdesk_task_not_found'})` разрешает запрос Б24.
Другой 404, отказ доступа, сеть, ошибка хранилища или неверный DTO прекращают чтение
и сохраняют прежний кеш. Оба запроса используют исходный транспорт устройства.

Для собственных задач и задач Б24 внутри этого диапазона сначала обновляют сервер,
затем окно: старый сервер не знает нового маршрута и его точного кода отсутствия.
Кеш деталей и мутации Б24 сохраняют прежний контракт.

Явный источник ссылки отменяет диапазонный fallback: собственный читает только own,
внешний требует совпадения текущего source. [Контракт ссылок](../web/task-source-links.md).
