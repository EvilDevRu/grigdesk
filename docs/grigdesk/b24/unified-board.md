# Общая доска внешних задач

«Мои задачи» объединяет списки включённых внешних трекеров. Встроенной доски GrigDesk,
её карточки и переключателя источника нет. Без подключений показан баннер настройки.
Ошибка каталога отличается от пустого набора подключений.

По умолчанию задачи упорядочены по дате создания: известные даты по убыванию, равные
даты и строки без даты сохраняют порядок снимка. Фильтры источников и проекта сочетаются
через AND с поиском, избранным, новыми и триажем. Явный пустой набор источников остаётся
пустым. При чтении прежних настроек удаляется только встроенный источник `grigdesk`.

Внешние снимки читаются независимо. Ошибка одной доски сохраняет её последний успешный
снимок с причиной недоступности; смена реквизитов закрывает затронутую ветку до проверки
владельца. Сводка, графики и виджеты относятся к доске по умолчанию. Чип называет драйвер
и показывает его PNG либо монограмму. Пагинация, связанные роли и свайп телефона сохранены.

## Идентичность

Источник — `<driverId>@<accountScope>`. Scope вычисляет сервер по прежней нормализации
адреса и пользователя; общий ключ — JSON-пара `[source,id]`. Две доски с одинаковым номером
имеют разные карточки, кеши и личные метки. Старый vendor-маркер `b24` не подтверждает
принадлежность конвейеру. Identity и dashboard захватываются в одном контексте; после
ожидания поколение проверяется повторно.

Числовая оценка и массовая постановка на анализ относятся к доске по умолчанию.
Чужой явный источник отвергается до очереди. Запуск конвейера подтверждает внешний
источник по immutable тикету и dispatch identity через `FactoryTaskSources`.

## Создание и личное состояние

Форма предлагает только включённые доступные доски с capability `create`. Доступный default
выбран при открытии; иначе человек выбирает доску явно. Создание не меняет default.
Смена доски отменяет прежний GET, сбрасывает проект и сохраняет название с описанием.
Проекты запрашиваются только при capability `projects`. Повторный submit блокируется;
неизвестный исход POST не повторяется автоматически.

Личные метки используют `/api/tracker[/<driverId>]/task-favorites`, `task-seen`, `task-shelf`.
Файлы, хеши, revisions, baseline и очереди внешних меток сохранены. Scope нельзя передать
из клиента. Контекст повторно проверяется внутри очереди записи. Старые own-маршруты
возвращают 404; исторические scopes не переносятся и не очищаются.
