# Отсутствующая задача в ошибке внешнего драйвера

Внешний пакет содержит собственный снимок типов и конструктор `TrackerError`.
Его ошибка не проходит `instanceof TrackerError` ядра даже при том же контракте 1.

Фасад нормализует сочетание `code: task_not_found`, `status: 404` и строкового
`message` в ошибку ядра. Общий HTTP wrap мутаций сохраняет 404 вместо прежнего 502.
Прочие неизвестные ошибки сохраняют прежнюю обработку. GET-обработчики не менялись.

Проверки `STOCK-CARD` в `tests/server/tracker-stock.test.js` используют настоящий
внешний пакет и отказ портала для всех новых операций карточки и возобновления.
