# Удаление внешней задачи и завершение Битрикс24

`TrackerCapabilities.delete` обязателен в общем контракте и по умолчанию равен `false`.
Метод драйвера `deleteTask(id)` возвращает `{ ok: boolean }`. Старые пакеты без флага
не получают удаление; legacy metadata fallback также оставляет его выключенным.

`DELETE /api/tracker/task/:id` вызывает метод выбранного внешнего драйвера и отвечает
`{ ok: true }`. Фасад отклоняет неподдерживаемое действие до вызова драйвера: HTTP 400,
`error: unsupported`. Заголовок `x-grigdesk-tracker-generation` проверяется до мутации.

Карточка показывает «Удалить» только для внешней задачи с `delete: true`. Общий
`confirmDialog` предупреждает о необратимости. Отмена не вызывает сеть. Подтверждение
принадлежит исходным задаче и поколению подключения; после успешного удаления кеш
задачи очищается, доска обновляется, карточка закрывается.

Пакет `grigdesk-b24` версии 0.1.4 включает удаление через `tasks.task.delete` и принимает
только `result.task === true`. Завершение сначала использует `tasks.task.complete`.
При HTTP 400/403 с кодом `0` либо описанием «Действие над задачей не разрешено» он один
раз вызывает `tasks.task.update` с `fields.STATUS=5`. Другие ошибки запасной запрос
не запускают. Если запасной запрос не подтверждён, возвращается исходная ошибка
завершения с обычным скрытием секретов. Комментарии эта доработка не меняет.
