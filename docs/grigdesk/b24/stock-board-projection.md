# Строковые подписи доски из объектов REST

Облачный Битрикс24 возвращает `group` и `responsible` в задачах как объекты.
У задачи вне проекта `group` может быть пустым объектом `{}`. Это происходит
даже при явно ограниченном `select` в `tasks.task.list`.

`BoardTask` ожидает строковые подписи `group` и `responsible`. Если пакет
передаёт REST-объекты без преобразования, HTTP dashboard отвечает 200, но
`decodeBoardDashboard` отклоняет снимок. В интерфейсе появляется общий отказ
«Не удалось обновить задачи трекера», а в подробностях — «Сервер вернул
некорректный снимок доски».

Пакет `grigdesk-b24` преобразует оба поля только при чтении списков задач:
берёт строковый `name`, сохраняет уже готовую строку либо выдаёт пустую строку
при отсутствии имени. Все роли dashboard и задачи на приёмке используют одну
проекцию. `taskDetail` сохраняет исходный объект исполнителя для карточки.

Регресс проверяют `tests/dashboard.test.js` пакета и проверки ядра
`tests/server/tracker-stock.test.js`, `tests/web/tracker-stock-legacy-dto.test.js`.
Обновление исходников пакета не заменяет уже загруженную установленную версию:
в рабочем приложении нужно штатно установить обновление и вручную перезапустить
сервер после завершения хода агента.
