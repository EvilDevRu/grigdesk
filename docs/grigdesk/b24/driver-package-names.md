# Имена пакетов владельца

`grigdesk-b24` — стоковый REST-драйвер Битрикс24; `grigdesk-b24-discript` — драйвер
кастомного портала. В `driver.json` и `package.json` обоих пакетов версия — `0.1.0`.

Имя папки пакета совпадает с `driver.json.id` и id возвращаемого экземпляра драйвера.
Реестр проверяет это соответствие; специальных исключений для пакетов владельца нет.

Интеграционные проверки по умолчанию читают эти папки в соседнем `grigdesk-desk-drivers`.
Явные пути задаются через `GRIGDESK_STOCK_DRIVER_DIR` и `GRIGDESK_CUSTOM_DRIVER_DIR`;
подробности — [подготовка пакетов для проверок](../testing/tracker-driver-package.md).
