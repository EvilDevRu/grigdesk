# Статусы и приоритет обработки

Коды портала: `2` — ждёт выполнения, `3` — выполняется, `4` — сдана и ждёт приёмки
постановщиком, `5` — завершена, `6` — отложена, `7` — отклонена. Для статуса 4 действие
принадлежит постановщику, а не ответственному.

`describeStatus` вычисляет, требуется ли действие текущего пользователя. Триаж сортирует
задачи так: требующие действия → ручной `custom_priority` → горящие → просроченные →
обычный приоритет по убыванию → дедлайн → ID.
