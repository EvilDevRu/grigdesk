# Действия карточки до загрузки деталей

Обычный числовой номер, включая 12-значный, читается через внешний трекер.
Явный источник требует подтверждённой identity. Историческая ссылка `grigdesk:<id>`
показывает отсутствие задачи до загрузки деталей и любых личных или триажных эффектов.
[Контракт ссылок](../web/task-source-links.md) сохраняет отличие от default.

Внешние действия ограничены capabilities активного драйвера. Metadata загружается
независимо от details; таймер, завершение и оценка сохраняют прежнюю готовность при
медленном ответе. Запуск и редактирование требуют загруженных деталей.

Ошибка metadata не разрешает возможности. Legacy fallback применяется только при 404
самого metadata endpoint. Смена трекера отменяет старые details и незавершённые формы;
после подтверждения новой ревизии карточка [перечитывает детали](tracker-ui-refresh.md).
