# Действия карточки до загрузки деталей

Задача №93032. Номер вне собственного 12-значного диапазона подтверждает источник Б24
до ответа портала, как и [маршрутизация чтения](task-source-routing.md).
Карточка сразу показывает подпись Битрикс24, таймер, завершение, избранное и комментарии.
Оценка остаётся доступной при медленном ответе или ошибке загрузки деталей:
сервер получает постановку самостоятельно. Запуск конвейера по-прежнему требует деталей.

Кнопка «Изменить» появляется после загрузки деталей задачи Б24: форма редактирования
заполняется их значениями. Известный источник сам по себе не делает форму доступной.

Внутри собственного диапазона источник подтверждает загруженная запись. До подтверждения
портальные действия и оценка недоступны. У собственной задачи действия Б24 и личные
эффекты скрыты; ошибка чтения не разрешает считать её задачей портала.

Задача №100000000000: известный источник дополнительно ограничен capabilities активного
драйвера. Metadata загружается независимо от details, поэтому известные custom-действия
сохраняют прежнюю готовность, а stock не показывает таймер, комментарии, editing и renew.
Ошибка metadata не разрешает возможности; legacy fallback применяется только при HTTP 404
самого metadata endpoint. Смена трекера отменяет старые details и незавершённые формы.
После подтверждения новой ревизии metadata открытая карточка
[перечитывает детали](tracker-ui-refresh.md) без ручного обновления.
