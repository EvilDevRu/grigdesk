# Явное сохранение нового пункта

В карточке кнопка «+ Добавить пункт» открывает форму внутри выбранного списка.
Она сама ничего не записывает. «Сохранить» или Enter отправляет текущий текст через
прежний `addChecklistItem` с `parentId`; для сохранения не нужен следующий пункт.

Успешное чтение обновлённых деталей закрывает форму и показывает пункт в списке
вместе с подтверждением сохранения. Ошибка сохраняет введённый текст. «Отмена» и Esc
закрывают форму без запроса; во время записи сохранение и отмена заблокированы.
Вложенный пункт использует те же действия и показывает название своего родителя.
Удаление родителя закрывает его форму и освобождает добавление в остальных списках.

Общее поведение и семантика корневых списков описаны в
[полях карточки задачи](task-card-fields.md#ux-чек-листов-и-тегов).
