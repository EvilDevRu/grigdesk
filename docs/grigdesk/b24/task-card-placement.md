# Размещение карточки задачи

Desktop с capability `windows` открывает каждую задачу
отдельным немодальным окном GrigDesk. Повтор поднимает тот же документ без reload и потери
набранного текста; другая задача из карточки получает своё окно. Лимита числа окон нет.
Браузер, Android и старый desktop без этой возможности используют прежний диалог и «Назад».
Все обычные входы остаются на общем `ui.openTask`.

Для задач Б24 общий TaskModal сохраняет редактирование, комментарии, таймер, избранное, полку, диф,
диктовку и запуск конвейера. Переход к конвейеру сначала подтверждается главным окном.
Черновики между окнами не переносятся и после закрытия не восстанавливаются. «Код», чат,
Monaco и терминалы остаются в главном документе. Заголовок и описание чужими событиями
не заменяются; они обновляются собственным действием и новым открытием после закрытия.

Доска, таймеры, избранное, просмотренное и полка обновляются между окнами без ожидания
периодического опроса. Открытие карточки Б24 гасит «Новая» на доске. Только главное окно
держит постоянные потоки и опрашивает dashboard. Карточка перечитывает dashboard после
своего действия, остальные получают снимок без новых обращений к порталу.

Полка surface пассивна до первой загрузки и после повторного входа: принимает entries,
сохраняет pending/error и подтверждённые мутации, но не гидратирует детали задач вне доски
или без проекта и не отправляет оповещений. `acknowledge` передаёт закрытый сигнал главному
окну: оно обновляет запись со своим полным наблюдением оценки и конвейера. Огонёк от ворот
конвейера гаснет при открытии карточки. Main и page сохраняют прежнюю полку с гидратацией
и уведомлениями. Формат серверного личного состояния не меняется.

Подробности: [окна карточек](../web/feature-windows.md),
[снимки и события](../web/window-relay.md).

Собственные задачи используют тот же вход и размещение; их доступные действия описаны
в [контракте задач GrigDesk](grigdesk-tasks.md).
