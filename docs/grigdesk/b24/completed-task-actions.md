# Действия завершённой задачи в карточке

Контракт уточнён в задаче №93002. Полный клиент, включая телефон, использует один
компонент `web/src/views/TaskModal.vue`.

У задачи со статусом `5` («Завершена») основное действие — «↺ Возобновить».
Общий диалог подтверждает действие; после согласия вызывается
`POST /api/tracker/task/:id/renew`. Отказ ничего не меняет. Ошибка отображается в карточке
тем же способом, что и ошибки остальных действий.

После возобновления доска и детали перечитываются принудительно. Ответ renew не является
карточкой задачи: новый статус берётся из отдельного GET деталей, без подстановки кода
«В работе». Когда задача перестаёт быть завершённой, возвращается «✓ Завершить».

«▶ Начать учёт» у завершённой задачи недоступна с подсказкой
«Задача завершена — сначала возобновите её». Уже идущий учёт можно остановить.
Остальные статусы сохраняют прежние действия.

Успешные complete и renew помечают кеш деталей этой задачи устаревшим до обновления
доски. Повторное открытие не возвращает прежний статус из кеша на 30 секунд, а название
задачи остаётся в кеше для списка конвейера. После complete карточка закрывается, после
renew остаётся открытой со свежими деталями.
