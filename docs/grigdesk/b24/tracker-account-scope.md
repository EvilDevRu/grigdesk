# Нейтральная идентичность и личный scope

`TrackerIdentity` содержит `baseUrl: string` и `userId: string`. Фасад принимает также
числовой id пакета прежней версии и приводит его к строке. Имена портов избранного,
просмотренного, полки, Inbox и фабрики относятся к трекеру, а не поставщику.

`trackerAccountScope` находится в `server/src/lib/trackers/accountScope.ts`.
Ключ по-прежнему равен sha256 от нормализованного адреса подключения, нулевого байта
и обрезанной по краям строки userId. Нормализация URL не менялась. Для числового id
хеш совпадает побитово; прежние записи favorites/seen/shelf читаются без миграции.

Проверка id теперь требует непустую строку: внешний драйвер может вернуть собственный
строковый идентификатор. Пустая идентичность по-прежнему закрывает доступ к личным данным.
Регресс проверяет чтение старых файлов всеми тремя сервисами после переоткрытия store.
Имена полей DTO задач и числовая статусная семантика поставщика этим изменением не затрагиваются.
