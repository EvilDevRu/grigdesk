# Декларативные настройки драйвера

Схема поддерживает string, number, boolean и select. Для select обязателен непустой
массив options: уникальные непустые строки value и подписи TrackerLabel. UI использует
общий UiSelect; HTTP принимает только одно из объявленных значений.

Секретное поле string допускает `format: 'api-token'`. Остальным типам и обычной строке
этот формат запрещён. Для прежних пакетов сохраняется распознавание общей подписи
`core.trackerAccessToken`. Формат и проверка подлинности перед записью описаны в
[валидации токенов](token-validation.md).

Поля string и number допускают visibleIf: { field, equals }. Видимость определяется
строгим равенством текущего значения строке equals. Boolean и select всегда видимы.
Скрытые поля сохраняют черновик до переключения режима, но не рендерятся и не входят
в POST настроек. Пустой секрет по прежнему сохраняет ранее записанное значение.

Стоковый пакет версии 0.1.1 требует явный authMode: token либо password. При обновлении
с прежней версии пользователь выбирает режим в настройках. Ядро не выбирает транспорт
по имени пакета и передаёт реквизиты только драйверу.
