# Корневой узел чек-листа Б24

Живой интерфейс Б24 трактует корневой узел с `parentId: 0` как именованный список:
«Чек-лист 1», «Чек-лист 2». У заголовка списка нет чекбокса. Отмечаемые пункты
живут внутри списка, а прогресс считается по ним, исключая сам корень.

Драйвер Б24 0.1.6 уже создаёт корень через `task.checklistitem.add` без `PARENT_ID`.
Ядро вызывает существующий `addChecklistItem` без `parentId`; для добавления пункта
передаёт id его списка. Отдельного метода драйвера для списка не требуется.

Разметка, создание, переименование, подтверждение удаления и мгновенная запись пунктов
описаны в [UX карточки задачи](task-card-fields.md#ux-чек-листов-и-тегов).
