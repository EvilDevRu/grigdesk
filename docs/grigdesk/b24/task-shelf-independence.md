# Полка не является фильтром доски и не связана с избранным

- **Полка не является фильтром доски и не связана с избранным.** Её `entries` остаются
  durable до явного DELETE, а `rows` строятся единственной чистой функцией
  `web/src/shared/taskShelfDecision.ts` из снимка записи и уже загруженных `analysis`, `notify-watch`,
  `board`. Источник без успешного снимка даёт неизвестность, а не событие. Первый
  сопоставимый снимок каждого источника зажигает накопленное состояние молча; оповещение
  через `web/src/shared/alerts.ts` уходит только на следующий переход neutral → lit. Открытие
  `TaskModal` делает PUT с `createIfMissing:false`: пересобирает снимок и не воскрешает
  запись, уже удалённую в другом окне. `task-shelf-changed` идёт через singleton SSE и
  означает только «перечитай полный снимок». Поверх решения события стор строит недолговечную
  `details`-проекцию: актуальные название, проект, статус B24, ответственный, срок и непрочитанные
  берутся из доски, шкалы — из триажа, текущие `done/total` и узел — из уже загруженного
  `notify-watch` графа. Если закрытая задача уже ушла из dashboard, название и проект лениво
  дозагружаются из её полной B24-карточки с дедупликацией и cooldown; это не меняет наблюдаемое
  состояние `present:false`. Эти поля не расширяют серверную schema полки и при недоступном
  источнике не выдаются за новое наблюдение. Панель сначала показывает группу «Требуют внимания»:
  новые события и задачи, которые конвейер держит на человеке (`needsHuman`), включая
  уже просмотренные остановки. Затем идут обычное ожидание и завершённые B24-задачи
  в приглушённой группе внизу.
  Задачи образуют плоский список с разделителями. На широкой панели сведения источников
  находятся справа от задачи, а в узкой складываются под причиной ожидания;
  зарезервированный gutter скроллбара не сдвигает строки при его появлении.
  Причина ожидания расположена под названием, компактная шкала прогона с видимым числом
  шагов — в нижней строке. Поиск по номеру, названию, проекту и ответственному сочетается
  с явными кнопками групп; счётчики фильтров остаются общими. Фильтрация не меняет entries и latch.
  Событие можно погасить отдельной галочкой, а крестик по-прежнему означает только DELETE записи.
  Продуктовый контракт полки: `docs/grigdesk/guide/ru/tasks.md`, раздел «Полка задач».
  Компоновка и адаптив — [рабочая область полки](../web/shelf-design.md).
