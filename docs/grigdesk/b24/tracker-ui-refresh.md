# Обновление карточки и графиков при смене трекера

Задача №100000000000. Событие `trackers-changed` отменяет чтения прежнего подключения,
очищает детали и незавершённые формы открытой карточки. После получения metadata
с ревизией не ниже объявленной событием карточка принудительно перечитывает детали.
Ожидание сохраняется, если другой подписчик или настройки заменили запрос metadata.
Поздний ответ прежнего чтения не возвращается в карточку. Правило одинаково для диалога
и отдельного окна; дополнительный поток SSE и опрос доски не создаются.

Колонка «Учтено», значения времени в строках и активные таймеры доски подчиняются
одному признаку `capabilities.timer`. При `false` скрываются и данные, и место колонки;
сетка сохраняет название задачи и оценку, включая узкую раскладку. Снимок прежнего
сервера без capabilities сохраняет прежнее отображение времени.

Каждый chart-виджет отображается одним графиком с общей шкалой и всеми объявленными
рядами. Подсказка связывает подпись ряда с его собственными значениями и форматом
из DTO. Отсутствующий ряд не добавляется с нулевыми значениями. Подписи переводятся
только по явному descriptor; название драйвера и id ряда не определяют их смысл.
Переключение периода заменяет набор рядов целиком.
