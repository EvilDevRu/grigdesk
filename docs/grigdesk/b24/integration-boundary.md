# Граница B24

Доска и действия используют локальный `B24Client`, медиа — локальный pipeline, вход в
фабрику — `engine/bin/factory`. Команда `b24` идёт по цепочке `b24/src` → собранный `bin/b24`
→ локальный HTTP API GrigDesk (`/api/b24/*` с CLI-токеном); без сборки `bin/grigdesk-ctl b24`
исполняет тот же исходник. Прямого клиента портала, cookies и кредов у команды нет: сессией
портала владеет сервер ([команда b24](binary-cli.md)). Резервный
Python-dashboard тоже использует GrigDesk `B24Client` и хранилище кредов, но держит отдельный
cookie jar, чтобы два процесса не перезаписывали один файл. Прямых путей к внешнему checkout
в рабочем коде нет; внешние host hooks/settings/containers находятся вне репозитория.
Полный контракт авторизации, HTTP и мутаций — в [b24.md](README.md).
