# Сохранение источника ролика и начало сборки не пересекаются

`source` входит в содержательный снимок сборки. Если сборка создаёт снимок во время
сохранения выбора и лишь затем ждёт его в `prepareScript`, следующая проверка
совместимости видит другой `source` и останавливает запуск с `build_inputs_changed`.
Ожидание внутри этапа сценария эту гонку не закрывает.

Служба отмечает сохранение в `sourceSaveRequests`, а регистрацию запуска — в
`pendingBuildStarts`, синхронно до первого `await`. Начавшаяся второй операция
получает `script_busy`; после завершения первой её можно повторить с текущей редакцией.
Счётчик запусков нужен для параллельных повторов HTTP-запроса. Отметки снимаются в
`finally`, включая ошибки. Уже идущая сборка защищена списком активных запусков.
Сборка во время ручного разбора, не меняющего `source`, по-прежнему ждёт его результат.

Явно пустой список репозиториев `repos: []` сохраняется и разбирается без чтения
паспорта постоянного стенда. Снятые репозитории не могут стать причиной отказа
`source_unavailable` у ролика, который рассказывает только по пожеланию человека.

У блока выбора своя граница: подтверждение сужения относится к показанному ролику и
черновику. Смена ролика или сброс черновика делает поздний ответ неактуальным; повторный
клик во время вопроса не начинает вторую операцию.

Ошибка чтения истории не скрывает сохранённые отметки. Их можно снять отдельно, сохранив
выбор остальных репозиториев. Выбранные незакоммиченные правки тоже можно снять, даже
когда рабочее дерево уже чистое.

`tests/web/showcase-source-panel.component.test.js`.
