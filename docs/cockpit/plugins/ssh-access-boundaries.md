# SSH-плагин закрывается на каждой границе

Пароль существует только в памяти формы и raw `application/octet-stream` запроса при
ручном входе; он не хранится и не попадает в prefs, state, argv, JSON или журнал. Такой
запрос разрешён лишь с loopback либо по HTTPS. Нельзя «для удобства» добавить пароль в
профиль соединения или автопереподключение: тем самым агент получил бы возможность
поднять сессию без человека.

TOFU относится к host key, а не к паролю пользователя. Первый отпечаток подтверждает
человек; смена известного ключа всегда блокирует вход до явной замены known-hosts записи.
Вывод exec недоверенный и способен нести prompt injection. Обрамление и лимит уменьшают
случайное влияние, но не превращают текст боевого сервера в доверенную инструкцию.

В браузерной вкладке остаётся один EventSource и единственный `ToolHost`; SSH-панель
переиспользует один xterm/WebSocket между внутренними вкладками. Второй mount создаст два
human shell attach и расходящееся состояние. При этом сами сессии принадлежат процессу
Cockpit и не закрываются от unmount браузера.

SSH-ожидания fail-closed не выдаются в Telegram: там не должны оказаться host, user и
полная команда. Старый PWA-бандл тоже не видит и не разрешает их: default
`/api/chat/waiting` исключает SSH, generic permission endpoint отвергает `origin:'ssh'`,
а новый интерфейс делает явный opt-in и отвечает через SSH endpoint. Поэтому смешанный
rollout безопасно оставляет команду ждать новое окно, а не молча разрешает её.
