# Рабочая папка разговора

Кнопка «Папка» с контурной иконкой рядом с задачей показывает рабочую папку и репозитории, которые увидит
исполнитель. В свободном чате можно выбрать Кокпит, проект, недавнюю папку или абсолютный
путь существующего каталога. Git не обязателен. Корень файловой системы и весь домашний
каталог выбрать нельзя. Ошибка пути остаётся видимой и запрещает запуск в другой папке.

Проект использует основной репозиторий из паспорта (`defaultRepoKey`), остальные добавляет
как дополнительные корни. Чат из «Кода» запоминает выбранный репозиторий; кнопка «Чат с
проектом» в паспорте передаёт проект явно. Эти действия создают черновик, не отправляя его.
Контекст открытой страницы сам по себе рабочую папку не меняет.

У чата по задаче приоритет имеют рабочие копии задачи, затем репозитории доверенно
связанного проекта, затем сохранённый выбор чата. Снятие задачи возвращает сохранённую
папку. Компаньон показывает папку без произвольного редактирования. При внешнем изменении
копий задачи он может подтвердить перенос памяти, сохранив ту же задачу.

Последний успешный явный выбор папки становится умолчанием для новых свободных чатов.
Список последних выборов хранит восемь записей. Недоступный или архивный неявный дефолт
заменяется Кокпитом до первого сохранения нового чата; явный выбор и существующий разговор
не получают такого fallback. Обрыв связи с сервером также не меняет выбранную папку.

Claude, Codex и Ollama продолжают разговор после смены папки и переходят сразу, без окна
выбора. DeepSeek и Kimi при новом cwd открывают окно: «Сжать разговор и перейти», «Перейти
без выжимки» или отмена. Для выжимки сервер использует прежнюю сессию и прежний cwd,
сохраняет результат, затем сбрасывает память и подтверждает новую папку. Пока идёт перенос,
можно набирать черновик; запуск сообщения, смена задачи, модели и режима ждут завершения
операции. Если ответ сервера о переходе потерялся (обрыв связи), окно предлагает «Повторить»
тот же запрос: второй выжимки и второго сброса памяти не будет.

В чате с перепиской появляется плашка «📁 Папка: откуда → куда». Пустому чату переносить
нечего, поэтому смена папки в нём плашки не оставляет и стартовый экран не пропадает. Выбор
той же папки без переноса памяти — не переход: ни операции, ни плашки.

Выбор задачи в селекте — просьба о переходе. После подтверждения чат получает название
задачи, как и раньше. Пока переход ждёт решения в окне или если он отклонён, селект
показывает фактическую задачу чата; причина отказа пишется в разговор. «Другая папка…»
принимает только абсолютный путь: относительный и «~/…» объясняются на месте.

Выжимка передаётся сервером один раз в следующий обычный ход. Ошибка, остановка и перезапуск
сервера сохраняют её для следующей попытки с чистой сессией. Служебная slash-команда не
потребляет выжимку. При отмене до начала перехода папка и память остаются прежними.
Обычная кнопка сжатия также ждёт подтверждения, если фактическая папка изменилась.
Смена профиля исполнителя перед сжатием даёт отказ с сохранением прежней сессии;
пользователь может явно сбросить память.

Поддержка нескольких корней зависит от исполнителя. Claude, Codex, Ollama и Kimi contained
получают дополнительные рабочие корни. DeepSeek и Kimi host пишут в основной папке;
остальные пути показаны отдельно и могут требовать разрешения. Кокпит не выбирает общий
родительский каталог вместо заданного cwd. Kimi contained проверяет запреты монтирования
при предпросмотре и повторно при запуске.

Общая настройка «Доверенные каталоги» удалена. Рабочая область теперь задаётся разговором,
проектом и задачей; режим прав исполнителя продолжает действовать отдельно.
