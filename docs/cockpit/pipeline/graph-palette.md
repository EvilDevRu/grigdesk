# Палитра

Тёмная тема: фон `#0a0c10`, карточка `#151b24`, вторичная поверхность `#1c222c`.
`--accent` (работа) `#5aa2ff`, good `#3fb950`, warn `#e0a33a`, bad `#f0564c`.
Токены типов: агент `#e0873f`, человек `#d9c04a`, код `#37b7c3`.
Базовая палитра живёт в `web/src/styles/tokens.css`, оформление схемы — в
`web/src/views/pipeline/FactoryGraph.vue`. Будущие узлы имеют спокойные контуры и оттенки по типу и читаемые
подписи. Агент — скруглённый прямоугольник, код — срезанные углы, человек — капсула.
Рамка текущей работы и остановок принимает цвет состояния; силуэт и значок типа сохраняются. Возможные возвраты — приглушённый пунктир, фактические — красные линии;
связи выбранного узла выделяются при наведении или фокусе. Подробности — в
`docs/cockpit/guide/pipelines.md`.
