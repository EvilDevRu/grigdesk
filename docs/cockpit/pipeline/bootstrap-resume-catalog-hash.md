# Resume читает закреплённый hash каталога из загрузчика попытки

Чтение bootstrap-журнала выполняется и на `resume`, до обычного запуска узла.
Маршрут с `bootstrap=skip` поэтому тоже зависит от корректности этого reader.

`attempt_bootstrap_journal_v2` сначала вызывает `_attempt_stage_state_load_locked`.
Загрузчик заполняет `ASTAGE_CATALOG_HASH`; именно это поле передаётся Python-reader
как закреплённый каталог попытки. Имя `ASTAGE_CATALOG` не объявлено. С `set -u`
оно обрывало продолжение сообщением `unbound variable` ещё до проверки курсора.
Заменять отсутствующее значение пустой строкой или текущим каталогом нельзя:
reader должен получить проверенный immutable pin.

Регрессия `tests/engine/integration/route-loop-launcher.sh` проверяет этот путь
настоящим `factory resume`: продолжение после потолка кругов, повторный визит
исполнителя и восстановление обычного маршрута. При неверном имени переменной
в этих сценариях падали 20 проверок из 51.
