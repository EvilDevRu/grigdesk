# Жёлтая карточка без единых ворот = доинференс возврата поверх живого курсора

Похожая ошибка уже возникала в [проверке линейности этапов](active-stage-linearity.md).
Здесь симптом выглядит как запрос решения человека.
Задача с отклонённой приёмкой показывала на схеме работу на узле `build`, а идущий
следом `review` — «ещё не начинался»; прогресс отставал на узел (13/21 при фактических
14/21). Через пять минут `build` желтел в «ждёт твоего решения», и вся карточка задачи
становилась жёлтой — «работа стоит на тебе», хотя ворот, требующих решения, не было ни
одного, а конвейер в это время работал.

Виноват был доинференс возврата после reject в `computeNodeStatuses`:

```js
const recent = mtimeMs && Date.now() - mtimeMs < 300000;
st[back] = recent ? 'run' : 'wait';   // back = build
```

То есть **`wait` тут означал не «ждём человека», а «реестр давно не переписывали»** —
пять минут тишины у работающего этапа набегают сами собой.

Половина блока при этом была нужна и осталась: реестр — вторичная проекция, и после
возврата узлы хвоста держат `done` с прошлого круга (проверено по архивному реестру
задачи: `REVIEW/MEASURE/LINT=done` при `GATE_ACCEPT=rejected`), так что сбрасывать их
надо. Убран только доинференс ФРОНТА: когда курсор журнала известен, левее него —
пройдено, правее — предстоит, а сам узел курсора красит `getTaskGraph` по состоянию
журнала. Доинференс остался там, где другого источника нет: исторический реестр v1 и
нечитаемый ledger.

Отдельно стоит запомнить, почему симптом читался как поломка оповещений: карточку красит
`cardState` (`PipelineView.vue`) по ЛЮБОМУ узлу в `wait`, а чип «⏳ ждут тебя», вотчер и
оповещения идут через `waitingReason`, который смотрит только `gate_*`. Экран
противоречил сам себе — карточка звала человека, счётчик над ней её не считал. Это
расхождение не исчезло совсем: `wait` законно ставится и узлу курсора в состоянии
`paused`, то есть неворотная пауза по-прежнему желтит карточку молча для чипа.

Как отличить такой случай за один взгляд: сравни `statuses` из `/api/tasks/:id/graph` с
СЫРЫМ реестром и курсором ledger. Расходятся — врёт проекция, а не движок. Сторож —
`tests/server/factory-graph-reject-rewind.test.js`.
