# Осторожно: проверки окружения гоняются в песочнице с урезанным PATH и сетью

`which <пакет>` и `curl` в этой среде врут — на реальном случае дали ложный вывод «пакет
не установлен», хотя пакет стоял и его демон работал. Существование хостовых пакетов проверять
через `dpkg -l`/`pgrep`/`ip addr`, доступность сети — не по одному упавшему curl. Вывод
песочницы об окружении мозга сам по себе не доказывает ничего.
