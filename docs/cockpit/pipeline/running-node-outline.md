# Работа видна по обводке узла

`FactoryGraph` показывает выполняемый этап движущейся синей дугой на существующем
контуре значка. Дополнительной точки справа снизу и отдельного внешнего кольца нет.
Период — 0,85 секунды, как у индикатора работающего чата. У агента дуга идёт по кругу,
у автоматического шага — по ромбу; сам значок и подписи остаются неподвижными.
Знаки готовности, ожидания человека, ошибок и разбора арбитра сохраняются.

Обводка и стрелки используют один признак работы: `status=run`, `daemonAlive=true`,
отсутствие `stall` и выключенный эталонный режим. Старый `run` после остановки демона
не создаёт движения. При `prefers-reduced-motion` дуга остаётся синей и неподвижной.

Фактический возврат, ведущий к работающему этапу, получает синюю движущуюся стрелку;
стартовая связь к тому же узлу остаётся статичной. История возвратов сохраняет красный
цвет на паузе. В режиме `loop` обе штатные передачи остаются синими, а движение идёт
к работающему агенту. Режим берётся только из `graph.loop`, по названиям узлов или
счётчикам обычных возвратов пара не угадывается.

Проверка: `tests/web/factory-graph.component.test.js` проводит передачу от ведущего
к исполнителю и обратно, проверяет отсутствие точки, контур автоматического шага,
паузу с сохранённым `run`, остановку и эталонный режим.
