# Экраны приложения и дизайн Кокпита

Эталон приложения — рабочая оболочка `web/src/shared/layout/AppShell.vue`, список
`web/src/views/chat/ChatList.vue`, лента и composer `ChatSession.vue`, общие controls
из `web/src/styles/components/`. Мобильный пакет сохраняет независимые исходники:
продуктовые компоненты веба и его stores в APK не импортируются.

## Общие решения

- В рабочей оболочке используется знак ◧, названия «Чаты», «Конвейер», «Задачи»,
  «Настройки» и контуры значков Кокпита. На телефоне навигация снизу; на планшете
  слева, с компактной рейкой значков в обеих ориентациях.
- Рабочая страница имеет фон `surface`, поля и вложенные карточки — `ground`.
  Обычные controls берут радиус 9 px, поверхности — 12 px. Поле ввода чата
  прямоугольное с такими же скруглениями, как в вебе; кнопка отправки не круглая.
- Числовые метки и состояния имеют компактную рамку. Синий — работа, жёлтый —
  ожидание человека, зелёный — завершение. Выбранная строка и ожидание ответа
  используют ту же заливку и левую полоску, что список чатов веба.
- Сенсорная область обычно не меньше 44 CSS px; компактные контролы планшетного чата
  имеют явно ограниченное исключение 28–36 px: [плотность](chat-controls.md#плотность-планшета).
  Текст масштабируется в `rem`.
  Крупный системный шрифт не компенсируется уменьшением шрифта отдельных controls.
- Подтверждения расположены по центру, с прокруткой тела и отдельным подвалом.
  Кнопка называет действие: «Остановить», «Принять», «Запустить», «Отвязать».

## Разбор экранов и сценариев

| Экран | Устройство и проверяемые состояния |
| --- | --- |
| Первая привязка | «Подключить Кокпит», камера и вставка кода, ошибка/истёкший код, очистка незавершённой привязки |
| Блокировка | Название Кокпита, разблокировка, отозванный телефон, подтверждение отвязки |
| Посредники | Активная запись, онлайн/нет сети/подключение/VPN, выбор, удаление с подтверждением |
| Добавление посредника | Та же форма QR внутри рабочей страницы с возвратом к списку |
| Список чатов | Поиск названия/модели/превью, тумблер «Показывать архив», пустой список и пустая выдача, длинные названия, очередь/работа/ожидание |
| Чат | Пустая и длинная история, сообщения и код, изображения и ошибка загрузки, работа и остановка, очередь доставки, разрешения, типизированные вопросы, неподдерживаемое действие, ошибка чтения |
| Список конвейера | Поиск по номеру/названию/этапу, «Все»/«Требуют меня», приоритет ожиданий, пустой список и ошибка |
| Карточка конвейера | Полный заголовок и номер, этапы, постраничный план, ворота после чтения, подтверждения продолжения/остановки/решения |
| Задачи Б24 | Поиск по номеру/названию, «Все»/«На конвейере», пустой список, статус и срок |
| Карточка Б24 | Полный заголовок и номер, статус/ответственный/срок, длинное описание, варианты запуска с причинами недоступности и подтверждение |
| Настройки | Подключение, версия и обновление, требование обновиться, диагностика по раскрытию, незавершённые действия, отвязка |

Поиск и фильтры работают по уже загруженным строкам. Если сервер вернул `hasMore`,
интерфейс явно сообщает границу поиска; «Показать ещё» доступно и при пустой выдаче.
Запрос и фильтр сохраняются при открытии карточки и возврате, поскольку родительский
список остаётся смонтированным. Новый запрос к серверу для каждого символа не создаётся.

Диагностика размеров окна находится в раскрываемом блоке настроек. Незавершённые
действия показывают пользовательское название вместо URL API и внутреннего ID;
проверка результата не отправляет действие повторно.

## Проверка и границы

Визуальная матрица описана в [проверках](checks.md). Она проверяет начало и конец
прокручиваемых колонок: чат при открытии находится снизу, поэтому проверять только
исходную позицию недостаточно. Прокрутка тела диалога проверяется отдельно от фона.
Компонентные тесты проверяют поиск, фильтры, сохранение запроса при возврате,
отправку сообщений и решений с настоящими decoder и stores. Browser E2E использует
изолированный Кокпит и посредник.

Планшет, аватары, превью, черновики, Markdown и действия уточнены в [планшетном разговоре](tablet-chat.md).
Поиск, архив, настройки вида и доводка ленты 0.1.8 — в [виде разговора](chat-layout-controls.md).

Это приведение поддержанных мобильным API возможностей к дизайну Кокпита.
Создание чата, выбор модели/эффорта, задачи/папки, контекст и индикаторы добавлены в 0.1.9:
[управление чатом](chat-controls.md). Оставшиеся [границы приложения](limitations.md)
перечислены отдельно. Браузерные кадры не заменяют
проверку системной клавиатуры, биометрии и фонового lifecycle на физическом Android.
