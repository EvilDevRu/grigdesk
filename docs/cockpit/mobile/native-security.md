# Нативная сессия и границы доступа

Сеть принадлежит `CockpitLink`, не WebView fetch. P256 private key находится в Android
Keystore и требует strong biometric либо device credential. Сессия проверяет monotonic
deadline 600 секунд и generation перед сетевым вызовом, публикацией файла и возвратом данных.
Переключение посредника меняет generation, сохраняя исходный deadline.

Уход в фон, lock, revoke и reset закрывают calls, pools, SSE, forwarder и активные пары.
Исчезают видимые чаты/задачи и media cache. Durable outbox переживает обычный lock;
явный reset удаляет ключ, привязку, очередь и кэши. Потерянный или повреждённый Keystore-ключ
не регенерируется под прежней привязкой: приложение предлагает явную отвязку.

## Транспорт

Внешний TLS 1.3 проверяет exact pin посредника до hello; внутренний — pin мозга до HTTP.
Нативный forwarder слушает случайный порт только на `127.0.0.1`. Сам порт не является
секретом или разрешением; доступ к мозгу требует Keystore client certificate.
OkHttp использует HTTP/1.1, `Proxy.NO_PROXY`, без redirects и автоматического POST retry.

Бюджет: REST 4, media 2, SSE 1 — всего 7 при пределе forwarder 8. Передача идёт с
backpressure; закрытие стороны закрывает пару. Native SSE имеет один reconnect/backoff
и watchdog 45 секунд; heartbeat подтверждает живость. Ошибки pin/auth/схемы останавливают
автоповтор до явного действия.

Посредник видит IP участников, роль внешнего соединения, токен этой роли, объём и время
трафика. Текст чата, команды, ответы, pair-код и содержимое media защищены внутренним TLS.
Секрет relay.env нельзя публиковать; компрометация посредника не заменяет pin мозга
или зарегистрированный сертификат телефона.

## WebView и файлы

WebView отдаёт bundled assets собственного приложения и только собственные проверенные
файлы media текущей сессии. Произвольная внешняя навигация, file/content URL, HTML из
текста агента и доступ к приватным JSON/updates закрыты. Gate проверяется также при чтении
уже открытого media stream после lock.

Явное нажатие HTTP(S)-ссылки в основном документе передаётся системному браузеру
через `ACTION_VIEW`. Условие требует `hasGesture`, `isForMainFrame` и GET;
перенаправления без жеста, ресурсы и файловые схемы остаются закрыты.

Растры проверяются по MIME, magic и размерам до декодирования: 10 MB/24 MP;
кэш ограничен 100 MB. Повтор использует ETag/304 только при наличии своего файла.
APK скачивается через тот же pinned brain, ограничивается по размеру и проверяется по hash
до выдачи URI системному установщику. Самостоятельного открытия APK внешним JavaScript нет.

## Граница VPN

Для публичного посредника мозг проверяет VPN-маршрут к каждому разрешённому числовому IP
перед соединением и следит за ним при активной связи. Потеря маршрута закрывает пары и
переводит связь в waiting_vpn. Домашний посредник допускается по локальному маршруту.

Проверка маршрута приложения не заменяет системный kill switch. До публичного подключения
владелец должен проверить отсутствие прямого исходящего трафика при падении VPN, включая
IPv4/IPv6 и существующее соединение. Приложение не выключает VPN и не меняет firewall
самостоятельно. Требование к реальной сетевой приёмке остаётся даже при зелёных unit-тестах.
