# Строка состояния полного чата — не отдельная форма

Селекты задачи/модели и слайдер эффорта — без своих коробок: подпись-метка (`задача`, `модель`,
`эффорт`), значение, шеврон; между блоками тонкая вертикальная линия. Раскрытому `<select>` всё
равно нужен непрозрачный фон (`option { background: var(--surface) }`), иначе на тёмной теме
системный список нечитаем. На полной странице задача растёт вместе со свободным местом до `620px`,
а полное название показывает общий `UiTooltip`. Настройка задачи, модели, усилия и режима
живёт только здесь, на `/chats`; у companion-чата пульта неактивен один селект задачи — его
`taskId` принадлежит server-owned identity.

Диалог вопроса — строки на всю ширину (отметка · название · пояснение агента справа), а не чипы:
видно, чем варианты отличаются, и попасть мышью проще.
