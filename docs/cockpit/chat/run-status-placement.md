# Сведения справа в строке текущего хода

`ChatThinking` остаётся последней строкой текущего запуска внутри прокручиваемой
`.cs-body`. `chatTimeline.ts` сохраняет его хвост после действий и реплик; до первого
шага этот же хвост показывает шапку запуска. `ChatStatusBar.vue` добавляет справа
модель, рабочий каталог и лимиты, сохраняя один горизонтальный ряд.

Отдельной постоянной полосы между лентой и композером нет. Сведения видны только рядом
с индикатором активного хода; в простое строки нет. При чтении истории она прокручивается
вместе с ней. Обновление лимитов не меняет высоту viewport ленты и положение композера.
Выравнивание, разделители и отдельный вид сжатия описаны в
[контракте строки активного хода](active-run-status.md).

Длинные значения сокращаются; полные модель, путь, дополнительные каталоги и окна
лимитов находятся в общей текстовой подсказке `title`. Правый блок — обычный текст
на [одной базовой линии](run-status-baseline.md) с индикатором.
Ширина контейнера влияет на подписи и количество видимых окон лимитов, без переноса
сведений под индикатор. На широкой строке показываются до двух окон, на узкой — одно
и `+N`.

`chat-status.component.test.js` проверяет размещение единственного таймера внутри
текущего запуска, живые квоты и текстовые сведения без кнопки.
`chat-timeline.test.js` сохраняет хвост хода;
`chat-run-provider.component.test.js` проверяет его принадлежность ленте.
Геометрия требует настоящего браузера: happy-dom её не вычисляет.
