# Одна базовая линия строки состояния

Слово состояния, время, токены и правые сведения о модели, папке и лимитах должны
находиться на одной базовой линии. У обоих блоков общий кегль 13 px и интерлиньяж 1.4;
правый блок прижат к краю строки, факты разделены `·`.

Правые сведения — обычный текст. У строки нет кнопки, состояния раскрытия и области
фокуса. Длинные значения сокращаются; общий `title` содержит полные модель, рабочий
путь, дополнительные каталоги, все окна сводки лимитов и пометку устаревших данных.

`ChatStatusBar.vue` выравнивает по `baseline` весь ряд и вложенные группы фактов.
Совпадение координат внешних контейнеров не доказывает совпадение текста: вложенный
control может задавать собственные высоту, отступы и выравнивание. Именно так прежний
`UiButton` поднимал правые надписи относительно индикатора.

Проверять уровень нужно в настоящем браузере по прямоугольникам текстовых узлов
через `Range.getBoundingClientRect()`, включая время и токены слева. При замере
отключается анимация появления слова через `prefers-reduced-motion`, чтобы временный
сдвиг не искажал результат. Допуск — 0.5 CSS px. Размеры композера и viewport ленты,
положение чтения истории и правый край сведений проверяются отдельно.

Видимость и сжатие сохраняют [контракт активной строки](active-run-status.md): в простое
её нет, при сжатии показаны только спиннер и «Сжимаю контекст» слева.
