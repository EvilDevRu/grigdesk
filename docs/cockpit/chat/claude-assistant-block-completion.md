# Claude: завершённые реплики остаются «Пишет…»

В `server/src/lib/executors/_claudeStream.ts` обработчик `handleEvent()` публикует
текст обычного события `assistant` через `onAssistantMessage` с `complete: false`.
Последующие сообщения, вызовы инструментов и итоговый `result` не завершают этот
блок. Единственная публикация `complete: true` находится в ветке
`injectedPending > 0`: она закрывает последний ответ на уточнение человека.

Поэтому несколько уже произнесённых промежуточных реплик одновременно сохраняют
подпись «Пишет…». `ChatInTurnReply.vue` показывает её по `block.complete === false`,
а `ChatAssistantPublisher.flush()` только ждёт операции записи и проверяет ошибки;
он не назначает завершение блокам вместо адаптера.

## Воспроизведение

Синтетический stream-json процесс отправляет три пары событий: текстовый
`assistant` с отдельным id, затем `assistant` с `tool_use` и `user` с
`tool_result`. Итоговый `result` временно удерживается. События проходят настоящий
`openClaudeStreamSession()` и `ChatAssistantPublisher` с `ChatAssistantMessages`.

После третьего результата инструмента сессия ещё активна, все три текстовых блока
имеют `complete: false`. После успешного `result` незавершённых блоков по-прежнему
три. Повторная загрузка журнала с диска возвращает три записи с пустым текстом:
`begin()` сохраняет пустой блок, `setDraft()` держит текст в памяти, а `complete()`
в этом сценарии не вызывается.

Это утверждение касается журнала блоков. Текстовые шаги ленты сохраняются отдельным
путём; результат проверки не доказывает потерю всей истории разговора.

## Покрытие и граница исправления

`tests/server/claude-in-turn.test.js` проверяет завершение ответа на уточнение,
а `tests/server/chat-in-turn-replies.test.js` — журнал при явном вызове завершения.
Все 11 проверок этих файлов проходят при наличии ошибки обычных реплик.

Исправление должно определять границу завершённого текстового блока в адаптере и
публиковать её с прежним `assistantMessageId`, сохраняя все части текста одного
сообщения. Нужна проверка нескольких обычных реплик до финала хода и восстановления
их текста из журнала. Скрытие подписи в компоненте оставит ошибку состояния и записи.
