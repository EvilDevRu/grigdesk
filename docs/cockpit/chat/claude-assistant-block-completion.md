# Claude: завершение промежуточных реплик

`server/src/lib/executors/_claudeStream.ts` собирает текстовые content-блоки одного
сообщения по общему `message.id`. Промежуточные события публикуют весь накопленный
текст с `complete: false`. Реплика получает `complete: true` с прежним id при
следующем сообщении главного агента с другим id, результате инструмента (`user`
с `tool_result`) или итоговом `result`.

Thinking и tool-use блоки с тем же id не обрывают сборку текста: сообщение может
содержать несколько текстовых частей. События субагента остаются вложенными шагами
и не завершают буфер главного агента. Обрыв процесса без границы сообщения не завершает
текущий черновик: конец хода помечает его брошенным ([общий контракт](assistant-draft-abandon.md)),
а уже завершённые реплики сохраняются в журнале.

`ChatInTurnReply.vue` снимает «Пишет…» по `block.complete`. Публикация завершения через
`ChatAssistantPublisher` сохраняет полный текст до SSE. Его `flush()` только ждёт
операции записи и проверяет ошибки; границы сообщений определяет адаптер.

## Финал и уточнения

Каждый result закрывает текущую реплику общей границей. Уточнение подтверждается
событием `command_lifecycle/started`; его текст может влиться в текущий ход или
прийти следующим ходом CLI. Адаптер ждёт следующий result только при подтверждённой
очереди без started. Повторное завершение того же блока не публикуется. Подробности —
[закрытие хода по lifecycle команд](claude-in-turn-live.md).

Когда текст завершённой реплики совпадает с `result`, адаптер возвращает её
`assistantMessageId` в результате хода. Pending и история дополняют уже показанный
блок. Модуль чата очищает служебный маркер названия до публикации и записи текста
блока; название извлекается из исходного результата штатным хуком.

## Причина прежнего дефекта и проверки

Раньше обычные реплики всегда публиковались с `complete: false`, а завершались
только ответы на уточнения. После трёх выполненных команд и успешного финала все
три реплики оставались «Пишет…». Текст жил в памяти журнала; на диске были пустые
незавершённые блоки. Текстовые шаги ленты сохранялись отдельно, поэтому это не
доказывало потерю всей истории разговора.

`tests/server/claude-in-turn.test.js` проверяет живую сессию и разовый
запуск: три реплики до финала, несколько частей с общим id вокруг tool-use блока,
вложенный ответ, однократное завершение, восстановление полного текста из журнала,
связь финала по id и обрыв процесса, а также доставку уточнений и продолжение
исходного хода. `chat-title-hook.test.js` проверяет очистку маркера в SSE, журнале
и pending.
