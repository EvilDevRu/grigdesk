# Измерение схем Mermaid и повтор пустого результата

Создание iframe в задаче после загрузки истории через `fetch` может дать нулевые
измерения текста внутри Mermaid. Общий renderer вкладки перед каждым созданием
frame ждёт один `requestAnimationFrame` родителя. Таймаут 15 секунд начинается
после ожидания: в скрытой вкладке схема дожидается возвращения человека.

Отмена во время ожидания завершает задание с `null`. Продолжение после кадра
проверяет, что renderer не закрыт и активно всё ещё то же задание, поэтому
не создаёт устаревший frame. Фабрика без `waitForPaint` сохраняет синхронное
создание frame для протокольных тестов.

SVG с шириной и высотой не больше 16 px считается отказом измерения. Родитель
снимает frame и таймер, возвращает задание в начало очереди и повторяет один раз
с прежней подпиской отмены. Второй пустой результат оставляет исходный код
и пояснение, как остальные ошибки рисования.

Регрессии покрывают RMD-MM-13/14 в `tests/web/markdown-mermaid.test.js`:
управляемый кадр, ожидание дольше timeout, отмена до кадра, пересоздание frame
и остановка после второго пустого ответа.

Связанный контракт: [оформление ответа](rich-markdown.md).
