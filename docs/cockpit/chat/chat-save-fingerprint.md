# «Чат уходит на сервер целиком при каждом сохранении» = отпечаток отправленного включал поле ответа, которого нет в снимке

Окно помнит отпечаток последнего отправленного снимка каждого чата (`sentChats` в
`web/src/stores/chat.js`), чтобы не слать неизменённый чат повторно. После PUT отпечаток
считался по снимку, дополненному полями ответа сервера (`applySaveAck`). Сервер возвращает
`modelRefState`, а `slimOf()` этого поля не несёт. Отпечаток больше не совпадал ни с одним
следующим снимком, и любая запись — пауза в наборе черновика другого чата, смена активного
чата, предпросмотр рабочей папки — снова отправляла чат целиком, вместе с лентой шагов.

Замер 28.09.2026 в живом окне: шесть переключений между двумя неизменёнными чатами давали
шесть полных PUT; после исправления — ни одного.

Правило: отпечаток подтверждения считается только по ключам самого снимка. Поле, которое
`applySaveAck` кладёт в чат, либо входит в `slimOf()`, либо в отпечаток не попадает. Сторож —
тест «подтверждение сервера с полем вне снимка не делает чат вечно несохранённым» в
`tests/web/chat-workdir.test.js`.
