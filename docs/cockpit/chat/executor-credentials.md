# Ключи доступа исполнителей задаются окном и живут в корневом .env

Ключи API исполнителей (DeepSeek, GLM) человек задаёт кнопкой «Задать ключи…» /
«Изменить ключи…» в блоке «Ключи доступа» карточки исполнителя («Настройки →
Исполнители»). Хранилище — тот же корневой `.env`, где ключи лежали раньше. В `.state`,
prefs и браузерные настройки ключи не попадают. Ручная правка `.env` продолжает работать.

## Контракт адаптера

Какие переменные нужны, объявляет сам адаптер полем `credentials`: массив либо
`(config) => массив`. Ядро и Vue вендоров не знают.

```ts
credentials: [
  { env: 'COCKPIT_GLM_API_MODE', kind: 'choice', label: 'Режим доступа Z.ai',
    options: [{ value: 'api', label: 'Обычный API' }, { value: 'coding-plan', label: 'Coding Plan' }] },
  { env: 'ZAI_API_KEY', kind: 'secret', label: 'Ключ обычного API', hint: '…' },
]
```

`env` — имя `A-Z0-9_`, `kind` — `secret` или `choice` (у выбора обязателен непустой
`options`). Сломанная запись, повтор имени и падение функции дают пустую или урезанную
декларацию. Произвольную переменную через маршрут записать нельзя. Нормализация живёт в
`server/src/lib/executorCredentials.ts`, правило имени — общее с писателем (`isEnvName`).
Маршрут — `server/src/modules/providers/credentials.ts`; кэши реестра и лимитов остаются у
модуля `providers`, маршрут только просит их сбросить.

## Проекция и маршрут

`GET /api/providers` отдаёт у карточки `credentials[]`. В каждой записи — декларация
и поля `set`, `inFile` (`true`/`false`, `null` — файл не прочитан), `preview` и `value`.
У секрета `value` всегда `null`, а `preview` — `…` и четыре последних символа, только если ключ
длиной от 16 символов. У выбора `value` — текущий вариант. Источник истины для `set` —
окружение процесса: именно его видят исполнители. Если `set` верно, а `inFile` ложно, значит
ключ задан вне `.env` (окружение службы). Окно предупреждает, что сохранение запишет его в файл.

`POST /api/providers/:id/credentials` с телом `{ values: { ИМЯ: строка | null } }` закрыт общим
auth guard. Он принимает только объявленные имена. У выбора допустимы только объявленные
варианты, у секрета — непустая строка; пробелы по краям обрезаются. `null` удаляет
переменную из `.env`. Из памяти процесса она снимается, только если была в файле: ключ,
заданный вне `.env`, правка файла убрать не может. Запись идёт общим писателем
[`lib/envFile.ts`](../server/env-file-writer.md). Ошибка ввода даёт 400, а состояние файла,
которое правит человек (неоднозначная строка, ссылка, конфликт), — 409. При ошибке окружение
не меняется. После успеха сервер переносит значения в `process.env` и сбрасывает кэш карточек
и лимитов. Каталог моделей он перечитывает в фоне, чтобы окно не ждало CLI и сеть всех
исполнителей, а по завершении рассылает `providers-update`.

## Почему без перезапуска

Адаптеры читают ключ из `process.env` в момент хода: DeepSeek — `buildDeepSeekChildEnv`,
GLM — `resolveGlmAccess` по ссылке на `process.env`. Конвейер получает `DEEPSEEK_API_KEY`
файлом `route-secrets.env` при каждом запуске маршрута. Поэтому новый ключ действует со
следующего хода и запуска. Сменившийся ключ даёт новый `authProfileId`, и разговор
начинает новую сессию исполнителя. Ручная правка `.env` по-прежнему требует перезапуска:
сервер читает файл только при старте.

## Окно

`web/src/views/settings/ProviderCredentials.vue`. Секреты вводятся в `UiPasswordInput`
(`autocomplete="new-password"`); пустое поле означает «не менять». На сервер уходят только
изменённые поля. Введённое стирается при закрытии окна. «Удалить из .env» показывается, только
когда `inFile === true`, и спрашивает подтверждение общим диалогом. Отказ сервера остаётся в
окне вместе с введённым значением.

Тесты: `tests/server/executor-credentials.test.js`,
`tests/web/provider-credentials.component.test.js`.
