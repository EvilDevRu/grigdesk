# Удалённый JS-файл валит снимок миграции, хотя код рабочий

`tests/docs/migration-inventory.test.mts` сверяет остаток собственного JavaScript и Vue без
TypeScript с `tests/fixtures/migration-inventory-baseline.json` на точное совпадение. Новый
файл и убыль ловятся одинаково, в том числе удаление теста вроде `tests/web/*.test.js`.
Падение выглядит так: «Остаток миграции изменился. Обнови снимок:
node tools/migrationInventory.mts --write (tests)». В diff assert виден ровно исчезнувший путь.

Этот тест не импортирует изменённые модули и не упоминает их имён. Поэтому правило «упавший
тест не ссылается на мои файлы — значит, не связано» относит его к чужим, хотя причина —
собственное удаление или добавление файла.

Что делать в том же заходе: после удаления или добавления JS-файла обнови снимок командой
`node tools/migrationInventory.mts --write`. Если в дереве есть чужие незакоммиченные
JS-файлы, вместо `--write` поправь в снимке только свою строку. Затем прогони тест через
сторож памяти.
