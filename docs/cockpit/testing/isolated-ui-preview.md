# Изолированный предпросмотр интерфейса

Для проверки отдельного Vue-компонента можно поднять временный Vite entry с настоящими
SFC, общей таблицей стилей и явными фикстурами API. Артефакты, HTML и снимки хранятся в
`~/.cockpit/artifacts/`; такой стенд проверяет интерфейс, но не заменяет проверку живого API.

Не назначай корень всего рабочего дерева корнем наблюдения Vite: `.state/` может
содержать большие копии сторонних проектов. Наблюдатель обходит их, тормозит загрузку
модулей и может исчерпать системный лимит с ошибкой `ENOSPC: System limit for number of
file watchers reached`. У разового стенда без HMR задай `server.watch: null` и ограничь
поиск зависимостей явными entry или `optimizeDeps.noDiscovery` с нужным `include`.

Если полный Chromium не открывает локальный стенд, хотя Node HTTP получает ответ,
проверь браузерный журнал. `ERR_BLOCKED_BY_LOCAL_NETWORK_ACCESS_CHECKS` означает запрет
браузерного доступа к loopback. В одноразовом тестовом браузере флаг запуска
`--disable-features=LocalNetworkAccessChecks` позволяет проверить такой стенд.
Этот флаг относится только к запуску теста; настройки приложения и браузера человека
при этом не меняются.
