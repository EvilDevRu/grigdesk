# Состояние дополнительных настроек видно у поля

В блоке «Дополнительные настройки» подпись и короткое пояснение стоят рядом
с редактором. На узкой колонке редактор переносится под подпись; переключатели
остаются компактными. Раскладка зависит от ширины блока через container query,
поскольку широкое окно может содержать узкую колонку рядом с MCP.

Под каждым параметром видно состояние: «Наследуется», «Свой выбор»,
«Не сохранено», «Сохраняем…» или «Не удалось сохранить». Сохранённый override
также выделен границей строки. Текст и цвет используются вместе.
«Свой выбор» подтверждает сохранение для следующего запуска чата;
подтверждённое применение моделью из него не следует.

Вложенные поля читают значение черновика из реактивной карты, включая `false`
и `null`. Проверка только через `Object.hasOwn` не подписывает computed на
добавление и удаление ключа в Vue: состояние могло оставаться «Не сохранено»
после успешного ответа. Регрессия проверяет весь переход ввода и очистки.
Необязательный JSON-черновик имеет явный default `undefined`: иначе Vue может
привести отсутствующий prop к `false`, поскольку JSON-union содержит boolean.
Переданное человеком `false` при этом остаётся настоящим черновиком.
Общая подпись об успешной записи скрывается, пока остался черновик или ошибка.

Текст и числа сохраняются по Enter или выходу из поля; подсказка стоит у редактора.
Выбор варианта и переключение boolean сохраняются сразу. Массив меняется как
черновик и отправляется целиком по кнопке «Сохранить список». При ошибке
сохраняется ввод, для одиночного поля появляется «Повторить».

«Сбросить» удаляет override и черновик этого параметра, возвращая наследование.
Если выход из текстового поля уже начал запись, сброс ставится в существующую
очередь store: кнопка не теряет click из-за внезапного disabled.
При недоступном источнике сохранённый выбор остаётся доступен для сброса;
обычный справочник read-only полей скрыт.

Неизвестный base показывает «Выбирает исполнитель» без подстановки schema default.
Boolean с неизвестным base сохраняет select после выбора, чтобы контроль
не менял вид и не терял фокус. Nullable boolean также использует select.
Обычные строковые enum показаны без кавычек; смешанные JSON-типы различаются
в подписях. `null`, пустая строка и удаление override остаются разными действиями:
у строкового `null` есть отдельная кнопка «Задать пустую строку».

Регрессии находятся в `provider-native-settings.component.test.js`.
Геометрию и работу действий проверяют в браузере на настоящей `SettingsView`
с собственными тестовыми каталогами, без пользовательских профилей.
