# Область дополнительных настроек и доставка runtime

Форма использует `catalog.scope.label`. Старый каталог сохраняет «Для чатов Cockpit»;
каталог с подтверждённым вторым consumer показывает чаты и конвейеры.

Поле получает подпись «Только чаты», когда чат подтверждён, а поддержка конвейера
доказанно отсутствует. `unverified` показывает причину непроверенной совместимости
и сохраняет доступный чатовый control. Draft, CAS, reset и прежний storage не меняются.

Карточка использует необязательную capability адаптера `distribution`. Встроенная
доставка показывает «Входит в Cockpit» и готовность сборки, скрывает отдельные команды
установки и обновления исполнителя. Без авторизации исправный runtime сохраняет
доступ к каталогу настроек и MCP; карточка показывает подсказку авторизации.

Недоступная сборка показывает `distribution.problem`: причину простыми словами и, если
есть, команду исправления кнопкой, открывающей терминал с введённой командой (затем
«Перепроверить»). Текст и команду формирует адаптер с учётом результата probe:
отсутствующую, повреждённую или собранную под другой Node сборку лечит
`<корень>/bin/cockpit deps`, незавершённую публикацию обновления — `--recover-job` с id
задания из маркера; нечитаемый маркер даёт только текст о ручной сверке.

Установленный внешний runtime сохраняет прежнюю карточку. Vue не проверяет vendor ID:
область полей и способ доставки приходят из общих публичных контрактов.
