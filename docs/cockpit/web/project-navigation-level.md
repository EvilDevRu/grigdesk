# Проект — главный уровень панели

- **Проект — главный уровень панели.** Это горизонтальный ряд кнопок с числами прогонов:
  в один клик можно перейти к «Все» или конкретному профилю. Невидимый измерительный ряд
  получает натуральную ширину тех же кнопок; `ResizeObserver` оставляет столько проектов,
  сколько реально помещается, а хвост переносит в правый `UiPopover` `+N`. Выбранный проект
  резервирует место и после выбора из списка остаётся в основном ряду. Контейнер измерителя
  обрезан локально, поэтому длинный хвост не создаёт горизонтальный overflow страницы.
