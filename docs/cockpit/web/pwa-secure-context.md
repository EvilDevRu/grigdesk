# Возможности устройства в локальном окне

PWA и её service worker сняты. Electron открывает интерфейс на loopback HTTP origin;
проверки Notification, wake lock и микрофона сохраняются по фактическим возможностям среды.
Отсутствие serviceWorker API не мешает wake lock, уведомлениям или обновлению интерфейса.

Системные уведомления используют Notification API, при недоступности остаётся мигание
заголовка скрытого окна. Нажатие фокусирует существующее приложение и открывает адрес цели.
Приложение телефона имеет отдельный мобильный вход и не зависит от прежней PWA.
