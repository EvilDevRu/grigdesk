# Раскладка окна установки без скачков

Фиксированной высоты самого диалога недостаточно: прежний footer содержал от одной
до трёх кнопок, на узком экране они меняли число строк. Шаги прокручивались вместе
с пакетом, а результат центрировался иначе, чем форма. Замер только первого чтения
current и поиска версий не обнаруживал эти переходы.

`PluginInstallDialog.vue` использует `UiDialog` с `bodyInset=false`. Заголовок, крестик
и полоса шагов принадлежат header. В footer постоянно существуют два места действий:
второстепенное слева и основное справа. Ни одно состояние не добавляет третий ряд
или кнопку; закрытие доступно также через общий крестик. На широком экране подсказка
стоит рядом с действиями, на мобильном — в постоянной строке над ними.

`install-workspace` занимает тело диалога. Внутри только `install-content` прокручивает
содержимое; `scrollbar-gutter: stable` сохраняет его ширину при появлении длинного diff.
Ошибки чтения, применения и восстановления стоят в отдельной нижней области workspace.
Они сокращают видимую высоту прокрутки, сохраняя начало формы, шапку и footer на месте.

Во время подготовки заранее отведены строка идентификатора пакета и места подписей
«Готово». Их заполнение после проверки не сдвигает список этапов и полосу прогресса.

Каждый экран начинается с одинакового блока статуса. Успешный итог завершает все три
шага, показывает карточку сохранённого пакета и дальнейшие действия. Переход между
экранами сбрасывает прокрутку; повторный snapshot того же экрана сохраняет её.
Крестик закрывает окно без отмены работающего задания. Отмена установки остаётся
отдельным действием, а recovery по-прежнему запрещает забыть незавершённое восстановление.

Проверка компонента дополнена сценариями завершения шагов, прокрутки и крестика.
Браузерный замер охватывает loading → source → running → ready → applying → done,
а также failed, recovery, появление ошибки и раскрытый diff. На ширинах 340, 390,
600 и 1100 px сравниваются прямоугольники окна, header, шагов, footer и основного
действия, а не только границы окна. На низких экранах проверяется доступность footer.
