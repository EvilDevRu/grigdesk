# Состояние — второй, визуально тихий уровень в той же строке

- **Состояние — второй, визуально тихий уровень в той же строке.** Проектный ряд занимает
  весь свободный левый участок, а состояния прижаты справа к кнопкам вида единым кластером;
  второй строки у панели нет. До 1250 px у состояний остаются точки и числа без текста,
  а до 760 px они сворачиваются в один `UiPopover`, чтобы не отнимать место у проектов.
  Панель сама поднята в верхний отступ общего layout, включая закреплённое состояние
  при прокрутке. Такой же компенсирующий отступ зарезервирован после неё, поэтому
  карточки конвейера остаются на прежней высоте.
  Категории берутся из того
  же взаимоисключающего классификатора `shared/pipeline-nav-badge.js`, что чип навигации
  и popover топбара, поэтому «Проблемы» сильнее «Ждут решения», а те — сильнее «В работе».
  Отсюда обязательный чип «Неактивные» (`projectTasks − totalCount`): завершённый,
  остановленный или read-only прогон не попадает ни в одну категорию вотчера, и без него
  сумма чипов не сходилась с «Все». Числа считаются ВНУТРИ выбранного проекта. Пустая
  выборка сбрасывает только состояние: выбранный проект остаётся контекстом человека.
