# Сенсорный размер общих элементов

Контейнер с `data-ui-touch` включает высоту элементов 44 px через общий
`web/src/styles/tokens.css`. Product-компонент выбирает режим атрибутом; локальные
CSS-декларации `--control-*` остаются запрещёнными.

Блок мобильного доступа в настройках использует этот режим для полей и кнопок.
Его QR-диалог получает атрибут на собственном surface, поскольку Teleport выводит
диалог за пределы родительского контейнера. Для общего `confirmDialog` опция
`touchTargets: true` включает тот же атрибут в `UiDialogHost`.

Режим действует только в отмеченном контейнере. Проверки публичной границы и
стилей — `npm --prefix web run check:ui` и `check:ui-styles`; поведение настроек
проверяет `tests/web/settings-mobile.component.test.js`.
