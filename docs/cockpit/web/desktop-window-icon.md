# Иконка окна на панели задач

У упаковки и системного окна разные PNG из одной геометрии `web/scripts/gen-icons.py`:

- `desktop/build/icon.png`, 512 × 512 — иконка пакета electron-builder;
- `desktop/build/window-icon.png`, 64 × 64 — иконка главного окна, настроек и заставки.

Desktop builder копирует второй файл в `dist/icon.png`, который уже используют все окна.
Растр заранее сглажен генератором. Форма, цвета и положение знака совпадают с большим PNG.

Передача единственного PNG 512 px в `BrowserWindow.icon` давала зубчатую дугу на панели
с иконками 32 px: редкие выборки большого растра почти полностью теряли сглаживание.
64 px сохраняет сглаженные края при таком уменьшении и подходит для крупных значков окна.

Несколько `nativeImage.addRepresentation` не решают это на X11: Chromium передаёт в
`_NET_WM_ICON` представление масштаба 1.0. Это видно в
[реализации SetWindowIcons](https://github.com/chromium/chromium/blob/main/ui/ozone/platform/x11/x11_window.cc).
Сам [протокол X11](https://specifications.freedesktop.org/wm/latest-single/)
допускает несколько размеров, но Electron не предоставляет отдельного API для их публикации.

После изменения PNG нужна пересборка пакета и новый запуск приложения. Уже открытое окно
сохраняет свою прежнюю системную иконку.
