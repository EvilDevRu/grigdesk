# Выбор рабочей папки чата

`ChatWorkdir.vue` открывается подписанной кнопкой «Папка» с контурной иконкой из общей
карты навигации. На узком экране кнопка остаётся в строке названия, а задача переносится ниже.
Пустой чат показывает текущий путь, недавние варианты и подсказки отдельными строками.

Окно разделяет текущий путь, дополнительные репозитории, быстрый выбор и поля проекта/пути.
Основной путь не повторяется в дополнительных репозиториях. Быстрые варианты используют
`UiSelectableRow`: иконка слева, название с пояснением, выделение и галочка текущего выбора.
Кокпит показан один раз; остальные недавние варианты сохраняют порядок. Полные пути
одноимённых каталогов видны в пояснении и подсказке. Длинный список прокручивается отдельно,
ширина окна ограничена экраном, текущий путь переносится без горизонтального переполнения.

Поля связаны с подписями через `UiField`. Форму абсолютного пути можно отправить клавишей
Enter. Успешный выбор закрывает окно; ошибка остаётся внутри него. Перед диалогом переноса
выбор закрывается, чтобы всплывающий слой не перекрывал подтверждение.
Контракты самого перехода описаны в [рабочей папке разговора](../guide/chat-workdir.md).

Оформление кнопки принадлежит `styles/components/actions.css`, строки — общему UI-набору.
Компонент задаёт раскладку содержимого. Размер телепортированного окна передаётся через
`style` у `UiPopover`, как в [контракте всплывающих слоёв](teleported-overlay-styles.md).
