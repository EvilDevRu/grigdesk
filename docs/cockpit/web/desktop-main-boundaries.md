# Границы главного процесса окна

`desktop/src/main.ts` создаёт главное окно, Session, UA и lifecycle, настраивает сессию
и защиту окон. Заставка, supervisor, контроллер выхода и контроллер настроек сохраняют
свои обязанности и порядок вызовов.

`windowDocuments.ts` экспортирует только loadDocument и loadPinnedDocument. Точное
равенство URL, включая hash, вызывает reload нового документа; другой адрес идёт через
loadURL. Внутренний reload снимает listeners при завершении, отказе главного фрейма,
destroyed или abort. Подфрейм не завершает попытку. Abort останавливает только живое
окно. До начала загрузки отменённый сигнал или уничтоженное окно дают возврат без эффектов.

Проверка закреплённого release использует привязанный в main Session.fetch. Несовместимая
версия, другой id, HTTP-отказ или битый JSON дают прежний PermanentConnectionError.
Совпавший релиз загружается со своим URL и hash исходного адреса; запасного перехода на
рабочую сборку нет.

`settingsWindowFactory.ts` собирает существующий settingsWindowController. Порты дают
создание BrowserWindow, рабочую область, Session, icon, packaged и callbacks защиты,
горячей клавиши и ошибки. До loadURL устанавливаются роль UA и защита потомков с теми же
опциями главного окна. Короткое замыкание canOpen остаётся: окно показано, родитель жив,
затем проверка сессии. Единственность и жизненный цикл окна принадлежат controller.

Новые модули импортируют Electron только как типы. Значения, пути пакета и параметры
окружения остаются в main: это позволяет прямые Node unit-тесты и сборку CJS без
вычисления путей через import.meta.
