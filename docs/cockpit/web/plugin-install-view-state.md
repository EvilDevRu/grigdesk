# Проекция состояния диалога установки

`web/src/shared/pluginInstallView.ts` содержит чистую `deriveInstallDialogView`.
Она получает job, режим и название инициатора, флаги bootstrap, ошибки, признаки текущего
действия и поля поиска/подтверждения. Целый Pinia store и реактивные ссылки ей не нужны.

Проекция выбирает loading, unavailable, source, progress, ready или result; вычисляет
заголовки, описание этапа, иконку, progress, шаги, completed, locked и canStart. Stage tone
и result tone независимы: recovery имеет предупреждение у этапа и нейтральный результат.
Footer содержит прежние подписи и доступность действий. Trim адреса и проверка совпадения
input key выполняются в проекции; ручные правки обновления требуют replaceModified.

`PluginInstallDialog.vue` собирает вход одним computed. Прежние имена остаются тонкими
computed aliases, поэтому разметка, обработчики и CSS сохраняются. Watch прокрутки
следит за примитивным screen через alias view, а не за новым объектом проекции.

Состоянием, запросами, polling, openingEpoch и закрытием владеют компонент и store.
Pending apply/reconciliation важнее ready; recovery закрывает мутации, но не разрешает
забыть job. Заголовок сохранённого глобального задания имеет приоритет над инициатором.
`pluginInstall.ts` сохраняет публичные подписи, progress и stage helpers.

Таблица чистых состояний проверяется отдельно от D1–D24 настоящего компонента. D24
сравнивает тексты, тоны, иконку, подсказку footer, класс результата и состояния шагов
для 13 состояний; D9 и D15 сохраняют запрет забыть recovery.
