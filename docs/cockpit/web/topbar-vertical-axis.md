# Вертикальная центровка топбара

В `AppShell.vue` нижняя линия топбара рисуется через `box-shadow: inset 0 -1px 0`.
Она не уменьшает область раскладки. При высоте топбара 36 CSS px центры текста,
разделителей, кадров логотипов, колокольчика и настроек находятся на y=18 px.
Прежний `border-bottom: 1px` оставлял для flex-строки 35 px и поднимал её ось на
полпикселя относительно геометрического центра шапки и системных кнопок Electron.

`v-svg-pixel-snap` корректирует только горизонтальное положение логотипов.
Независимое округление верхней границы значков высотой 13 и 14 px сдвигало их
вертикальные центры в разные стороны. При DPR=1 маленькие знаки оказывались
примерно на 0.47 CSS px выше Claude и Codex, хотя центры кнопок совпадали.
Вертикальное положение теперь целиком задаётся общей раскладкой; размеры
значков и площадок нажатия сохранены.

Браузерная проверка полного `AppShell.vue` с синтетическими хранилищами измеряет
`Range.getBoundingClientRect()` для текста, прямоугольники и видимые границы SVG.
Проверены ширины 600, 834, 1024 и 1920 CSS px при DPR 1, 1.25, 1.5, 2 и 3:
центры совпадают с осью топбара с допуском 0.01 CSS px. Дополнительно проверяются
открытие подсказок и оповещений, повторные resize и удаление/возврат исполнителей.
Горизонтальная привязка и прежние размеры логотипов сохраняются.
