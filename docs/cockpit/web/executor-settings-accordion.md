# Настройки исполнителей раскрываются по одному

В «Настройки → Исполнители» реестр показан вертикальной гармошкой. При открытии
страницы все строки закрыты; нажатие раскрывает одного исполнителя и закрывает
предыдущего. Повторное нажатие закрывает выбранного. Состояние раскрытия локально
для страницы и не меняет настройки исполнителей.

Карточки разделены по [типам исполнителей](../chat/executor-types.md). Заголовки
видны только при двух непустых группах; порядок внутри группы следует реестру.
Одна гармошка общая для всех типов. Узкий API-исполнитель не получает подпись
об установке CLI и будущем подключении чата.

В закрытой строке видны имя, поставщик, тип, версия, число моделей и доступность.
Точка обновления у имени сохраняет подсказку о версии CLI. Заголовок — общий
`UiDisclosureButton` с `aria-expanded` и `aria-controls`; панель с `role="region"`
ссылается на него через `aria-labelledby`. Enter и пробел работают как у кнопки.

Раскрытая панель содержит факты об авторизации и каталоге, команду установки при
необходимости, ключи доступа (если адаптер их объявил), настройки, ресурсы, MCP и
обновление CLI. На широком экране настройки
и ресурсы стоят рядом с MCP, на узком — друг под другом. Фиксированной высоты у
настроек и секции MCP нет; длинный список MCP ограничен 360 px и прокручивается.
Это убирает пустые участки, которые раньше выравнивали соседние высокие карточки.

Панели скрываются через `v-show`: поля и состояние операций сохраняются при
переключении. Опрос MCP и ресурсов по-прежнему начинается при открытии раздела,
а раскрытие строки не запускает повторный запрос. Проверки взаимодействия живут
в `tests/web/settings-mcp.component.test.js`.
