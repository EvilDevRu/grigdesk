# Клиент, намерения и подписка 3D

Панель Studio3dPanel живёт в единственном ToolHost: правая рейка, обычный док,
развёрнутый док и страница `/3d` используют один экземпляр. Адаптер маршрута переводит
query tab/model/version в команду open и очищает query; выбор остаётся в панели.
Compact даёт одну прокручиваемую колонку. active=false размонтирует просмотрщик
и снимает viewing-модель. Горячая клавиша по умолчанию — Ctrl+Shift+7.

Раздел `/3d` использует общий cookie API и декодирует JSON закрытым контрактом.
HTTP отказ сохраняет status, code и server payload; нарушенный DTO сообщает
«Некорректный ответ раздела «3D»…». Viewer и файлы используют ту же авторизацию.

Подписчик `sseSubscribe` принадлежит AppShell: один на авторизованную вкладку,
пока плагин включён. Уход в чат не останавливает обновления и уведомления.
Потеря сессии и отключение отменяют чтения, uploads и таймеры. Hello перечитывает state,
задачи и выбранную модель. Частый progress правит DTO без HTTP; changed
объединяется за 300 мс. Recent восполняет пропущенное событие без повторного тоста.
Показанные terminal ключи хранятся в localStorage отдельно для текущего входа,
не больше 500. Событие studio-progress содержит status, progress и etaSeconds.
Тост модели ведёт к `/3d?model=…&version=…`; видимая сейчас модель тоста не требует.

Поиск и цена ждут 300 мс после ввода. Поиск, offers, quote и detail имеют отдельные
controllers и поколения. Смена формы сразу очищает цену; поздний ответ не может
включить кнопку новой формы. Marker новой библиотеки отзывает старые проекции.
Внешний AbortSignal общего API сохраняет deadline и запрещает повтор после отмены.

Перед POST окна UUID, owner из clientScope текущей сессии, libraryId и полный снимок сохраняются
в IndexedDB `cockpit-studio3d-intents`. Transaction complete подтверждает запись.
Без хранилища запуск блокируется. Двойной клик объединяется до записи и отправки;
сетевой отказ оставляет прежний UUID. Изменённое содержимое получает новый UUID.
После reload сначала читается server job: только 404 разрешает повтор исходного
запроса, если нажатие не старше 10 минут. Более старое нажатие удаляется с тостом
«Заказ «…» не отправлен: связь оборвалась. Повторите вручную.». Ответ 4xx как от GET,
так и от повторного POST снимает запись с причиной. Старый marker, другой owner и
доказанный отказ не вызывают новую оплату.

Ширина навигатора — настройка устройства `cockpit-studio3d-nav-width`, 240–420px,
по умолчанию 260 px. Separator поддерживает pointer capture, стрелки, Shift,
Home/End и сброс двойным щелчком. Ни геометрия, ни поиск не меняют server prefs.

Проверки: `studio3d-api`, `studio3d-store`, `studio3d-view.component`, nav/icons,
SSE event names, alert targets/deep links и общий журнал API/окна.

Форма создаётся из словаря семи типов поля, с visibleWhen, группами движений,
поиском и раскрытием advanced при ошибке. Цена неизвестного шага и неизвестный
баланс платного шага блокируют запуск; ноль разрешён только как настоящая цена.
Кнопка удерживает UUID после сетевого отказа и не отправляет новое списание при
price_changed. Пачка до 50 строк подтверждает общую сумму и одним POST сохраняет
server snapshot. Отказ диалога и изменение формы до отправки закрывают запуск.

Виды принимают PNG/JPEG/WebP после проверки bytes и настоящего bitmap decode,
до 20 МиБ/64 Мп. Swap сохраняет файлы и upload identity. Общие линии «макушка/глаза/
подбородок» движутся вертикально с pointer capture, стрелками и Home/End.
Лист режется локально: углы определяют фон, порог 24, пустота <0,5%, gap 1%, поля 2%.
Прямоугольники и их назначения подтверждает человек; нераспознанные области можно
задать вручную. Bitmap, object URL и temporary canvas освобождаются при закрытии.
«Свой файл» создаёт модель бесплатно; GLTF получает подсказку сохранить GLB.

Offers вкладки «Создать» запрашиваются после появления libraryId. Сетевые ошибки
браузера переводятся в «Нет связи с сервером»; параметры версии выводятся списком.
