# VibeVoice: поддержка русского языка

Проверено 2026-10-01 по документации Microsoft. VibeVoice — семейство моделей;
поддержку языка нужно проверять отдельно для распознавания (ASR) и синтеза (TTS).
Локальный запуск моделей в рамках этой проверки не выполнялся.

## Распознавание

- **VibeVoice-ASR** поддерживает русский. В официальной таблице результатов для
  MLC-Challenge указаны WER 12,40% и DER 0,90% на русском. Эти показатели относятся
  к указанному набору данных, а не гарантируют качество на произвольной записи.
  Модель распознаёт язык автоматически и поддерживает переключение языков.
  Источник: [документация ASR](https://github.com/microsoft/VibeVoice/blob/main/docs/vibevoice-asr.md).
- **VibeVoice-ASR-Streaming-7B и 1.5B** также поддерживают русский: он прямо входит
  в список десяти языков в обеих официальных карточках.
  Источники: [7B](https://huggingface.co/microsoft/VibeVoice-ASR-Streaming-7B),
  [1.5B](https://huggingface.co/microsoft/VibeVoice-ASR-Streaming-1.5B).

## Синтез

- **VibeVoice-1.5B / VibeVoice-TTS**: официальная поддержка русского отсутствует.
  Карточка модели указывает обучение только на английском и китайском и считает
  остальные языки неподдерживаемыми. Общая формулировка README о других языках
  не подтверждает поддержку русского; межъязыковые возможности могут быть нестабильны.
  Источники: [карточка модели](https://huggingface.co/microsoft/VibeVoice-1.5B),
  [документация TTS](https://github.com/microsoft/VibeVoice/blob/main/docs/vibevoice-tts.md).
- **VibeVoice-Realtime-0.5B** ориентирована на английский. Предлагаются
  экспериментальные голоса для немецкого, французского, итальянского, японского,
  корейского, нидерландского, польского, португальского и испанского; русского
  в этом списке нет. Документация предупреждает о непредсказуемых результатах
  для других языков, поэтому считать русский официально поддерживаемым нельзя.
  Источник: [документация Realtime](https://github.com/microsoft/VibeVoice/blob/main/docs/vibevoice-realtime-0.5b.md).
