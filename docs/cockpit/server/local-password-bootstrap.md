# Первичная настройка пароля — только с самой машины

`/api/auth/setup` обязан быть публичным (иначе пароль нечем задать), поэтому на сетевом адресе
им завладел бы первый желающий — вместе с PTY-шеллом. Гард пускает его только при
`isLocalRequest`: loopback-адрес **и** отсутствие любых следов пересылки (`X-Forwarded-*`,
`Forwarded`). Двойная проверка не избыточна — любой локальный обратный прокси даёт `127.0.0.1`,
так что одного его мало. Проверено: с подделанным `X-Forwarded-For` или `-Proto` → 403,
чистый локальный запрос → 200.
