# Доступ к кокпиту с других устройств — границы вариантов

Направление «открыть кокпит на планшете как приложение» откатывалось; часть выводов действует
до сих пор, чтобы не проходить круг заново.

**Выбор решают стенды, а не удобство входа.** Стенды слушают на всех интерфейсах
(`0.0.0.0:5191`, `:5193`, `:8090`…), поэтому вариант с IP-связностью (VPN-клиент на планшете)
открывает их сам собой — ни прокси, ни поддоменов не нужно вовсе.
Вариант «на планшете только браузер» обязан проксировать КАЖДЫЙ порт отдельным именем, отсюда
`p<порт>.<домен>`, ограниченные диапазоны и `forward_auth` у VPS-шлюза. Всё, что даёт один
публичный хост без wildcard, стенды не покрывает в принципе.

- **Свой CA не даёт «автоматически»** — но для СВОИХ устройств этого достаточно, и именно так
  сделано сейчас (см. «Локальный HTTPS» ниже). Установка корня — решение о доверии на уровне ОС,
  из браузера её не выполнить (файл → системные настройки → «Сертификат ЦС» → PIN → предупреждение
  про мониторинг сети). Для «другой человек открыл и поехало» не подходит в принципе; для двух
  своих планшетов — разовый шаг.
  Важная деталь: серверный лист не длиннее **398 дней**, и браузеры смотрят ТОЛЬКО
  в subjectAltName (CN игнорируется).
- **Второй VPN-клиент на планшете — вариант закрыт.** У мобильной ОС активным может быть только
  ОДНО VPN-приложение, а если слот уже занят системной сетевой политикой, второй клиент его
  вытеснит. Причина именно в слоте и не зависит от продукта; на рабочей машине такого ограничения
  нет, пока дополнительный клиент не забирает default route. Любой новый кандидат этого сорта
  упирается в то же ограничение, обсуждать его заново не нужно.
- **Публичная ссылка одного сервиса** (внешний туннель с доверенным сертификатом, у открывающего
  ноль шагов) — прежнее возражение про открытый наружу PTY снято: весь `/api` за сессией,
  `setup` только с localhost, `COCKPIT_TOKEN` удалён. Закрывают такой путь **стенды**: он даёт
  один хост без wildcard и фиксированный набор портов.
- **Cloudflare Tunnel** — бесплатен и работает за CGNAT, но по этому кокпиту бьёт трижды:
  100-секундный потолок ответа (ошибка 524) режет `POST /api/chat`, который молчит весь ход
  агента; 100 МБ на тело запроса убивают загрузку видео в распознавание; и зона переезжает
  на NS Cloudflare, который вдобавок терминирует TLS и видит переписку, дифы и данные портала
  открытым текстом. Обход таймаута есть только через их WARP-клиент — то есть снова VPN-слот
  на планшете, но уже с посредником в середине.
