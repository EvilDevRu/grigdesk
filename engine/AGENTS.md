# Память агента

Перед работой в этом проекте прочитай `../.agents/memory/MEMORY.md` (каталог
`.agents/memory/` в корне кокпита), затем открой связанные с текущей задачей
заметки из того же каталога (разделы: `cockpit/`, `engine/`, `behavior/`). Это
накопленный проектный контекст: учитывай его, но сверяй с текущим кодом и
состоянием среды.

Каталог `.agents/memory/` — снимок памяти Claude Code. Не записывай изменения
обратно в `~/.claude`; обновляй проектную копию только по явной просьбе человека.
