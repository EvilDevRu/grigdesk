GrigDesk — окно и управление локальными компонентами

grigdesk-ctl                     Меню в терминале, иначе справка
grigdesk-ctl open [--force]       Открыть окно GrigDesk; сервер поднимает само окно
                                (без runtime.json — через службу)
grigdesk-ctl status [--json]
grigdesk-ctl server start [--wait]
grigdesk-ctl server stop [--force]
grigdesk-ctl server restart [--wait] [--force]
grigdesk-ctl server status [--json]
grigdesk-ctl server logs [-n N|--lines N] [-f|--follow]
grigdesk-ctl server check-updates [--json]
grigdesk-ctl server update [--restart] [--json] [--force]
grigdesk-ctl server update-status [--json]
grigdesk-ctl server resume-update [--restart] [--json] [--force]
                                [--rollback — вернуть прежний выпуск]
grigdesk-ctl server update-channel release|dev
grigdesk-ctl relay setup | restore [--ssh-port N] [--public-host h] [--public-port N]
                                [--candidate-host h]  Мастер удалённого доступа на VPS
grigdesk-ctl relay status [--json]
grigdesk-ctl device add <имя> [--address host:port] [--json]
grigdesk-ctl device list [--json]
grigdesk-ctl device revoke <id>
grigdesk-ctl artifacts-cleanup [--dry-run] [--older-than 7d] [--keep-generations 3] [--json]
                                Срок: положительное целое с m (минуты), h (часы), d (сутки)
grigdesk-ctl artifacts-cleanup --inventory [--topic <имя>] [--json]
                                Занятое место по категориям и крупнейшим папкам, без удаления
grigdesk-ctl desktop … | tracker … | pipeline … | voice … | mobile … | release …
grigdesk-ctl desktop use-server <ELF|R>  Выбрать серверный ELF или прежний SEA-комплект для окна
grigdesk-ctl build [all|server|web|window|factory|deepseek|deepseek-admission|apk]
                                Без аргументов: сервер, окно, tasks и voice (all)
                                factory: автономный движок в bin/factory
                                deepseek: собрать и установить DeepSeek Harness
                                deepseek-admission: проверить допуск GLM для обоих режимов
                                apk: Android-приложение со встроенным вебом
grigdesk-ctl dist build [--target linux-x64|windows-x64] [--channel release|dev]
                                Прогон в снимке исходников; Windows x64 — локальный ZIP канала dev
grigdesk-ctl dist doctor        Диагностика среды
grigdesk-ctl dist check --from <каталог> | --local-run <UUID>
grigdesk-ctl dist install --from <каталог> | --local-run <UUID> --mode local|remote|server
                                Отдельные пути и подтверждение установки обязательны
grigdesk-ctl dev | deps | run
grigdesk-ctl --help | -h | help | <группа> --help
grigdesk-ctl --version

--force разрешает открытие окна, stop и restart из хода агента.
Число строк журнала: 1–10000, по умолчанию 100.
