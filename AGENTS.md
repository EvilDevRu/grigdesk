# Общие инструкции проекта

Перед работой полностью прочитай `CLAUDE.md` и соблюдай его как общие инструкции
проекта для любого исполнителя. Строки вида `@путь` в разделе «База знаний» —
импорты Claude Code; исполнитель без поддержки такого синтаксиса должен сам открыть
относящиеся к текущей задаче документы по этим путям.

В подкаталогах учитывай ближайший `AGENTS.md`: он дополняет корневые инструкции и
может направлять в локальный `CLAUDE.md` или документацию подсистемы.

# База знаний

Карты `docs/cockpit/*.md` содержат только заголовки и темы. Адрес
`#/knowledge/<uuid>` — веб-маршрут, не файл: ищи запись командой
`knowledge search "<тема>"`, затем читай полностью через `knowledge read <uuid>`.
Исправляй факт в том же заходе командой `knowledge write <uuid>
--expected-revision <revision> ...`: ревизия защищает чужую правку, а успешная запись
обновляет карту. Записывай только при разрешённой файловой политике; удаление остаётся
человеку.

# Память сессии

- Агент умирает вместе с остановкой сессии и НЕ возвращается: фоновые задачи
  (`run_in_background`) при этом теряются на середине. Долгие операции (сборки,
  деплои) запускай отсоединённо — `nohup ... >log 2>&1 &` / `setsid` — чтобы процесс
  пережил агента, и проверяй результат по лог-файлу. Критичную работу по возможности
  доводи до конца в текущем ходе, не откладывая на «потом дочитаю из фона».
