# Общие инструкции проекта

Перед работой полностью прочитай `CLAUDE.md` и соблюдай его как общие инструкции
проекта для любого исполнителя. Строки вида `@путь` в разделе «База знаний» —
импорты Claude Code; исполнитель без поддержки такого синтаксиса должен сам открыть
относящиеся к текущей задаче документы по этим путям.

В подкаталогах учитывай ближайший `AGENTS.md`: он дополняет корневые инструкции и
может направлять в локальный `CLAUDE.md` или документацию подсистемы.
