# Общие инструкции проекта

Перед работой полностью прочитай `CLAUDE.md` и соблюдай его как общие инструкции
проекта для любого исполнителя. Строка `@CLAUDE.local.md` в нём — импорт Claude Code;
исполнитель без поддержки такого синтаксиса сам открывает этот файл, если он есть.

В подкаталогах учитывай ближайший `AGENTS.md`: он дополняет корневые инструкции и
может направлять в локальный `CLAUDE.md` или документацию подсистемы.

# Документация

Карта областей — раздел «Документация» в `CLAUDE.md`. Прежде чем править область, открой
её оглавление `docs/cockpit/<область>/README.md`: там контракты продукта, устройство и
грабли по строке на документ. Затем читай нужные файлы; поиск по тексту — `rg` по `docs/`.
Исправляй факт в том же заходе: новый проверенный факт — отдельный файл в папке области и
строка в её README. Опыт этой машины, которому не место в публичном репозитории, лежит в
`docs/local/` (вне git).

# Память сессии

- Агент умирает вместе с остановкой сессии и НЕ возвращается: фоновые задачи
  (`run_in_background`) при этом теряются на середине. Долгие операции (сборки,
  деплои) запускай отсоединённо — `nohup ... >log 2>&1 &` / `setsid` — чтобы процесс
  пережил агента, и проверяй результат по лог-файлу. Критичную работу по возможности
  доводи до конца в текущем ходе, не откладывая на «потом дочитаю из фона».
