# Сдача

Перед эффектом проверь approved acceptance, точную стратегию/actions/targets из delivery
и immutable pin попытки. Сдавай только объявленным в описании способом через deliver.py.
Передай --context доверенный файл и отдельный --path repo:relative/path для каждого пути задачи.
Commit создаёт локальный коммит в ветке задачи; merge — безопасное вливание в рабочую ветку
без PR; pull-request — обычный push ветки и объявленная argv-команда запроса на слияние.
Никаких force, add -A, переключения чужой ветки, stash/reset и комментариев в трекер.
Грязный чужой target или конфликт требуют человека до изменений. Повтор не дублирует сдачу.
Сообщение коммита содержит только смысл задачи, без частных данных из артефактов.
В artifacts.ship сохрани коммит, ветку, результат способа и адрес сохранённой копии.
Done только после выбранной сдачи, отказ human/environment не считается успехом.
