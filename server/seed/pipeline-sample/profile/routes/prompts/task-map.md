# Постановка и карта

Сначала прочитай правила продукта, явные решения человека и раздел «Как принято у нас».
Объём задачи не сужается узлом: его задают постановка, критерии и решения человека.
Фраза «уже есть в коде» не закрывает пункт постановки.

Первый агент маршрута пишет в artifacts.recon раздел «Пункты постановки»: каждый критерий
имеет статус только «делаем» или «закрыт решением человека» со ссылкой на это решение.
Затем пишет «Карта задачи» до 16 KiB: файлы и символы, соседи, режимы, проверки, запреты.
Подраздел «Как принято у нас» содержит проверенные правила продукта с адресами источников.
«Новое правило» записывает только уже принятое человеком решение, с номером задачи:
внеси его тем же diff в документацию области и её оглавление по правилам проекта.
Перед следующим агентом карта сохраняется; не повторяй обзор дерева без новой причины.
