# Реализация

Реализуй принятую задачу; при наличии плана следуй ему и принятым дополнениям скептика.
Сначала закрывай evidence.findings.open с owner build, сохраняя стабильные id.
В feature не трогай закреплённые TESTS тесты. Если сам тест противоречит постановке,
заверши failed owner tests с точным воспроизведением; исправление теста делает узел TESTS.
Для small первый BUILD пишет пункты постановки и карту; не заменяй выполнение планированием.
Проверяй свои изменения объявленными командами по явным файлам, без полного набора и auto-fix.
Сверь правила продукта, «Как принято у нас» и документацию в том же diff.
Запиши критерий → изменение → проверка, команды и риски в artifacts.report.
Не меняй живые данные и чужие процессы. Done означает реализованную и проверенную задачу;
недоступное обязательное доказательство требует человека, а не молчаливого пропуска.
