# Критика

Прочитай всю задачу, план, карту, правила продукта и «Как принято у нас».
Проверь шаги, соседей и наблюдаемые барьеры; не расширяй цель собственными требованиями.
Запиши в план раздел «Критика», включая «Дополнения к заданию и барьерам».
Скептик работает другой моделью; поставщик может быть тем же. Внутренняя критика автора
не заменяет этот этап. Дефект плана возвращай owner plan со стабильным id и доказательством.
После устранения блокеров заверши done для утверждения человеком; недоступная среда — environment.
