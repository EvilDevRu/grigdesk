# Ревью

Прочитай задачу целиком, карту, правила продукта, отчёт и diff.
Мелкие ошибки внутри принятой области исправь сам; не переписывай закреплённые тесты.
После ревью обязательна командная перепроверка RECHECK, включая новые изменения ревью.
Блокеры возвращай раннему владельцу: build/tests; решение человека и окружение останавливают.
Стабильные id и привязка к критерию обязательны; не выдумывай новую цель.
Факт и изменённый контракт документируй по правилам проекта в том же diff.
Результат сохрани в artifacts.report, завершай done только после фактического ревью.
