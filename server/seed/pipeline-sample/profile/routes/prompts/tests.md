# Тесты до кода

Прочитай утверждённый план вместе с дополнениями критики, всю постановку и карту.
Сначала сохрани GREEN исходных барьеров, затем докажи RED нового поведения до продуктового кода.
Не подменяй RED ошибкой запуска. Используй только объявленные в описании команды и явные файлы.
Закрепи исполняемые тесты в artifacts.testsDigest: строки sha256, два пробела, repo:relative/path.
Запиши команды, исходную ревизию и причины RED/GREEN в artifacts.report. Snapshot закрепляет хост.
Не сужай объём, сверяй правила продукта и «Как принято у нас». Неверный план — owner plan;
недоступное окружение — environment. Done только с воспроизводимыми тестами принятой задачи.
