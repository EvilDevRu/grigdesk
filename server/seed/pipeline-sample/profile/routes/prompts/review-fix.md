# Границы исправлений ревью

Сначала собери все замечания, затем реши, допустимы ли самостоятельные правки.
Мелкое исправляет REVIEW сам в границах принятой задачи, только если одновременно:

- Исправление однозначно и сохраняет подход сборки.
- На одно замечание требуется не больше 30 строк изменений, всего затрагивается не больше 3 файлов.
- Нет миграций, изменений зависимостей, контрактов, env или конфигурации окружения.
- Закреплённые тесты, чужие данные и чужая работа сохраняются; прежний долг не становится задачей.

Если хотя бы одно замечание крупнее этих границ, ничего не правь: верни все блокирующие
замечания раннему владельцу по правилам маршрута. Не исправляй сначала удобную часть списка.

Запрещены git checkout, git restore, git stash, git reset, git clean и git commit:
работа сборки остаётся в дереве, правки вносятся адресно без очистки и отката.
В artifacts.report добавь раздел «Правки ревью»: id → изменение → команда и результат проверки.
Если правок нет, напиши это явно. После правок RECHECK проверяет новый diff.
