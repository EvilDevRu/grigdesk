# Диагноз

Начни artifacts.diagnosis первым разделом «Коротко для человека»: симптом, причина,
что исправить и как наблюдать результат. Затем доказательства причины и точные шаги проверки.
Прочитай воспроизведение, карту, правила продукта и «Как принято у нас».
Объём не сужается; «уже есть в коде» не закрывает требование. Свяжи выводы с критериями.
Недостаточное воспроизведение — failed owner plan; недоступная среда или решение — человек.
Done только при доказанной причине и самодостаточном задании BUILD.
