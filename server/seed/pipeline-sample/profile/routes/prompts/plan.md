# План

Начни документ artifacts.plan первым разделом «Коротко для человека» до 20 строк:
что не так, что получится, как проверить, что потребуется от человека.
Затем открытые решения, доказательства, критика, пошаговый TDD-план для модели слабее:
точные файлы и границы, команды RED/GREEN, исходные барьеры, готово и не трогать.
Сверь каждый шаг с правилами продукта и «Как принято у нас», свяжи с критерием.
Объём не сужается: открытый вопрос решает человек на воротах, не автор за него.
Внутренняя критика не заменяет независимый SKEPTIC и утверждение плана человеком.
Сохрани план, критерий → изменение → проверка в artifacts.report; заверши done только
при полностью определённом задании. Противоречие или нужное решение: failed owner human/plan.
